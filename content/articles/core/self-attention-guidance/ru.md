# Self-Attention Guidance: размытие областей по карте внимания

## Что делает нода

`SelfAttentionGuidance` клонирует `MODEL` и ставит два связанных patch. Первый заменяет `attn1` в `middle`-блоке `0`, transformer index `0`: attention по-прежнему вычисляется полностью, но функция дополнительно сохраняет матрицу весов безусловной ветви. Второй patch работает после CFG и использует эту матрицу для построения маски.

Маска выделяет токены, сумма внимания к которым выше жёстко заданного порога `1.0`. Она приводится к пропорциям latent, увеличивается до его пространственного размера и смешивает исходный unconditional-прогноз с его Gaussian-размытой версией. Ядро размытия всегда `9 × 9`, а ширина задаётся `blur_sigma`.

Затем нода возвращает размытому latent исходный шум, делает дополнительный unconditional-прогон модели и добавляет поправку:

```text
degraded_noised = degraded + input − unconditional_prediction
result = cfg_result + scale × (degraded − repeated_unconditional)
```

Так реализация приближает идею Self-Attention Guidance: специально портит области, на которые модель сама обращает внимание, и направляет sampling в сторону, противоположную этому ухудшению. Веса checkpoint не меняются; на выходе получается пропатченная копия модели.

## Когда использовать и когда не использовать

SAG можно исследовать на 4D image latent, когда хочется усилить структуру без отдельного классификатора. Работайте через A/B-сравнение: один seed, один prompt, тот же sampler и schedule, сначала граф без SAG, затем нода с небольшим scale. Результат зависит от архитектуры и от того, насколько осмысленна карта attention выбранного middle-блока.

Нода помечена `experimental`. В исходнике прямо записано ограничение: при chunked batches сохраняется attention только одного UNet-вызова, поэтому большие или разбитые batch могут обрабатываться неверно. Код `create_blur_map` распаковывает latent как четыре измерения `B, C, H, W`; считать эту реализацию готовой для 5D video latent нельзя.

Не используйте `scale = 0` как способ полностью выключить ноду. В отличие от PAG, SAG при нулевом scale всё равно захватывает attention, строит degraded latent и делает дополнительный unconditional model call; только конечная поправка умножается на ноль. Для честного baseline обойдите patch или подайте исходную модель напрямую.

`blur_sigma = 0` формально разрешён runtime-схемой, но exact-source probe получил нечисловые значения: формула Gaussian kernel делит координаты на sigma, а затем нормирует неопределённую плотность. Оставляйте sigma строго больше нуля. В официальных 512 workflow JSON версии 0.1.42 SAG не найден, поэтому готового официального диапазона настроек нет.

## Короткий рецепт подключения

1. Подайте совместимый image `MODEL` в `SelfAttentionGuidance`.
2. Для первого опыта оставьте `scale = 0.5` и `blur_sigma = 2.0` — это runtime defaults, не универсальный quality preset.
3. Передайте выходной `MODEL` в ваш обычный CFG sampling path.
4. Используйте ненулевой CFG с обеими ветвями; нода сама отключает оптимизацию CFG=1, чтобы безусловный проход и его attention были доступны.
5. Сохраните baseline без SAG при том же seed.
6. Меняйте сначала `scale`, затем `blur_sigma`, не оба сразу.

Fragment «SAG: source-derived runtime defaults» содержит только patch-ноду с внешним `MODEL`. Он воспроизводит схему ComfyUI 0.32.0, но не притворяется готовым workflow: официальный wheel 0.1.42 не содержит ни одной точной SAG-ноды, а генерация изображения этим fragment не выполнялась.

## Входы, выходы и параметры

`model` — обязательный `MODEL`. Метод `execute` клонирует его, регистрирует post-CFG hook с `disable_cfg1_optimization=True` и replacement одного self-attention участка.

`scale` — `FLOAT`, default `0.5`, минимум `−2.0`, максимум `5.0`, шаг `0.01`. Он умножает разность `degraded − repeated_unconditional`. Положительные значения направляют результат от повторного прогноза по размытому входу; отрицательные разворачивают поправку. Ноль не экономит дополнительный forward.

`blur_sigma` — advanced `FLOAT`, default `2.0`, минимум `0.0`, максимум `10.0`, шаг `0.1`. Параметр определяет sigma separable Gaussian kernel размером `9 × 9`. Чем он выше, тем шире размытие внутри выбранной attention-маски. Нулевое значение интерфейс принимает, но pinned формула даёт NaN; это проверенный граничный случай, а не рекомендуемая настройка.

Выход — один `MODEL`. Точное системное имя — `SelfAttentionGuidance`, display name — `Self-Attention Guidance`, модуль — `comfy_extras.nodes_sag`, категория — `experimental`. Runtime не задаёт alias.

## Типовые связки

Базовая цепочка: `MODEL → SelfAttentionGuidance → CFGGuider`. Если scheduler зависит от model sampling object, используйте тот же выход SAG и там. В `SamplerCustomAdvanced` соедините этот `GUIDER` с sampler, sigmas, noise и image latent.

Нода рассчитана на sampling, где присутствует unconditional ветвь. Attention replacement смотрит на `cond_or_uncond`; если там есть метка `1`, он сохраняет соответствующий срез матрицы внимания. Post-CFG hook затем повторно вызывает модель именно с unconditional conditioning.

`PerturbedAttentionGuidance` близок по теме, но устроен иначе: он заменяет self-attention передачей `value` и повторяет conditional-ветвь. SAG сохраняет настоящие attention scores, размывает выбранные области и повторяет unconditional-ветвь. Ставить оба patch подряд можно только как отдельный эксперимент с явно зафиксированным порядком hook; готовой официальной топологии для такой комбинации нет.

## Практический пример

Exact-source probe взял latent `1 × 1 × 8 × 8` и синтетическую attention-матрицу из четырёх токенов, где все запросы указывали на первый ключ. Порог `> 1` выбрал одну область. После увеличения маски и Gaussian blur верхняя выбранная часть изменилась, а нижний правый угол, не попавший в маску, остался побитово прежним.

Тот же probe исполнил ноду с `scale = 0`. Attention был записан для группы `[unconditional, conditional]`, post-CFG result совпал с исходным CFG-тензором, но счётчик зафиксировал один дополнительный unconditional-вызов. Для spatial-размера `4 × 8` hook сразу вернул исходный результат, потому что минимальная ось равна четырём.

Отдельная проверка Gaussian helper дала конечный тензор при `blur_sigma = 2` и NaN при `blur_sigma = 0`. Это model-free тест точной математики; он не показывает, станет ли конкретное изображение лучше. Для визуальной проверки выбирайте кадр с крупным объектом и текстурным фоном, сохраняйте baseline и оценивайте структуру, детали вне маски, артефакты размытия и время шага.

## Частые ошибки и способы проверки

**`scale = 0`, а генерация всё равно медленная.** Это поведение исходника: ноль применяется после построения degraded latent и повторного model call. Исключите SAG из model path и сравните снова.

**Появились NaN или чёрный результат.** Первым делом проверьте `blur_sigma`. Значение `0` небезопасно, хотя входит в runtime range. Затем убедитесь, что latent четырёхмерный и обе пространственные оси больше четырёх.

**Batch даёт несогласованные кадры.** Уберите chunking и временно установите batch size `1`. Исходный TODO предупреждает, что сохраняется attention только одного UNet-вызова; это известное ограничение, а не случайная ошибка интерфейса.

**Видео падает при построении blur map.** Helper ожидает ровно `B, C, H, W`. Не переносите image-рецепт на video latent без отдельной реализации и проверки формы.

**Эффект слишком сильный или меняет не те области.** Верните defaults, зафиксируйте seed и снижайте scale. Маска строится из конкретного `middle/0/0` attention и порога `1.0`, который нельзя настроить из UI.

## Производительность и внутреннее поведение

При обычном проходе replacement вычисляет attention вручную, чтобы получить не только output, но и softmax-матрицу `sim`. При запросе fp32 attention similarity `q` и `k` приводятся к float32, что уменьшает риск переполнения, но повышает расход памяти. Матрица attention квадратична по числу токенов выбранного слоя.

Для безусловного среза код усредняет головы, суммирует ось запросов, сравнивает результат с порогом `1.0`, подбирает факторизацию числа токенов под пропорции latent и масштабирует маску до `H × W`. Gaussian blur реализован двумя одномерными ядрами, собранными в depthwise `conv2d`, с reflection padding шириной четыре.

После этого выполняется дополнительный unconditional forward на каждом шаге, если spatial-размер не попал под ранний bypass. Даже `scale = 0` эту работу не отменяет. `disable_cfg1_optimization=True` также не даёт sampling убрать безусловную ветвь при CFG=1.

Состояние `attn_scores` хранится в closure модели и перезаписывается последним подходящим attention-вызовом. Именно поэтому chunked или необычно сгруппированные batch требуют осторожности.

## Совместимость, изменения и устаревание

Материал проверен по ComfyUI 0.32.0, source commit `c2bcbecd…`, frontend 1.48.7 и pinned `/object_info`. Runtime ставит `experimental = true`; `deprecated`, `dev_only` и `api_node` равны `false`. В Node Replacement API версии 0.32.0 записи для `SelfAttentionGuidance` нет.

Код зависит от структуры middle attention, формы `cond_or_uncond`, 4D latent и поведения model patch hooks. Обновление attention backend, batching или архитектуры модели способно изменить результат даже при неизменной пользовательской схеме. После обновления ComfyUI проверяйте schema fingerprint и исходник.

Embedded docs 0.5.9 честно отмечают экспериментальный статус и chunked batch limitation, но не предупреждают о `blur_sigma = 0`, стоимости при `scale = 0` и 4D-распаковке. Эти пункты получены из pinned реализации и exact-source probe. Fragment остаётся draft до визуального model run и человеческой проверки.

## Связанные ноды и источники

`PerturbedAttentionGuidance` тоже использует self-attention для дополнительного guidance, но заменяет внимание и повторяет conditional-ветвь. `CFGGuider` предоставляет conditional/unconditional группы, от которых зависит SAG. `SamplerCustomAdvanced` делает весь sampling contract явным и удобен для контролируемого сравнения.

Технические детали сверены с `comfy_extras/nodes_sag.py`, embedded docs 0.5.9 и статьёй [Improving Sample Quality of Diffusion Models Using Self-Attention Guidance](https://arxiv.org/abs/2210.00939). Полный recursive census workflow wheel 0.1.42 дал ноль точных экземпляров. Probe проверил attention helper, маску, Gaussian blur, ранний bypass и дополнительный вызов без загрузки весов; оценка изображений и человеческое утверждение ещё ожидаются.
