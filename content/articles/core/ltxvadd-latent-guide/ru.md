# LTXV Add Latent Guide: опора из уже закодированного фрагмента

Прикрепляет готовый video-latent как guide без обязательного промежуточного VAE decode/encode. Удобна, когда референс уже получен на предыдущем этапе генерации.

## Как пользоваться

guiding_latent и целевой latent должны быть 5D. latent_idx измеряется в latent-кадрах, не в кадрах видео; отрицательные значения ставят guide до начала, а не отсчитывают от конца. Пространственный размер guide должен делить целевой по обеим осям с одинаковым целым коэффициентом. strength ограничен 0–1; attention_mask задаёт региональное влияние.

## Пример подключения

Подайте закодированный короткий фрагмент в guiding_latent и установите latent_idx = 0 для начала ролика. Соедините обновлённые positive, negative и latent с sampler. Если guide вдвое меньше по обеим сторонам, он размещается на разреженной сетке целевого кадра вместо простого растяжения тензора.

## Ограничения и частые ошибки

Guide не должен выходить за конец целевого latent. Разные коэффициенты ширины и высоты вызывают ошибку. Отрицательный индекс здесь имеет иной смысл, чем frame_idx у MiniMax H3. Не усиливайте strength выше 1 обходом UI: отрицательная маска у разреженного guide имеет специальное назначение.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `positive` | `CONDITIONING` | да | соединение / значение без фиксированного default |
| `negative` | `CONDITIONING` | да | соединение / значение без фиксированного default |
| `vae` | `VAE` | да | соединение / значение без фиксированного default |
| `latent` | `LATENT` | да | соединение / значение без фиксированного default |
| `guiding_latent` | `LATENT` | да | соединение / значение без фиксированного default |
| `latent_idx` | `INT` | да | по умолчанию: 0; минимум: -9999; максимум: 9999 |
| `strength` | `FLOAT` | да | по умолчанию: 1.0; минимум: 0.0; максимум: 1.0; шаг: 0.01 |
| `attention_mask` | `MASK` | нет | соединение / значение без фиксированного default |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `positive` | `CONDITIONING` | нет |
| `negative` | `CONDITIONING` | нет |
| `latent` | `LATENT` | нет |
