# ComfyNumberConvert

## Назначение

`ComfyNumberConvert` принимает число, логическое значение или числовую строку и выдаёт варианты `FLOAT` и `INT`.

## Место в графе

Используйте ноду между несовпадающими числовыми портами или после текстового источника. Официальный пример подаёт строку `"1"` и показывает оба результата через `PreviewAny`.

## Вход

`value` принимает `INT`, `FLOAT`, `STRING` или `BOOLEAN`. Пробелы по краям строки удаляются. Пустая строка и неподдерживаемый тип отклоняются.

## Выходы

`FLOAT` содержит число с плавающей точкой, `INT` — целое. Для `true` выходы равны 1 и 1. Для `false` — 0 и 0.

## Правила преобразования

Целое число сохраняется в `INT` и переводится в `float`. Дробное число преобразуется через Python `int`, то есть дробная часть отбрасывается к нулю. Строка сначала разбирается как `float`; для целого выхода нода пробует прямой `int`, затем отбрасывает дробную часть разобранного значения.

## Недопустимые числа

Строки и значения `NaN`, `Infinity` и `-Infinity` запрещены. Проверка `math.isfinite` выполняется и для готового `FLOAT`, и после разбора строки.

## Проверенный пример

В `basic_datatype_conversion` строка `"1"` подключена к `ComfyNumberConvert`. Выходы `1.0` и `1` идут в отдельные `PreviewAny`; целый результат также используется в математическом выражении.

## Частые ошибки

Строка `"1.5"` даёт `INT=1`, а не округление до 2. Строки с запятой вроде `"1,5"` Python не разбирает. Для округления сначала примените отдельную математическую операцию.

## Ограничения и производительность

Нода преобразует одно значение и не создаёт пакеты. Большое целое при переводе в `FLOAT` может потерять младшие разряды из-за точности IEEE 754.
