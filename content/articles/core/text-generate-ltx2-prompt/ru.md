# LTX: подготовка подробного видеопромпта

Расширяет исходный запрос в описание сцены для LTX с помощью совместимой Gemma. Генерирует текст, а не видео. Выход `generated_text` передайте текстовому кодировщику LTX; второй выход `thinking` предназначен для просмотра рассуждений.

## Как пользоваться

Подайте языковую модель на `clip`, описание сцены на `prompt`. Для генерации по первому кадру подключите `image`; без него выбирается инструкция для генерации по тексту. Наследуемые входы `audio` и `video` сами по себе этот выбор не меняют.

Если имя токенизатора содержит `gemma4`, используется формат диалога и инструкция для LTX 2.4; иначе — вариант Gemma 3/LTX 2.0. Неподходящий кодировщик не становится совместимым только из-за совпадения типа порта `CLIP`.

## Системная инструкция и параметры

Непустой `system_prompt` заменяет встроенную инструкцию для выбранной ветки. Нода сама собирает специализированный диалог и затем передаёт его базовой `TextGenerate`. Поэтому не следует переносить на неё правило об игнорировании `system_prompt` из обычной TextGenerate: здесь вход используется до вызова базовой ноды.

`max_length`, `sampling_mode`, `thinking` и `mtp` работают через TextGenerate. Встроенная инструкция просит описывать видимые действия, движение и звук; язык и форма ответа зависят от шаблона и модели. Если основной ответ пуст, нода возвращает исходный `prompt`.

## Пример и ограничения

Для ролика по изображению подключите первый кадр и опишите нужное движение камеры и персонажа. Просмотрите полученный текст: модель может добавить нежелательные детали. Подробная системная инструкция занимает часть контекста; слишком короткий лимит способен оборвать ответ. Разделение рассуждений использует маркеры базовой TextGenerate, а не произвольные форматы любой языковой модели.

## Входы и настройки

Снимок ComfyUI 0.38.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `clip` | `CLIP` | да | соединение / значение без фиксированного default |
| `prompt` | `STRING` | да | по умолчанию:  |
| `max_length` | `INT` | да | по умолчанию: 512; минимум: 1; максимум: 32768 |
| `sampling_mode` | `COMFY_DYNAMICCOMBO_V3` | да | режимы: on, off |
| `sampling_mode=on → temperature` | `FLOAT` | да | по умолчанию: 0.7; минимум: 0.01; максимум: 2.0; шаг: 1e-06 |
| `sampling_mode=on → top_k` | `INT` | да | по умолчанию: 64; минимум: 0; максимум: 1000 |
| `sampling_mode=on → top_p` | `FLOAT` | да | по умолчанию: 0.95; минимум: 0.0; максимум: 1.0; шаг: 0.01 |
| `sampling_mode=on → min_p` | `FLOAT` | да | по умолчанию: 0.05; минимум: 0.0; максимум: 1.0; шаг: 0.01 |
| `sampling_mode=on → repetition_penalty` | `FLOAT` | да | по умолчанию: 1.05; минимум: 0.0; максимум: 5.0; шаг: 0.01 |
| `sampling_mode=on → seed` | `INT` | да | по умолчанию: 0; минимум: 0; максимум: 18446744073709551615 |
| `sampling_mode=on → presence_penalty` | `FLOAT` | нет | по умолчанию: 0.0; минимум: 0.0; максимум: 5.0; шаг: 0.01 |
| `image` | `IMAGE` | нет | соединение / значение без фиксированного default |
| `video` | `IMAGE` | нет | соединение / значение без фиксированного default |
| `audio` | `AUDIO` | нет | соединение / значение без фиксированного default |
| `thinking` | `BOOLEAN` | нет | по умолчанию: false |
| `use_default_template` | `BOOLEAN` | нет | по умолчанию: true |
| `mtp` | `COMBO` | нет | по умолчанию: auto; варианты: auto, off, 2, 3, 4, 5 |
| `system_prompt` | `STRING` | нет | соединение / значение без фиксированного default |

## Источники и границы проверки

[Реализация ComfyUI 0.38.0](https://github.com/Comfy-Org/ComfyUI/blob/6b747c0428c343e1417219641db93a4fb7cb69ae/comfy_extras/nodes_textgen.py#L224-L270). Входы и выходы сверены с чистой установкой от 3 октября. Полная генерация с весами не выполнялась; человеческое утверждение ещё нужно.

## Официальные примеры подключения

`template_image_speech_to_video.json`, подграф «Video Generation (LTX-2.3)»: входы от `LoraLoader`, `PrimitiveStringMultiline`, `ResizeImageMaskNode`; выходы к `CLIPTextEncode`, `PreviewAny`.

`template_ltx2_3_ic_lora_ingredients.json`, подграф «LTX-2.3 IC-LoRA Video Generation»: входы от `LoraLoader`, `SubgraphInput`; выходы к `ComfySwitchNode`.

Шаблоны из [официального пакета 0.1.96](https://pypi.org/project/comfyui-workflow-templates-json/0.1.96/), закреплённого ComfyUI 0.38.0. Это сохранённые соединения, не отчёт о запуске. Внешние входы и переключатели подграфа могут менять значения и путь выполнения. `SubgraphInput` и `SubgraphOutput` обозначают границы подграфа.
