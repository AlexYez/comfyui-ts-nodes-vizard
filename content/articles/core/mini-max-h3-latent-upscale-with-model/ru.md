# Увеличение латента H3 моделью

Увеличивает пространственную сетку видеочасти H3 через LATENT_UPSCALE_MODEL. Вложенная аудиочасть передаётся без изменений; временная длина видео не увеличивается.

## Подключение и пример

Подайте модель латентного увеличения из совместимого загрузчика и готовые samples. width и height задают выходные пиксельные размеры, внутри делятся на 16. Результат затем можно уточнить подходящим сэмплированием или декодировать. Если латент уже имеет нужный размер, возвращается исходная структура.

## Ограничения

При изменении размера поле noise_mask удаляется: старую пространственную маску нельзя считать согласованной. Нода не выполняет диффузионное уточнение и не заменяет весь конвейер TS H3 Regenerate. Больший выход требует памяти и для апскейлера, и для последующего декодирования.

## Входы и настройки

Снимок ComfyUI 0.45.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `model` | `LATENT_UPSCALE_MODEL` | да | соединение / значение без фиксированного default |
| `samples` | `LATENT` | да | соединение / значение без фиксированного default |
| `width` | `INT` | да | по умолчанию: 2560; минимум: 32; максимум: 16384; шаг: 32 |
| `height` | `INT` | да | по умолчанию: 1440; минимум: 32; максимум: 16384; шаг: 32 |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `LATENT` | `LATENT` | нет |
