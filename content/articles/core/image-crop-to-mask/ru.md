# Image Crop To Mask: подготовка объекта по маске

Вырезает область объекта, заменяет фон и приводит результат к заданному размеру. Подходит для подготовки изображения к 3D-генерации, когда важны силуэт и масштаб объекта.

## Как пользоваться

width и height задают итоговый размер, pad_factor — поле вокруг объекта, grow_mask — расширение или сжатие маски, background — цвет фона. Одна маска может применяться ко всему batch; остальные размеры batch должны согласовываться. Внутри есть эвристика исправления инвертированной маски и поиск уверенного foreground.

## Пример подключения

Подайте изображение предмета и аккуратную маску, оставьте небольшое поле вокруг силуэта и посмотрите результат до Trellis/Pixal3D conditioning. Проверьте тонкие ножки, ручки и края: слишком агрессивное сжатие маски отрежет их ещё до генерации.

## Ограничения и частые ошибки

Нода возвращает только IMAGE, без плана обратной вставки и обновлённой MASK. Пустая или неоднозначная маска может быть инвертирована эвристикой; это не гарантированный сигнал «ничего не обрабатывать». Для согласованных многовидовых изображений независимый crop может нарушить масштаб между ракурсами.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `images` | `IMAGE` | да | соединение / значение без фиксированного default |
| `masks` | `MASK` | да | соединение / значение без фиксированного default |
| `width` | `INT` | да | по умолчанию: 1024; минимум: 64; максимум: 4096; шаг: 8 |
| `height` | `INT` | да | по умолчанию: 1024; минимум: 64; максимум: 4096; шаг: 8 |
| `pad_factor` | `FLOAT` | да | по умолчанию: 1.0; минимум: 1.0; максимум: 2.0; шаг: 0.01 |
| `grow_mask` | `INT` | да | по умолчанию: 0; минимум: -32; максимум: 32; шаг: 1 |
| `background` | `COLOR` | да | по умолчанию: #000000 |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `images` | `IMAGE` | нет |
