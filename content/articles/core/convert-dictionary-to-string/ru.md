# Convert Dictionary to String

## 1. Назначение

Нода сериализует `DICT` в JSON-строку через `json.dumps`.

## 2. Место в графе

Используйте её перед текстовым API, `SaveText` или просмотром структурированного результата.

## 3. Входы

`dictionary` принимает `DICT`. `indent` от 0 до 8, default 2, задаёт число пробелов на уровень.

## 4. Выход

Выход имеет тип `STRING` и содержит допустимый JSON, если все значения словаря сериализуемы.

## 5. Форматирование

При `indent=0` код передаёт `None`, поэтому JSON остаётся одной строкой, но стандартные пробелы после разделителей сохраняются. Положительный indent включает многострочный pretty print.

## 6. Unicode и типы

`ensure_ascii=false` сохраняет кириллицу и emoji без `\u`-экранирования. Несериализуемый объект, например произвольный Python instance или tensor, вызывает `TypeError`.

## 7. Проверенный пример

Рецепт принимает внешний словарь и использует indent 2. Probe проверяет Unicode, вложенный список, compact mode и ошибку несериализуемого значения. Официальных случаев ноды нет.

## 8. Диагностика

Если возникает `TypeError`, найдите значение вне набора JSON: объект, tensor, bytes или нестандартный ключ. Нода не преобразует такие значения автоматически.

## 9. Ограничения и производительность

Весь результат создаётся в памяти. Большой indent увеличивает размер. Порядок ключей следует текущему порядку Python-словаря; `sort_keys` не включён.

## 10. Совместимость и источники

Контракт сверён с ComfyUI 0.32.0/frontend 1.48.7, `json.dumps`, embedded docs 0.5.9 и workflow-пакетом 0.1.42. Человеческое утверждение ожидается.
