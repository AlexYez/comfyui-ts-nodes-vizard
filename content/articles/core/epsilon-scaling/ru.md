# Epsilon Scaling: равномерное масштабирование предсказанного шума

## Что делает нода

`Epsilon Scaling` клонирует `MODEL` и добавляет функцию, которая выполняется после расчёта CFG. Она берёт текущий noisy input `x` и полученный `denoised`, рассматривает их разность как предсказанный шум и делит её на постоянный коэффициент:

```text
noise_prediction = x − denoised
scaled_noise_prediction = noise_prediction / scaling_factor
new_denoised = x − scaled_noise_prediction
```

При `scaling_factor = 1` результат точно совпадает с исходным `denoised`. Коэффициент выше единицы уменьшает модуль компонента шума и сдвигает новый denoised ближе к текущему `x`. Коэффициент ниже единицы усиливает компонент и уводит denoised дальше от `x`.

Реализация следует идее epsilon scaling из работы об exposure bias диффузионных моделей. Она использует равномерный schedule: один и тот же коэффициент применяется на всех sampling steps. Нода не знает текущую sigma, не меняет checkpoint и не запускает модель повторно.

## Когда использовать и когда не использовать

Эту ноду имеет смысл проверять как небольшой controlled perturbation sampling, когда есть стабильный baseline и хочется исследовать влияние exposure-bias correction. Default `1.005` очень близок к тождественному значению `1`, поэтому сравнение требует одинакового seed и полного совпадения остальных настроек.

Не воспринимайте коэффициент выше единицы как гарантированное улучшение. Направление изменения тензора однозначно, а визуальный эффект зависит от параметризации модели, sampler, schedule, числа шагов и других hooks. Сравнивайте детали, соответствие prompt и артефакты, а не только субъективную резкость.

Для точного baseline используйте `scaling_factor = 1`, а не удаляйте ноду между прогонами: так порядок остальных model patches останется неизменным. Если Epsilon Scaling стоит рядом с PAG, SAG, APG или другим post/pre-CFG patch, обязательно фиксируйте порядок, потому что один hook может получать результат другого.

В официальном workflow wheel 0.1.42 точный NodeId `Epsilon Scaling` не встретился ни разу среди 512 JSON и recursive subgraphs. Значение `1.005` — runtime default ComfyUI 0.32.0, а не подтверждённый официальный preset для всех моделей.

## Короткий рецепт подключения

1. Подайте исходный `MODEL` в `Epsilon Scaling`.
2. Сначала задайте `scaling_factor = 1.0` и убедитесь, что граф воспроизводит baseline.
3. Затем верните runtime default `1.005`, сохранив seed, prompt, sampler, sigmas, CFG и latent.
4. Передайте выходной `MODEL` в тот же guider/sampler path.
5. Если исследуете диапазон, меняйте коэффициент малыми шагами и сохраняйте результаты рядом.
6. Не вводите `0` через API или изменённый workflow: UI ограничивает параметр диапазоном `0.5…1.5`.

Fragment «Epsilon Scaling: source-derived runtime default» содержит одну patch-ноду с `scaling_factor = 1.005` и внешний `MODEL`. Полного workflow нет: официальный пакет 0.1.42 не даёт реального кейса, а визуальный model run не выполнялся.

## Входы, выходы и параметры

`model` — обязательный `MODEL`. Исходный model patcher не меняется: нода вызывает `clone()` и регистрирует post-CFG function на копии.

`scaling_factor` — advanced `FLOAT` с default `1.005`, минимумом `0.5`, максимумом `1.5` и шагом `0.001`. Widget отображается как обычное число. Формула использует деление, поэтому эффект несимметричен вокруг единицы: например, `1.25` оставляет `80%` исходного noise component, а `0.5` удваивает его.

Если вызвать Python-метод напрямую с нулём, source заменит коэффициент на `1e−9`, чтобы избежать деления на ноль. Такой вызов создаёт огромный по модулю результат и не относится к поддерживаемому UI-диапазону. Защитная ветвь не превращает ноль в режим bypass.

Выход — один пропатченный `MODEL`. Точный runtime `classType` содержит пробел: `Epsilon Scaling`. Python-класс называется `EpsilonScaling`, но это не alias NodeId. Модуль — `comfy_extras.nodes_eps`, категория — `model/patch/unet`; display name и runtime aliases не заданы.

## Типовые связки

Обычная цепочка: `MODEL → Epsilon Scaling → CFGGuider`, затем `GUIDER` входит в `SamplerCustomAdvanced` вместе с sampler, sigmas, noise и latent. Нода также подходит к стандартному `KSampler`-пути через model input, если выбранная модель использует обычный post-CFG contract.

При `scaling_factor = 1` hook алгебраически тождественен, поэтому это удобная контрольная точка для проверки подключения. Затем можно сравнить `1.005`, значение выше единицы и значение ниже единицы на одном seed.

`APG` связан с guidance, но работает до финального CFG-смешивания и преобразует conditional/unconditional predictions. Epsilon Scaling работает после CFG с уже готовым denoised. При цепочке нескольких patch nodes их порядок регистрации становится частью эксперимента; перестановку нельзя считать косметической.

## Практический пример

Exact-source probe использовал `x = [4, −2]` и `denoised = [1, 2]`. При коэффициенте `1` функция вернула `[1, 2]`. При `1.25` разность `[3, −4]` разделилась на `1.25`, а новый denoised стал приблизительно `[1.6, 1.2]`. При `0.5` разность удвоилась и результат стал `[−2, 6]`.

Probe также вызвал защитную ветвь с нулём: после замены на `1e−9` значения остались конечными в float32, но стали огромными. Это подтверждает только отсутствие деления на ноль, не пригодность такого параметра.

Для визуального опыта сначала сохраните кадр с `1.0`, затем с `1.005`. Если разница незаметна, не увеличивайте коэффициент резко: сделайте небольшую серию и проверяйте одинаковый seed. Смотрите, не меняет ли нода мелкие текстуры или соответствие prompt вместе с предполагаемым снижением exposure bias.

## Частые ошибки и способы проверки

**Нода не даёт видимого эффекта.** Проверьте, что sampling использует её выход. Default отличается от единицы всего на `0.005`; при конкретной модели изменение может быть едва заметным. Сравнивайте сохранённые результаты, а не память о предыдущем кадре.

**Коэффициент `1` изменил результат.** Формула тождественна при единице. Ищите другой источник: порядок model patches, изменившийся seed, cache invalidation, sampler, sigmas или иной model input.

**Значение выше единицы назвали «добавлением шума».** В коде происходит обратное: `x − denoised` делится на factor. При factor > 1 его модуль уменьшается, хотя новый denoised действительно оказывается ближе к noisy input `x`. Эти два описания относятся к разным величинам.

**После перестановки hooks кадр изменился.** Post-CFG functions образуют последовательность. Зафиксируйте порядок Epsilon Scaling и других patch nodes, затем переставляйте только один элемент за раз.

**В workflow указан NodeId `EpsilonScaling` без пробела.** Exact runtime key — `Epsilon Scaling`. Каталог embedded docs содержит и папку без пробела, но это дубликат документации, а не подтверждённый alias или replacement.

## Производительность и внутреннее поведение

На каждом sampling step hook выполняет одно вычитание, деление и ещё одно вычитание над denoised tensor. Полного model forward, attention matrix или дополнительного conditioning batch здесь нет. По сравнению с диффузионной моделью вычислительная цена мала, но создаются временные тензоры того же размера.

Функция не читает `sigma`, step index, conditioning или model architecture. Поэтому schedule действительно uniform: коэффициент постоянен на всём ходе sampling. Параметр захватывается closure при создании patch.

Клон модели защищает исходный path от изменения на месте. Сам post-CFG hook получает результат текущей цепочки и возвращает новый tensor. Если раньше зарегистрирован другой hook, Epsilon Scaling преобразует уже изменённый denoised; если порядок обратный, другой hook увидит результат scaling.

## Совместимость, изменения и устаревание

Материал проверен по ComfyUI 0.32.0, source commit `c2bcbecd…`, frontend 1.48.7 и pinned `/object_info`. Runtime-флаги `experimental`, `deprecated`, `dev_only` и `api_node` равны `false`. В Node Replacement API записи для `Epsilon Scaling` нет.

Системное имя с пробелом критично для resolver. Embedded docs 0.5.9 содержит две директории — `Epsilon Scaling` и `EpsilonScaling`; статья привязана к первой, потому что она совпадает с exact NodeId. Наличие второй директории не даёт основания публиковать alias.

После обновления ComfyUI сверяйте schema fingerprint, формулу и hook registration. В том же `nodes_eps.py` есть отдельный `TemporalScoreRescaling`, но это другая runtime-нода с зависимостью от sigma; она не является заменой Epsilon Scaling без записи replacement API.

## Связанные ноды и источники

`APG` меняет guidance до финального CFG, `CFGGuider` создаёт denoised, который получает post-CFG hook, а `SamplerCustomAdvanced` позволяет собрать и воспроизвести весь sampling path. Эти связи описывают место ноды в графе, но не объявляют алгоритмы взаимозаменяемыми.

Формула и runtime-контракт сверены с `comfy_extras/nodes_eps.py`, exact embedded-docs route 0.5.9 и работой [Elucidating the Exposure Bias in Diffusion Models](https://arxiv.org/abs/2308.15321). Exhaustive census workflow wheel 0.1.42 дал ноль точных экземпляров. Tensor-probe подтвердил identity при factor=1, оба направления scaling и zero guard; генерация изображений и человеческое утверждение ещё не выполнены.
