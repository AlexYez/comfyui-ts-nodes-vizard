# MiniMax H3: контекстные окна

Добавляет к копии MODEL обработку временными окнами при сэмплировании H3. Начала окон согласованы с 17-кадровыми частями модели, чтобы не нарушать соответствие видео и аудио.

## Подключение и пример

Передайте модель через ноду в сэмплер. context_length и context_overlap заданы в реальных кадрах на сетке 17×n+5; значения по умолчанию — 124 и 39. Внутри они переводятся в латентные позиции; перекрытие ограничивается длиной окна. fuse_method управляет объединением, freenoise — перемешиванием шума. Начните с короткого контрольного ролика и сравните стыки.

## Ограничения

Это изменение расчёта модели, не нарезка готового файла и не увеличение длины входного латента. Окна не гарантируют неизменности лица, движения или звуковой синхронизации на любом материале. Снижение рабочего контекста не отменяет памяти полного входа и результата.

## Входы и настройки

Снимок ComfyUI 0.45.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `model` | `MODEL` | да | соединение / значение без фиксированного default |
| `context_length` | `INT` | да | по умолчанию: 124; минимум: 22; максимум: 16384; шаг: 17 |
| `context_overlap` | `INT` | да | по умолчанию: 39; минимум: 5; шаг: 17 |
| `fuse_method` | `COMBO` | да | по умолчанию: pyramid; варианты: pyramid, relative, flat, overlap-linear |
| `freenoise` | `BOOLEAN` | да | по умолчанию: true |
| `split_conds_to_windows` | `BOOLEAN` | да | по умолчанию: false |

## Выходы
