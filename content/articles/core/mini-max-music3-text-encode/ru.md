# MiniMax Music 3 Text Encode: описание и слова песни

Создаёт музыкальное conditioning из описания звучания и текста песни. Внутри работает авторегрессионная часть MiniMax Music 3; на выходе ещё не готовая звуковая дорожка.

## Как пользоваться

caption описывает музыку, lyrics содержит слова. seed задаёт случайность авторегрессионного этапа, max_duration ограничивает его длину. cfg_scale и top_k управляют этим этапом, а не настройками следующего diffusion sampler. clip должен быть совместимым музыкальным энкодером. Выход seconds сообщает фактическую длительность полученной последовательности.

## Пример подключения

Подайте caption с жанром и инструментами, а lyrics — с куплетом. Conditioning направьте в музыкальный sampler, seconds подключите к EmptyMiniMaxMusic3LatentAudio. Затем декодируйте результат соответствующим аудио-VAE. Такое соединение согласует длину latent с реально подготовленным conditioning.

## Ограничения и частые ошибки

Не подменяйте seconds вручную максимальной длительностью: авторегрессионная генерация может завершиться раньше. Обычный CLIP для изображений здесь не подходит. Нода не сохраняет WAV и не заменяет музыкальную модель, sampler и декодер. Сначала проверьте короткий фрагмент, прежде чем заказывать длинную песню.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `clip` | `CLIP` | да | соединение / значение без фиксированного default |
| `caption` | `STRING` | да | соединение / значение без фиксированного default |
| `lyrics` | `STRING` | да | соединение / значение без фиксированного default |
| `seed` | `INT` | да | по умолчанию: 0; минимум: 0; максимум: 18446744073709551615 |
| `max_duration` | `FLOAT` | да | по умолчанию: 120.0; минимум: 0.04; максимум: 360.0; шаг: 0.04 |
| `cfg_scale` | `FLOAT` | да | по умолчанию: 1.5; минимум: 0.0; максимум: 100.0; шаг: 0.1 |
| `top_k` | `INT` | да | по умолчанию: 50; минимум: 1; максимум: 16384 |

## Проверенные источники и кейсы

В музыкальном шаблоне seconds напрямую управляет пустым latent, а ConditioningZeroOut готовит отрицательную ветку для KSampler. Так длительность не приходится дублировать вручную.

В официальном шаблоне `audio_minimax_music_3`: Граф: Text to Music (MiniMax Music 3) (root/definitions/subgraphs/0). Входящие связи: `CLIPLoader`, `SeedNode`, `SubgraphInput`. Исходящие связи: `ConditioningZeroOut`, `EmptyMiniMaxMusic3LatentAudio`, `KSampler`. Имя файла: `audio_minimax_music_3.json`, пакет [workflow-templates-json 0.1.92](https://pypi.org/project/comfyui-workflow-templates-json/0.1.92/). SubgraphInput/Output обозначают границы подграфа. Это сохранённые связи; переключатели и внешние входы могут менять путь исполнения и значения виджетов. Полный запуск с весами здесь не выполнялся.
