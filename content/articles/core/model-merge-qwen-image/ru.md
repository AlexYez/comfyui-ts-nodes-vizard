# ModelMergeQwenImage

## Что делает нода

`ModelMergeQwenImage` смешивает две совместимые Qwen Image-модели по именованным частям архитектуры. Коэффициент каждой группы — это доля `model1`: `1` оставляет первую модель, `0` переносит группу из `model2`, `0,5` усредняет веса.

Карта включает `pos_embeds.`, `img_in.`, `txt_norm.`, `txt_in.`, `time_text_embed.`, 60 групп `transformer_blocks.0.`…`transformer_blocks.59.` и `proj_out.`. Эти имена совпадают с модулями закреплённой реализации Qwen Image в ComfyUI 0.32.0.

## Когда она нужна и когда не нужна

Нода подходит для исследования двух checkpoint одной Qwen Image-архитектуры: например, можно смешать один transformer-блок донора с базовой моделью и проверить, сохраняется ли нужное поведение на фиксированном наборе запросов.

Она не предназначена для Krea 2, MageFlow или других моделей, даже если те используют похожие текстовые энкодеры или latent-форматы. Нода не переносит CLIP/VAE и не делает модели совместимыми. Для простого глобального смешивания используйте `ModelMergeSimple`.

## Короткий рецепт подключения

1. Загрузите две версии Qwen Image с одинаковой структурой диффузионной модели.
2. Подключите базовую к `model1`, вторую к `model2`.
3. Оставьте значения по умолчанию `1`.
4. Установите `transformer_blocks.0. = 0,5`.
5. Проверьте полученный `MODEL` в неизменном Qwen Image workflow.

Встроенный fragment содержит только эту ноду и два внешних входа. Он составлен по исходному коду и `/object_info`: прямых официальных workflow с `ModelMergeQwenImage` в пакете 0.1.42 нет.

## Входы и параметры

`model1` клонируется и задаёт основу результата. `model2` предоставляет патчи для совпадающих ключей. Одинаковое название семейства недостаточно: формы соответствующих тензоров и конфигурация блоков должны совпасть.

Числовых коэффициентов 66: пять групп до transformer-последовательности, 60 отдельных блоков и выходная проекция. Все имеют диапазон `0…1`, шаг `0,01`, default `1`. Wizard подмешивает актуальный порядок и ограничения из установленного ComfyUI.

## Выход и место в графе

Результат — `MODEL`, который подключают к guider/sampler или saver. Текстовый энкодер, VAE, conditioning и reference latents нода не меняет. Для корректного теста эти входы должны соответствовать выбранной Qwen Image-модели.

Merge располагают после двух загрузчиков модели. Патчи LoRA, ControlNet-обвязку, attention backend и другие преобразования лучше применять после него одинаковым образом во всех сравниваемых вариантах.

## Как устроено смешивание

Нода наследует `ModelMergeBlocks`. Алгоритм клонирует `model1`, перебирает ключи `diffusion_model.` из `model2` и выбирает для каждого ключа самый длинный подходящий префикс. Вес первой модели равен `ratio`, второй — `1 - ratio`.

Для ключа, не вошедшего в карту, используется первый числовой коэффициент — в штатном порядке `pos_embeds.`. Это означает, что новые или нестандартные параметры не игнорируются автоматически. Перед важным merge полезно сравнить список ключей обеих моделей, а не полагаться только на успешное создание ноды.

## Практический пример

Сначала прогоните вариант со всеми значениями `1`: он служит контрольной копией `model1` для охваченных ключей. Затем измените только `transformer_blocks.0.` на `0,5`. Сравните несколько фиксированных seed, сохраняя prompt, reference images, scheduler и CFG неизменными.

Если нужен диапазон блоков, добавляйте их по одному или небольшими непрерывными группами. Так можно заметить точку, после которой меняются композиция, текстовая точность или стабильность редактирования, и вернуть последний рабочий набор.

## Частые ошибки и проверка

- Коэффициент трактуется как доля `model2`. На деле `0` означает второй вход, `1` — первый.
- Подключены разные варианты архитектуры Qwen-подобных моделей. Проверьте точный model class и shapes.
- Вместе с merge изменены reference image, prompt или seed. Верните одинаковый контрольный набор.
- Выбран неверный блок из-за длинного списка. Сверьте номер в сохранённом workflow JSON.
- Результат создаётся, но sampler падает на shape mismatch. Это признак несовместимых весов, а не повод менять scheduler.

## Ограничения и производительность

Нода не оценивает смысловую совместимость и не гарантирует, что линейная смесь будет полезна. В этой редакционной партии выполнялась точная проверка схемы и выбора префикса без настоящих Qwen Image checkpoint; полный fragment не запускался.

60 блоков дают тонкий контроль, но увеличивают число параметров эксперимента. Клонирование `ModelPatcher` не отменяет стоимости крупных весов при sampling или сохранении. Планируйте тесты короткими сериями с журналом коэффициентов.
