# Trellis2 Texture Stage: подготовка материала по форме

Готовит разреженный latent и conditioning текстурного этапа Trellis2, сохраняя связь с уже полученной формой. Цвет и свойства материала ещё предстоит сгенерировать sampler.

## Как пользоваться

shape_latent должен содержать sampled shape_slat и его координаты. Нода добавляет эти данные к conditioning, выбирает texture_generation и создаёт нулевые samples на той же координатной сетке. Positive и negative выходят уже с метаданными нового этапа.

## Пример подключения

После sampler формы разветвите shape_latent: один выход направьте в VaeDecodeShapeTrellis, другой — сюда. Три выхода этой ноды подключите к текстурному sampler. Его latent декодируйте через VaeDecodeTextureTrellis вместе с SHAPE_SUBDIVIDES из первой ветки.

## Ограничения и частые ошибки

Не подавайте сюда пустую заготовку ShapeStage до сэмплирования: материал должен опираться на полученную форму. Нода не строит UV и не создаёт PNG. Несогласованные форма и текстурный latent приводят к неверному соответствию геометрии и цвета, даже если разъёмы соединяются.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `positive` | `CONDITIONING` | да | соединение / значение без фиксированного default |
| `negative` | `CONDITIONING` | да | соединение / значение без фиксированного default |
| `shape_latent` | `LATENT` | да | соединение / значение без фиксированного default |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `positive` | `CONDITIONING` | нет |
| `negative` | `CONDITIONING` | нет |
| `LATENT` | `LATENT` | нет |
