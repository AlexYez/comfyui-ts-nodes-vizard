# Repeat Latent Batch: повторить весь LATENT-батч

`RepeatLatentBatch` увеличивает batch-размер, копируя входной тензор `samples` заданное число раз. Повторяется весь порядок элементов, а не каждый элемент по отдельности. Нода также меняет `batch_index` и частично обрабатывает `noise_mask`, поэтому её поведение шире обычного tensor repeat.

## 1. Что делает нода

Для входа `[A, B, C]` и `amount = 2` результатом будет `[A, B, C, A, B, C]`. Это два последовательных блока исходного батча. Результат `[A, A, B, B, C, C]` нода не строит.

Копии `samples` сначала совпадают по значениям. Различия могут появиться позже, если sampler назначит им разный начальный шум, conditioning или другие batch-зависимые данные. Само повторение не создаёт новых смысловых вариантов.

## 2. Место в графе

Ноду ставят после LATENT-источника, когда одну подготовленную структуру нужно отправить в более крупный batch: например, проверить несколько шумовых вариантов при одинаковом исходном latent или согласовать число элементов с другой веткой. После неё часто полезно явно задать поведение шума через `LatentBatchSeedBehavior`.

Для уменьшения батча используйте `LatentFromBatch`. Для соединения разных LATENT-источников нужна batch-нода. `RepeatLatentBatch` не умеет добавлять второй вход, менять размер сетки, переставлять элементы или выбирать отдельные позиции.

## 3. Входы

- `samples` — входной `LATENT`. Поле `samples` содержит тензор, первая ось которого считается batch-осью.
- `amount` — число полных повторов. В ComfyUI 0.32.0 допустимы целые значения от `1` до `64`, значение по умолчанию — `1`.

Итоговый batch size равен `B × amount`, где `B` — размер первой оси входного `samples`. `amount = 1` сохраняет число элементов, но реализация всё равно создаёт новый тензор `samples` через `repeat`.

## 4. Выход и перенос метаданных

Выход имеет тип `LATENT`. Новый `samples` физически содержит повторённые данные. Словарь сначала копируется поверхностно, поэтому неизвестные ноде metadata-поля остаются общими объектами со входом и не расширяются автоматически.

Если есть `batch_index`, нода строит новый список для всех блоков. Если поля не было, оно не добавляется. `noise_mask` с batch-размером `1` остаётся прежним объектом из поверхностной копии; предполагается, что downstream сможет применить одну маску ко всему батчу. Маска с batch-размером больше единицы повторяется `amount` раз.

## 5. Как устроено повторение

Для `samples` вызывается `repeat((amount,) + (1,) × остальные_оси)`. Поэтому меняется только первая ось. Память выделяется под все копии, а не под лёгкое представление одного storage.

Для существующего `batch_index` вычисляется `offset = max(indexes) - min(indexes) + 1`. Первый блок сохраняет исходный список, каждый следующий получает прибавку `i × offset`. Например, `[5, 7]` при `amount = 3` превращается в `[5, 7, 8, 10, 11, 13]`. Пропуски внутри блока сохраняются; при обычном `[0, 1]` получится непрерывный `[0, 1, 2, 3, 4, 5]`.

В ветке `noise_mask` исходник 0.32.0 содержит заметную деталь. Если масок больше одной, но меньше, чем элементов `samples`, код вычисляет временно дополненный `masks`, однако в итоговую строку передаёт не его, а исходный `samples["noise_mask"]`. Поэтому фактический batch-размер маски становится `M × amount`, а не обязательно `B × amount`. Downstream может затем растянуть маску по своим правилам, но точное соответствие «маска к элементу» в таком случае нельзя считать гарантированным.

## 6. Как выбирать amount и поведение шума

Начинайте с минимального размера, который нужен следующей операции. `amount = 4` для входа из двух элементов создаёт восемь латентов и примерно во столько же раз увеличивает объём `samples`. Максимум `64` быстро становится дорогим даже для обычной 2D-модели, а для video latent рост особенно заметен.

Если повторённые элементы должны получить одинаковый начальный шум, поставьте `LatentBatchSeedBehavior` в режиме `fixed` после повторения. Если нужны разные шумовые поля при том же sampler seed, используйте режим `random`. Порядок нод существенен: `fixed` до `RepeatLatentBatch` может быть снова развёрнут в разные смещённые индексы самим повторением.

При masked sampling проверьте batch-размер `noise_mask`. Самый предсказуемый случай — одна общая маска либо маска с тем же batch-размером, что и `samples`. Смешанный размер `1 < M < B` затрагивает описанную особенность реализации 0.32.0.

## 7. Проверенный пример

Fragment `Повторить LATENT с одинаковым индексом шума` принимает внешний `LATENT`, пропускает его через `RepeatLatentBatch` с `amount = 4`, затем через `LatentBatchSeedBehavior` с `seed_behavior = fixed`. Такое расположение сначала формирует окончательный батч, а затем назначает всем его элементам один `batch_index`.

Настройки, типы и соединение сверены с runtime `/object_info`; fragment прошёл схему и проверку портов, но не исполнялся в живом ComfyUI. Во всех 512 JSON-файлах официального workflow-пакета 0.1.42, включая subgraph, `RepeatLatentBatch` не найден. Пример поэтому документирует проверенный кодом способ соединения двух нод, а не копирует неподтверждённый production workflow.

## 8. Частые ошибки

- Ожидают поэлементный порядок `[A, A, B, B]`. Реальный порядок при `amount = 2` — `[A, B, A, B]`.
- Считают повторение источником разнообразия. До добавления разного шума или conditioning копии одинаковы.
- Ставят `LatentBatchSeedBehavior fixed` перед повторением и получают новые индексы в последующих блоках. Для одного индекса на весь итоговый батч порядок должен быть обратным.
- Не учитывают линейный рост памяти и времени следующих batch-операций.
- Передают пустой `batch_index`. Вызовы `max()` и `min()` для пустого списка завершаются ошибкой.
- Полагаются на временное выравнивание многомасочного `noise_mask`. В 0.32.0 вычисленный локальный `masks` не используется при присваивании результата.
- Ожидают, что пользовательские metadata-тензоры повторятся вместе с `samples`. Неизвестные поля переносятся поверхностно.

## 9. Ограничения и производительность

Операция `torch.repeat` выделяет новый тензор размером `amount` полных входных батчей. Время копирования и память растут линейно с `amount`. Следующие sampler и VAE обычно тоже работают уже со всем увеличенным батчем, поэтому общая цена графа может вырасти сильнее, чем время одной ноды.

Многомасочный `noise_mask` также повторяется и занимает дополнительную память; одиночная маска остаётся одной. Построение `batch_index` имеет линейную сложность по числу выходных элементов и обычно мало по сравнению с тензорами. Нода не меняет dtype, устройство, spatial-форму или значения `samples` кроме блочного копирования.
