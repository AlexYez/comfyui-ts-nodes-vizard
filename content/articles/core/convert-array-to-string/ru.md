# Convert Array to String

## 1. Назначение

Нода сериализует `ARRAY` в JSON-строку через тот же `_dump_json`, что и словарный вариант.

## 2. Место в графе

Она подготавливает массив для API, сохранения или просмотра как текста.

## 3. Входы

`array` принимает `ARRAY`. `indent` от 0 до 8, default 2, управляет отступом.

## 4. Выход

Выход — `STRING` с JSON-массивом либо другим JSON-совместимым значением, которое реально пришло через порт.

## 5. Форматирование

`indent=0` означает `indent=None`: результат однострочный. Положительное значение добавляет переносы и отступы. Unicode не превращается в ASCII escape.

## 6. Типы элементов

Строки, числа, boolean, null, списки и словари сериализуются. Tensor, bytes и произвольные объекты без JSON encoder вызывают `TypeError`.

## 7. Проверенный пример

Рецепт принимает внешний ARRAY и пишет compact JSON с indent 0. Probe проверяет кириллицу, вложенные структуры, null и ошибку на объекте. Официальных `ConvertArrayToString` нет.

## 8. Диагностика

При `TypeError` проверяйте каждый элемент и вложенные значения. Если нужен человекочитаемый Python repr, эта нода не подходит: её контракт — JSON.

## 9. Ограничения и производительность

Весь массив и итоговая строка находятся в памяти. Нода не сортирует элементы и не выполняет потоковую запись.
