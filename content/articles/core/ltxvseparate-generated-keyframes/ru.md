# LTXV Separate Generated Keyframes: отделение кадров детализации

Извлекает служебные generated keyframes из sampled video-latent и удаляет их метаданные из conditioning. Возвращает отдельно основной ролик и ключевые кадры с записанными позициями.

## Как пользоваться

Positive и negative должны соответствовать latent, в который добавлялись кадры. keyframes_to_batch = false сохраняет их как многокадровый latent; true превращает в batch одиночных кадров. Проверяются пространственный размер и положение блока: масштабированный после добавления latent уже не соответствует записи.

## Пример подключения

После sampler разделите объединённый AV-latent, затем подключите video-latent сюда вместе с исходным conditioning. Видео и ключевые кадры теперь можно масштабировать отдельно. Для повторного сэмплирования используйте AddGeneratedKeyframes, для фиксированных guides — GeneratedKeyframesToGuides.

## Ограничения и частые ошибки

Не запускайте LTXV Crop Guides раньше: она может удалить generated keyframes как расходуемые guides. Разделение нужно выполнить до пространственного upscale. Нода не умеет угадывать потерянные метаданные по одному тензору, поэтому сохраняйте связанные ветки conditioning и latent вместе.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `positive` | `CONDITIONING` | да | соединение / значение без фиксированного default |
| `negative` | `CONDITIONING` | да | соединение / значение без фиксированного default |
| `latent` | `LATENT` | да | соединение / значение без фиксированного default |
| `keyframes_to_batch` | `BOOLEAN` | да | по умолчанию: false |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `positive` | `CONDITIONING` | нет |
| `negative` | `CONDITIONING` | нет |
| `latent` | `LATENT` | нет |
| `keyframes` | `LATENT` | нет |
