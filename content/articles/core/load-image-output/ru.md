# Load Image Output: вернуть сохранённый файл из output в граф

`LoadImageOutput` выбирает файл из выходного каталога ComfyUI и читает его тем же decoder-путём, что обычный `LoadImage`. Нода удобна для повторной обработки уже сохранённого результата, но не связывает два запуска автоматически: пользователь выбирает конкретный файл.

## Вход image — обновляемый COMBO из output

Runtime задаёт `image` как `COMBO` с `image_folder = "output"`. Список обслуживает route `/internal/files/output`; рядом показывается кнопка refresh.

После refresh frontend обновляет варианты и выбирает первый (`control_after_refresh = "first"`). Это именно поведение интерфейса, а не поиск самого нового файла по времени создания.

## Нода наследует decoder от LoadImage

`LoadImageOutput` переопределяет список файлов, описание и experimental-флаг, но оставляет `FUNCTION = "load_image"`. Чтение, EXIF-поворот, обработка кадров, IMAGE и MASK приходят из родительского `LoadImage`.

Поэтому различие между двумя нодами — прежде всего область выбора: LoadImage работает с input, LoadImageOutput — с output. Формат тензоров на выходе общий.

## IMAGE получает RGB-кадры

Основной путь использует video/file decoder и возвращает его кадры. Fallback для animated WebP открывает файл через Pillow, применяет EXIF transpose и преобразует каждый подходящий кадр в RGB float32 с диапазоном 0–1.

Если кадры fallback-анимации отличаются от размера первого, такие кадры пропускаются. Нода не масштабирует их к общей геометрии.

## MASK хранит обратную прозрачность

Когда decoder даёт alpha, MASK вычисляется как `1 − alpha`: непрозрачному пикселю соответствует 0, прозрачному — 1. Это стандартная полярность ComfyUI MASK для областей обработки.

При отсутствии alpha основной путь создаёт нулевую маску `64 × 64` для каждого кадра. Fallback Pillow делает такую же нулевую заглушку. MASK без прозрачности поэтому не обязана совпадать с пространственным размером IMAGE.

## Многокадровый файл становится IMAGE-бэтчем

Поддерживаемая анимация или video-compatible файл возвращает несколько кадров по первой оси IMAGE. MASK также содержит кадры, если alpha доступна.

Нода не выдаёт FPS, duration или audio. После загрузки остаётся последовательность изображений; временные параметры исходного контейнера не становятся отдельными выходами.

## Изменение файла инвалидирует кэш

Унаследованный `IS_CHANGED` читает выбранный файл и вычисляет SHA-256 его содержимого. Если файл с тем же именем перезаписан другими байтами, значение меняется и ComfyUI может пересчитать зависимую ветку.

`VALIDATE_INPUTS` отдельно проверяет, что annotated filepath существует. Несуществующий или недоступный файл отклоняется сообщением `Invalid image file`.

## Refresh не означает автоматический latest

Кнопка выбирает первый элемент обновлённого COMBO. Порядок определяется ответом file route и frontend-контролом; source не обещает сортировку по дате или счётчику.

Если нужен определённый результат, проверьте полное имя и подпапку. Не стройте автоматизацию на предположении, что refresh всегда подхватывает последнюю генерацию.

## Нода помечена experimental

Runtime inventory ComfyUI 0.32.0 содержит `experimental = true`. Remote-схема списка и взаимодействие frontend/backend могут меняться быстрее стабильных core-контрактов.

В официальном workflow wheel 0.1.42 exact type `LoadImageOutput` не встречается ни в одном из 496 графов, включая subgraph. Поэтому recipe ниже source-derived, а не извлечён из шаблона.

## LoadImageOutput не заменяет хранение зависимостей

Провод между нодами передаёт текущий IMAGE без дополнительной компрессии. Цепочка Save → LoadImageOutput сначала кодирует файл, затем снова декодирует его; для lossy WebP это изменит пиксели, для PNG всё равно добавит файловый этап.

Используйте повторную загрузку, когда нужен именно сохранённый артефакт или новый запуск. Для продолжения того же графа подключайте IMAGE-выход save-ноды либо исходный upstream.

## Fragment показывает обе выходные ветви

Рецепт оставляет выбор output-файла внутри LoadImageOutput, отправляет IMAGE в PreviewImage, а MASK — через MaskToImage во второй PreviewImage. Он помогает проверить полярность прозрачности и число кадров.

Fragment прошёл проверку схемы, но не исполнялся в ComfyUI: для него нужен реальный файл в output. Локальная проверка Pillow покрывает формат изображения, а не полный LoadImage decoder. Редактор пока не проверил материал вручную.
