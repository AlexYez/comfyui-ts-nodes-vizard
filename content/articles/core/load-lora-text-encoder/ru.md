# Загрузка нескольких LoRA для текстового энкодера

Применяет список LoRA к объекту CLIP и возвращает изменённый текстовый энкодер. Диффузионную MODEL эта нода не принимает и не модифицирует.

## Как пользоваться

Подключите CLIP из совместимого загрузчика. В группе `loras` задайте до двадцати строк с именем файла, силой и переключателем `enabled`. Файлы берутся из папок LoRA; пустая, выключенная или нулевая по силе строка пропускается.

Выход подключается к текстовому кодированию, а не напрямую к сэмплеру. Если файл содержит и модельную часть, её нужно применить отдельной Load LoRA (Model) или штатным объединённым загрузчиком.

## Пример

Соедините CheckpointLoaderSimple → CLIP с этой нодой, затем её выход — с CLIP Text Encode. Проверяйте адаптер на том энкодере, под который он обучен; общий тип CLIP не делает все архитектуры взаимозаменяемыми.

## Ограничения

Не у каждой LoRA есть веса текстового энкодера. Большая или отрицательная сила может ухудшить условия; диапазон виджета не означает, что все значения полезны. Нода меняет энкодер для последующих вычислений, но не пересчитывает заранее сохранённый CONDITIONING.

## Входы и настройки

Снимок ComfyUI 0.43.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `clip` | `CLIP` | да | соединение / значение без фиксированного default |
| `loras` | `COMFY_DYNAMICGROUP_V3` | да | минимум: 1; максимум: 20 |
| `loras → lora_name` | `COMBO` | да | соединение / значение без фиксированного default |
| `loras → strength` | `FLOAT` | да | по умолчанию: 1.0; минимум: -100.0; максимум: 100.0; шаг: 0.01 |
| `loras → enabled` | `BOOLEAN` | да | по умолчанию: true |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `CLIP` | `CLIP` | нет |
