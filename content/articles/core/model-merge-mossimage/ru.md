# Поблочное смешивание моделей MOSS-Image

Смешивает совместимые веса двух MOSS-Image с отдельными коэффициентами для эмбеддеров, текстовых блоков, временных модулей, 42 основных слоёв и выходной части. Это работа с весами MODEL, не смешивание изображений и не загрузка LoRA.

## Как пользоваться

Подайте две модели одинаковой архитектуры. Для каждого префикса коэффициент задаёт долю первой модели: 1 сохраняет соответствующие веса model1, 0 берёт их из model2, 0,5 смешивает поровну. По умолчанию все коэффициенты равны 1.

Реализация клонирует model1 и перебирает ключи model2 с префиксом diffusion_model. Для каждого ключа выбирается самое длинное совпадение с указанными префиксами; для неохваченных ключей используется первый коэффициент — `video_embedder.`. Не считайте такой ключ автоматически сохранённым из model1.

## Пример

Загрузите два совместимых варианта MOSS-Image, оставьте всё на 1 и меняйте один блок небольшими шагами, сравнивая одинаковый промпт и seed. Для сохранения отдельного файла нужна Model Save после проверки результата.

## Ограничения

Нода не проверяет художественную совместимость моделей и не обучает новую модель. Разные формы весов или архитектуры могут вызвать ошибки применения. Само наличие названий блоков не даёт универсального соответствия «этот слой отвечает за цвет или композицию».
