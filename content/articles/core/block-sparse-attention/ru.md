# Block Sparse Attention: разреженное внимание совместимой модели

Подключает экспериментальное блочно-разреженное внимание к копии MODEL. Может сократить часть вычислений на длинных последовательностях, но требует подходящей модели, устройства и ядра.

## Как пользоваться

sol-attn использует адаптивный отбор с tau; SLA — keep_percent для специально обученных весов; VSA предназначен для FastH3/MiniMax H3. start_percent/end_percent ограничивают участок сэмплирования, min_tokens — минимальную длину. dense_blocks оставляет указанные блоки плотными. sink_conditioning управляет сохранением условных токенов в H3; verbose помогает увидеть причины fallback.

## Пример подключения

Начните с официальной модели и режима, для которого заявлена поддержка. Сравните один workflow с нодой и без неё при одинаковых размерах и seed. Включите verbose и проверьте, что действительно выбран sparse-путь, прежде чем объяснять ему изменение скорости.

## Ограничения и частые ошибки

Не-CUDA устройство, отсутствие скомпилированного ядра, неподходящая размерность головы или форма attention могут привести к плотному fallback. Малое число токенов также не включает оптимизацию. SLA нельзя произвольно применять к обычным весам; снижение keep_percent способно ухудшить результат. Ускорение и экономия VRAM не гарантированы.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `model` | `MODEL` | да | соединение / значение без фиксированного default |
| `selection` | `COMFY_DYNAMICCOMBO_V3` | да | режимы: sol-attn, sla, vsa |
| `selection=sol-attn → tau` | `FLOAT` | да | по умолчанию: 1.3; минимум: 0.0; максимум: 4.0; шаг: 0.05 |
| `selection=sla → keep_percent` | `FLOAT` | да | по умолчанию: 10.0; минимум: 0.5; максимум: 95.0; шаг: 0.5 |
| `selection=vsa → keep_percent` | `FLOAT` | да | по умолчанию: 10.0; минимум: 0.5; максимум: 95.0; шаг: 0.5 |
| `start_percent` | `FLOAT` | да | по умолчанию: 0.2; минимум: 0.0; максимум: 1.0; шаг: 0.01 |
| `end_percent` | `FLOAT` | да | по умолчанию: 1.0; минимум: 0.0; максимум: 1.0; шаг: 0.01 |
| `dense_blocks` | `STRING` | да | по умолчанию:  |
| `min_tokens` | `INT` | да | по умолчанию: 12288; минимум: 0; максимум: 1048576; шаг: 512 |
| `extra_tokens` | `INT` | да | по умолчанию: 256; минимум: 0; максимум: 256; шаг: 64 |
| `sink_conditioning` | `COMBO` | да | по умолчанию: exact_kv_and_rows; варианты: exact_kv, exact_kv_and_rows, off |
| `verbose` | `BOOLEAN` | да | по умолчанию: false |
