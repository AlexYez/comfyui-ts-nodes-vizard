# Save Conditioning: сохранение вычисленных условий

Записывает conditioning в safetensors и одновременно пропускает его дальше. Полезно для повторного использования дорогостоящего кодирования при неизменных условиях генерации.

## Как пользоваться

filename_prefix управляет именем в output. Поддерживается только conditioning из одного элемента. Тензоры переносятся на CPU и сохраняются в непрерывном представлении; списки тензоров и простые скалярные значения также сериализуются. Неподдерживаемые объекты метаданных вызывают ошибку, а не незаметно исчезают.

## Пример подключения

Поставьте ноду сразу после совместимого энкодера, до объединения нескольких conditioning и добавления сложных объектов управления. Подключите её выход к sampler. Для повторной загрузки перенесите файл в models/embeddings и выберите его в ConditioningLoader.

## Ограничения и частые ошибки

Это не универсальный снимок состояния графа. ConditioningCombine может дать несколько элементов, которые эта нода не принимает. Живые объекты управления и произвольные Python-структуры не сериализуются. Храните рядом сведения о модели, энкодере и версии: одного файла недостаточно для воспроизводимости всего workflow.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `conditioning` | `CONDITIONING` | да | соединение / значение без фиксированного default |
| `filename_prefix` | `STRING` | да | по умолчанию: conditioning/ComfyUI |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `conditioning` | `CONDITIONING` | нет |
