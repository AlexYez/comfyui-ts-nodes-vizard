# Z-Image / Qwen 2.1: Fun ControlNet

Применяет совместимый Fun ControlNet к копии модели. В ComfyUI 0.38.0 публичное описание включает Z-Image и Qwen Image 2.1; это не универсальная управляющая нода для любых моделей.

## Подключение

Обязательны `MODEL`, `MODEL_PATCH`, совместимый `VAE` и `strength`. Управляющее изображение поступает на `image`, исходник редактирования — на `inpaint_image`, область — на `mask`. Набор нужных входов зависит от архитектуры загруженной заплатки. Выходную модель передайте сэмплеру.

В отличие от QwenImageDiffsynthControlnet, здесь `image` необязателен и есть публичный `inpaint_image`. Если нет ни обоих изображений, ни маски, возвращается исходная модель. Одна маска не гарантирует полноценной рабочей цепочки: требования определяет выбранная заплатка.

## Сила и расписание

`strength = 0` теперь возвращает исходную модель без подготовки заплатки. `start_percent` и `end_percent` ограничивают воздействие участком расписания сэмплирования, по умолчанию от 0 до 1. Это не координаты маски и не время в ролике.

## Различия архитектур

Класс наследует обработчик QwenImageDiffsynthControlnet. Он выбирает специальную ветвь Qwen Image 2.1 Fun Control, Z-Image либо обычный DiffSynth. RGB берётся из первых трёх каналов; путь и полярность обработки маски зависят от ветви. Не переносите детали внутренней инверсии Z-Image на Qwen 2.1 без проверки.

## Ограничения

В Z-Image при разных размерах входов подготовка может откладываться до первого вычисления, когда изображения приводятся к целевому размеру и кодируются VAE. Несовместимая заплатка способна завершиться ошибкой, даже если типы портов совпадают.

## Пример подключения

Для локального редактирования подключите исходник к `inpaint_image`, маску к `mask` и подходящую inpaint-заплатку к `model_patch`. Сначала проверьте короткий проход с маской небольшой области. Веса обычного ControlNet для другого семейства сюда не подходят.

## Входы и настройки

Снимок ComfyUI 0.38.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `model` | `MODEL` | да | соединение / значение без фиксированного default |
| `model_patch` | `MODEL_PATCH` | да | соединение / значение без фиксированного default |
| `vae` | `VAE` | да | соединение / значение без фиксированного default |
| `strength` | `FLOAT` | да | по умолчанию: 1.0; минимум: -10.0; максимум: 10.0; шаг: 0.01 |
| `image` | `IMAGE` | нет | соединение / значение без фиксированного default |
| `inpaint_image` | `IMAGE` | нет | соединение / значение без фиксированного default |
| `mask` | `MASK` | нет | соединение / значение без фиксированного default |
| `start_percent` | `FLOAT` | нет | по умолчанию: 0.0; минимум: 0.0; максимум: 1.0; шаг: 0.001 |
| `end_percent` | `FLOAT` | нет | по умолчанию: 1.0; минимум: 0.0; максимум: 1.0; шаг: 0.001 |
