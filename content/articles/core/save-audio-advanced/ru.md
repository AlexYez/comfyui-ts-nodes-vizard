# SaveAudioAdvanced: сохранить FLAC, MP3 или Opus

## Что делает нода

`SaveAudioAdvanced` кодирует входной `AUDIO` в FLAC, MP3 или Opus и пишет файлы в каталог `output` ComfyUI. Формат задаётся динамическим виджетом: после выбора MP3 или Opus появляется соответствующее поле `quality`.

Каждый элемент batch сохраняется отдельно. При waveform формы `[B,C,T]` получится `B` файлов с общим prefix и возрастающим пятизначным счётчиком.

Нода одновременно возвращает исходный `AUDIO` через подключаемый выход `audio`. Сохранение не заменяет waveform перекодированной копией: следующая нода получает тот же входной объект.

## Когда использовать и когда не использовать

Выбирайте эту ноду для постоянного результата: lossless-мастера в FLAC, совместимого MP3 или компактного Opus. Она подходит и как конечная точка, и как промежуточный output node, если тот же AUDIO должен продолжить граф.

Для быстрого прослушивания без постоянного файла используйте `PreviewAudio`: он пишет FLAC в `temp`. Для изменения громкости, каналов или sample rate сначала подготовьте waveform отдельными нодами; saver выполняет только необходимое формату Opus преобразование частоты.

Не подавайте многоканальный материал как 5.1 или 7.1 без предварительного сведения. Реализация корректно различает только mono и stereo.

## Короткий рецепт подключения

1. Подайте готовый `AUDIO` во вход `audio`.
2. Укажите `filename_prefix`, например `audio/ComfyUI`.
3. Выберите `mp3`, затем `V0`, если нужен вариант из официальных шаблонов.
4. Запустите граф и проверьте созданные файлы в `output/audio`.
5. При необходимости продолжите ветку с выхода `audio`.

Fragment «Сохранить AUDIO как MP3 с настройкой V0» принимает внешний AUDIO и повторяет сериализацию официальных workflow: prefix `audio/ComfyUI`, `format: mp3`, `quality: V0`. Он не создаёт исходный звук и не считается полным выполненным workflow.

## Входы, выходы и параметры

`audio` — обязательный `AUDIO`. `filename_prefix` — строка с default `audio/ComfyUI`; часть до имени образует подкаталог внутри `output`. Общий path helper запрещает выход за пределы output-каталога. Маркер `%batch_num%` заменяется номером элемента batch до добавления счётчика.

`format` — `COMFY_DYNAMICCOMBO_V3`:

- `flac` не имеет поднастроек;
- `mp3` предлагает `V0` по умолчанию, `128k` и `320k`;
- `opus` предлагает `64k`, `96k`, `128k` по умолчанию, `192k` и `320k`.

Выход `audio` имеет тип `AUDIO` и не является list-output. UI-result отдельно содержит имена файлов, подкаталог и `type: output`. Embedded docs 0.5.9 перечисляют только UI, но runtime и исходник подтверждают подключаемый passthrough.

## Типовые связки

`VAEDecodeAudio → SaveAudioAdvanced` экспортирует сгенерированный звук. `AudioMerge → SaveAudioAdvanced` записывает сведённую дорожку. `LoadAudio → обработка → SaveAudioAdvanced` создаёт новый файл после преобразований.

Выход saver можно направить в `CreateVideo`, как сделано в официальном Sonilo workflow. Поскольку это исходный AUDIO, downstream получает исходную частоту и waveform; возможный Opus-resample существует только внутри сохранённого файла.

Для одновременного постоянного и временного контроля подключите passthrough к `PreviewAudio`. Это создаст два артефакта: выбранный формат в `output` и временный FLAC в `temp`.

## Практический пример

Полный census 512 официальных JSON нашёл шесть `SaveAudioAdvanced` в шести корневых графах. Во всех сохранены MP3 и `V0`; примеров FLAC, Opus, MP3 128k/320k и Opus bitrate-вариантов в bundle 0.1.42 нет.

В `api_sonilo_v2m.json`, workflow UUID `9132f036-0cbe-44bb-9948-c8d1348ec66b`, нода № 728 принимает результат `SoniloVideoToMusic`, пишет `audio/Sonilo` как MP3 V0 и через выход `audio` передаёт тот же сигнал во вход `extra_audio` подграфа `Video Audio Merger`. Это единственный официальный случай с используемым passthrough-выходом; в остальных пяти saver остаётся конечным.

Изолированный прогон штатного helper сохранил batch из двух stereo-элементов двумя FLAC-файлами и корректно подставил `%batch_num%`. Исполнены все варианты format/quality. MP3 128k сообщил 44,1 кГц и 128000 бит/с; Opus из 44,1 кГц был пересчитан к 48 кГц. Opus 320k записался для stereo, но закреплённый `libopus` отверг 320k для mono; субъективное сравнение качества не проводилось.

## Частые ошибки и способы проверки

**Ищут один файл для всего batch.** Цикл идёт по оси `B`; каждый элемент получает отдельное имя и счётчик. Используйте `%batch_num%`, если номер должен быть виден до suffix.

**Считают Opus-файл точной копией sample rate.** Допустимы 8, 12, 16, 24 и 48 кГц. Частота выше 48 кГц понижается до 48; другая меньшая частота повышается до следующей поддерживаемой. Например, 44,1 становится 48 кГц.

**Передают больше двух каналов.** Любое `C != 1` объявляется layout `stereo`, затем значения flatten-ятся. В изолированной проверке три канала по 80 отсчётов превратились в два по 120, четыре — в два по 160. Сведите материал до mono/stereo заранее.

**Ожидают, что downstream получит данные из файла.** Выход — исходный AUDIO. Чтобы проверить кодированный результат, загрузите сохранённый файл отдельной `LoadAudio`.

**Путают V0 с числовым bitrate.** Для V0 реализация задаёт `codec_context.qscale = 1`; для 128k и 320k — явный `bit_rate`. Статья не приравнивает эти режимы по размеру или слышимому качеству.

**Mono Opus 320k не кодируется.** В закреплённом окружении `libopus` вернул `Invalid argument` для одного канала при 320k, хотя UI предлагает этот пункт. Stereo 320k прошёл. Для mono выберите 192k или ниже и перепроверьте файл.

## Производительность и внутреннее поведение

Waveform каждого batch-элемента переносится на CPU, превращается в NumPy и кодируется в `BytesIO`. Только после закрытия контейнера весь буфер записывается в файл. Поэтому длинная дорожка требует памяти и под исходный tensor, и под кодированный результат.

FLAC использует codec `flac`; MP3 — `libmp3lame`; Opus — `libopus`. Для Opus-resample требуется доступный `torchaudio`. Значения 64k–320k напрямую задают bitrate Opus, а MP3 128k/320k — bitrate MP3.

Если metadata включены, helper записывает сериализованные `prompt` и `extra_pnginfo` в контейнер. Дополнительные поля самого AUDIO-словаря в кодек не передаются. Нода не нормализует амплитуду и не ограничивает пики перед кодированием.

## Совместимость, изменения и устаревание

Статья относится к ComfyUI `0.32.0`, frontend `1.48.7`, runtime ID `SaveAudioAdvanced` и модулю `comfy_extras.nodes_audio`. Fingerprint: `sha256:4161e0e67516eb2cda31011008c8602f0ef4cad7d9b3b6e8e5edcbd9b64d4940`.

Нода не experimental и не deprecated; runtime помечает её как output node. Формат сериализуется новым `COMFY_DYNAMICCOMBO_V3`, поэтому старый frontend без поддержки dynamic combo может не показать вложенный `quality` корректно.

Embedded docs подтверждают список форматов и вариантов качества, но пропускают AUDIO passthrough, batch-файлы, точные правила Opus sample rate и ограничение каналов. Эти части основаны на pinned helper и изолированном файловом прогоне.
