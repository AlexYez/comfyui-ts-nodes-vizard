# SeedVR2TemporalMerge

## Назначение
`SeedVR2TemporalMerge` собирает список обработанных временных частей SeedVR2 в один LATENT.

## Место в графе
Подайте список после sampler и `temporal_overlap` прямо из `SeedVR2TemporalChunk`. Не вводите overlap вручную независимо от splitter.

## Входы
`latents` — список 5D LATENT, `temporal_overlap` — принудительный INT-вход, который из-за list-режима приходит как список и берётся по индексу 0.

## Выходы
Один LATENT сохраняет metadata первой части, кроме `noise_mask`, которую нода удаляет как несогласованную с новой временной длиной.

## Как работает
Без overlap samples склеиваются по T. С overlap общая длина рассчитывается по шагу, а общие кадры смешиваются: вес предыдущей части задаёт окно Hann с плоскими внешними третями, вес следующей равен `1-w`.

## Параметры
Перекрытие ограничивается `chunk_latent-1`. Последняя часть может быть короче; промежуточные обязаны совпадать с первой по T, а все части — по B/C/H/W.

## Проверенный пример
Официальный видеограф использует merge после двух ветвей sampler через switch/temporal routing и перед VAEDecodeTiled. Настроек у ноды нет; overlap приходит из Chunk и в примере равен 0.

## Частые ошибки
Пустой список не обрабатывается. Несовместимые формы дают `ValueError`. Отрицательное перекрытие запрещено. Передача частей не по порядку меняет временной порядок результата.

## Ограничения и производительность
Результат выделяется целиком на устройстве первой части. При overlap одновременно читаются предыдущая область и новая часть. Полный видеопроход при проверке не выполнялся.

## Совместимость и источники
List-схема, проверки форм и отпечаток сверены с ComfyUI 0.32.0; окно смешивания — с исходником; положение в графе — с официальным видео 0.1.42.
