# ChromaRadianceOptions: параметры NeRF и text IDs

## Назначение

Локальная нода передаёт модели Chroma Radiance дополнительные параметры NeRF и текстовых идентификаторов только в заданном окне сигмы. Она не изменяет веса и не обращается к API.

## Место в графе

Подключите исходный `MODEL`, а выход — в сэмплер. `CONDITIONING` и `LATENT` не меняются: параметры временно добавляются в `transformer_options` непосредственно перед вызовом модели.

## Входы

`preserve_wrapper` управляет вызовом прежней модельной обёртки. `start_sigma` и `end_sigma` ограничены 0–1, по умолчанию 1 и 0. `nerf_tile_size=-1` не записывает настройку, 0 включает режим без тайлов. `force_sequential_txt_ids` нужен лишь определённым checkpoint.

## Выход

Если `nerf_tile_size < 0` и последовательные идентификаторы выключены, словарь параметров пуст: метод возвращает тот же объект модели без клонирования и полностью игнорирует окно сигмы и `preserve_wrapper`. Иначе клон получает новую UNet-обёртку.

## Sigma-окно

Из batch берётся максимальное значение `args["timestep"]`, переносится на CPU и превращается в число Python. Параметры добавляются при `end_sigma <= sigma <= start_sigma`, включая обе границы. Если пользователь задаст `start_sigma < end_sigma`, условие никогда не выполнится; нода не переставляет значения.

## NeRF tile

При `nerf_tile_size >= 0` точное число записывается в `chroma_radiance_options`. Ноль выбирает вычисление без тайлов и может резко увеличить расход видеопамяти. Значение −1 оставляет настройку модели нетронутой; tooltip указывает внутреннее значение по умолчанию 32, но сама нода число 32 не записывает.

## Sequential IDs

Включённый флаг добавляет `use_sequential_txt_ids=True`. По закреплённой подсказке это предназначено для checkpoint, обученных с 22 мая по 1 июня 2026 года, но не содержащих маркер `__sequential__`. Для других весов принудительное включение не обосновано.

## Проверенный пример

Единственный официальный экземпляр сериализован как `[true,1,0,-1]`; старый граф не содержит хвостового boolean. При его современном значении по умолчанию `false` словарь параметров пуст, поэтому нода возвращает исходный `MODEL` без обёртки. Рецепт Wizard, основанный на исходнике, явно задаёт tile 32 и тем самым действительно активирует ноду.

## Wrapper-порядок

При `preserve_wrapper=true` существующая обёртка вызывается с копией аргументов и изменённым `c`. При `false` код вызывает `apply_model` напрямую и обходит старую обёртку. Новый словарь `c` и вложенные `transformer_options` копируются, поэтому исходные словари вызова не меняются, но порядок нескольких модельных заплаток зависит от этой настройки.

## Совместимость и источники

Проверено по ComfyUI 0.32.0, frontend 1.48.7, закреплённому исходнику, `/object_info`, документации 0.5.9 и единственному официальному графу 0.1.42. Реальный Chroma forward и измерения памяти не выполнялись; человеческое утверждение ожидается.
