# Применение операции к предсказанию CFG

Добавляет к копии MODEL операцию над предсказанием перед вычислением classifier-free guidance. Нода экспериментальная и отличается от Latent Apply Operation, которая сразу обрабатывает переданный LATENT.

## Как пользоваться

Соедините модель с `model`, совместимую `LATENT_OPERATION` с `operation`, затем отправьте выход MODEL в сэмплер. В ComfyUI 0.43.0 доступны `start_percent` и `end_percent`: начало и конец действия на расписании денойзинга.

Границы преобразуются через `model_sampling.percent_to_sigma`. Внутри интервала при двух ветвях операция получает разность positive − negative, после чего отрицательная ветвь добавляется обратно. При одной ветви операция применяется непосредственно к её предсказанию. Вне интервала предсказания не меняются.

## Пример

Подключите Latent Operation Blend, задайте небольшой strength и ограничьте действие частью расписания. Сравнивайте с исходной моделью при одинаковых остальных настройках. Референс должен соответствовать форме и пространству предсказаний модели; это не обычный переход между готовыми изображениями.

## Ограничения

Проценты не обозначают номера кадров или долю длительности видео. Значения start больше end не переставляются автоматически. Результат зависит от CFG и числа реально вычисляемых ветвей; универсальной рекомендуемой силы для всех операций нет.

## Входы и настройки

Снимок ComfyUI 0.43.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `model` | `MODEL` | да | соединение / значение без фиксированного default |
| `operation` | `LATENT_OPERATION` | да | соединение / значение без фиксированного default |
| `start_percent` | `FLOAT` | нет | по умолчанию: 0.0; минимум: 0.0; максимум: 1.0; шаг: 0.001 |
| `end_percent` | `FLOAT` | нет | по умолчанию: 1.0; минимум: 0.0; максимум: 1.0; шаг: 0.001 |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `MODEL` | `MODEL` | нет |
