# TruncateText: первые max_length кодовых точек строки

## Что делает нода

`TruncateText` возвращает выражение `texts[:max_length]`. Это обычный Python-срез от начала строки до заданной длины.

Срез считает кодовые точки Unicode, а не слова, токены модели, байты или видимые пользовательские символы-графемы. Комбинируемый знак может отделиться от основной буквы, а сложная emoji-последовательность — оборваться внутри визуального символа.

Если текст короче предела, он возвращается целиком. Общий base class помещает строку в одноэлементный список, хотя runtime оставляет `output_is_list = null`.

## Когда использовать и когда не использовать

Нода подходит для простого технического ограничения Python-строки по числу кодовых точек: например, оставить короткий префикс для служебного поля.

Она не гарантирует лимит токенов текстового энкодера и не старается закончить на границе слова. Значение по умолчанию 77 не означает 77 CLIP-токенов.

Для интерфейсного текста или пользовательского описания лучше заранее решить, допустим ли обрыв слова и комбинируемой последовательности. При необходимости нужен другой алгоритм.

## Короткий рецепт подключения

1. Подключите одну строку к `texts`.
2. Оставьте `max_length = 77` или задайте свой предел.
3. Проверьте конец результата, особенно если встречаются emoji и комбинируемые знаки.
4. Не трактуйте число как токенный бюджет модели.

Фрагмент «Оставить первые 77 кодовых точек» содержит одну `TruncateText` и внешний `STRING`. Число совпадает с default runtime-схемы; официального workflow с ним нет. Фрагмент не выполнялся после импорта.

## Входы, выходы и параметры

`texts` — обязательный однострочный `STRING` с `multiline = false`. Нода работает индивидуально: `is_input_list = false`.

`max_length` — обязательный `INT`, default 77, минимум 1, максимум 10 000. Base class разворачивает одноэлементную списочную форму параметра, если исполнитель передал `[77]`.

Выход `texts` имеет тип `STRING` и `output_is_list = null`. Внутренний `NodeOutput` содержит `[result]`.

## Типовые связки

Обрезку можно поставить перед полем с жёстким лимитом кодовых точек либо после другой текстовой трансформации. Порядок важен: `upper()` иногда расширяет строку, поэтому лимит результата нужно применять после смены регистра.

Прямое соединение со старыми соседними `TextProcessingNode` требует проверки дополнительной оболочки выхода. Нельзя исходить только из подписи порта `STRING`.

В официальном workflow wheel 0.1.42 нода не встречается. Применение в рецепте выведено из точного кода и схемы, а не из подтверждённой топологии.

## Практический пример

Синтетическая строка `A😀éБ` содержит латинскую букву, emoji, `e`, отдельный комбинируемый акцент и кириллическую букву. При `max_length = 4` нода вернула `A😀é`: Python посчитал акцент четвёртой кодовой точкой.

При пределе 3 результатом было бы `A😀e` без акцента, хотя исходно читатель видит `é` как один графический знак. Две emoji и `max_length = [1]` подтвердили разворачивание одноэлементного параметра и возврат одной emoji.

Это безопасный точный вызов класса без внешних данных, а не полный workflow. Case-sensitive проверка всех 512 JSON не нашла `TruncateText`.

## Частые ошибки и способы проверки

**Предел 77 не совпал с лимитом модели.** Нода считает Python-кодовые точки. Токенизация выполняется по другим правилам и зависит от энкодера.

**Последний видимый символ повреждён.** Проверьте Unicode-кодовые точки возле границы: срез может отделить комбинируемый знак или часть ZWJ-последовательности.

**Слово оборвалось посередине.** Код не ищет пробел и не добавляет многоточие; он просто берёт префикс.

**Следующая нода получила вложенный список.** Уточните фактическую форму `NodeOutput`; base class заворачивает строку в список при неявном `output_is_list`.

## Производительность и внутреннее поведение

Python создаёт строковый префикс длиной не более `max_length`. Время и дополнительная память ограничены размером копируемой части.

Операция детерминирована и не обращается к модели, сети или файлам. Она не нормализует строку до или после среза.

`max_length` может прийти как одноэлементный список: общий `execute` извлечёт скаляр перед вызовом `_process`.
