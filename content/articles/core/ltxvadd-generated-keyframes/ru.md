# LTXV Add Generated Keyframes: дополнительные кадры детализации

Добавляет к video-latent служебные ключевые кадры, которые генерируются вместе с видео. Они помогают специальной LTX-модели детализации и не должны попадать в итоговый декодированный ролик.

## Как пользоваться

Нужны positive, negative, VAE и обычный 5D video-latent до объединения с аудио. interval_frames задаёт шаг в пиксельных кадрах, frame_indices — явное размещение вместо шага. Нулевой кадр запрещён, последний разрешён; занятые guide/I2V-позиции нельзя повторять. keyframes может инициализировать содержимое из предыдущего этапа, но оно остаётся сэмплируемым.

## Пример подключения

В совместимом detailing-workflow добавьте ключевые кадры до Concat AV Latent. После sampler сначала разделите аудио и видео, затем извлеките кадры через LTXVSeparateGeneratedKeyframes. Только очищенный video-latent отправляйте на дальнейший upscale или декодирование.

## Ограничения и частые ошибки

Требуется checkpoint, обученный generated keyframes и содержащий keyframes_abs_pos_embedding. Это не универсальный способ улучшить любую LTX-модель. Начальные keyframes влияют на содержимое при старте ниже sigma 1; они не становятся жёсткими референсами. Дополнительные токены увеличивают вычисления.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `positive` | `CONDITIONING` | да | соединение / значение без фиксированного default |
| `negative` | `CONDITIONING` | да | соединение / значение без фиксированного default |
| `vae` | `VAE` | да | соединение / значение без фиксированного default |
| `latent` | `LATENT` | да | соединение / значение без фиксированного default |
| `interval_frames` | `INT` | нет | по умолчанию: 24; минимум: 1; максимум: 1024 |
| `keyframes` | `LATENT` | нет | соединение / значение без фиксированного default |
| `frame_indices` | `STRING` | нет | по умолчанию:  |
