# Bake Normal Map: детали high-poly на low-poly

Запекает направления нормалей подробной сетки в UV-развёртку упрощённой. Выход — tangent-space normal map в соглашении glTF/OpenGL +Y; число граней low-poly не увеличивается.

## Как пользоваться

low_poly должен иметь UV, high_poly — совпадать с ним по положению и масштабу. resolution задаёт размер карты. cage_distance — полоса поиска поверхности как доля диагонали bounding box. ignore_backfaces исключает поверхности, обращённые в противоположную сторону.

## Пример подключения

Разветвите исходную сетку до DecimateMesh. Упрощённую ветку разверните через UnwrapMesh и подайте в low_poly; исходную — в high_poly. Подключите normal_map к ApplyTextureToMesh вместе с той же low-poly сеткой. Сравните её рендер с исходником при одинаковой камере.

## Ограничения и частые ошибки

Если детали не захватываются, немного увеличьте cage_distance; слишком большой диапазон может зацепить соседнюю стенку через зазор. Отключать ignore_backfaces стоит только при осознанной работе с неверным направлением граней. Карта меняет освещение, но не силуэт и не реальную геометрию.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `low_poly` | `MESH` | да | соединение / значение без фиксированного default |
| `high_poly` | `MESH` | да | соединение / значение без фиксированного default |
| `resolution` | `INT` | да | по умолчанию: 1024; минимум: 64; максимум: 8192; шаг: 64 |
| `cage_distance` | `FLOAT` | да | по умолчанию: 0.05; минимум: 0.001; максимум: 0.5; шаг: 0.001 |
| `ignore_backfaces` | `BOOLEAN` | да | по умолчанию: true |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `normal_map` | `IMAGE` | нет |
