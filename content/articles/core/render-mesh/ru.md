# Render Mesh: изображение и маска из сетки

Строит один вид MESH методом пересечения лучей с треугольниками. Возвращает IMAGE и MASK попадания лучей в поверхность; это серверный рендер, а не снимок окна браузера.

## Как пользоваться

auto выбирает текстуру, затем цвет вершин, затем однотонное затенение. Есть отдельные режимы normal и depth. width и height задают размер кадра, background — фон. camera_info и model_3d_info можно взять из одного 3D-просмотрщика, чтобы согласовать ракурс и положение модели.

## Пример подключения

После ApplyTextureToMesh включите RenderMesh в режиме auto и передайте IMAGE в PreviewImage. Для подготовки маски предмета используйте второй выход: белым отмечены пиксели сетки. Для воспроизводимого ракурса подключите камеру и преобразование модели, а не полагайтесь на автоматическое кадрирование.

## Ограничения и частые ошибки

Обрабатывается только первая сетка batch. depth нормализуется по видимым попаданиям: ближнее светлее, но это не метрическая глубина. Рендер не воспроизводит полностью PBR-освещение внешнего просмотрщика; наличие normal_map в MESH не означает, что этот простой renderer покажет весь материал как игровой движок.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `mesh` | `MESH` | да | соединение / значение без фиксированного default |
| `mode` | `COMBO` | да | варианты: auto, texture, vertex colors, solid, normal, depth |
| `width` | `INT` | да | по умолчанию: 1024; минимум: 64; максимум: 4096; шаг: 8 |
| `height` | `INT` | да | по умолчанию: 1024; минимум: 64; максимум: 4096; шаг: 8 |
| `background` | `COLOR` | да | по умолчанию: #000000 |
| `model_3d_info` | `LOAD3D_MODEL_INFO` | нет | соединение / значение без фиксированного default |
| `camera_info` | `LOAD3D_CAMERA` | нет | соединение / значение без фиксированного default |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `image` | `IMAGE` | нет |
| `mask` | `MASK` | нет |
