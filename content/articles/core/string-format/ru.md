# Format Text

## 1. Назначение

`StringFormat` подставляет именованные значения в шаблон Python `str.format`.

## 2. Место в графе

Нода собирает текст из чисел, строк и других значений перед API, сохранением или выводом. Autogrow добавляет входы по мере подключения.

## 3. Входы

`values` — группа произвольных входов с именами `a`–`z`, минимум 0. `f_string` — шаблон, default `{a}`. Имя поля должно совпадать с подключённым ключом.

## 4. Выход

Выход — результат `f_string.format(**values)` как `STRING`.

## 5. Синтаксис формата

Поддерживаются обычные поля `{a}`, доступ к атрибутам/индексам и спецификаторы вроде `{a:.2f}`. Литеральные фигурные скобки записываются как `{{` и `}}`.

## 6. Ошибки

Отсутствующее поле вызывает `KeyError`, неверный format specifier — `ValueError`, несовместимый тип — соответствующую ошибку Python. Нода их не перехватывает.

## 7. Проверенный пример

Рецепт подключает ширину к `a`, высоту к `b` и формирует `Size: {a}×{b}`. Probe проверяет числа, округление, экранированные скобки и ошибки. Официальных `StringFormat` в пакете 0.1.42 нет.

## 8. Диагностика

При `KeyError` сравните имя между скобками и autogrow-портом. При `ValueError` упростите спецификатор. Не вставляйте недоверенный шаблон без проверки: он может обращаться к атрибутам переданных объектов.

## 9. Ограничения и производительность

Доступно не более 26 имён шаблона `a`–`z`. Форматирование выполняется в памяти и обычно дёшево. Это не Python f-string и не выполняет произвольные выражения.

## 10. Совместимость и источники

Проверено на ComfyUI 0.32.0/frontend 1.48.7 по runtime, exact `str.format`, embedded docs 0.5.9 и workflow census. Человеческое утверждение ожидается.
