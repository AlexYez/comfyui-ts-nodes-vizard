# WeVisOne-VL: поиск объектов, рамки и маски

Запускает специализированный WeVisOne-VL для распознавания объектов и текста, указания точек и получения масок. Требует его текстовый энкодер, не произвольный CLIP.

## Подключение и пример

Подайте image, выберите task и опишите искомое в query. Для detection и point используется по одной метке на строку; visual_prompt принимает опорные bboxes. Выходы — masks, рамки по кадрам, JSON точек и сырой текст ответа. В JSON точки записаны в пикселях с номером frame.

Для выделения предмета выберите segmentation, задайте его описание и проверьте маску через preview. individual_masks возвращает отдельные маски по рамкам; иначе формируется объединённая маска кадра.

## Ограничения

Кадры обрабатываются последовательно, а число отдельных масок может отличаться от числа кадров. Пустой ответ не доказывает отсутствия объекта. Проверяйте OCR и границы вручную; max_length ограничивает ответ, но не гарантирует точность. Распознавание не заменяет временной трекинг объекта по ролику.

## Входы и настройки

Снимок ComfyUI 0.45.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `clip` | `CLIP` | да | соединение / значение без фиксированного default |
| `image` | `IMAGE` | да | соединение / значение без фиксированного default |
| `task` | `COMBO` | да | по умолчанию: segmentation; варианты: segmentation, detection, referring, point, count_box, count_point, ocr, ocr_grounding, visual_prompt, freeform |
| `query` | `STRING` | да | по умолчанию:  |
| `individual_masks` | `BOOLEAN` | да | по умолчанию: false |
| `max_length` | `INT` | да | по умолчанию: 4096; минимум: 1; максимум: 32768 |
| `bboxes` | `BOUNDING_BOX` | нет | по умолчанию: {"x":0,"y":0,"width":512,"height":512} |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `masks` | `MASK` | нет |
| `bboxes` | `BOUNDING_BOX` | нет |
| `points` | `STRING` | нет |
| `text` | `STRING` | нет |
