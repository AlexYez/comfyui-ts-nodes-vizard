# ComfyOrNode

## Что делает нода

`ComfyOrNode` принимает от одного до десяти autogrow-значений и возвращает результат Python `any(values.values())`. Выход true, если хотя бы один элемент truthy.

Тип каждого входа — AnyType, выход — `BOOLEAN`. Это логическое сведение, а не выбор исходного значения.

## Когда она нужна и когда не нужна

OR подходит для условия «достаточно одного»: включён любой режим, заполнено хотя бы одно поле, ненулевой хотя бы один scalar. Результат можно подать в switch или другой boolean-вход.

Если нужен сам первый непустой объект, а не bool, используйте switch или специальный selector. `ComfyOrNode` не возвращает найденное значение, хотя Python-оператор `or` в выражении мог бы это делать.

## Короткий рецепт подключения

Source-derived fragment показывает ложный результат:

1. Пустая строка идёт в `values.value0`.
2. `PrimitiveInt(0)` — в `values.value1`.
3. Оба значения falsy, поэтому OR возвращает false.
4. Замените любой источник на непустой/ненулевой — результат станет true.

Рядом тот же fragment содержит NOT и AND для сравнения правил.

## Autogrow-входы

`values` имеет тип `COMFY_AUTOGROW_V3`. Template создаёт AnyType-входы `value0`… с min 1 и max 10; semantic fragment использует имена `values.value0`, `values.value1`.

Нулевое число входов штатно запрещено. Если вызвать метод напрямую с пустым dict, Python `any([])` вернёт false, но UI-схема требует хотя бы один элемент.

## Правила truthiness

OR ищет первое truthy-значение. False, None, числовые нули, пустые строки и коллекции не подходят; непустые обычно подходят. Строка `"false"` считается true.

Объекты с неоднозначным `__bool__`, включая многoэлементные tensors, могут вызвать ошибку до получения результата.

## Как работает внутри

Реализация — `io.NodeOutput(any(values.values()))`. `any` прекращает truth-проверку после первого true, следуя порядку значений mapping.

Autogrow-входы не lazy. Short-circuit Python не гарантирует, что дорогие upstream-ноды после первого true не были вычислены системой исполнения.

## Практический пример

Подключите `PrimitiveBoolean(false)`, пустую строку и INT 0: результат false. По очереди измените их на true, `ready` и 1 — любого одного изменения достаточно для true.

Затем передайте результат в строковый `ComfySwitchNode`. Эта связка отделяет дешёвое вычисление условия от lazy-выбора данных.

## Частые ошибки и проверка

- Ожидают возврат первого непустого объекта. Выход всегда BOOLEAN.
- Принимают строку `"false"` за ложь.
- Считают autogrow lazy и рассчитывают на пропуск дорогих входов.
- Подключают tensor без явного scalar-сведения.
- Добавляют одиннадцатый вход, хотя template max равен 10.

## Ограничения и производительность

Логическая операция почти бесплатна; вычисление источников может быть дорогим. Для экономии используйте OR над простыми флагами, а его результат — для lazy switch.

Порядок входов не меняет обычный boolean-результат, но влияет на то, какое значение Python проверит первым и где возникнет ошибка неоднозначной truthiness.
