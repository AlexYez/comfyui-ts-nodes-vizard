# MOSS-Image Edit: инструкция и референсы

Кодирует инструкцию редактирования и опорные изображения для edit-LoRA MOSS-Image. Тот же тип энкодера используется отдельно для отрицательного промпта. Нода экспериментальная.

## Как пользоваться

Подключите совместимый CLIP, изображения и при необходимости VAE. `edit_format` должен совпадать со способом обучения LoRA: `ai-toolkit`, `ai-toolkit (kv_cache off)` или `Moss-Image-Edit`. Смена формата меняет схему внимания к референсам, а не переводит веса между форматами.

Для ai-toolkit текстовый энкодер видит уменьшенные референсы с площадью не более 384² пикселей. `image_strength` меняет их вклад во внимание текстового энкодера: 0 исключает этот визуальный вход, 1 оставляет обычный вес. При подключённом VAE изображения отдельно кодируются в исходном размере как reference_latents. Параметр силы не отключает эти латенты.

В формате Moss-Image-Edit с VAE изображения не подаются в визуальную часть текстового энкодера. Без VAE любой формат использует только эту визуальную часть и не добавляет опорные латенты.

## Пример

Подготовьте размеры референсов заранее, загрузите соответствующую edit-LoRA, закодируйте положительную и отрицательную инструкции с одинаковыми референсами и передайте условия в сэмплер подходящей модели.

## Ограничения

Нода не создаёт пустой LATENT и не подгоняет исходные изображения для VAE. В реализации ключи изображений сортируются как строки: при наличии `image_10` он оказывается перед `image_2`. Учитывайте это при сопоставлении нескольких референсов с номерами Picture. Отключение KV-cache заставляет пересчитывать референсы на шагах и может увеличить время генерации.

## Входы и настройки

Снимок ComfyUI 0.43.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `clip` | `CLIP` | да | соединение / значение без фиксированного default |
| `prompt` | `STRING` | да | соединение / значение без фиксированного default |
| `edit_format` | `COMBO` | да | варианты: ai-toolkit, ai-toolkit (kv_cache off), Moss-Image-Edit |
| `images` | `COMFY_AUTOGROW_V3` | да | префикс: image_ |
| `images → image` | `IMAGE` | да | соединение / значение без фиксированного default |
| `image_strength` | `FLOAT` | да | по умолчанию: 1.0; минимум: 0.0; максимум: 100.0; шаг: 0.05 |
| `vae` | `VAE` | нет | соединение / значение без фиксированного default |

## Официальные примеры подключения

В закреплённом пакете [workflow-templates-json 0.1.123](https://pypi.org/project/comfyui-workflow-templates-json/0.1.123/) найдено 1 вхождений. Примеры сохранённых связей:

- `image_moss_image_edit.json`, подграф «main»: входы от `CLIPLoader`, `ImageScaleToTotalPixels`, `VAELoader`; выходы к `KSampler`.

Это автоматическая сверка сохранённых соединений, не запуск и не ручная проверка всех сценариев. Внешние входы и переключатели подграфа могут менять путь выполнения.
