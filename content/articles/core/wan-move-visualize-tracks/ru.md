# WanMoveVisualizeTracks

## Назначение
Нода рисует Wan Move trajectories поверх кадров для проверки пути и visibility до генерации.
## Место в графе
Подайте source frames и optional TRACKS. Выход предназначен для просмотра/сохранения, не для обязательного model conditioning.
## Входы
Line resolution 1–1024, circle size 1–128, opacity 0–1 и line width 1–128.

`line_resolution` означает глубину истории polyline в кадрах, а не пространственное разрешение. `circle_size` и `line_width` измеряются в пикселях итогового изображения. Opacity применяется к circles и градиентным линиям при alpha blending.
## Pass-through
Если tracks отсутствует, возвращается исходный `images` без копии.
## Подготовка
Path и visibility получают leading batch axis; images умножаются на 255 перед PIL-отрисовкой.

Внутренняя функция ожидает track path вида `[B,T,N,2]` и visibility `[B,T,N]`. Нода добавляет `B=1` к обычному объекту `TRACKS`. Координаты используются непосредственно как пиксельные, без clamp к ширине и высоте.
## Повтор кадров
Если число images отличается от T, `repeat_count=T//images_count`, затем batch повторяется. Остаток не дополняется.
## Рисование
Внутренняя функция строит circles и polyline overlays с alpha blending; visibility определяет, какие точки участвуют.

Для каждого видимого track рисуется круг текущей позиции. Линия использует позиции от `max(t-line_resolution,0)` до текущего кадра и отдельный цвет, выбранный по индексу track. Скрытая текущая точка не добавляет круг и новую polyline.
## Выход
PIL frames превращаются `to_tensor`, затем BCHW→BHWC float и переносятся на intermediate device.

Преобразование через `uint8` PIL квантует визуализированный результат до 256 уровней на канал. Поэтому выход предназначен для диагностики, а не как прозрачный pass-through для дальнейшей высокоточной обработки. Только ветвь без tracks возвращает исходный tensor как есть.
## Ограничения
Если T не кратно image batch и больше него, integer repeat может оставить недостаточно кадров. При T меньше batch repeat_count=0 создаёт пустой input.
## Совместимость и источники
Проверено по ComfyUI 0.32.0. Edge поведения repeat зафиксировано; визуальная сверка не выполнялась.
