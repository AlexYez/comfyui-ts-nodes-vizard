# Generate Text V2: текст с несколькими медиавходами

Генерирует текст локальным совместимым энкодером и раздельно возвращает generated_text и thinking. В V2 можно подключать несколько изображений, видеопакетов и аудиозаписей.

## Подключение и пример

Подайте CLIP языковой модели, запрос и нужные медиа. Изображения из пакетов разворачиваются в отдельные картинки, видео остаются последовательностями. sampling_mode on открывает температуру, top-k/top-p/min-p, штрафы и seed; off отключает случайную выборку. max_length ограничивает ответ.

Для описания нескольких кадров укажите в запросе, что сравнивать, и проверьте фактический порядок входов. system_prompt применяется только с use_default_template. MTP влияет лишь при наличии соответствующих весов, а thinking зависит от возможностей модели.

## Ограничения

Множество портов не означает, что конкретная модель умеет одновременно понимать звук, видео и изображения. Незакрытое рассуждение при исчерпании лимита может оставить основной текст пустым. Ни seed, ни temperature не гарантируют фактической точности описания или одинакового ответа после смены рантайма.

## Входы и настройки

Снимок ComfyUI 0.45.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `clip` | `CLIP` | да | соединение / значение без фиксированного default |
| `prompt` | `STRING` | да | по умолчанию:  |
| `max_length` | `INT` | да | по умолчанию: 512; минимум: 1; максимум: 32768 |
| `sampling_mode` | `COMFY_DYNAMICCOMBO_V3` | да | режимы: on, off |
| `sampling_mode=on → temperature` | `FLOAT` | да | по умолчанию: 0.7; минимум: 0.01; максимум: 2.0; шаг: 1e-06 |
| `sampling_mode=on → top_k` | `INT` | да | по умолчанию: 64; минимум: 0; максимум: 1000 |
| `sampling_mode=on → top_p` | `FLOAT` | да | по умолчанию: 0.95; минимум: 0.0; максимум: 1.0; шаг: 0.01 |
| `sampling_mode=on → min_p` | `FLOAT` | да | по умолчанию: 0.05; минимум: 0.0; максимум: 1.0; шаг: 0.01 |
| `sampling_mode=on → repetition_penalty` | `FLOAT` | да | по умолчанию: 1.05; минимум: 0.0; максимум: 5.0; шаг: 0.01 |
| `sampling_mode=on → presence_penalty` | `FLOAT` | да | по умолчанию: 0.0; минимум: 0.0; максимум: 5.0; шаг: 0.01 |
| `sampling_mode=on → seed` | `INT` | да | по умолчанию: 0; минимум: 0; максимум: 18446744073709551615 |
| `images` | `COMFY_AUTOGROW_V3` | нет | входы: image1 … image50 |
| `images → image` | `IMAGE` | да | соединение / значение без фиксированного default |
| `videos` | `COMFY_AUTOGROW_V3` | нет | входы: video1 … video100 |
| `videos → video` | `IMAGE` | да | соединение / значение без фиксированного default |
| `audios` | `COMFY_AUTOGROW_V3` | нет | входы: audio1 … audio100 |
| `audios → audio` | `AUDIO` | да | соединение / значение без фиксированного default |
| `thinking` | `BOOLEAN` | нет | по умолчанию: false |
| `use_default_template` | `BOOLEAN` | нет | по умолчанию: true |
| `mtp` | `COMBO` | нет | по умолчанию: auto; варианты: auto, off, 2, 3, 4, 5, tree2s1, tree2s2, tree3s1, tree4s1m8 |
| `system_prompt` | `STRING` | нет | соединение / значение без фиксированного default |
