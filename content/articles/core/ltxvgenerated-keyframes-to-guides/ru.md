# LTXV Generated Keyframes to Guides: закрепление кадров следующего этапа

Использует извлечённые generated keyframes как guides на новом video-latent. В отличие от повторного Add Generated Keyframes предназначена для закрепления ранее полученного содержания.

## Как пользоваться

Нужен выход keyframes из Separate с сохранёнными индексами, очищенные positive/negative и целевой latent с batch = 1. При изменении длины ролика позиции масштабируются к той же относительной точке времени; override_frame_indices заменяет их явно. При одинаковом пространственном размере используются latent напрямую, иначе кадры декодируются по одному и перекодируются после изменения размера.

## Пример подключения

Отделите кадры после первого sampler, увеличьте длительность или разрешение основного ролика и добавьте их через эту ноду. Начните со strength = 1. Подключите все обновлённые выходы к следующему этапу, а перед окончательным декодированием уберите служебные guides штатным способом.

## Ограничения и частые ошибки

Strength ниже 1 ослабляет закрепление; не считайте любой режим побитным сохранением кадра. Batch больше одного не поддерживается. Нельзя передать произвольный latent без generated_keyframe_indices. Не используйте conditioning, в котором ещё остались неотделённые generated keyframes.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `positive` | `CONDITIONING` | да | соединение / значение без фиксированного default |
| `negative` | `CONDITIONING` | да | соединение / значение без фиксированного default |
| `vae` | `VAE` | да | соединение / значение без фиксированного default |
| `latent` | `LATENT` | да | соединение / значение без фиксированного default |
| `keyframes` | `LATENT` | да | соединение / значение без фиксированного default |
| `strength` | `FLOAT` | да | по умолчанию: 1.0; минимум: 0.0; максимум: 10.0; шаг: 0.01 |
| `override_frame_indices` | `STRING` | нет | по умолчанию:  |
