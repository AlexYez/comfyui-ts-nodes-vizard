# Create Camera Info: камера для 3D-рендера

Создаёт `LOAD3D_CAMERA` для совместимых 3D-нод в правой системе координат с вертикальной осью Y. Не генерирует изображение и не оценивает камеру по фотографии. В ComfyUI 0.43.0 реализация находится в `comfy_extras.nodes_camera`, а не в прежнем модуле Gaussian Splat.

## Как пользоваться

`orbit` задаёт yaw, pitch и distance вокруг target. `look_at` задаёт мировую позицию с направлением на target. `quaternion` задаёт позицию и вращение камеры в соглашении three.js, где локальное направление взгляда — −Z; quaternion нормализуется вспомогательной функцией.

`fov` — вертикальный угол обзора, `zoom` меняет масштаб без перемещения, `camera_type` выбирает perspective или orthographic. В quaternion-режиме target и roll не применяются. В orbit/look_at roll поворачивает камеру вокруг оси взгляда. Необязательный `camera_info_state` присутствует в схеме, но текущий execute его не использует.

## Пример

Подключите orbit-камеру к Render Splat. Меняйте yaw по последовательности углов для облёта вокруг модели, удерживая target в её центре. Если объект расположен не в начале координат, настройте target, иначе орбита будет проходить вокруг другой точки.

## Ограничения

Тип выхода не гарантирует, что любой сторонний 3D-рендерер использует те же координаты и проекцию. При переносе между версиями учитывайте перемещение Python-модуля: это подтверждённый перенос того же официального ID, не повод сопоставлять стороннюю одноимённую ноду по названию.

## Входы и настройки

Снимок ComfyUI 0.43.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `mode` | `COMFY_DYNAMICCOMBO_V3` | да | режимы: orbit, look_at, quaternion |
| `mode=orbit → yaw` | `FLOAT` | да | по умолчанию: 35.0; минимум: -360.0; максимум: 360.0; шаг: 1.0 |
| `mode=orbit → pitch` | `FLOAT` | да | по умолчанию: 30.0; минимум: -89.0; максимум: 89.0; шаг: 1.0 |
| `mode=orbit → distance` | `FLOAT` | да | по умолчанию: 4.0; минимум: 0.01; максимум: 1000.0; шаг: 0.01 |
| `mode=look_at → position_x` | `FLOAT` | да | по умолчанию: 4.0; минимум: -1000.0; максимум: 1000.0; шаг: 0.01 |
| `mode=look_at → position_y` | `FLOAT` | да | по умолчанию: 4.0; минимум: -1000.0; максимум: 1000.0; шаг: 0.01 |
| `mode=look_at → position_z` | `FLOAT` | да | по умолчанию: 4.0; минимум: -1000.0; максимум: 1000.0; шаг: 0.01 |
| `mode=quaternion → position_x` | `FLOAT` | да | по умолчанию: 4.0; минимум: -1000.0; максимум: 1000.0; шаг: 0.01 |
| `mode=quaternion → position_y` | `FLOAT` | да | по умолчанию: 4.0; минимум: -1000.0; максимум: 1000.0; шаг: 0.01 |
| `mode=quaternion → position_z` | `FLOAT` | да | по умолчанию: 4.0; минимум: -1000.0; максимум: 1000.0; шаг: 0.01 |
| `mode=quaternion → quat_x` | `FLOAT` | да | по умолчанию: 0.0; минимум: -1.0; максимум: 1.0; шаг: 0.001 |
| `mode=quaternion → quat_y` | `FLOAT` | да | по умолчанию: 0.0; минимум: -1.0; максимум: 1.0; шаг: 0.001 |
| `mode=quaternion → quat_z` | `FLOAT` | да | по умолчанию: 0.0; минимум: -1.0; максимум: 1.0; шаг: 0.001 |
| `mode=quaternion → quat_w` | `FLOAT` | да | по умолчанию: 1.0; минимум: -1.0; максимум: 1.0; шаг: 0.001 |
| `target_x` | `FLOAT` | да | по умолчанию: 0.0; минимум: -1000.0; максимум: 1000.0; шаг: 0.01 |
| `target_y` | `FLOAT` | да | по умолчанию: 0.0; минимум: -1000.0; максимум: 1000.0; шаг: 0.01 |
| `target_z` | `FLOAT` | да | по умолчанию: 0.0; минимум: -1000.0; максимум: 1000.0; шаг: 0.01 |
| `roll` | `FLOAT` | да | по умолчанию: 0.0; минимум: -180.0; максимум: 180.0; шаг: 1.0 |
| `fov` | `FLOAT` | да | по умолчанию: 35.0; минимум: 1.0; максимум: 120.0; шаг: 1.0 |
| `zoom` | `FLOAT` | да | по умолчанию: 1.0; минимум: 0.01; максимум: 100.0; шаг: 0.01 |
| `camera_type` | `COMBO` | да | варианты: perspective, orthographic |
| `camera_info_state` | `CAMERA_INFO_STATE` | нет | соединение / значение без фиксированного default |
