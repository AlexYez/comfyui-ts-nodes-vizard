# Запекание текстуры из нескольких ракурсов

Проецирует изображения на UV-развёртку mesh и возвращает base_color и маску confidence. Позволяет отредактировать виды Render Mesh и перенести их цвет обратно на поверхность.

## Подключение и пример

Используйте ту же UV-развёрнутую сетку и те же камеры, которыми были получены виды. Изображений должно быть ровно столько, сколько камер, в том же порядке. Пропорции кадров должны соответствовать рендеру. Выход base_color подайте в Apply Texture to Mesh. resolution 0 выбирает размер текущей текстуры или 2048 при её отсутствии.

blend_exponent повышает вес фронтальных ракурсов: большие значения дают более резкие переходы между видами. mask ограничивает проекцию отредактированными областями; одиночная маска применяется ко всем видам.

## Ограничения

Нужны UV и грани; из пакета mesh используется первый элемент. Невидимые участки сохраняют старую текстуру или цвет вершин, а fill_unseen заменяет их разрастанием видимых цветов. confidence показывает наблюдаемость, не достоверность восстановленной детали. Преобразование модели в viewer может нарушить совмещение. Большие текстуры требуют значительной памяти.

## Входы и настройки

Снимок ComfyUI 0.45.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `mesh` | `MESH` | да | соединение / значение без фиксированного default |
| `images` | `IMAGE` | да | соединение / значение без фиксированного default |
| `resolution` | `INT` | да | по умолчанию: 0; минимум: 0; максимум: 8192; шаг: 64 |
| `blend_exponent` | `FLOAT` | да | по умолчанию: 4.0; минимум: 0.0; максимум: 32.0; шаг: 0.5 |
| `fill_unseen` | `BOOLEAN` | да | по умолчанию: false |
| `camera_info` | `LOAD3D_CAMERA` | нет | соединение / значение без фиксированного default |
| `mask` | `MASK` | нет | соединение / значение без фиксированного default |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `base_color` | `IMAGE` | нет |
| `confidence` | `MASK` | нет |
