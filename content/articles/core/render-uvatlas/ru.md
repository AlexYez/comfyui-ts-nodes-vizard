# Render UV Atlas: просмотр UV-островов

Рисует двумерную раскладку UV сетки как IMAGE. Помогает осмотреть острова и упаковку перед запеканием, не создавая новую развёртку.

## Как пользоваться

mesh должен уже содержать UV; resolution управляет разрешением диагностической картинки. Цвета и линии этого изображения предназначены для просмотра раскладки, а не для использования как готовый base_color материала.

## Пример подключения

Подключите выход UnwrapMesh к RenderUVAtlas и далее к PreviewImage. Сравните разные segmenter и padding при одном resolution. Если вместо связных островов видны отдельные треугольники, проверьте исходную связность и параметр weld_distance в UnwrapMesh.

## Ограничения и частые ошибки

Для batched-тензоров показывается только первый элемент. Без UV нода завершится ошибкой. Красиво расположенные острова ещё не гарантируют отсутствие растяжения и совпадение с уже запечённой текстурой. Финальную проверку выполните на рендере того же mesh с материалом.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `mesh` | `MESH` | да | соединение / значение без фиксированного default |
| `resolution` | `INT` | да | по умолчанию: 1024; минимум: 64; максимум: 4096; шаг: 64 |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `image` | `IMAGE` | нет |
