# SaveLatent: сохранить tensor LATENT в файл

## Что делает нода

`SaveLatent` записывает численный tensor `samples` в файл с расширением `.latent`. Внутри используется формат safetensors: tensor хранится под ключом `latent_tensor`, а пустой tensor `latent_format_version_0` служит маркером современного масштаба.

Нода не сериализует весь словарь LATENT. `noise_mask`, `batch_index` и пользовательские поля на диск не попадают. Prompt и `extra_pnginfo` записываются отдельно как строковые metadata safetensors, если ComfyUI запущен без `--disable-metadata`.

После записи нода возвращает исходный объект LATENT в выход `samples`. Поэтому текущий граф может продолжить работу со всеми его полями, хотя повторная загрузка файла восстановит только численные samples.

## Когда использовать и когда не использовать

Сохраняйте LATENT, когда нужно перенести промежуточный tensor в другой сеанс, сравнить несколько продолжений sampling или передать данные вместе с точной версией модели и VAE. Файл полезен до декодирования, если важны исходные латентные значения.

Для просмотра или публикации изображения используйте `SaveImage`: `.latent` не является картинкой и не открывается обычным редактором. Для полного восстановления inpaint- или batch-контракта одного файла недостаточно, потому что контейнерные поля не сохраняются.

Не считайте два LATENT совместимыми только из-за одинакового расширения. Получателю нужны сведения о модели, VAE, форме каналов и версии pipeline; prompt metadata сами по себе этого не гарантируют.

## Короткий рецепт подключения

1. Подключите нужный `LATENT` к входу `samples`.
2. Оставьте `filename_prefix = latents/ComfyUI` или задайте отдельный путь внутри output, например `latents/wizard/session-a`.
3. Выполните граф и найдите файл вида `session-a_00001_.latent` в созданной подпапке.
4. Для `LoadLatent` скопируйте нужный файл в корень `input`; сохранённый output-файл не появляется в его combo автоматически.
5. Запишите рядом версию модели и VAE, если файл предназначен для другого графа.

Fragment «Сохранить внешний LATENT в output/latents» содержит одну `SaveLatent`. Его выход остаётся свободным для продолжения текущей ветки. Полного workflow нет.

## Входы, выходы и параметры

`samples` — обязательный `LATENT`. `filename_prefix` — строка с default `latents/ComfyUI`. Скрытые входы `prompt: PROMPT` и `extra_pnginfo: EXTRA_PNGINFO` ComfyUI передаёт автоматически.

Нода помечена как `OUTPUT_NODE = True`, но runtime одновременно объявляет выход `LATENT` с именем `samples`. Результат выполнения содержит UI-описание файла — `filename`, `subfolder`, `type: output` — и исходный LATENT для следующей ноды.

Файл называется `<prefix>_<counter:05>_.latent`. Helper вычисляет следующий счётчик по содержимому подпапки и создаёт её при необходимости. Попытка вывести путь за пределы output отклоняется до записи.

На диск передаётся `samples["samples"].contiguous()` без преобразования dtype. Остальные ключи словаря не входят в payload.

## Типовые связки

`KSampler` → `SaveLatent` фиксирует промежуточный или финальный LATENT. Выход `samples` можно одновременно направить в `VAEDecode`, чтобы сохранить tensor и увидеть соответствующее изображение за один запуск.

`SaveLatent` и `LoadLatent` образуют файловую пару, но между ними нет прямой связи на графе. Сначала файл создаётся в output, затем пользователь переносит его в input и выбирает в другом запуске.

Для inpaint после загрузки придётся заново проверить или построить `noise_mask`. Файл SaveLatent содержит только tensor и не переносит маску из исходного контейнера.

## Практический пример

В 496 официальных workflow-графах пакета 0.1.42 `SaveLatent` не найден: просмотрены root nodes и все subgraphs. Минимальный рецепт Wizard основан на точном runtime-контракте и исходном коде.

Изолированная exact-source проба передала не contiguous `float16` tensor вместе с `noise_mask`, `batch_index` и пользовательским полем. Файл содержал только `latent_tensor` в `float16` и `latent_format_version_0`; сохранённый tensor стал contiguous и сохранил значения.

В metadata попали JSON-строки `prompt` и `workflow`. При включённом `disable_metadata` раздел metadata отсутствовал. Метод вернул тот же исходный словарь, а protected path helper отклонил `../escape`. Проба работала в временной папке через минимальный совместимый safetensors-кодек; это не полный запуск fragment в ComfyUI.

## Частые ошибки и способы проверки

**После загрузки исчезла `noise_mask`.** Это штатный контракт 0.32.0: Save записывает только `samples["samples"]`. Сохраняйте параметры маски отдельно и восстанавливайте её в новом графе.

**Файл не появился в `LoadLatent`.** Save пишет в output, а Load перечисляет `.latent` только в корне input. Скопируйте файл и обновите интерфейс или ноду.

**Ожидалось изображение.** `.latent` — safetensors-контейнер, а не PNG или видео. Для визуальной проверки подключите выход SaveLatent к `VAEDecode` и затем к preview или save image.

**Следующий запуск создал новый номер.** Нода не перезаписывает совпадающий prefix, а увеличивает счётчик. Проверьте точное имя в UI-результате.

**Путь с `..` завершился ошибкой.** Helper запрещает запись вне output. Используйте относительную подпапку без выхода к родительскому каталогу.

**Файл открылся, но decode неверен.** Tensor сохранён без VAE и описания latent-формата модели. Возьмите совместимые компоненты из того же pipeline.

## Производительность и внутреннее поведение

Вызов `.contiguous()` может создать полную копию tensor перед записью. Для большого video latent это добавляет память, равную размеру samples, если исходное размещение было non-contiguous.

Запись safetensors синхронно передаёт весь tensor на файловую систему. Скорость зависит от размера latent и накопителя; output-node не выполняет сжатие изображений и не уменьшает форму.

Prompt и каждое значение `extra_pnginfo` проходят через `json.dumps`. Эти metadata обычно малы по сравнению с tensor. Выходной LATENT не копируется: downstream получает исходный объект, а не данные, перечитанные с диска.

## Совместимость, изменения и устаревание

Статья проверена для ComfyUI `0.32.0`, frontend `1.48.7`, модуль `nodes`. Runtime fingerprint: `sha256:dc2ac40f84ee6776529071b553054d613b48f4d59f4a6658bcbe42b003a8f061`.

Нода не помечена как experimental, deprecated или API node. В Node Replacement API для неё нет замены. Маркер `latent_format_version_0` важен для парной логики `LoadLatent`; изменение ключа или масштаба потребует обновить обе статьи.

Embedded docs 0.5.9 пишут о сохранении «структуры latent data» и перечисляют UI-результат, но не объясняют LATENT passthrough и потерю контейнерных полей на диске. Здесь эти ограничения взяты из исполняемого кода.

## Связанные ноды и источники

`LoadLatent` читает `.latent` из input и применяет legacy-масштаб только к файлам без маркера. `VAEDecode` показывает сохранённые samples через совместимый VAE. `SaveImage` нужен для обычного изображения, а не для промежуточного tensor.
