# Trim Text

## 1. Назначение

`StringTrim` удаляет пробельные символы с обоих краёв строки, только слева или только справа. Пробелы внутри текста остаются.

## 2. Место в графе

Ноду полезно ставить после чтения файла, ответа API или ручного многострочного поля, до сравнения и объединения строк.

## 3. Входы

`string` — исходный текст. `mode` выбирает `Both`, `Left` или `Right`. Схема не объявляет отдельного default для combo.

## 4. Выход

Выход — новый `STRING`. Если строка состоит только из распознаваемых Python пробельных символов, результат выбранной полной очистки будет пустым.

## 5. Какие символы удаляются

Режимы вызывают `.strip()`, `.lstrip()` и `.rstrip()` без аргумента. Поэтому удаляется не только ASCII-пробел, но и табуляция, перевод строки, неразрывный пробел и другие Unicode-символы, которые Python считает whitespace.

## 6. Что остаётся без изменений

Нода не сжимает повторные пробелы внутри строки, не удаляет пунктуацию и не нормализует переносы. `"  a  b  "` в режиме `Both` превращается в `"a  b"`.

## 7. Проверенный пример

Рецепт очищает обе стороны строки с табуляцией и переводом строки. Probe отдельно проверяет `Both`, `Left`, `Right`, U+00A0 и U+2003. Официальных `StringTrim` в workflow-пакете 0.1.42 нет.

## 8. Ошибки и диагностика

Если видимый отступ не исчез, определите его кодовую точку: это может быть не whitespace по правилам Python. Если исчезло больше ожидаемого, проверьте переносы на выбранном краю. Для удаления конкретного символа используйте буквальную или регулярную замену.

## 9. Ограничения и производительность

Нода обрабатывает только края и возвращает новую строку. Она не предоставляет поле со своим набором удаляемых символов. Стоимость для обычного текста мала.
