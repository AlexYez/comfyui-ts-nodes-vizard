# Pixal3D MultiView Conditioning: согласованные ракурсы объекта

Собирает визуальное conditioning Pixal3D из одного или нескольких видов одного объекта. Ракурсы привязаны к фиксированным направлениям, а не определяются автоматически по изображениям.

## Как пользоваться

Виды front, left, back и right соответствуют углам 0, 90, 180 и 270 градусов. Нужен хотя бы один вид; первый подключённый становится опорным. fov задаёт общий горизонтальный угол обзора в градусах, по умолчанию 20°. Картинки приводятся к квадрату 1024; ожидается согласованный масштаб объекта с небольшим полем вокруг него.

## Пример подключения

Подготовьте четыре рендера одного объекта с одинаковой камерой и масштабом, разместив объект на чёрном или прозрачном фоне. Подключите их согласно направлениям. Сначала сравните форму с одним front, затем добавьте боковой и задний виды: так проще найти несогласованный ракурс.

## Ограничения и частые ошибки

Независимый crop каждого вида может нарушить масштаб и проекцию. Разные объекты или перспективы не превращаются в согласованную фотограмметрию. Размер batch задаётся первым входом; более короткие batch остальных видов повторяются циклически, поэтому следите за соответствием объектов.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `clip_vision_model` | `CLIP_VISION` | да | соединение / значение без фиксированного default |
| `fov` | `FLOAT` | да | по умолчанию: 20.0; минимум: 1.0; максимум: 170.0; шаг: 0.01 |
| `front` | `IMAGE` | нет | соединение / значение без фиксированного default |
| `left` | `IMAGE` | нет | соединение / значение без фиксированного default |
| `back` | `IMAGE` | нет | соединение / значение без фиксированного default |
| `right` | `IMAGE` | нет | соединение / значение без фиксированного default |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `positive` | `CONDITIONING` | нет |
| `negative` | `CONDITIONING` | нет |
