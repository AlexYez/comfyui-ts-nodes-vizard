# Load Image (as Mask): маска из alpha, red, green или blue

## Что делает нода

`LoadImageMask` читает файл из входной папки ComfyUI и превращает один его канал в `MASK`. Можно выбрать `alpha`, `red`, `green` или `blue`.

Это не загрузчик пары «изображение плюс маска»: у ноды один выход, и он всегда имеет тип `MASK`. Если нужен сам `IMAGE`, добавьте `LoadImage` или используйте его два выхода, когда маска уже хранится в прозрачности.

## Место в графе

Нода стоит в начале mask-ветки. Её выход подключают к inpaint, ControlNet, композитингу, `SetLatentNoiseMask` или сначала к `MaskToImage`, чтобы увидеть полярность и края.

Она полезна для отдельного чёрно-белого файла маски и для изображений, где нужная разметка записана в одном RGB-канале. Если нужна только прозрачность того же файла, `LoadImage` уже возвращает её вторым выходом, поэтому дублировать чтение не обязательно.

## Входы

`image` — файл из каталога `input` и дополнительных разрешённых входных путей ComfyUI. Сам файл в workflow не встраивается: на другом компьютере его придётся предоставить отдельно.

`channel` принимает ровно четыре значения:

| Значение | Что попадает в маску |
| --- | --- |
| `alpha` | Инвертированный alpha: прозрачное становится белым (`1`), непрозрачное — чёрным (`0`). |
| `red` | Нормализованное значение красного канала без инверсии. |
| `green` | Нормализованное значение зелёного канала без инверсии. |
| `blue` | Нормализованное значение синего канала без инверсии. |

## Выход

`MASK` содержит значения с пакетным измерением. Для RGB-канала размер соответствует декодированному изображению или кадрам. Канал клонируется из RGB-тензора, поэтому дальнейшие ноды получают отдельный tensor маски.

Для `alpha` используется маска, которую готовит базовый `LoadImage`. В ComfyUI 0.32.0 файл без alpha даёт нулевую маску размером `64 × 64`, а не маску полного размера изображения. Это безопасное значение «ничего не выделено», но его размер может удивить следующую ноду.

## Как работает

`LoadImageMask` наследует декодирование у `LoadImage`. Сначала ComfyUI пробует общий файловый/video-путь; для animated WebP остаётся отдельный путь через Pillow. Кадры переводятся в нормализованный RGB, а alpha хранится отдельно.

При выборе `alpha` нода сразу возвращает подготовленную базовым загрузчиком маску. Для `red`, `green` или `blue` берётся соответствующий индекс последней оси RGB-тензора. Цвета не смешиваются в яркость, порог не применяется.

Изменение байтов файла обнаруживается по SHA-256, поэтому граф не должен повторно использовать старую маску после замены изображения под тем же именем.

## Параметры канала

Белый цвет обычно означает активную область, но смысл задаёт следующая нода. Для RGB маска повторяет яркость выбранного канала: красный пиксель `255` даёт значение `1`, красный `0` — значение `0`.

У alpha полярность иная по происхождению: код вычисляет `1 - alpha`. Поэтому полностью прозрачное место становится активным. Не применяйте автоматическую инверсию только потому, что в названии выбран alpha; сначала посмотрите результат.

## Проверенный пример подключения

Фрагмент «Проверить маску из выбранного канала» соединяет `LoadImageMask` с `MaskToImage`, затем с `PreviewImage`. Выберите файл и последовательно проверьте `alpha`, `red`, `green`, `blue`: preview сразу показывает, какой канал совпадает с требуемой областью.

Поиск по 496 официальным workflow из пакета 0.1.42 не нашёл ни одного экземпляра `LoadImageMask`. Поэтому этот диагностический фрагмент основан на точной схеме и реализации ноды, но не выдаётся за официальный кейс и пока не отмечен как исполненный.

## Частые ошибки

**Alpha выделяет фон, а не объект.** Это ожидаемая инверсия: прозрачное белое, непрозрачное чёрное. Инвертируйте маску, если следующей ноде нужен объект.

**Красный канал кажется чёрным.** В выбранном файле разметка может находиться в green/blue либо быть записана как общая яркость. Проверьте каждый канал через preview.

**У файла без прозрачности alpha-маска неожиданно `64 × 64`.** Выберите RGB-канал или подготовьте явный файл маски. В версии 0.32.0 отсутствие alpha обрабатывается нулевым placeholder такого размера.

**Workflow открыт на другом компьютере, но файла нет.** Скопируйте изображение в входную папку и заново выберите его; JSON хранит имя, а не содержимое.

**Маска и исходный IMAGE расходятся по кадрам.** Убедитесь, что оба загрузчика читают один и тот же файл и одинаковый набор кадров. Для alpha проще взять оба выхода одного `LoadImage`.

## Ограничения и производительность

Даже если нужен один канал, базовый загрузчик декодирует изображение или последовательность кадров и формирует RGB-тензор. Для больших анимаций и видео это заметнее, чем простая выборка канала.

Нода не выполняет threshold, blur, grow или feather. Такие операции требуют отдельных mask-нод. Она также не гарантирует смысл маски: значение канала переводится технически точно, но только автор файла знает, что в нём закодировано.
