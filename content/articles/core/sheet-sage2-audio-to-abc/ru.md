# SheetSage2 Audio to ABC: нотный план из записи

Преобразует входное AUDIO в музыкальную запись ABC с помощью совместимого аудио-энкодера. Результат пригоден как нотное условие для YuE2, но не является новой звуковой дорожкой.

## Как пользоваться

audio_encoder получает модель типа AUDIO_ENCODER, audio — waveform вместе с частотой дискретизации. mode = melody запрашивает мелодию, full — более полную запись. Реализация передаёт звук и его sample_rate в generate_abc и возвращает список строк STRING.

## Пример подключения

Загрузите короткую музыкальную запись, подключите энкодер SheetSage2 и выберите melody. Просмотрите текст ABC; при необходимости выберите одну строку через GetItemFromList. Подайте её в YuE2GenerateMusic с согласованным mode и новым описанием инструментов.

## Ограничения и частые ошибки

Не путайте список STRING с единственной строкой: дальнейшие ноды могут выполняться отдельно для каждого элемента списка. Это распознавание музыкальной структуры, а не безошибочная транскрипция и не извлечение вокальной дорожки. Проверяйте ноты и ритм на сложной полифонии; используйте записи, на обработку которых у вас есть права.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `audio_encoder` | `AUDIO_ENCODER` | да | соединение / значение без фиксированного default |
| `audio` | `AUDIO` | да | соединение / значение без фиксированного default |
| `mode` | `COMBO` | да | варианты: melody, full |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `abc` | `STRING` | да |

## Проверенные источники и кейсы

В audio_yue2_music_cover выбран melody. ABC проходит через PreviewAny к YuE2GenerateMusic: исходная запись задаёт музыкальный план, а описание и слова следующего этапа управляют новым результатом.

В официальном шаблоне `audio_yue2_music_cover`: Граф: Music Cover (YuE2) (root/definitions/subgraphs/0). Входящие связи: `AudioEncoderLoader`, `SubgraphInput`. Исходящие связи: `PreviewAny`.
