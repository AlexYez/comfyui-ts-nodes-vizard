# Trellis2 Upsample Stage: переход к более подробной форме

Готовит разреженные координаты и conditioning для следующего, более высокого разрешения Trellis2. Это переход между этапами, а не законченный upscale поверхности одной нодой.

## Как пользоваться

На вход нужен shape_latent этапа 512 и VAE формы, а также positive и negative. target_resolution выбирает целевой масштаб от 1024 до 2048. VAE помогает получить новые координаты, после чего создаётся пустой 32-канальный latent; в conditioning устанавливается режим следующего этапа. Поддерживаются и проекционные данные Pixal3D.

## Пример подключения

Сначала получите форму на этапе 512. Подайте её latent сюда, выберите 1024 и подключите обновлённые positive, negative и latent к sampler следующей модели. Сравните декодированную геометрию с исходной до перехода к текстурированию.

## Ограничения и частые ошибки

Нода не гарантирует автоматического уменьшения числа токенов под доступную VRAM. Высокое разрешение может резко увеличить память и время последующей генерации. Нельзя заменить этот переход обычным масштабированием IMAGE или mesh: здесь меняется разреженное представление модели.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `positive` | `CONDITIONING` | да | соединение / значение без фиксированного default |
| `negative` | `CONDITIONING` | да | соединение / значение без фиксированного default |
| `shape_latent` | `LATENT` | да | соединение / значение без фиксированного default |
| `vae` | `VAE` | да | соединение / значение без фиксированного default |
| `target_resolution` | `INT` | да | по умолчанию: 1024; минимум: 1024; максимум: 2048; шаг: 128 |

## Выходы
