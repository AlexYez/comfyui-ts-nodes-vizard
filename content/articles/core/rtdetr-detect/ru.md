# RTDETR_detect

## Назначение
`RTDETR_detect` запускает Real-Time Detection Transformer и возвращает рамки объектов COCO. Результат содержит координаты, размер, метку класса и score отдельно для каждого изображения batch.

## Место в графе
Подайте detection MODEL и IMAGE. BBOX можно передать в `DrawBBoxes`, SDPose или другие ноды, которые принимают bounding boxes. Сам детектор не изменяет изображение.

## Входы
`model`, `image`, `threshold`, `class_name` и `max_detections` обязательны. Runtime не задаёт min/max для threshold и max_detections; class_name выбирается из `all` и COCO_CLASSES.

## Выходы
`bboxes` — список на каждый кадр, внутри которого словари `{x,y,width,height,label,score}`. Координаты возвращаются в пространстве исходных W×H, потому что модель получает `(W,H)` вместе с входом 640×640.

## Как работает
Модель загружается на GPU. Изображения обрабатываются блоками до 32: BCHW-тензор bilinear-масштабируется до 640×640 без crop. Затем остаются detection со строго `score > threshold`, применяется class filter, сортировка по убыванию score и срез max_detections.

## Параметры
`threshold=0.5` по умолчанию. `class_name=all` отключает фильтр. `max_detections=100`; ноль вернёт пустой список, отрицательное значение из API даст Python-срез с неожиданным отбрасыванием последних элементов, потому что схема не ограничивает минимум.

## Проверенный пример
Два официальных SDPose workflow используют threshold 0,5 и класс `person`: image-вариант оставляет 1 detection, video — 2. Фрагмент повторяет первый пресет, но модельный inference не выполнялся.

## Частые ошибки
Нода ожидает COCO label indices от совместимой RT-DETR модели. Threshold равенство не проходит из-за оператора `>`. Передача другого detection MODEL может дать неверные labels или структуру результата.

## Ограничения и производительность
Каждый batch chunk масштабируется к квадрату, поэтому исходное соотношение сторон меняется на входе модели; обратное преобразование делает сама модель. Размер chunk 32 жёсткий. Большие IMAGE-batch требуют GPU-памяти.

## Совместимость и источники
Fingerprint и порты сверены с `/object_info` 0.32.0, алгоритм — `nodes_rtdetr.py`, справка — embedded-docs 0.5.9. В 512 JSON найдено два точных случая; человеческое утверждение ожидается.
