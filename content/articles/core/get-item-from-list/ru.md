# Get Item From List: один элемент списка

Выбирает один элемент из списка ComfyUI по индексу и возвращает его как отдельное значение. Помогает передать один результат дальше вместо автоматической обработки всего списка.

## Как пользоваться

list принимает список значений ANY; index — позицию. Нумерация начинается с нуля. Реализация использует Python-индексацию: -1 выбирает последний элемент, если отрицательное значение передано программно. Индекс за пределами списка вызывает ошибку, автоматического ограничения нет.

## Пример подключения

Если SheetSage2AudioToABC вернул несколько строк, подключите список сюда и задайте index = 0, чтобы выбрать первую для YuE2GenerateMusic. Проверьте выбранный текст перед генерацией. Для последнего элемента сначала убедитесь, что список не пуст.

## Ограничения и частые ошибки

Список ComfyUI и batch внутри тензора IMAGE или LATENT — разные структуры. Эта нода не вырезает кадр из tensor batch; для этого нужна соответствующая batch-нода. Не используйте фиксированный индекс без проверки, если длина списка меняется между запусками.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `list` | `*` | да | соединение / значение без фиксированного default |
| `index` | `INT` | да | по умолчанию: 0 |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `*` | `*` | нет |
