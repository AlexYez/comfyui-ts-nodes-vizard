# Unwrap Mesh UVs: развёртка поверхности

Разбивает сетку на участки, раскладывает их на плоскости и упаковывает UV-атлас. Вершины на швах дублируются, поэтому их число после операции может вырасти без добавления деталей формы.

## Как пользоваться

pec выполняет разбиение на вычислительном устройстве, adaptive — на CPU. resolution задаёт целевую плотность атласа; 0 включает подгонку по содержимому. padding оставляет промежутки между островами. weld_distance задаёт предварительное объединение близких вершин относительно размера сетки; 0 выбирает автоматический режим.

## Пример подключения

Завершите RemeshMesh и DecimateMesh, затем выполните UnwrapMesh. Посмотрите RenderUVAtlas: много отдельных треугольников вместо крупных островов может указывать на несваренные вершины. Используйте полученный mesh одновременно в запекании и последующем ApplyTextureToMesh.

## Ограничения и частые ошибки

Повторная развёртка меняет соответствие текстуры поверхности. Старая текстура может сохраниться как поле объекта, но это не означает, что она подходит новым UV. Не ставьте WeldVertices или DecimateMesh после готового запекания без пересборки UV и карт.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `mesh` | `MESH` | да | соединение / значение без фиксированного default |
| `segmenter` | `COMBO` | да | по умолчанию: pec; варианты: pec, adaptive |
| `resolution` | `INT` | да | по умолчанию: 1024; минимум: 0; максимум: 8192; шаг: 256 |
| `padding` | `INT` | да | по умолчанию: 1; минимум: 0; максимум: 16 |
| `weld_distance` | `FLOAT` | да | по умолчанию: 0.0; минимум: 0.0; максимум: 1.0; шаг: 0.0001 |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `mesh` | `MESH` | нет |
