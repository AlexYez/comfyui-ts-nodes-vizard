# SAM3_Detect

## Назначение
`SAM3_Detect` обнаруживает и сегментирует объекты SAM3 по тексту, рамкам или положительным и отрицательным точкам. За один вызов можно использовать несколько видов подсказок; маски затем объединяются или выдаются по объектам.

## Место в графе
Подайте SAM3 MODEL и IMAGE. Текстовое conditioning приходит из совместимого кодировщика CLIP, BBOX — из детектора, координаты — JSON-строками. MASK можно использовать для дорисовки, начального видеотрека или композиции.

## Входы
Обязательны `model` и `image`. Необязательны `conditioning`, `bboxes`, `positive_coords` и `negative_coords`. `threshold` принимает значения 0–1, по умолчанию 0,5; `refine_iterations` — 0–5, по умолчанию 2; `individual_masks` по умолчанию выключен.

## Выходы
Возвращаются MASK и BBOX. При `individual_masks=false` для каждого изображения получается объединённая маска H×W. При `true` маски всех обнаруженных объектов из разных кадров склеиваются по первой оси, поэтому число элементов уже не обязано совпадать с размером пакета.

## Как работает
RGB-вход билинейно масштабируется до 1008². Рамки переводятся из пиксельного формата xywh в нормализованный cxcywh, а точки из JSON — в координаты сетки 1008. Точки и рамки проходят через декодер SAM, текст — через детектор с сигмоидной оценкой и строгим сравнением `> threshold`.

## Параметры
При нулевом уточнении текстовая ветвь возвращает грубую маску после масштабирования и пороговой обработки. Большее значение вырезает область с полем 10% и повторяет работу декодера. Для точек и рамок число дополнительных проходов равно `max(0, iterations-1)`. Это разные ветви одного параметра.

## Проверенный пример
В четырёх официальных графах используются значения `[0.5,2,false]`: сегментация изображения, сегментация видео, дорисовка видео VOID и дорисовка Wan VACE. Фрагмент повторяет вариант с текстовым conditioning без вымышленных весов модели.

## Частые ошибки
Некорректный JSON вызывает исключение. Без подсказок нода вернёт пустые маски и рамки. Покадровый список BBOX, который короче пакета, дополняется последним элементом; пустой список не создаёт рамочных подсказок.

## Ограничения и производительность
Каждый кадр обрабатывается отдельно, и каждая текстовая категория отдельно запускает детектор. Уточнение добавляет проходы декодера. При `individual_masks=true` форма выхода больше не хранит явную границу между кадрами.

## Совместимость и источники
Схема и отпечаток сверены с `/object_info` 0.32.0, ветви подсказок и уточнения — с `nodes_sam3.py`, справка — с embedded-docs 0.5.9. Четыре официальных случая проверены; модель не запускалась, человеческое утверждение ещё не получено.
