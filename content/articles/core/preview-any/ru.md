# PreviewAny

## Назначение

`PreviewAny` превращает входное значение в текст, показывает его на ноде и одновременно выдаёт через порт `STRING`.

## Место в графе

Подключайте ноду к промежуточному выходу для диагностики. Поскольку `PreviewAny` отмечена как выходная нода, она выполняется как конечная точка графа.

## Вход

Вход `source` имеет универсальный тип `*`. Он принимает строку, число, логическое значение, словарь, список, тензор и другие объекты, если соединение разрешено графом.

## Выход

Выход `STRING` совпадает с текстом в интерфейсе. Для `None` это `"None"`; строки остаются без кавычек; числа и `bool` проходят через `str`.

## Как сериализуется значение

Для остальных объектов нода сначала вызывает `json.dumps` с отступом 4. Если JSON не поддерживает объект, используется `str`. Если и это не удалось, возвращается сообщение о невозможности сериализации.

## Тензоры

Перед преобразованием нода временно задаёт PyTorch `edgeitems=6`, поэтому строка большого тензора показывает края и сокращает середину. Затем вызывается `torch.set_printoptions()` без аргументов; это сбрасывает параметры к значениям PyTorch по умолчанию, а не восстанавливает произвольные прежние настройки.

## Проверенный пример

В `basic_datatype_conversion` несколько `PreviewAny` показывают результаты преобразований. В `image_hidream_o1` текст проходит через ноду дальше в `CLIPTextEncode`, поэтому выход можно использовать не только для просмотра.

## Частые ошибки

Текстовое представление не сохраняет исходный тип. Не подключайте выход обратно к порту числа или тензора без явного преобразования. Большой сериализуемый объект может создать длинный ответ интерфейса.

## Ограничения и производительность

JSON-сериализация и `str(tensor)` выполняются на серверной стороне. Нода не сохраняет данные в файл и не ведёт журнал. В наборе шаблонов 0.1.42 найдено 129 экземпляров, включая облачные; статья описывает только локальное поведение самой ноды.

## Совместимость и источники

Проверены ComfyUI 0.32.0, frontend 1.48.7, встроенная документация 0.5.9 и шаблоны 0.1.42. Статья ждёт человеческого утверждения.
