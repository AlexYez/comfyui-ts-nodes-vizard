# Compare Text

## 1. Назначение

`StringCompare` сравнивает две строки и возвращает `BOOLEAN`. Режим `Equal` проверяет полное равенство, `Starts With` — начало `string_a`, `Ends With` — конец.

## 2. Место в графе

Нода подходит для управляющего условия после получения текста: выбора ветви по префиксу, проверки ожидаемого ответа или расширения файла. Она не маршрутизирует граф сама; выход нужно подключить к ноде, принимающей `BOOLEAN`.

## 3. Входы

`string_a` — проверяемая строка, `string_b` — образец. `mode` имеет ровно три значения. `case_sensitive` по умолчанию `true`; при `false` код сначала вызывает `.lower()` для обеих строк.

## 4. Выход

Выход — одно логическое значение. Сами строки не изменяются и не возвращаются.

## 5. Как выполняется сравнение

Для `Equal` используется `a == b`, для начала — `a.startswith(b)`, для конца — `a.endswith(b)`. Это буквальное сравнение: пробелы, переносы, нормализация Unicode и пунктуация значимы. Регистронезависимый режим использует `lower`, а не более широкое `casefold`.

## 6. Граничные случаи

Пустой `string_b` считается началом и концом любой строки. В режиме `Equal` пустой образец совпадёт лишь с пустой `string_a`. Визуально одинаковые строки с разными Unicode-представлениями могут не совпасть; нода их не нормализует.

## 7. Проверенный пример

В официальном `templates_graphic_design_recomposer.json` найден один `StringCompare`: `Nano Banana 2` сравнивается с `nano banana 2` в режиме `Starts With` при `case_sensitive=false`, результат истинен. Рецепт воспроизводит эту проверку без остальной сетевой ветви.

## 8. Ошибки и диагностика

Неожиданный `false` чаще всего вызван пробелом, переносом, другой Unicode-формой или неверным режимом. Выведите обе строки рядом и при необходимости измерьте их через `StringLength`. Значение mode вне списка интерфейс не создаёт; прямой некорректный вызов не возвращает `NodeOutput`.

## 9. Ограничения и производительность

Сравнение выполняется в памяти и для обычных строк почти не влияет на время графа. Это не регулярное выражение, не локализованное сравнение и не поиск приблизительного совпадения. `lower()` создаёт две дополнительные строки.
