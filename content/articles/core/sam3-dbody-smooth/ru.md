# Smooth SAM3D Body Pose Data: уменьшение дрожания позы

Сглаживает временные колебания параметров и геометрии MHR-позы. Полезна после предсказания видео, когда соседние кадры немного дрожат при плавном движении человека.

## Как пользоваться

strength смешивает исходные и сглаженные данные; 0 оставляет исходник. method выбирает gaussian или savgol, window — нечётную ширину окна в кадрах. rotation_threshold_degrees снижает сглаживание геометрии при быстрых поворотах, чтобы не сплющивать тело усреднением. Значение 0 отключает эту защиту, а не всю фильтрацию.

## Пример подключения

После Predict или FaceExpression сравните Render до и после сглаживания. Начните с небольшого окна, затем увеличьте его только при заметном дрожании. Для резких поворотов смотрите на объём корпуса и кисти, а не только на положение силуэта.

## Ограничения и частые ошибки

Большое окно может сгладить нужные быстрые движения. Сопоставление идёт по позиции человека в списке кадров: перестановки людей нельзя исправить одним фильтром. Один кадр или окно 1 не дают временного эффекта. Это не повторный inference модели и не восстановление пропущенной реальной анимации.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `mhr_pose_data` | `MHR_POSE_DATA` | да | соединение / значение без фиксированного default |
| `strength` | `FLOAT` | да | по умолчанию: 1.0; минимум: 0.0; максимум: 1.0; шаг: 0.05 |
| `method` | `COMBO` | да | по умолчанию: savgol; варианты: gaussian, savgol |
| `window` | `INT` | да | по умолчанию: 7; минимум: 1; максимум: 51; шаг: 2 |
| `rotation_threshold_degrees` | `FLOAT` | да | по умолчанию: 30.0; минимум: 0.0; максимум: 90.0; шаг: 1.0 |
