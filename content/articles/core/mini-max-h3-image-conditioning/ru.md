# MiniMax H3 Image: текст и изображения для генерации

Готовит положительные условия и пустой LATENT для MiniMax-H3-Image. С изображениями выполняет подготовку редактирования, без них — генерации по тексту.

## Подключение и пример

Подключите совместимый CLIP, инструкцию и при необходимости изображения и VAE MiniMax-H3-Image. В тексте можно ссылаться на <Picture 1>, <Picture 2>; первый референс — редактируемая картинка. Без VAE изображения участвуют только в текстовом энкодере, с ним добавляются опорные латенты minimax_refs. Нулевые размеры используют подготовленный первый референс или 2048×2048 без изображений.

## Ограничения

Выходной тензор имеет 24 канала и одну временную позицию, с пространственным сжатием 16. Это не обычный SDXL-латент. Референсы масштабируются внутренними правилами модели; нулевые размеры не означают безусловное сохранение исходного разрешения. Декодирование и сэмплирование требуют согласованных компонентов H3 Image.

## Входы и настройки

Снимок ComfyUI 0.45.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `clip` | `CLIP` | да | соединение / значение без фиксированного default |
| `prompt` | `STRING` | да | соединение / значение без фиксированного default |
| `width` | `INT` | да | по умолчанию: 0; минимум: 0; максимум: 16384; шаг: 32 |
| `height` | `INT` | да | по умолчанию: 0; минимум: 0; максимум: 16384; шаг: 32 |
| `vae` | `VAE` | нет | соединение / значение без фиксированного default |
| `images` | `COMFY_AUTOGROW_V3` | нет | префикс: image_ |
| `images → image` | `IMAGE` | да | соединение / значение без фиксированного default |
