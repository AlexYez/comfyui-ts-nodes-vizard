# UltraTex: условия для текстурирования сетки

Готовит conditioning для FLUX.2 Klein 9B с UltraTex LoRA: внешний вид референса переносится на набор видов объекта. Нода сама не загружает LoRA и не запекает текстуру.

## Подключение и пример

Получите через Render Mesh четыре боковых world-normal вида либо шесть канонических с верхом и низом, вместе с их masks. Подайте conditioning, совместимый VAE и фронтальный reference. UltraTex обучалась с пустым текстовым промптом. Дополнительные референсы extra_views связываются со своими ракурсами. Результат генерации видов можно вернуть на сетку через Bake Texture From Views.

## Ограничения

Количество масок должно совпадать с количеством видов. Произвольные ракурсы не заменяют каноническую раскладку. Используется первое изображение каждого референса; без reference_mask он считается полностью непрозрачным. Нода инвертирует Y-компоненту нормалей сама — не делайте это повторно без проверки.

## Входы и настройки

Снимок ComfyUI 0.45.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `conditioning` | `CONDITIONING` | да | соединение / значение без фиксированного default |
| `vae` | `VAE` | да | соединение / значение без фиксированного default |
| `normals` | `IMAGE` | да | соединение / значение без фиксированного default |
| `masks` | `MASK` | да | соединение / значение без фиксированного default |
| `reference` | `IMAGE` | да | соединение / значение без фиксированного default |
| `extra_views` | `COMFY_DYNAMICCOMBO_V3` | да | режимы: off, on |
| `extra_views=on → right` | `IMAGE` | нет | соединение / значение без фиксированного default |
| `extra_views=on → back` | `IMAGE` | нет | соединение / значение без фиксированного default |
| `extra_views=on → left` | `IMAGE` | нет | соединение / значение без фиксированного default |
| `extra_views=on → top` | `IMAGE` | нет | соединение / значение без фиксированного default |
| `extra_views=on → bottom` | `IMAGE` | нет | соединение / значение без фиксированного default |
| `reference_mask` | `MASK` | нет | соединение / значение без фиксированного default |
