# TextEncodeQwenImageEditPlus: до трёх изображений

## Назначение

Нода создаёт edit-conditioning из prompt и до трёх изображений, нумеруя только реально подключённые референсы.

## Место в графе

Используйте с Qwen Image Edit Plus CLIP. Подключение VAE добавляет latent-референсы для diffusion-модели.

## Входы

Обязательны CLIP и prompt. `image1`–`image3` и VAE необязательны; промежутки допустимы, но label строится по позиции слота, а список vision-images — только из непустых.

## Выход

Один scheduled conditioning. При VAE в metadata добавляется упорядоченный список reference_latents.

## Vision-разрешение

Каждый IMAGE уменьшается/увеличивается area до площади около 384² без crop и подаётся tokenizer-у. Alpha не обрезается явно в vision-ветке.

## VAE-разрешение

Тот же исходный IMAGE отдельно приводится к площади 1024²; ширина и высота округляются к кратным 8. В VAE идут только первые три канала.

## Prompt-шаблон

Перед текстом добавляются маркеры `Picture N` и vision tokens. Также передаётся фиксированный system llama-template с инструкцией описать изображение и применить правку.

## Проверенный пример

55 официальных экземпляров охватывают single/multi-reference и множество edit-графов; 37 имеют пустой widget prompt из-за подключённого STRING. Рецепт использует два внешних IMAGE.

## Ограничения и ошибки

Неподдерживаемый llama_template или images API ломает CLIP. Очень узкое изображение может после округления дать нулевой размер; schema IMAGE этого заранее не запрещает.

## Совместимость и источники

Проверено по ComfyUI 0.32.0, frontend 1.48.7, source, docs 0.5.9 и 55 cases 0.1.42. Полная edit-модель не исполнялась.
