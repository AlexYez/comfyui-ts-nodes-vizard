# VOIDWarpedNoiseSource

## Назначение
Нода превращает готовый warped-noise `LATENT` в объект `NOISE`, который понимает `SamplerCustomAdvanced`.
## Место в графе
Подайте результат `VOIDWarpedNoise`; выход подключите к noise-входу advanced sampler вместо `RandomNoise`.
## Вход
`warped_noise` должен быть словарём с ключом `samples`. Другие metadata нода не использует.
## Выход
Возвращается экземпляр внутреннего `Noise_FromLatent`, а не новый tensor непосредственно.
## Seed
Объект выставляет `seed=0` для интерфейсного контракта, но не генерирует случайность и не меняет заранее вычисленный noise.
## Генерация
`generate_noise(input_latent)` полностью игнорирует форму, dtype, устройство и содержимое `input_latent`, клонирует сохранённые `samples` и переносит их на CPU. Автоматического repeat, resize или проверки совместимости здесь нет.
## Независимость вызовов
Clone не даёт sampler изменить сохранённый тензор in-place. Однако каждый вызов создаёт полную CPU-копию, а исходный тензор остаётся на прежнем устройстве. Для длинного видео это увеличивает трафик и пиковую память.
## Ошибки
Словарь без `samples` падает при создании wrapper. Несовпадающая с input latent форма не исправляется здесь и проявится позже.
## Ограничения
Нода не делает RAFT, warping, нормализацию или batch matching. Она только адаптирует тип между двумя ComfyUI-контрактами.
## Совместимость и источники
Проверено по ComfyUI 0.32.0. В официальном `Video Inpaint (VOID)` есть один адаптер без настроек: он получает `VOIDWarpedNoise(672,384,45,1)` и подаёт NOISE во второй `SamplerCustomAdvanced`, тогда как первый использует `RandomNoise`. Точное clone/CPU-поведение закреплено; полный sampler workflow не исполнялся.
