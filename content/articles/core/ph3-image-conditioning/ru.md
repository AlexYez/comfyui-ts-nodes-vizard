# p-h3-image: условия генерации и редактирования

Готовит conditioning и составной латент неподвижного изображения для p-h3-image. Модель требует ModelSamplingMiniMaxH3 с настройками 1.0/1.0.

## Подключение и пример

Подайте CLIP, промпт и до девяти входов изображений. При наличии референсов короткая инструкция получает префикс Edit <Picture 1>; уже оформленная инструкция редактирования сохраняется. VAE добавляет minimax_refs, без него остаётся визуальное условие текстового энкодера. При нулевых размерах и отсутствии изображений используется 2912×2912; для референса размер подбирается по площади.

## Ограничения

Выход содержит видеопозицию неподвижного изображения и две соответствующие аудиопозиции. Он не взаимозаменяем с обычным IMAGE или четырёхканальным LATENT. Проверьте sampling, энкодер и VAE именно этой модели; название семейства H3 не гарантирует совместимости любых весов.

## Входы и настройки

Снимок ComfyUI 0.45.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `clip` | `CLIP` | да | соединение / значение без фиксированного default |
| `prompt` | `STRING` | да | соединение / значение без фиксированного default |
| `width` | `INT` | да | по умолчанию: 0; минимум: 0; максимум: 16384; шаг: 32 |
| `height` | `INT` | да | по умолчанию: 0; минимум: 0; максимум: 16384; шаг: 32 |
| `vae` | `VAE` | нет | соединение / значение без фиксированного default |
| `images` | `COMFY_AUTOGROW_V3` | нет | входы: image_1 … image_9 |
| `images → image` | `IMAGE` | да | соединение / значение без фиксированного default |
