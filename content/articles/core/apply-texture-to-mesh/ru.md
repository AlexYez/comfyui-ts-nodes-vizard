# Apply Texture to Mesh: прикрепление карт материала

Прикрепляет изображения материала к MESH с готовыми UV. Обязателен base_color; металлическость, шероховатость, затенение и карта нормалей подключаются отдельно.

## Как пользоваться

metallic, roughness и occlusion объединяются в glTF ORM: R — occlusion, G — roughness, B — metallic. Из карты берётся первый канал. При сборке ORM отсутствующие каналы заполняются значениями 1, 1 и 0 соответственно. Разные размеры карт приводятся к общему размеру. Для normal_map пересчитываются касательные.

## Пример подключения

Возьмите ровно тот выход UnwrapMesh, по которому работал BakeTextureFromVoxel. Передайте три запечённые карты в одноимённые входы, при необходимости добавьте карты из BakeAmbientOcclusion и BakeNormalMapFromMesh. Сохраните результат через MeshToFile3D и Save3DAdvanced.

## Ограничения и частые ошибки

Нода не переносит текстуру между разными развёртками и не исправляет неверную ориентацию карты нормалей. Без UV выполнение останавливается. Если подключаете только часть карт к уже текстурированной сетке, учитывайте сохранённые на входе атрибуты: это не безусловный сброс всего старого материала.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `mesh` | `MESH` | да | соединение / значение без фиксированного default |
| `base_color` | `IMAGE` | да | соединение / значение без фиксированного default |
| `metallic` | `IMAGE` | нет | соединение / значение без фиксированного default |
| `roughness` | `IMAGE` | нет | соединение / значение без фиксированного default |
| `occlusion` | `IMAGE` | нет | соединение / значение без фиксированного default |
| `normal_map` | `IMAGE` | нет | соединение / значение без фиксированного default |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
