# JSON: извлечение значения в строку

Находит первый корректный JSON-объект в тексте и возвращает значение указанного ключа верхнего уровня. В ComfyUI 0.38.0 перед объектом и после него могут находиться пояснения или ограждения Markdown.

## Пример подключения

Подайте ответ языковой модели на `json_string`, а имя свойства — на `key`. Для текста `Ответ: {"prompt": "лес"}` ключ `prompt` даст строку `лес`. Регистр значим; точка в имени остаётся обычным символом, а не переходом к вложенному полю.

Код проверяет каждую открывающую фигурную скобку, пока не найдёт объект, который может разобрать JSON-декодер. На первом таком объекте поиск заканчивается даже тогда, когда нужного ключа в нём нет. Нода не выбирает наиболее подходящий объект из нескольких.

## Что возвращается

Строка возвращается без JSON-кавычек. Число, логическое значение, список или словарь преобразуются через Python `str`: например, `true` станет `True`, а словарь может содержать одинарные кавычки. Поэтому выход со вложенными данными не обязательно является корректным JSON.

Отсутствующий ключ, значение `null` или отсутствие корректного объекта дают пустую строку. Отдельного статуса ошибки нет. JSONPath, пути по вложенным полям и выбор элемента массива не поддерживаются. Объект внутри массива также может быть найден, потому что поиск начинается с фигурных скобок.

## Диагностика и ограничения

При пустом результате сначала найдите первый корректный объект и проверьте, содержит ли он нужный ключ. Затем проверьте написание ключа и значение. Не считайте любой пустой результат доказательством неверного JSON: объект может быть корректным, но не содержать нужного поля.

## Входы и настройки

Снимок ComfyUI 0.38.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `json_string` | `STRING` | да | соединение / значение без фиксированного default |
| `key` | `STRING` | да | соединение / значение без фиксированного default |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `STRING` | `STRING` | нет |

## Официальные примеры подключения

`api_bytedance_seed.json`, подграф «main»: входы от `RegexReplace`; выходы к `PreviewAny`.

`audio_stable_audio_3_medium.json`, подграф «Audio Generation (Stable Audio 3 Medium)»: входы от `CustomCombo`; выходы к `StringReplace`.

Шаблоны из [официального пакета 0.1.96](https://pypi.org/project/comfyui-workflow-templates-json/0.1.96/), закреплённого ComfyUI 0.38.0. Это сохранённые соединения, не отчёт о запуске. Внешние входы и переключатели подграфа могут менять значения и путь выполнения. `SubgraphInput` и `SubgraphOutput` обозначают границы подграфа.
