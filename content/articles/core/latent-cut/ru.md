# LatentCut: вырезать диапазон по x, y или t

`LatentCut` возвращает непрерывный участок тензора `LATENT` по ширине, высоте либо третьей оси с конца. Она использует `torch.narrow`, поэтому не пересчитывает значения и не копирует выбранный тензорный участок.

## 1. Что делает нода

Нода принимает `samples`, направление `dim`, начальную позицию `index` и длину `amount`. Для положительного индекса она берёт участок вперёд; для отрицательного — считает позицию от правого края выбранной оси.

Размер результата по выбранной оси может быть меньше `amount`, если диапазон упирается в границу. Выход остаётся `LATENT`, а остальные поля словаря переносятся без изменения.

## 2. Место в графе

`LatentCut` полезна перед декодированием, разбиением последовательности или повторной компоновкой. В официальном Wan 2.2 S2V она выделяет первый latent-кадр перед `LatentConcat`. В Qwen layered workflow она отбрасывает первый элемент по `t`, после чего `LatentCutToBatch` превращает оставшуюся ось в batch.

Для выбора элементов по batch-оси нужна `LatentFromBatch`; для одинаковых блоков вдоль оси — `LatentCutToBatch`; для склейки двух областей — `LatentConcat`.

## 3. Входы

- `samples` — входной словарь `LATENT` с тензором в поле `samples`.
- `dim` — `x`, `y` или `t`.
- `index` — начальная позиция, целое от `-16384` до `16384` в runtime 0.32.0.
- `amount` — запрошенная длина от `1` до `16384`.

`x` соответствует последней оси, `y` — предпоследней, `t` — третьей с конца. Тип LATENT сам по себе не сообщает, сколько у тензора измерений.

## 4. Выход

Выход имеет тип `LATENT`. Словарь сначала копируется поверхностно, а поле `samples` заменяется view, созданным `torch.narrow`. Данные выбранного участка используют то же storage, что и исходный тензор.

`noise_mask`, `batch_index` и любые пользовательские поля не режутся. Они остаются прежними объектами и могут не совпасть с новой пространственной либо временной формой.

## 5. Как работает

Положительный `index` ограничивается диапазоном от `0` до последней позиции. `amount` затем сокращается до доступного хвоста. Поэтому слишком большой положительный индекс выбирает последний элемент, а не даёт пустой результат.

Для отрицательного индекса код ограничивает значение снизу величиной `-size`. Длина не может превышать `-index`, после чего Python-преобразование `size + index` даёт реальный старт. Например, при размере 5 параметры `index = -2`, `amount = 10` возвращают два последних элемента.

На video latent `[B, C, T, H, W]` `t` означает время. На image latent `[B, C, H, W]` третья ось с конца — `C`, поэтому `t` вырезает каналы. Runtime не блокирует такую комбинацию.

## 6. Параметры и настройка

Для первого элемента задайте `index = 0`, `amount = 1`; для последнего — `index = -1`, `amount = 1`. Большое `amount` можно использовать как «весь доступный хвост», но результат всё равно ограничится границей.

Перед выбором `t` проверьте пятиосевую форму. Если downstream-нода ожидает согласованную маску или временные индексы, обработайте соответствующие metadata отдельно: `LatentCut` меняет только `samples`.

## 7. Проверенный пример

Recipe `Добавить первый latent-кадр перед видео` использует `LatentCut(dim = t, index = 0, amount = 1)`, как официальный Wan 2.2 S2V workflow. Выбранный кадр идёт в первый вход `LatentConcat`, а полная последовательность — во второй.

В другом подтверждённом официальном случае Qwen layered нода настроена как `t, 1, 16384` и передаёт результат в `LatentCutToBatch(t, 1)`: первый элемент отбрасывается, остальные превращаются в batch отдельных latent-слоёв. JSON fragment проверен по runtime-портам; exact-source tensor-проба подтвердила границы и shared storage. Полные workflows не исполнялись.

## 8. Частые ошибки

- Считают, что выход независим от входа. Тензор — view с общим storage.
- Ожидают пустой результат при слишком большом положительном `index`; код прижимает его к последнему элементу.
- Принимают `amount` за гарантированный размер. У границы он сокращается.
- Используют `t` на четырёхосевом image latent и режут каналы.
- Ожидают синхронный срез `noise_mask` или `batch_index`; нода их не меняет.
- Пытаются выбрать несколько несоседних участков. Операция возвращает один непрерывный диапазон.

## 9. Ограничения и производительность

Сам `torch.narrow` дешёвый и не копирует tensor storage. Это экономит память, но удерживает исходное большое хранилище живым, пока существует маленький срез. Для долговременного хранения компактного результата отдельное клонирование downstream может оказаться полезнее.

Операция не исправляет форму metadata и не проверяет семантику оси. Нулевой размер выбранной оси не является обычным случаем для этой реализации: вычисление последнего индекса предполагает хотя бы один элемент.
