# ModelPatchLoader

## Назначение
Экспериментальная нода загружает не обычный checkpoint, а специализированный `MODEL_PATCH` для последующей прикладной ноды.
## Место в графе
Выберите файл из `models/model_patches`, затем подключите выход к совместимой Apply-ноде. Сам загрузчик не изменяет diffusion `MODEL`.
## Вход
Единственный вход `name` — динамический список файлов model patches текущей установки.
## Выход
Возвращается `MODEL_PATCH`, обёрнутый в `CoreModelPatcher` с текущим устройством загрузки и устройством выгрузки UNet.
## Как определяется тип
Исходник проверяет характерные ключи state dict по порядку. Поддерживаются ветви Anima LLLite, Qwen blockwise ControlNet, SigLIP multi-feature projection, Z-Image control, Wan Uni3C, LTX duration head, MultiTalk и SUPIR.
## Загрузка весов
Файл читается с `safe_load=True` и metadata; dtype выводится из весов. Некоторые ветви переименовывают ключи, отделяют префиксы или принудительно оставляют маленькую голову в float32.
## Проверенный пример
Каталог сверил все сигнатурные условия и создание patcher. Реальные файлы каждой из восьми ветвей не загружались, поэтому их исполнение отмечено как пробел.
## Ошибки
Неизвестный state dict не получает fallback-модель и завершится ошибкой до корректного выхода. Частично похожий набор ключей может выбрать неверную ветвь и упасть на ожидаемой форме.
## Ограничения и ресурсы
Это общий контейнер разных архитектур, а не взаимозаменяемый формат. Совместимость определяется парой конкретного patch-файла и Apply-ноды.
## Совместимость и источники
Проверено по ComfyUI 0.32.0. Нода experimental; список ветвей привязан к закреплённому исходнику и должен пересматриваться при обновлении.
