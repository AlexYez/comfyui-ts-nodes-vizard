# Qwen Image 2.1 Cache: память для повторно используемых данных

Настраивает кэширование Qwen Image 2.1 в копии MODEL. Это модельная оптимизация выполнения, а не кэш браузера или ускорение интерфейса ComfyUI.

## Как пользоваться

device выбирает auto, gpu, cpu или off. Auto использует видеопамять, затем оперативную память; off отключает кэш и заставляет пересчитывать данные. dtype оставляет исходное представление либо выбирает int8/int4. Нода записывает настройки в transformer_options модели, не меняя исходный MODEL на другой ветке.

## Пример подключения

Поставьте её после загрузки совместимой модели и перед sampler. Сначала сравните auto с off при одном seed и одинаковом workflow, затем при нехватке VRAM проверьте cpu. Меняйте квантование отдельно, чтобы видеть его влияние на качество и время.

## Ограничения и частые ошибки

Экспериментальная функция не обещает ускорения на любом устройстве. Кэш занимает память, перенос между CPU и GPU тоже стоит времени, а квантование может изменить результат. Она не предназначена для SDXL, Flux или устранения тормозов canvas.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `model` | `MODEL` | да | соединение / значение без фиксированного default |
| `device` | `COMBO` | да | по умолчанию: auto; варианты: auto, gpu, cpu, off |
| `dtype` | `COMBO` | да | по умолчанию: default; варианты: default, int8, int4 |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `MODEL` | `MODEL` | нет |

## Проверенные источники и кейсы

В Qwen edit-шаблонах нода расположена между UNETLoader и KSampler. Параметры кэша выведены наружу подграфа, поэтому сравнение режимов не требует менять внутреннюю цепочку генерации.

В официальном шаблоне `image_qwen_image_2_1_background_removal`: Граф: Image Edit (Qwen Image 2.1) (root/definitions/subgraphs/0). Входящие связи: `SubgraphInput`, `UNETLoader`. Исходящие связи: `KSampler`. Имя файла: `image_qwen_image_2_1_background_removal.json`, пакет [workflow-templates-json 0.1.92](https://pypi.org/project/comfyui-workflow-templates-json/0.1.92/). SubgraphInput/Output обозначают границы подграфа. Это сохранённые связи; переключатели и внешние входы могут менять путь исполнения и значения виджетов. Полный запуск с весами здесь не выполнялся.

В официальном шаблоне `image_qwen_image_2_1_image_edit`: Граф: Image Edit (Qwen Image 2.1) (root/definitions/subgraphs/0). Входящие связи: `SubgraphInput`, `UNETLoader`. Исходящие связи: `KSampler`. Имя файла: `image_qwen_image_2_1_image_edit.json`, пакет [workflow-templates-json 0.1.92](https://pypi.org/project/comfyui-workflow-templates-json/0.1.92/). SubgraphInput/Output обозначают границы подграфа. Это сохранённые связи; переключатели и внешние входы могут менять путь исполнения и значения виджетов. Полный запуск с весами здесь не выполнялся.
