# ModelSamplingLTXV: патч семплирования по форме latent

`ModelSamplingLTXV` вычисляет flow-shift из формы необязательного `LATENT` и ставит `ModelSamplingFlux + CONST` в клон `MODEL`. Значения latent не читаются: для расчёта нужны только его размеры.

## Нода клонирует MODEL и заменяет model_sampling

Метод вызывает `model.clone()`, создаёт новый sampling-объект и добавляет его под ключом `model_sampling`. Исходная модель не мутирует.

Выход остаётся типом `MODEL`, но его sampling-правила отличаются от входа. Следующие ноды должны получать именно эту ветвь, если расписание строится для патча LTXV.

## Необязательный latent задаёт форму

В `/object_info` перечислены три обязательных входа: `model`, `max_shift`, `base_shift`. `latent` находится в секции `optional`.

Если latent подключён, нода обращается к `latent["samples"].shape`. Она не проверяет содержимое samples, frame rate или модель, которая создала этот latent.

## Число токенов — произведение размеров после канала

Код вычисляет `math.prod(shape[2:])`: batch и channel не участвуют. Для обычной видеоформы `[B, C, T, H, W]` это `T·H·W`; для четырёхмерного latent — `H·W`.

Например, shape `[1, C, 4, 16, 16]` даёт 1024 токена. Изменение batch при тех же остальных размерах не изменит shift.

## Опорные точки равны 1024 и 4096

`base_shift` соответствует 1024 токенам, `max_shift` — 4096. Между ними используется линейная формула с наклоном `(max_shift − base_shift)/(4096 − 1024)`.

При defaults 0,95 и 2,05 latent на 1024 токена даёт 0,95, а на 4096 — 2,05. Оба поля принимают 0–100 с шагом 0,01.

## Без latent выбирается max_shift

Если необязательный вход не подключён, код явно ставит `tokens = 4096`. Итоговый shift поэтому равен `max_shift`, независимо от предполагаемой длительности или разрешения будущего latent.

Такой fallback удобен только как известное поведение. Он не определяет форму автоматически по другим нодам и может не соответствовать реальному видео.

## Формула не ограничивает экстраполяцию

При числе токенов меньше 1024 прямая продолжается ниже `base_shift`, при числе больше 4096 — выше `max_shift`. Принудительного ограничения нет.

Названия параметров не гарантируют минимальную и максимальную границу. Runtime также разрешает `base_shift > max_shift`, что разворачивает наклон.

Вычисленное число позже проходит через `math.exp(mu)`. Очень большая форма или крутой наклон могут привести к переполнению либо нечисловой sigma-сетке; встроенной проверки конечности нет.

## Вычисленный shift становится mu у Flux

Новый объект наследует `ModelSamplingFlux` и `CONST`. Функция sigma использует `exp(mu)`, где `mu` — результат линейного расчёта по tokens.

Это не SD3/AuraFlow-формула с прямым коэффициентом shift. Значение 0 у Flux даёт нейтральное преобразование `sigma(t)=t`, а положительные и отрицательные mu меняют кривую через экспоненту.

## Форма должна совпадать с sampling latent

Подключайте latent той же формы, которая затем участвует в sampling. Если нода видит короткий или уменьшенный placeholder, а sampler получает другой `[T,H,W]`, shift рассчитан для чужого числа токенов.

Scheduler также должен читать изменённый `MODEL`. Иначе `SIGMAS` будут построены по прежнему `model_sampling`, хотя guider или sampler использует LTXV-патч.

## В официальных шаблонах нода не встречается

Полный подсчёт по 512 JSON-файлам, 496 корневым графам и 272 подграфам не нашёл ни одного `ModelSamplingLTXV`. Поэтому закреплённый набор не подтверждает сериализованные значения виджетов, схему связей latent или следующую ноду scheduler для этого точного типа.

Статья не подменяет её `LTXVScheduler`: это отдельный runtime-ID, который напрямую возвращает `SIGMAS`, а не изменённый `MODEL`.

## Учебный фрагмент собран по контракту исходника

Учебный фрагмент передаёт внешний `MODEL` и `LATENT`, который задаёт форму, в `ModelSamplingLTXV` с настройками по умолчанию. Затем изменённый `MODEL` подключается к `BasicScheduler(simple, 20, 1)`. Это типосовместимая схема по исходнику, а не официальный граф.

Метод исполнен на подставной модели для режима без latent (4096), опорной точки 1024 и значения выше 4096. Реальная LTXV-модель и полный фрагмент не запускались, поэтому `exampleExecuted=false`. Редактор пока не проверил материал вручную.
