# ModelMergeSubtract: построить масштабированную разность моделей

## Что делает нода

`ModelMergeSubtract` строит разность diffusion-весов двух моделей. В ComfyUI 0.32.0 multiplier применяется к обеим сторонам:

`result = multiplier × model1 − multiplier × model2`  
`result = multiplier × (model1 − model2)`.

Это отличается от распространённого прочтения `model1 − multiplier × model2`. При `multiplier = 0` совпадающие веса результата становятся нулевыми; первая модель не проходит без изменений.

## Когда использовать и когда не использовать

Нода нужна для построения дельты между совместимыми checkpoint. Например, `source − base` можно прибавить к `target` через `ModelMergeAdd`. Multiplier задаёт силу всей дельты: 0,5 делит разность пополам, 2 удваивает её, отрицательное значение меняет знак.

Не используйте subtract как обычный способ ослабить вторую модель относительно неизменной первой. Для формулы с фиксированной базой понадобится другая конструкция; эта нода масштабирует и `model1`. Не вычитайте модели разных архитектур без проверки ключей и форм.

## Короткий рецепт подключения

1. Подключите модель с нужным изменением к `model1` как `source`.
2. Подключите её исходную или контрольную модель к `model2` как `base`.
3. Оставьте `multiplier = 1` для дельты `source − base`.
4. Передайте выход в `model2` ноды `ModelMergeAdd`, а в её `model1` — `target`.
5. Сравните target до и после переноса на одном seed.

Fragment `Перенести дельту source − base на target` связывает обе ноды. Он не содержит loader и sampler, чтобы не притворяться проверенным полным workflow.

## Входы, выходы и параметры

- `model1` (`MODEL`) — первая сторона разности и основа клона.
- `model2` (`MODEL`) — вычитаемая сторона; берутся только key patches `diffusion_model.`.
- `multiplier` (`FLOAT`, −10…10, шаг 0,01, по умолчанию 1) — общий множитель всей разности.
- `MODEL` — ленивый patch-объект, а не записанный checkpoint.

Положительный multiplier сохраняет направление `model1 − model2`. Отрицательный разворачивает его: при −1 результат равен `model2 − model1` для совместимых ключей.

## Типовые связки

`ModelMergeSubtract → ModelMergeAdd` образует перенос дельты. Для прямого процентного смешивания используйте `ModelMergeSimple`; у него коэффициенты суммируются в единицу. `CLIPMergeSubtract` выполняет отдельную операцию над текстовыми энкодерами и пропускает специальные CLIP-ключи.

Если результат сохраняется, CLIP и VAE должны быть выбраны отдельно. Дельта diffusion-весов не переносит автоматически tokenizer, текстовый encoder, latent scaling или метаданные обучения.

## Практический пример

Exact-source probe взял `model1 = 2`, `model2 = 10`. При `multiplier = 2` получено `2 × (2 − 10) = −16`. При `multiplier = −1` результат равен `−1 × (2 − 10) = 8`, то есть знак разности развёрнут.

Проверка использовала сам метод `ModelSubtract.merge` и извлечённую из pinned source функцию `calculate_weight`. Реальные checkpoint не загружались, поэтому пример подтверждает формулу и ветви обработки ключей, но не качество дельты.

## Частые ошибки и способы проверки

- Multiplier принят за силу только `model2`. Запишите формулу рядом с графом: `m × (A − B)`.
- `multiplier = 0` используется как bypass. Он обнуляет совпадающие diffusion-веса.
- Source и base поменяны местами. Получается дельта противоположного знака.
- Shape mismatch оставлен без внимания. Базовый вес успевает умножиться на multiplier, а несовместимое вычитание пропускается; для такого ключа остаётся `multiplier × model1`.
- Ключ существует только во второй модели. `add_patches` первой модели его не принимает, поэтому он исчезает из операции.

Перед sampling проверьте консоль и по возможности сравните списки state-dict ключей обеих моделей.

## Производительность и внутреннее поведение

Метод клонирует `model1`, получает patches второй модели с фильтром `diffusion_model.` и регистрирует для каждого ключа `strength_patch = −multiplier`, `strength_model = multiplier`. Штатный calculate-weight сначала масштабирует текущий вес первой модели, затем прибавляет отрицательный вес второй.

Результат остаётся ленивым до применения модели. Цепочка subtract/add может держать ссылки на несколько patch-объектов и потребовать заметную память при materialization. Сохранение checkpoint отдельно записывает итоговые тензоры на диск.

## Совместимость, изменения и статус

Факты проверены по ComfyUI 0.32.0, frontend 1.48.7 и pinned wheels docs/workflows. Встроенное описание говорит о вычитании с multiplier, но формулировка не показывает, что множитель применяется также к `model1`. Полный census официальных templates не нашёл точного `ModelMergeSubtract`.

Нода не deprecated и не experimental; replacement entry отсутствует. Рецепт source-derived и не выдаётся за успешный запуск модели.

Редактор пока не проверил материал вручную.
