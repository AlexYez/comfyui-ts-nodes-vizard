# Save Text

## 1. Назначение

`SaveText` сохраняет входную строку в каталоге output и одновременно возвращает её дальше по графу.

## 2. Место в графе

Это output-нода: очередь выполняет её как конечное действие. Подключите текст после форматирования или сериализации.

## 3. Входы

`text` принудительно подключается проводом. `filename_prefix` по умолчанию `ComfyUI`. `format` выбирает `txt`, `csv`, `md` или `json`.

## 4. Выход и UI

Выход `text` повторяет исходную строку. UI-результат содержит сохранённый файл, его подпапку и тип output.

## 5. Имя и путь

Нода использует `folder_paths.get_save_image_path`, затем имя `{filename}_{counter:05}.{extension}`. Это применяет общую защиту и счётчик ComfyUI; ручное `../` не становится произвольным системным путём.

## 6. Форматы

TXT, CSV и Markdown записываются как есть в UTF-8; нода не проверяет синтаксис CSV/Markdown. Для JSON она пробует `json.loads`, а затем пишет форматированный JSON с indent 2 и Unicode.

## 7. Некорректный JSON и пример

Если JSON не разбирается, исходный текст всё равно сохраняется в файл `.json`; ошибки нет. Рецепт записывает корректный объект с prefix `Text/report`. В официальных шаблонах найдено 11 `SaveText`, преимущественно TXT.

## 8. Ошибки и диагностика

Неизвестный format вызывает `ValueError`, но UI его не предлагает. Ошибка диска, прав или полного тома прерывает ноду. Расширение `.json` само по себе не доказывает корректность содержимого.

## 9. Ограничения и производительность

Запись не атомарная: файл открывается напрямую. Большой текст находится в памяти. CSV не получает экранирование, а Markdown не рендерится. Безопасный probe использовал временный output-каталог, не рабочие данные пользователя.

## 10. Совместимость и источники

Проверено на ComfyUI 0.32.0/frontend 1.48.7, exact source, embedded docs 0.5.9, workflow census и временной файловой системе. Человеческое утверждение ожидается.
