# MoGe Geometry To FOV: угол обзора из оценки геометрии

Вычисляет поле зрения по intrinsics из данных MoGe. Позволяет согласовать предполагаемую камеру с последующей 3D-обработкой, например Pixal3D.

## Как пользоваться

Выберите horizontal, vertical или diagonal и единицы degrees либо radians. При пакетной матрице intrinsics используется первый элемент. Отдельный выход фокусного расстояния в пикселях требует размеров изображения, points или depth; он не равен фокусному расстоянию объектива в миллиметрах.

## Пример подключения

Для camera_angle_x в Pixal3DConditioning выберите horizontal и degrees. Передайте геометрию обычной перспективной оценки MoGe, затем сравните реконструкцию с разумной исходной камерой. При известной калибровке используйте её как независимую проверку оценки.

## Ограничения и частые ошибки

Панорамные данные без intrinsics не поддерживаются. Результат наследует ошибки оценки MoGe и не превращается в точную калибровку реальной камеры. Не путайте вертикальный и горизонтальный FOV, особенно у широкого кадра; разные соглашения дадут разную перспективу.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `moge_geometry` | `MOGE_GEOMETRY` | да | соединение / значение без фиксированного default |
| `axis` | `COMBO` | да | по умолчанию: vertical; варианты: vertical, horizontal, diagonal |
| `unit` | `COMBO` | да | по умолчанию: degrees; варианты: degrees, radians |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `fov` | `FLOAT` | нет |
| `focal_pixels` | `FLOAT` | нет |
