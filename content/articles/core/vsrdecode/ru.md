# VSR Decode: восстановление кадров RelayVSR

Декодирует латент RelayVSR через совместимый Flash-декодер, который одновременно получает исходные низкокачественные кадры.

## Подключение и пример

Подайте VAE RelayVSR, samples после сэмплирования и точно тот же images, что использовался в RelayVSR Conditioning. detail от 0 до 1 задаёт, сколько деталей декодера сохраняется относительно bicubic-увеличения. Полученный IMAGE-пакет можно собрать в видео, отдельно сохранив частоту и звук.

## Ограничения

Обычный Wan VAE не заменяет специализированный декодер только потому, что имеет тот же тип порта. Параметр detail не является числом шагов и не гарантирует восстановление достоверных мелких деталей. Полный выходной ряд кадров требует памяти даже при разреженном сэмплировании.

## Входы и настройки

Снимок ComfyUI 0.45.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `vae` | `VAE` | да | соединение / значение без фиксированного default |
| `samples` | `LATENT` | да | соединение / значение без фиксированного default |
| `images` | `IMAGE` | да | соединение / значение без фиксированного default |
| `detail` | `FLOAT` | да | по умолчанию: 1.0; минимум: 0.0; максимум: 1.0; шаг: 0.01 |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `IMAGE` | `IMAGE` | нет |
