# MiniMax H3 Add Guide: кадр, клип или звук в заданной позиции

Добавляет изображение, короткий видеоклип или аудио как временную опору для локальной MiniMax H3. Обновляет positive conditioning; целевой AV-latent задаёт длительность и размер.

## Как пользоваться

frame_idx измеряется в кадрах видео; отрицательное значение отсчитывается от конца. Для image нужен video VAE, для audio — audio VAE. Batch изображений короче пяти использует только первый кадр; более длинный обрезается вниз до допустимой длины 5, 22, 39… (17k + 5). Аудио начинается в той же позиции и ограничивается оставшейся длительностью.

## Пример подключения

Возьмите H3 AV-latent и его positive, подключите стартовое изображение с frame_idx = 0. Вторую ноду можно добавить цепочкой для изображения в конце с frame_idx = -1. Для клипа заранее проверьте, что его допустимая длина целиком помещается после выбранной позиции.

## Ограничения и частые ошибки

Нужен именно nested MiniMax H3 AV-latent, а не LTX или обычный latent картинки. Хотя бы один вход image/audio обязателен. Изображения масштабируются и кадрируются под целевой размер. Нода задаёт условие генерации, а не выполняет обычную монтажную вставку без изменений.

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| --- | --- | --- | --- |
| `positive` | `CONDITIONING` | да | соединение / значение без фиксированного default |
| `latent` | `LATENT` | да | соединение / значение без фиксированного default |

| `audio` | `AUDIO` | нет | соединение / значение без фиксированного default |
