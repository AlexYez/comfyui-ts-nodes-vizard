# Увеличение изображения нейросетевой моделью

Увеличивает пиксельный `IMAGE` через модель `UPSCALE_MODEL`. Коэффициент увеличения задаёт сама модель; это не интерполяция ImageScale и не увеличение латента.

## Подключение

Соедините UpscaleModelLoader с `upscale_model`, подайте изображение на `image`. Результат можно просмотреть, сохранить или уменьшить обычным масштабированием до нужного размера. Для видео сначала получите кадры; сохранение частоты и аудио выполняется отдельно.

## Крупные изображения

Код обрабатывает перекрывающиеся участки, начиная с размера 512 и перекрытия 32. При нехватке памяти размер участка уменьшается вдвое; если он стал меньше 128, ошибка передаётся пользователю. Другие ошибки не выдаются за нехватку памяти.

Сокращение участка снижает память промежуточных вычислений, но не размер весов и полного выходного изображения. Для модели ×4 площадь результата примерно в 16 раз больше входа. Пакет увеличивает общий объём данных.

## Прозрачность в ComfyUI 0.38.0

RGBA теперь поддерживается отдельно: RGB проходит через модель, альфа увеличивается билинейно до полученного размера и присоединяется обратно. Прозрачность не предсказывается нейросетью и не получает те же новые детали, что RGB. Прежнее предупреждение о неизбежной ошибке на четырёхканальном входе к этой версии не относится.

## Пример и ограничения

Загрузите совместимую RealESRGAN-модель, увеличьте один кадр и сравните мелкие детали и края. Для точного разрешения добавьте ImageScale после нейросетевого увеличения. Не ожидайте восстановления достоверных исходных деталей: модель создаёт новые. Значения RGB ограничиваются диапазоном 0–1, поэтому эта цепочка не сохраняет расширенный линейный HDR-диапазон.

## Входы и настройки

Снимок ComfyUI 0.38.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `upscale_model` | `UPSCALE_MODEL` | да | соединение / значение без фиксированного default |
| `image` | `IMAGE` | да | соединение / значение без фиксированного default |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `IMAGE` | `IMAGE` | нет |
