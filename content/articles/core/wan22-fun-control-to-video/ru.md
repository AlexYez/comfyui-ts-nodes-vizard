# Wan22FunControlToVideo
## Назначение
Готовит Fun Control conditioning для локальных Wan 2.2 и совместимых VAE.
## Место в графе
Ставится перед sampler; control video, start image и reference image независимы.
## Входы
Обязательны обе ветви conditioning, VAE, размер, длина и batch. `ref_image` и `control_video` необязательны. Метод Python также принимает `start_image`, но схема `/object_info` 0.32.0 не объявляет такого сокета: штатный локальный граф не может передать его этой ноде.
## Выходы
Возвращаются две обновлённые ветви conditioning и нулевой LATENT формы `[batch,C,((length−1)//4)+1,H/scale,W/scale]`, где `C` и spatial scale берутся у подключённого VAE.
## Как работает
Вспомогательный concat-латент сначала нормализуется форматом Wan 2.2 при 48 каналах, иначе форматом Wan 2.1, а затем удваивается по каналам. Управляющее видео записывается в первую половину. Недоступное через интерфейс `start_image` предназначено для второй половины и одновременно закрывает начало concat-маски.
## Параметры
Ширина и высота имеют шаг 16, длина — шаг 4. Ключ `concat_mask_index` равен исходному числу каналов VAE и сообщает модели границу двух половин. Маска строится с четырьмя фазами по временной компрессии; без `start_image` она остаётся полностью открытой.
## Проверенный пример
В доступном через UI варианте с одним `control_video` первая половина concat-латента содержит закодированное управление, а вторая остаётся нормализованным нулём. `ref_image` использует только первый кадр, кодируется отдельно и добавляется в список `reference_latents` обеих ветвей conditioning.
## Ошибки
Нельзя рассчитывать на скрытый аргумент `start_image`: сериализованный workflow не имеет такого входа и frontend не создаёт сокет. Видео и референс обрезаются до RGB перед VAE. Слишком длинный латент управления обрезается при записи до целевой временной длины.
## Ограничения и производительность
Управляющее видео и референс кодируются VAE отдельными вызовами. Большой batch заранее выделяет нулевой и удвоенный concat-латенты целиком. Ветка выбора формата считает любой размер каналов, отличный от 48, Wan 2.1; это не общая гарантия совместимости с произвольным VAE.
## Совместимость и источники
Сверено с ComfyUI 0.32.0; расхождение start_image сохранено как факт, а не скрытый интерфейс Wizard.
