# TextEncodeQwenImageEdit: prompt с одним изображением

## Назначение

Нода создаёт Qwen Image Edit conditioning из prompt и необязательного изображения. VAE добавляет latent-референс, но не обязателен для vision-токенов.

## Место в графе

Подключите совместимый Qwen CLIP. Выход используется как conditioning edit-модели; IMAGE и VAE подключаются вместе, если модели нужен reference latent.

## Входы

`clip` и `prompt` обязательны. `image` и `vae` независимы: image без VAE всё равно передаётся tokenizer-у, VAE без image не используется.

## Выход

Один scheduled `CONDITIONING`. При VAE-кодировании metadata получает список `reference_latents` с append semantics.

## Масштабирование

IMAGE переводится BHWC→BCHW и масштабируется area без crop так, чтобы площадь стала примерно 1024². Соотношение сторон сохраняется, размеры округляются обычным `round`.

## Как работает

Tokenizer получает prompt и список из одного RGB IMAGE. Затем выполняется scheduled encoding. Если VAE доступен, тот же масштабированный RGB кодируется и добавляется в conditioning.

## Проверенный пример

Нода встречается 4 раза в официальных LongCat/Qwen edit-графах, включая два пустых prompt. Рецепт Wizard оставляет текст и зависимости внешними.

## Ошибки и диагностика

Нулевая пространственная сторона приводит к делению на ноль. Несовместимый CLIP может не принимать `images`. Alpha отбрасывается перед tokenizer/VAE.

## Ограничения и производительность

Все элементы IMAGE batch сохраняются после resize. Площадь 1024² может увеличить маленькое изображение и память. Нода не создаёт negative conditioning.

## Совместимость и источники

Проверено по ComfyUI 0.32.0, frontend 1.48.7, source, docs 0.5.9 и 4 workflow cases 0.1.42. Реальное encoding не выполнялось.
