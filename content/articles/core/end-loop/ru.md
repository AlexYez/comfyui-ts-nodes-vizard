# End Loop: результат и перенос данных между итерациями

Завершает штатный цикл ComfyUI и определяет, что вернуть наружу и что передать на следующий шаг. Выход оформляется как список, даже когда нужен только последний результат.

## Как пользоваться

output_value — возвращаемое значение; accumulate включает сбор всех итераций вместо последней. next_iteration_value становится current_iteration_value у StartLoop на следующем шаге. Входы terminations заставляют выполнять подключённые ветви превью или побочных действий на каждой итерации; их значения не возвращаются.

## Пример подключения

Для последовательного улучшения изображения подайте обработанное изображение одновременно в output_value и next_iteration_value. С accumulate = false получите финальный результат; включите accumulate для сравнения всех шагов. При необходимости выберите один элемент через GetItemFromList.

## Ограничения и частые ошибки

Название terminations не означает условие break: это зависимости выполнения, а не проверка досрочного выхода. Нода работает только внутри корректно созданной пары границ цикла. Накопление крупных изображений или latent увеличивает память; не включайте его без необходимости для длинных циклов.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `accumulate` | `BOOLEAN` | да | по умолчанию: false |
| `output_value` | `COMFY_MATCHTYPE_V3` | нет | допустимый тип: * |
| `next_iteration_value` | `COMFY_MATCHTYPE_V3` | нет | допустимый тип: * |
| `terminations` | `COMFY_AUTOGROW_V3` | нет | префикс: termination |
| `terminations → termination` | `*` | да | соединение / значение без фиксированного default |

## Проверенные источники и кейсы

В Wan Animate 2 включено accumulate: наружу возвращаются результаты итераций, затем RebatchImages собирает нужные batch. CreateList готовит переносимые данные, отделённые от возвращаемых кадров.

В официальном шаблоне `video_wan_animate2`: Граф: Motion Transfer (Wan Animate 2) (root/definitions/subgraphs/1). Входящие связи: `ComfySwitchNode`, `CreateList`, `WanAnimate2ToVideo`. Исходящие связи: `RebatchImages`. Имя файла: `video_wan_animate2.json`, пакет [workflow-templates-json 0.1.92](https://pypi.org/project/comfyui-workflow-templates-json/0.1.92/). SubgraphInput/Output обозначают границы подграфа. Это сохранённые связи; переключатели и внешние входы могут менять путь исполнения и значения виджетов. Полный запуск с весами здесь не выполнялся.
