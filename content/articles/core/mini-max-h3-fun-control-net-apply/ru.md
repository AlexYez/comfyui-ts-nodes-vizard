# MiniMax H3 Fun ControlNet Apply: управление локальной видео-моделью

Подключает совместимый Fun ControlNet к MiniMax H3 как model patch. Может использовать управляющее видео и маску для управления генерацией или перерисовкой области.

## Как пользоваться

Нужны MODEL, MODEL_PATCH и video VAE. strength задаёт влияние, start_percent/end_percent — участок расписания сэмплирования. Белая область mask означает перегенерировать. source_video читается только при подключённой mask; control_video передаёт управляющие кадры. При strength = 0 или отсутствии и control_video, и mask возвращается исходная модель.

## Пример подключения

Загрузите H3 text-to-video и подходящий Fun ControlNet patch. Для локальной правки подайте исходные кадры, маску области и согласованную по размеру видеозаготовку. Выход MODEL направьте в sampler; сначала проверьте короткий клип и правильную полярность маски.

## Ограничения и частые ошибки

Это не универсальный Apply ControlNet для SDXL и не удалённый API MiniMax. Patch должен соответствовать архитектуре. Процент относится к ходу сэмплирования, а не к позиции внутри ролика. Один source_video без mask не включает правку. Совместимость размеров и длительности нужно проверять во всей цепочке.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `model` | `MODEL` | да | соединение / значение без фиксированного default |
| `model_patch` | `MODEL_PATCH` | да | соединение / значение без фиксированного default |
| `vae` | `VAE` | да | соединение / значение без фиксированного default |
| `strength` | `FLOAT` | да | по умолчанию: 1.0; минимум: 0.0; максимум: 10.0; шаг: 0.01 |
| `start_percent` | `FLOAT` | да | по умолчанию: 0.0; минимум: 0.0; максимум: 1.0; шаг: 0.001 |
| `end_percent` | `FLOAT` | да | по умолчанию: 1.0; минимум: 0.0; максимум: 1.0; шаг: 0.001 |
| `control_video` | `IMAGE` | нет | соединение / значение без фиксированного default |
| `mask` | `MASK` | нет | соединение / значение без фиксированного default |
| `source_video` | `IMAGE` | нет | соединение / значение без фиксированного default |
