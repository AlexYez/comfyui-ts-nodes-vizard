# Branch: выбор ветки по имени

Передаёт на выход значение одного из подключённых входов. В отличие от переключателя с булевым условием, ветка выбирается по имени. Нода экспериментальная.

## Как пользоваться

Подключите варианты к расширяемой группе входов и переименуйте их двойным щелчком. В селекторе `branch` выберите нужное имя. Доступно до 32 входов; тип выхода согласуется с подключёнными данными, преобразования типов нет.

Выбранная ветка запрашивается лениво: нода не требует вычислять остальные варианты ради своего результата. Однако другая выходная нода может независимо запустить ту же ветку.

## Пример

Подключите исходное и увеличенное изображения, назовите входы «Исходник» и «Апскейл», затем передайте выход в Preview Image. Выбор имени меняет источник изображения, но не объединяет их.

## Ограничения

Неизвестное имя или выбранный неподключённый вход вызывают ошибку. Переименование должно согласоваться со списком `branch_names`, который поддерживает frontend; вручную редактировать только строку выбора в API-графе недостаточно. Старому frontend могут быть неизвестны новые виджеты выбора ветки.

## Входы и настройки

Снимок ComfyUI 0.43.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `autogrow` | `COMFY_AUTOGROW_V3` | да | префикс: branch |
| `autogrow → branch` | `COMFY_MATCHTYPE_V3` | нет | допустимый тип: * |
| `branch` | `STRING` | да | соединение / значение без фиксированного default |
| `branch_names` | `ARRAY` | да | соединение / значение без фиксированного default |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `output` | `COMFY_MATCHTYPE_V3` | нет |
