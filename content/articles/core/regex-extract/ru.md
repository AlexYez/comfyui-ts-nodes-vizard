# Extract Text

## 1. Назначение

`RegexExtract` извлекает совпадения или группы Python regex и возвращает их одной строкой.

## 2. Место в графе

Нода разбирает структурированный ответ, отделяет часть подсказки или собирает несколько совпадений перед дальнейшей обработкой.

## 3. Входы

Кроме текста и шаблона, доступны четыре mode, три regex-флага и `group_index` от 0 до 100. По умолчанию поиск нечувствителен к регистру, индекс группы равен 1.

## 4. Выход

Выход всегда `STRING`. Несколько результатов соединяются `\n`. Отсутствие совпадения, недоступная группа и неверный regex дают пустую строку.

## 5. Режимы совпадений

`First Match` возвращает `group(0)` первого `re.search`. `All Matches` вызывает `findall`; без групп соединяет полные совпадения, а при нескольких группах берёт только первый элемент каждого tuple. Это не равно выводу всех capture-групп.

## 6. Режимы групп

`First Group` возвращает `group(group_index)` первого совпадения, если число capture-групп не меньше индекса. Индекс 0 фактически возвращает полное совпадение. `All Groups` берёт выбранную группу из каждого совпадения; шаблон без capture-групп даёт пустой результат.

## 7. Проверенный пример

Официальные шаблоны используют `First Group` для текста после строки `---` и `First Match` для частей вокруг `--no`. Рецепт повторяет вариант `(?s)(?<=\n---\n)([\s\S]*)$`. Всего найдено 14 `RegexExtract`.

## 8. Ошибки и диагностика

Пустой выход неоднозначен: проверьте regex, наличие совпадения и `group_index`. Если `All Matches` с несколькими группами теряет данные, используйте `All Groups` для конкретного индекса или измените шаблон.

## 9. Ограничения и производительность

Все результаты собираются в память и соединяются переводами строк, которые нельзя заменить другим delimiter. Сложный regex может быть дорогим; timeout отсутствует.
