# Stitch Images: сшивание двух изображений по стороне

## Что делает нода

`ImageStitch` присоединяет `image2` к `image1`: справа, снизу, слева или сверху. Между ними можно добавить одноцветную полосу.

Если `image2` не подключено, нода возвращает `image1` без изменений. Остальные параметры в этом случае не влияют на результат.

## Место в графе

Ноду используют для референсных коллажей, storyboard, character sheet и multi-image API-входов. Несколько `ImageStitch` можно соединить цепочкой: сначала собрать строки, затем соединить строки по вертикали.

Для наложения слоёв друг на друга эта нода не подходит: изображения располагаются рядом. Перекрытие и mask-смешивание выполняет `ImageCompositeMasked`.

## Входы

`image1` — обязательная основа. `image2` — необязательное присоединяемое изображение.

`direction` задаёт положение image2 относительно image1: `right`, `down`, `left`, `up`.

`match_image_size` управляет подгонкой поперечного размера. `spacing_width` задаёт полосу от 0 до 1024 пикселей с шагом 2. `spacing_color` принимает white, black, red, green или blue.

## Выход

Выходной `IMAGE` имеет batch, равный большему из двух входных batch. Если один пакет короче, его последний кадр повторяется до нужной длины; нода не циклически перебирает все кадры короткого пакета.

При горизонтальном соединении складывается ширина, при вертикальном — высота. Поперечный размер после scale или padding становится общим.

## Как работает

При `match_image_size=true` масштабируется только `image2` с сохранением пропорций. Для left/right его высота приравнивается к высоте image1; для up/down — ширина к ширине image1. Метод фиксирован: Lanczos без crop.

При `false` меньший поперечный размер дополняется симметрично. Для white/black padding использует выбранное значение. Для red/green/blue боковой padding вокруг меньшего изображения остаётся чёрным — цвет применяется именно к полосе между изображениями.

Если число каналов различается, недостающие каналы дополняются единицами; у RGB/RGBA это даёт непрозрачный alpha. Затем при ненулевом spacing создаётся полоса, и tensors соединяются через `torch.cat`.

## Параметры направления и размера

Для `right` порядок — image1, полоса, image2. Для `left` — image2, полоса, image1. `down` помещает image2 ниже, `up` — выше.

Нечётный `spacing_width`, переданный программно, увеличивается на один до чётного. Обычный виджет уже меняет значение с шагом 2.

Подгонка image2 может заметно изменить его разрешение, но не aspect ratio. Image1 никогда не масштабируется этой нодой.

## Проверенные примеры

Официальный `utility_image_stitch` строит сетку из четырёх загрузок: две пары соединяются вправо двумя нодами (`right`, match=true, spacing=0), затем готовые строки соединяются вниз третьей нодой с теми же настройками размера.

В `api_bfl_flux_1_kontext_multiple_images_input` два изображения сначала соединяются вверх с белым spacing 8, затем третье добавляется справа с белым spacing 20. Результат одновременно идёт в Flux Kontext API и `PreviewImage`.

`templates-character_sheet` соединяет две reroute-ветки вправо и сохраняет итог. Ещё четыре workflow используют ноду для Flux Kontext, storyboard и virtual try-on референсов.

Рецепт «Собрать четыре изображения в сетку 2 × 2» повторяет точную топологию utility-шаблона. Он структурно проверен, но ещё не исполнен на четырёх тестовых файлах.

## Частые ошибки

**Второе изображение изменило размер.** По умолчанию `match_image_size=true`. Отключите его, если требуется сохранить исходные размеры и принять padding.

**Красный spacing выбран, но поля вокруг низкого изображения чёрные.** При `match_image_size=false` цветные значения применяются к центральной полосе; выравнивающий padding для RGB tuple в версии 0.32.0 остаётся чёрным.

**Короткий batch повторяет неожиданный кадр.** Нода повторяет последний кадр, а не весь пакет по кругу.

**При left/up порядок кажется обратным.** Direction описывает положение `image2` относительно `image1`.

**RGBA и RGB дали странную прозрачность.** Недостающий канал дополняется единицами. Проверьте alpha до сшивания.

## Ограничения и производительность

Lanczos resize, padding, выравнивание batch и итоговый `torch.cat` создают новые tensors. Коллажи быстро увеличивают число пикселей, особенно при многократном вертикальном и горизонтальном соединении.

Нода не ограничивает итоговый размер параметром модели и не уменьшает большой коллаж автоматически. Перед API или VAE проверьте ширину, высоту и лимиты потребителя.
