# OpticalFlowLoader

## Назначение
Нода загружает модель оптического потока для VOID. В закреплённой версии поддерживается только формат torchvision RAFT-large.
## Место в графе
Передайте `OPTICAL_FLOW` в ноду, которая строит движение или warped noise по видео. Loader сам не принимает кадры.
## Вход
`model_name` выбирается из `models/optical_flow`. Веса должны быть установлены локально; скачивания при выполнении нет.
## Выход
Возвращается patcher с `RaftOpticalFlow`, пригодный для управляемой загрузки и выгрузки ComfyUI.
## Проверка формата
State dict обязан иметь хотя бы по одному ключу с префиксами `feature_encoder.`, `context_encoder.` и `update_block.`. Иначе выдаётся явный `ValueError`.
## Загрузка модели
Создаётся `torchvision.models.optical_flow.raft_large(weights=None)`, затем загружаются веса, включается eval и float32.
## Проверенный пример
Официальный `utility_void_video_inpainting`, подграф `Video Inpaint (VOID)`, содержит один loader с `raft_large_C_T_SKHT_V2-ff5fadd5.safetensors`; его `OPTICAL_FLOW` подключён к `VOIDWarpedNoise`, а имя весов вынесено наружу как COMBO-вход. Отдельно проверены три сигнатуры, запрет встроенного скачивания и точность float32. Полный RAFT inference на реальных кадрах не выполнялся.
## Ошибки
Файл другого RAFT-варианта может пройти проверку префиксов, но упасть на формах state dict. Отсутствующий путь останавливает выполнение до создания модели.
## Ограничения и ресурсы
RAFT-large тяжёлый и работает в float32, поэтому требует заметной GPU-памяти. Loader не меняет разрешение кадров и не задаёт качество потока.
## Совместимость и источники
Проверено по ComfyUI 0.32.0. Формат привязан к torchvision RAFT-large; расширять список по одному имени файла нельзя.
