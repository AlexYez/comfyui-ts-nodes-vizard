# Pad Image: расширение холста

Добавляет поля вокруг изображения, заполняя их цветом или зеркальным продолжением краёв. Исходная картинка не масштабируется. Это подготовка холста, а не генеративная дорисовка.

## Как пользоваться

`pad dimensions` задаёт пиксели с каждой стороны. `pad by multiplier` увеличивает ширину и высоту в указанное число раз; дополнительные пиксели делятся поровну между противоположными сторонами. `pad to multiple` дополняет каждое измерение до кратного выбранному числу. Нечётный лишний пиксель уходит вправо или вниз.

В режиме `color` выберите цвет и при необходимости `feathering`. Сглаживание затрагивает края исходного изображения на дополненных сторонах, смешивая их с цветом. Альфа из выбранного цвета игнорируется: добавленная область RGBA получает альфу 1. Зеркальный режим отражает пиксели без повторения крайнего пикселя и может многократно повторить отражение при широких полях.

## Пример

Чтобы дополнить 1000×750 до сетки 32, выберите `pad to multiple`, multiple 32: получится 1024×768. Для генеративного outpainting подготовьте отдельную маску и подходящую цепочку перерисовки — эта нода возвращает только IMAGE.

## Ограничения

Широкие поля увеличивают выходной тензор и расход памяти. Не используйте feathering, если требуется побитовое сохранение края исходника. При нулевых полях возвращается исходное изображение.

## Входы и настройки

Снимок ComfyUI 0.43.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `image` | `IMAGE` | да | соединение / значение без фиксированного default |
| `padding_type` | `COMFY_DYNAMICCOMBO_V3` | да | режимы: pad dimensions, pad by multiplier, pad to multiple |
| `padding_type=pad dimensions → left` | `INT` | да | по умолчанию: 0; минимум: 0; максимум: 16384; шаг: 1 |
| `padding_type=pad dimensions → top` | `INT` | да | по умолчанию: 0; минимум: 0; максимум: 16384; шаг: 1 |
| `padding_type=pad dimensions → right` | `INT` | да | по умолчанию: 0; минимум: 0; максимум: 16384; шаг: 1 |
| `padding_type=pad dimensions → bottom` | `INT` | да | по умолчанию: 0; минимум: 0; максимум: 16384; шаг: 1 |
| `padding_type=pad by multiplier → multiplier` | `FLOAT` | да | по умолчанию: 1.0; минимум: 1.0; максимум: 8.0; шаг: 0.01 |
| `padding_type=pad to multiple → multiple` | `INT` | да | по умолчанию: 32; минимум: 1; максимум: 16384; шаг: 1 |
| `padding_style` | `COMFY_DYNAMICCOMBO_V3` | да | режимы: color, mirror image |
| `padding_style=color → color` | `COLOR` | да | по умолчанию: #000000 |
| `padding_style=color → feathering` | `INT` | да | по умолчанию: 0; минимум: 0; максимум: 16384; шаг: 1 |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `image` | `IMAGE` | нет |
