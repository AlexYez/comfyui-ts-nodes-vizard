# FreeU: усиление backbone и частотная фильтрация skip-связей

## Что делает нода

`FreeU` принимает `MODEL`, клонирует его и добавляет patch выходных блоков U-Net. Нода вмешивается в место, где decoder соединяет текущий backbone-тензор `h` со skip-тензором `hsp` из encoder. Она не меняет веса checkpoint и не добавляет новый sampling step.

Patch действует только на двух уровнях каналов. Сначала он читает `model_channels` из конфигурации U-Net. Если число каналов `h` равно `model_channels × 4`, используются `b1` и `s1`; при `model_channels × 2` — `b2` и `s2`. На остальных уровнях оба тензора проходят без изменений.

На подходящем уровне первая половина каналов `h` равномерно умножается на `b`. Skip-тензор `hsp` переводится в float32, преобразуется двумерным FFT по последним осям и сдвигается так, чтобы низкие частоты оказались в центре. Коэффициент `s` применяется только к центральному прямоугольнику `2 × 2`; остальной спектр сохраняется. Обратный FFT возвращает исходный dtype.

Метод FreeU основан на наблюдении авторов, что backbone U-Net в основном отвечает за denoising-семантику, а skip-связи приносят высокочастотные признаки. ComfyUI реализует конкретную форму этого перевзвешивания, поэтому смысл статьи опирается на точный patch, а не на общее обещание качества.

## Когда использовать и когда не использовать

FreeU удобно проверять на U-Net-модели, когда нужен контролируемый опыт с балансом крупных структур и мелких признаков. Сохраните baseline без patch, зафиксируйте seed, prompt, sampler, sigmas, CFG и размер, затем добавьте ноду. Сравнивайте не только резкость, но и форму объектов, фон, текстуры и соответствие prompt.

Нода зависит от `unet_config["model_channels"]` и от классического output-block contract с 4D feature maps. Для transformer-модели без этого поля `execute` завершится ошибкой ещё до sampling. На архитектуре с другими channel stages patch может ни разу не сработать, хотя граф останется формально валидным.

Не переносите параметры между моделями вслепую. Runtime defaults `b1 = 1.1`, `b2 = 1.2`, `s1 = 0.9`, `s2 = 0.2` отличаются от некоторых наборов в reference-репозитории FreeU. Сам репозиторий приводит разные значения для SD 1.x, SD 2.1 и SDXL. Wizard фиксирует defaults ComfyUI 0.32.0 как воспроизводимую отправную точку, а не универсальный preset.

Для video feature map формы `B, C, T, H, W` pinned helper непригоден: он распаковывает FFT-тензор строго как `B, C, H, W`. Первая попытка вызывает исключение, CPU fallback повторяет ту же функцию и снова падает. Упоминание video в статье FreeU не доказывает совместимость этой конкретной реализации со всякой video-архитектурой.

## Короткий рецепт подключения

1. Подайте совместимый U-Net `MODEL` в `FreeU`.
2. Для первого опыта оставьте `b1 = 1.1`, `b2 = 1.2`, `s1 = 0.9`, `s2 = 0.2`.
3. Передайте выходной `MODEL` в прежний sampler или guider path.
4. Сгенерируйте baseline тем же seed без FreeU.
5. Если нужно понять вклад частей, сначала верните `b1` и `b2` к `1`, затем отдельно верните `s1` и `s2` к `1`.
6. Меняйте по одному коэффициенту и следите за артефактами, а не только за общей контрастностью.

Fragment «FreeU: source-derived runtime defaults» содержит одну patch-ноду и внешний вход `MODEL`. В официальном workflow wheel 0.1.42 точный `FreeU` не найден ни в одном из 512 JSON и recursive subgraphs, поэтому fragment не называется официальным кейсом и не включает фиктивный полный workflow.

## Входы, выходы и параметры

`model` — обязательный `MODEL`. Нода читает `model.model.model_config.unet_config["model_channels"]`, клонирует patcher и регистрирует `output_block_patch` на копии.

`b1` — advanced `FLOAT`, default `1.1`, диапазон `0…10`, шаг `0.01`. Он умножает первую половину каналов `h` на уровне `model_channels × 4`. `b1 = 1` оставляет этот участок без изменений, `0` обнуляет половину каналов, значения выше единицы усиливают их равномерно.

`b2` имеет тот же диапазон и шаг, default `1.2`, но применяется на уровне `model_channels × 2`.

`s1` — advanced `FLOAT`, default `0.9`, диапазон `0…10`, шаг `0.01`. Он масштабирует центральные `2 × 2` frequency bins skip-тензора на первом из двух уровней. `s1 = 1` делает Fourier-фильтр тождественным с учётом погрешности FFT; остальные частоты при любом `s1` получают множитель `1`.

`s2` работает так же на втором уровне, default `0.2`. Выход — один `MODEL`. Exact NodeId — `FreeU`, модуль — `comfy_extras.nodes_freelunch`, категория — `model/patch/unet`; display name и runtime aliases отсутствуют.

## Типовые связки

Самая простая цепочка — `CheckpointLoader → FreeU → sampler`. В custom sampling выход FreeU можно передать в `CFGGuider` и scheduler, который читает model sampling object, затем собрать `GUIDER`, `SIGMAS`, noise, sampler и latent в `SamplerCustomAdvanced`.

`FreeU_V2` использует те же channel stages и тот же Fourier-фильтр skip-связи, но коэффициент `b` превращает в пространственную карту усиления. Эти ноды связаны, но не являются aliases и не должны автоматически стоять одна за другой.

`FreSca` тоже работает в частотной области, однако фильтрует не skip feature map, а CFG-разность `conditional − unconditional` перед итоговым смешиванием. Замена FreeU на FreSca меняет и место patch, и обрабатываемый тензор.

Несколько output-block patches исполняются последовательно в порядке регистрации. Если поставить `FreeU`, затем `FreeU_V2`, второй patch увидит уже изменённые `h` и `hsp`. Exact probe показал, что перестановка этих двух patches меняет backbone-результат; порядок входит в конфигурацию эксперимента.

## Практический пример

Model-free probe использовал `model_channels = 4`, поэтому первый уровень соответствовал `16` каналам. При `b1 = 1.1` patch точно умножил каналы `0…7` на `1.1`, а каналы `8…15` оставил прежними. Тензор с `12` каналами не совпал ни с одним порогом и прошёл побитово без изменений.

Skip-вход был постоянным float16-тензором. У постоянного сигнала энергия сосредоточена в центральной DC-компоненте, поэтому `s1 = 0.9` дал приблизительно `0.8999` после возврата в float16. Dtype сохранился. Отдельная проверка `s = 1` воспроизвела исходный тензор в пределах численной погрешности FFT.

Probe также передал 5D skip-тензор и получил `ValueError` после CPU retry. Это проверка точного helper, а не полный model run. Для практического A/B-теста используйте обычную 4D image U-Net, сначала подтвердите соответствие channel stages, затем оценивайте изображения при одинаковом seed.

## Частые ошибки и способы проверки

**Нода не меняет результат.** Проверьте, есть ли в модели `model_channels` и встречаются ли в decoder тензоры с `4×` и `2×` каналами. Если channel counts не совпадают, patch честно обходит все блоки.

**Появилась ошибка FFT на устройстве.** FreeU запоминает устройство, для которого первая попытка упала, и дальше фильтрует skip на CPU с возвратом назад. Это может замедлить каждый подходящий блок. Если CPU retry тоже падает, проверьте форму: 5D input не поддерживается helper этой версии.

**`s1 = 0` должен был удалить всю skip-связь.** Он обнуляет лишь центральные `2 × 2` frequency bins. Высокочастотная часть остаётся. Чтобы понять точное действие, не описывайте `s` как общий множитель всего `hsp`.

**После добавления FreeU_V2 эффект стал непредсказуемым.** Два output patches складываются, а не заменяют друг друга. Уберите один patch или явно зафиксируйте порядок; сравнение одиночных нод обычно информативнее.

**Параметры из чужого workflow дают артефакты.** Сверьте архитектуру и версию реализации. Channel thresholds масштабируются через `model_channels`, но одинаковые числа `b/s` не обязаны иметь одинаковый визуальный смысл на разных checkpoint.

## Производительность и внутреннее поведение

Умножение половины backbone-каналов выполняется на месте. Skip-фильтр создаёт float32 complex spectrum и полноразмерную маску `B × C × H × W`, затем делает FFT, shift, умножение и inverse FFT. На больших feature maps временная память и цена преобразований заметнее, хотя дополнительного U-Net forward нет.

Порог Fourier filter жёстко равен `1`, поэтому на обычной карте центральная область имеет размер `2 × 2`, а не радиус, зависящий от разрешения. Если пространственная ось короче двух позиций, фактический срез ограничивается её размером. Основной расчёт рассчитан на обычные decoder feature maps.

CPU fallback оборачивает любой exception первой FFT-попытки, а не только отсутствие backend. После первого сбоя устройство попадает в `on_cpu_devices`, и следующие вызовы сразу идут через CPU. Копирование между CPU и accelerator становится частью каждого подходящего блока.

Два stage patches используют один closure с параметрами и состоянием fallback. Клон модели хранит функцию; исходный model patcher не меняется.

## Совместимость, изменения и устаревание

Статья проверена по ComfyUI 0.32.0, commit `c2bcbecd…`, frontend 1.48.7 и exact `/object_info`. Runtime-флаги `experimental`, `deprecated`, `dev_only` и `api_node` равны `false`. В Node Replacement API этой версии записи для `FreeU` нет.

Метод `patch = execute` оставлен в Python-классе с комментарием TODO, но exact runtime NodeId остаётся `FreeU`; это внутренний совместимый entry point, а не alias статьи. Resolver должен использовать module и NodeId.

Embedded docs 0.5.9 верно связывает `b1/s1` с `model_channels × 4`, а `b2/s2` — с `×2`. Ограничение 4D, точный центральный срез, in-place half-channel update и CPU fallback требуют чтения исходника. После обновления ComfyUI сверяйте fingerprint и этот контракт.

## Связанные ноды и источники

`FreeU_V2` добавляет пространственную min-max карту усиления backbone. `FreSca` фильтрует CFG guidance, а не decoder skip. Связь помогает выбрать место воздействия, но не объявляет методы взаимозаменяемыми.

Технические детали сверены с `comfy_extras/nodes_freelunch.py`, embedded docs 0.5.9, [официальным репозиторием FreeU](https://github.com/ChenyangSi/FreeU) и работой [FreeU: Free Lunch in Diffusion U-Net](https://arxiv.org/abs/2309.11497). Exhaustive census workflow wheel 0.1.42 дал ноль точных экземпляров. Tensor-probe подтвердил channel branches, FFT, dtype, 5D failure и stacking order; полный fragment, качество изображений и человеческое утверждение ещё не проверены.
