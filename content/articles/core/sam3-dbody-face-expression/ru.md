# Face Expression to SAM3D Body: мимика по исходным кадрам

Добавляет выражение лица к MHR-позе: распознаёт facial blendshapes, переводит их в параметры MHR и пересчитывает геометрию. Не заменяет восстановление тела через Predict.

## Как пользоваться

Нужны та же модель, mhr_pose_data и соответствующие image. strength управляет общей амплитудой, mouth_strength, eye_strength и brow_strength — группами движений. input_threshold отсекает малые сигналы. blendshape_smooth_window задаёт нечётное окно сглаживания; 1 отключает его. Для достаточно длинного клипа вычитается оценка фонового смещения мимики.

## Пример подключения

Соедините SAM3DBody_Predict с этой нодой и подайте те же кадры в том же порядке. Начните с исходных множителей и проверьте лицо через Render. Если рот или глаза двигаются чрезмерно, уменьшайте соответствующий множитель отдельно от общего strength.

## Ограничения и частые ошибки

Маленькие, закрытые или повёрнутые лица распознаются хуже. Реализация пытается заполнить короткие пропуски, но это не доказательство точной мимики. Для последовательности людей важно устойчивое соответствие между кадрами. При более коротком IMAGE-batch используется последний доступный кадр, что не заменяет правильную синхронизацию.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `sam3d_body_model` | `SAM3D_BODY_MODEL` | да | соединение / значение без фиксированного default |
| `mhr_pose_data` | `MHR_POSE_DATA` | да | соединение / значение без фиксированного default |
| `image` | `IMAGE` | да | соединение / значение без фиксированного default |
| `strength` | `FLOAT` | да | по умолчанию: 1.0; минимум: 0.0; максимум: 4.0; шаг: 0.05 |
| `mouth_strength` | `FLOAT` | да | по умолчанию: 1.0; минимум: 0.0; максимум: 4.0; шаг: 0.05 |
| `eye_strength` | `FLOAT` | да | по умолчанию: 2.0; минимум: 0.0; максимум: 4.0; шаг: 0.05 |
| `brow_strength` | `FLOAT` | да | по умолчанию: 2.0; минимум: 0.0; максимум: 4.0; шаг: 0.05 |
| `input_threshold` | `FLOAT` | да | по умолчанию: 0.02; минимум: 0.0; максимум: 0.5; шаг: 0.01 |
| `blendshape_smooth_window` | `INT` | да | по умолчанию: 7; минимум: 1; максимум: 31; шаг: 2 |
