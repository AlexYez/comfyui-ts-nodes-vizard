# ComfyNotNode

## Что делает нода

`ComfyNotNode` применяет Python-оператор `not` к одному входу и возвращает `BOOLEAN`. На входе стоит AnyType `*`, поэтому нода умеет проверять не только готовый bool, но и истинность числа, строки или другого значения.

Результат всегда типизирован как `BOOLEAN`, даже если исходное значение было STRING или INT.

## Когда она нужна и когда не нужна

Нода нужна для инверсии флага и простых проверок «значение пусто/нулевое». Например, `not ""` даёт true, а `not "ready"` — false.

Для сравнения числа с порогом или строки с образцом используйте expression/compare. Python truthiness отвечает только на общий вопрос об истинности и может быть не тем условием, которое требуется графу.

## Короткий рецепт подключения

В source-derived рецепте пустая `PrimitiveString` идёт в `ComfyNotNode`:

1. Оставьте строку пустой.
2. Подключите её к `value`.
3. Результат NOT будет true.
4. Подайте его вместе с непустой строкой в `ComfyAndNode`.

Так одновременно видны инверсия и последующее объединение условий.

## Вход и правила truthiness

`value` принимает `*`. Falsy в обычном Python: `False`, `None`, числовой ноль, пустая строка, пустая коллекция. Непустая строка `"false"` truthy, потому что её содержимое не разбирается как boolean.

Некоторые объекты не имеют однозначной истинности. Например, многoэлементный tensor PyTorch при `bool(tensor)` обычно вызывает ошибку «Boolean value of Tensor ... is ambiguous».

## Выход и место в графе

Выход `BOOLEAN` можно подключить к `ComfySwitchNode`, boolean-параметру, `ComfyAndNode` или `ComfyOrNode`. Разместите NOT рядом с источником, чтобы инверсия была видна.

Если флаг уже имеет подходящий смысл, лишняя двойная инверсия только усложнит чтение. Лучше переименовать title источника и оставить формулу короткой.

## Как работает внутри

Выполнение состоит из `io.NodeOutput(not value)`. Нет преобразования строки, проверки типа или try/catch вокруг truth test.

AnyType расширяет совместимость сокета, но не гарантирует, что любой Python-объект безопасно приводится к bool. Ответственность за такой объект остаётся у автора графа.

## Практический пример

Проверьте четыре значения через `PreviewAny`: пустая строка → true, `ready` → false, INT 0 → true, INT 1 → false. Затем сравните строку `"false"`: результат будет false, потому что сама строка непустая.

Эта таблица помогает обнаружить ошибку, когда текстовый флаг по ошибке подключили вместо `PrimitiveBoolean`.

## Частые ошибки и проверка

- Считают строку `"false"` ложью. Для Python это непустая строка.
- Подключают image/latent tensor и получают неоднозначную boolean-ошибку.
- Используют NOT вместо сравнения с нулём или порогом.
- Ожидают возврат исходного типа. Выход всегда BOOLEAN.
- Не замечают двойную инверсию перед switch.

## Ограничения и производительность

Для scalar и строки операция дешева. Она не делает upstream-вход lazy: значение должно быть доступно, прежде чем NOT сможет его проверить.

Подключение большого tensor не означает сканирование его элементов, но попытка truth conversion может завершиться ошибкой. Для tensor-условия сначала вычислите явный scalar.
