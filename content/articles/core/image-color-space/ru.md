# Image Color Space: преобразование цвета SDR, HDR и linear

Пересчитывает значения RGB между поддерживаемыми цветовыми пространствами. Используется при согласовании изображений, линейных данных и HDR, а не для произвольного изменения насыщенности.

## Как пользоваться

source и destination выбираются явно: sRGB, линейный Rec.709, HLG Rec.2020 или PQ Rec.2020. Это не автоматическое чтение профиля файла. Преобразования учитывают передаточную функцию и первичные цвета; для HDR используются принятые в реализации уровни белого. Alpha у RGBA переносится без изменения.

## Пример подключения

Если следующий этап ожидает линейный RGB, переведите корректно интерпретированный sRGB в linear, выполните нужную операцию, затем верните sRGB перед обычным просмотром. Для HDR согласуйте destination с настройкой сохранения видео, иначе правильные числа будут показаны неверно.

## Ограничения и частые ошибки

Ошибка в source приводит к двойной гамме или неверной яркости. Linear может содержать значения вне диапазона 0–1; последующая нода способна их обрезать. Некоторые направления используют тональное отображение и сжатие охвата, поэтому круговой переход не обязан восстанавливать исходник побитно.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `image` | `IMAGE` | да | соединение / значение без фиксированного default |
| `source` | `COMBO` | да | по умолчанию: sRGB; варианты: sRGB, HDR, HDR PQ, linear |
| `destination` | `COMBO` | да | по умолчанию: sRGB; варианты: sRGB, HDR, HDR PQ, linear |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `IMAGE` | `IMAGE` | нет |
