# T5TokenizerOptions

## Назначение
`T5TokenizerOptions` задаёт минимальное дополнение и минимальную длину последовательности для T5-составляющих объекта `CLIP`. Она полезна моделям, где форма T5-токенов должна быть не короче выбранного порога.

## Место в графе
Поставьте ноду после загрузчика CLIP и перед любой нодой текстового кодирования. Выход подключается вместо исходного `CLIP`; уже вычисленный `CONDITIONING` эта настройка не меняет.

## Входы
`clip` — исходный объект CLIP. `min_padding` и `min_length` — целые числа от 0 до 10000 с шагом 1; оба по умолчанию равны 0.

## Выходы
Возвращается клон `CLIP` с изменёнными параметрами токенизатора. Исходный объект остаётся доступным другим ветвям графа без этих настроек.

## Как работает
После `clip.clone()` нода обходит пять префиксов: `t5xxl`, `pile_t5xl`, `t5base`, `mt5xl` и `umt5xxl`. Для каждого она задаёт опции `<тип>_min_padding` и `<тип>_min_length` одинаковыми входными значениями.

## Параметры
`min_padding` требует не менее заданного числа дополняющих позиций; `min_length` задаёт нижнюю границу полной длины. Точный итог зависит от реализации токенизатора внутри загруженного CLIP; нода не обрезает длинный текст сама.

## Проверенный пример
Фрагмент задаёт `min_padding=0` и `min_length=0`, то есть явно сохраняет минимальные значения схемы. Два официальных workflow Chroma используют ровно `[0, 0]` перед дальнейшим кодированием текста.

## Частые ошибки
Изменение не действует задним числом на готовое conditioning. Не подключайте выход параллельно с исходным CLIP, если ожидаете единое поведение: ветви получат разные tokenizer options. Большие значения увеличивают длину последовательности и расход памяти.

## Ограничения и производительность
Настройки записываются для всех пяти известных T5-вариантов, даже если текущий CLIP содержит только один из них. Сам узел лёгкий, но более длинные последовательности делают последующее кодирование и attention дороже. Нода experimental.

## Совместимость и источники
Диапазоны и fingerprint сверены с `/object_info` 0.32.0, список префиксов — с `nodes_cond.py`, два случая применения — с workflow-templates-json 0.1.42. Статья ожидает запуска с реальными моделями и человеческого утверждения.
