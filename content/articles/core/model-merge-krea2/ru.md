# ModelMergeKrea2

## Что делает нода

`ModelMergeKrea2` объединяет две совместимые Krea 2-модели по группам весов. Каждый коэффициент задаёт долю `model1`: значение `1` оставляет первую модель, `0` берёт группу из `model2`, `0,5` смешивает их поровну.

Карта описывает `first.`, `tmlp.`, `txtmlp.`, `tproj.`, два `txtfusion.layerwise_blocks.N.`, `txtfusion.projector.`, два `txtfusion.refiner_blocks.N.`, 28 `blocks.N.` и `last.`. В отличие от более простой карты transformer, здесь отдельно вынесен путь обработки текстовых признаков.

## Когда она нужна и когда не нужна

Нода нужна для аккуратных сравнений двух моделей одной Krea 2-архитектуры. Она позволяет проверить основной поток изображения отдельно от text-fusion, временной проекции и выходного слоя, не смешивая всю модель одним коэффициентом.

Не используйте её для Qwen Image только из-за родственного текстового стека: у Qwen Image другая карта и 60 transformer-блоков. Нода не объединяет text encoder, VAE или reference latents и не устраняет несовпадение форм. Для общего коэффициента есть `ModelMergeSimple`.

## Короткий рецепт подключения

1. Загрузите две совместимые Krea 2-модели.
2. Подайте базовую модель в `model1`, вторую — в `model2`.
3. Оставьте все группы равными `1` для контрольного варианта.
4. Установите `blocks.0. = 0,5`.
5. Запустите тот же Krea 2 workflow с фиксированными prompt, reference inputs и seed.

Recipe Wizard вставляет только merge-ноду и два внешних порта `MODEL`. Это source-derived fragment: exhaustive-поиск по официальным templates 0.1.42 не нашёл прямого `ModelMergeKrea2`.

## Входы и параметры

`model1` — клонируемая основа, `model2` — источник патчей. Оба входа должны иметь одинаковые имена и формы параметров Krea 2. Совпадение только типа порта `MODEL` не подтверждает совместимость.

Числовых входов 38. Четыре управляют изображением и временем, пять — text-fusion-контуром, 28 — основными `blocks`, один — `last.`. Диапазон каждого `0…1`, шаг `0,01`, default `1`. Точный порядок Wizard получает из `/object_info` текущей установки.

## Выход и место в графе

Выходной `MODEL` передают в sampler/guider либо saver. CLIP, VAE, conditioning и reference latents остаются вне merge. Их следует подключить из совместимого набора и не менять во время A/B-проверки.

Ставьте ноду сразу после двух model loaders. LoRA, attention-патчи и compile лучше применять к уже объединённому выходу; иной порядок допустим, но это будет другой эксперимент.

## Как устроено смешивание

Базовый алгоритм клонирует `model1`, получает патчи `model2` под `diffusion_model.` и для каждого ключа выбирает самый длинный совпавший префикс. Затем он оставляет долю `ratio` от первой модели и добавляет `1 - ratio` от второй.

Неохваченные ключи используют первый числовой коэффициент; для обычного вызова Krea 2 это `first.`. Поэтому неизвестный параметр не обязательно остаётся из `model1`. Порядок `kwargs` при нестандартном прямом вызове Python также влияет на fallback.

## Практический пример

Сравните три варианта: исходную `model1`, контрольный merge со всеми `1` и merge с `blocks.0. = 0,5`. Для каждого используйте одинаковые seed и reference inputs. Если третий вариант стабильно отличается, проверьте `blocks.1.` отдельно, а затем — `txtfusion.layerwise_blocks.0.` как независимую гипотезу.

Не смешивайте основной блок и text-fusion одновременно на первом шаге. Иначе нельзя понять, изменилось ли визуальное преобразование или интерпретация текстового контекста.

## Частые ошибки и проверка

- `ratio` прочитан как доля второго входа. Направление обратное: `1 = model1`, `0 = model2`.
- Подана Qwen Image или другая Qwen-подобная модель. Сверьте точный класс и набор ключей.
- Забыта отдельная группа `txtfusion.projector.` или refiner-блоки. Проверьте сохранённые settings целиком.
- A/B-тест использует разные reference images или conditioning. Зафиксируйте все внешние данные.
- Ошибка формы появляется при sampling. Вернитесь к двум checkpoint одной конфигурации; смена sampler проблему весов не исправит.

## Ограничения и производительность

Нода не знает, обучались ли модели от общей базы, и не оценивает качество смеси. Карта префиксов подтверждена исходным кодом, но реальные Krea 2 checkpoint в этой проверке не загружались и не семплировались.

Тонкая карта создаёт большое пространство комбинаций. Ведите журнал коэффициентов и меняйте одну группу за раз. Память и время зависят не только от merge, но и от dtype, offload, reference latents и дальнейших патчей.

## Совместимость, изменения и источники

Статья проверена для ComfyUI `0.32.0` и frontend `1.48.7`. Закреплённый `SingleStreamDiT` использует 28 основных слоёв и отдельный `TextFusionTransformer`; эти группы отражены в карте. Node Replacement API не объявляет замену.

Редактор пока не проверил материал вручную. Статус — `draft/in_review`; fragment прошёл схему, порты и prefix-probe, но не полноценное выполнение с моделью.
