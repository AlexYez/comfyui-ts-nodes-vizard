# Rotate Mesh: поворот геометрии

Поворачивает вершины сетки, её нормали и направления касательных. Текстуры и UV остаются привязаны к тем же вершинам; исходный объект не переписывается.

## Как пользоваться

В euler_xyz углы задаются в градусах и применяются вокруг мировых осей в порядке X, Y, Z. В quaternion порядок компонентов — w, x, y, z; кватернион нормализуется. Нулевой кватернион недопустим. Поворот выполняется вокруг начала координат, а не автоматически найденного центра сетки.

## Пример подключения

Если импортированная модель лежит на боку, задайте angle_x = 90 при нулевых остальных углах и посмотрите результат через RenderMesh. При неверном направлении попробуйте -90. Не меняйте одновременно камеру и сетку: иначе трудно понять, какая настройка исправила ориентацию.

## Ограничения и частые ошибки

Нода не переносит объект к центру и не меняет масштаб. У смещённой от начала координат модели поворот изменит и положение в кадре. Перед передачей кватерниона из другой программы проверьте порядок его компонентов и систему координат.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `mesh` | `MESH` | да | соединение / значение без фиксированного default |
| `mode` | `COMFY_DYNAMICCOMBO_V3` | да | режимы: euler_xyz, quaternion |
| `mode=euler_xyz → angle_x` | `FLOAT` | да | по умолчанию: 0.0; минимум: -360.0; максимум: 360.0; шаг: 0.1 |
| `mode=euler_xyz → angle_y` | `FLOAT` | да | по умолчанию: 0.0; минимум: -360.0; максимум: 360.0; шаг: 0.1 |
| `mode=euler_xyz → angle_z` | `FLOAT` | да | по умолчанию: 0.0; минимум: -360.0; максимум: 360.0; шаг: 0.1 |
| `mode=quaternion → qw` | `FLOAT` | да | по умолчанию: 1.0; минимум: -1.0; максимум: 1.0; шаг: 0.001 |
| `mode=quaternion → qx` | `FLOAT` | да | по умолчанию: 0.0; минимум: -1.0; максимум: 1.0; шаг: 0.001 |
| `mode=quaternion → qy` | `FLOAT` | да | по умолчанию: 0.0; минимум: -1.0; максимум: 1.0; шаг: 0.001 |
| `mode=quaternion → qz` | `FLOAT` | да | по умолчанию: 0.0; минимум: -1.0; максимум: 1.0; шаг: 0.001 |
