# Paint Mesh: цвет вершин из вокселей

Назначает каждой вершине цвет ближайшего вокселя из VOXEL. Результат хранится в vertex_colors; UV-развёртка и двумерная текстура не создаются.

## Как пользоваться

mesh и voxel_colors должны относиться к одной геометрии и системе координат. Из многоканальных PBR-данных используются только RGB. Цвета переводятся в линейное представление для glTF. При пустом поле вокселей реализация возвращает чёрные цвета вершин.

## Пример подключения

Для быстрой проверки Trellis-декодера подключите его MESH и цветной VOXEL к PaintMesh, затем к RenderMesh с режимом vertex colors. Такой просмотр помогает оценить расположение цветов до более дорогого UV-запекания.

## Ограничения и частые ошибки

Детализация цвета ограничена плотностью вершин. На редкой сетке мелкий рисунок потеряется даже при подробном поле вокселей. MeshTextureToImage не сможет извлечь результат как texture, потому что окраска вершин не является текстурой. Для текстурированного low-poly используйте BakeTextureFromVoxel и ApplyTextureToMesh.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `mesh` | `MESH` | да | соединение / значение без фиксированного default |
| `voxel_colors` | `VOXEL` | да | соединение / значение без фиксированного default |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `mesh` | `MESH` | нет |
