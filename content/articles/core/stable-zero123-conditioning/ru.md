# StableZero123_Conditioning: один ракурс камеры для пакета

## Что делает нода

`StableZero123_Conditioning` готовит три входа для семплирования моделью Stable Zero123: positive conditioning, negative conditioning и пустой `LATENT`. Нода не строит mesh и не запускает диффузию сама.

Опорное изображение проходит две независимые обработки. `CLIP_VISION` извлекает его признаки. VAE получает центрально обрезанную и билинейно масштабированную RGB-копию размером `width × height`, после чего кодирует её в latent. В positive conditioning признаки CLIP объединяются с четырёхкомпонентным описанием камеры. В negative conditioning признаки CLIP и reference latent заменяются нулями.

Камера задаётся одной парой `elevation` и `azimuth`. Она остаётся одной и той же для всего выходного пакета, даже если `batch_size` больше единицы.

## Когда использовать и когда не использовать

Нода подходит, когда нужен один заданный ракурс объекта и несколько его вариантов в одном batch. Модель, `CLIP_VISION` и VAE должны относиться к совместимой контрольной точке Stable Zero123. Согласованный набор компонентов можно получить через `ImageOnlyCheckpointLoader`.

Для ряда разных углов внутри одного batch используйте `StableZero123_Conditioning_Batched`. Для круговой многокадровой последовательности модели SV3D предназначена `SV3D_Conditioning`.

На вход `init_image` следует подавать одно изображение. Закреплённый код формирует CLIP tensor как `[1, число_изображений, признаки]`, а camera tensor — как `[1, 1, 4]`. При нескольких опорных изображениях эти размеры не совпадают; синтетическая проверка точного исходника завершилась ошибкой `torch.cat`.

## Короткий рецепт подключения

1. Загрузите совместимую контрольную точку через `ImageOnlyCheckpointLoader`.
2. Подайте его `CLIP_VISION` и VAE в одноимённые входы ноды, а одно опорное `IMAGE` — в `init_image`.
3. Укажите итоговые `width`, `height`, `batch_size`, `elevation` и `azimuth`.
4. Соедините `positive`, `negative` и `latent` с совместимым sampler, используя `MODEL` из той же контрольной точки.
5. Декодируйте результат sampler тем же VAE.

Рецепт `recipe.stable-zero123-conditioning-basic` содержит только ноду подготовки conditioning. Checkpoint, sampler и decode в него не входят: официальный пакет workflow 0.1.42 не содержит примера Stable Zero123, поэтому у справочника нет оснований предлагать настройки семплирования.

## Входы, выходы и параметры

Все восемь входов находятся в группе `required` runtime-схемы. Значение по умолчанию означает, что виджет можно не менять, но не превращает вход в optional.

| Имя | Тип | Поведение в ComfyUI 0.32.0 |
| --- | --- | --- |
| `clip_vision` | `CLIP_VISION` | Кодирует исходное `init_image` и отдаёт `image_embeds`. |
| `init_image` | `IMAGE` | Одно опорное изображение; для VAE используется только RGB. |
| `vae` | `VAE` | Кодирует масштабированную копию изображения в `concat_latent_image`. |
| `width` | `INT` | По умолчанию 256, диапазон 16–16384, шаг 8. |
| `height` | `INT` | По умолчанию 256, диапазон 16–16384, шаг 8. |
| `batch_size` | `INT` | По умолчанию 1, диапазон 1–4096; задаёт первый размер пустого latent. |
| `elevation` | `FLOAT` | Вертикальный угол от −180° до 180°, по умолчанию 0°, шаг 0,1°. |
| `azimuth` | `FLOAT` | Горизонтальный угол от −180° до 180°, по умолчанию 0°, шаг 0,1°. |

Выходы `positive` и `negative` имеют тип `CONDITIONING`. Выход `latent` содержит нулевой tensor формы `[batch_size, 4, height // 8, width // 8]`. Код не добавляет к нему `batch_index`.

## Типовые связки

`ImageOnlyCheckpointLoader` → `StableZero123_Conditioning` — основная связка: loader возвращает согласованные `MODEL`, `CLIP_VISION` и VAE. Подмена только одного компонента может привести к несовместимым размерностям или неверному conditioning.

`StableZero123_Conditioning` → `KSampler` — три выхода ноды подключаются к `positive`, `negative` и `latent_image`. Настройки sampler зависят от конкретной контрольной точки и не выводятся из схемы этой ноды.

`KSampler` → `VAEDecode` — sampled latent декодируется VAE из той же контрольной точки. Набор изображений на выходе соответствует `batch_size`, но углы камеры у всех элементов одинаковы.

CLIP Vision получает исходное изображение до масштабирования в `width × height`. Его стандартная preprocessing-ветвь отбрасывает alpha и делает центральный квадратный crop под размер vision encoder. VAE-ветвь отдельно делает center crop под заданное соотношение сторон, билинейно масштабирует результат и оставляет только RGB.

## Практический пример

Метод ноды проверен на одном синтетическом RGBA-изображении `37 × 61`. Размер результата был равен `56 × 40`, `batch_size = 3`, `elevation = 12,5`, `azimuth = −30`. В проверке использовались заглушки CLIP Vision и VAE; полный workflow с весами не запускался.

Проверка зафиксировала:

- VAE получил RGB tensor `40 × 56` после точного `common_upscale(..., "bilinear", "center")`;
- positive tensor имел форму `[1, 1, D + 4]`, где последние четыре значения совпали с формулой камеры;
- negative tensor имел форму `[1, 1, D]` и нулевой reference latent;
- пустой latent имел форму `[3, 4, 5, 7]` и не содержал `batch_index`.

Четыре значения камеры равны `−elevation` в радианах, `sin(azimuth)`, `cos(azimuth)` и `π/2`. Это внутреннее представление; вручную вычислять его в графе не требуется.

## Частые ошибки и способы проверки

- **Sampler сообщает о несовместимой размерности.** Проверьте, что `MODEL`, `CLIP_VISION` и VAE загружены из совместимого Stable Zero123 checkpoint.
- **На вход подан batch опорных изображений.** Оставьте один элемент через `ImageFromBatch`: закреплённая реализация не согласует несколько CLIP embeddings с одним camera embedding.
- **Все элементы batch показывают один и тот же угол.** Это штатное поведение этой ноды. Для углового ряда нужна версия `_Batched`.
- **Края объекта пропали.** Обе ветви используют центрирование, но с разными целевыми пропорциями. Подготовьте изображение с запасом вокруг объекта или заранее приведите его к нужному соотношению сторон.
- **Размеры не кратны 8.** UI предлагает шаг 8. Сам метод не отклоняет другое число и создаёт пустой latent через целочисленное деление `// 8`, поэтому для предсказуемого согласования используйте кратные 8.
- **Ожидается готовый 3D-файл.** Нода возвращает условия и latent для синтеза нового вида; mesh, point cloud или textured model она не создаёт.

## Производительность и внутреннее поведение

CLIP Vision и VAE вызываются по одному разу независимо от `batch_size`. Затем нода создаёт нулевой latent, объём которого растёт линейно с batch и площадью `width × height`. Сам tensor создаётся на CPU с типом `float32`; основная нагрузка появляется позже при семплировании.

Reference latent от VAE не размножается внутри ноды. Модель Stable Zero123 в `extra_conds` приводит его batch к размеру noise tensor. Когда последняя размерность cross-attention не равна 768, модель применяет `cc_projection`: так camera embedding, добавленный к признакам изображения, попадает в ожидаемое пространство.

У одиночной версии нет списка углов и нет `batch_index`. Поэтому обычная подготовка шума sampler создаёт разные шумы для элементов batch при одном seed, тогда как camera conditioning остаётся постоянным.

## Совместимость, изменения и устаревание

Статья сверена с ComfyUI 0.32.0, frontend 1.48.7 и модулем `comfy_extras.nodes_stable3d`. Runtime помечает ноду как `deprecated: false`, `experimental: false`, `api_node: false`, `dev_only: false`. В закреплённом `/api/node_replacements` её ID отсутствует.

Schema fingerprint: `sha256:64b1504203fd0c301fa0582b51bf23fb6c9d2fb6aac24bfc8a2efee37ae0dba4`.

Официальный wheel workflow templates JSON 0.1.42 просмотрен рекурсивно: 512 JSON, 496 корневых графов, 272 subgraph, 8120 нод. Строковых и типизированных вхождений `StableZero123_Conditioning` нет, поэтому topology и widgets для этой ноды нельзя подтвердить официальным примером из wheel.

Встроенная документация 0.5.9 правильно перечисляет основные выходы, но не раскрывает два разных crop, ограничение одного `init_image` и отсутствие `batch_index`. Русский файл переводит системные имена портов и дважды использует слово «высота» для `height` и `elevation`; в Wizard идентификаторы оставлены без перевода.
