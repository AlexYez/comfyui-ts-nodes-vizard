# Bake Texture From Voxel: запекание PBR-карт

Переносит цвет и PBR-данные из разреженного поля вокселей на существующую UV-развёртку сетки. Возвращает три IMAGE: base_color, metallic и roughness.

## Как пользоваться

texture_size задаёт сторону квадратного атласа. Необязательный reference_mesh — подробная сетка до упрощения: по ней уточняется положение поверхности для выборки цвета. У mesh уже должны быть UV; нода сама их не строит. При отсутствии PBR-каналов соответствующие карты получаются чёрными.

## Пример подключения

Сохраните подробный MESH отдельной веткой. Основную ветку пропустите через DecimateMesh и UnwrapMesh. Подключите её к mesh, подробную — к reference_mesh, а VOXEL текстурного декодера — к voxel_colors. Карты и тот же развёрнутый mesh передайте в ApplyTextureToMesh.

## Ограничения и частые ошибки

После запекания нельзя менять развёртку или подставлять похожую сетку с другими UV. Увеличение texture_size повышает расход памяти и не добавляет исходных деталей воксельного поля. Чёрная roughness означает гладкую поверхность; проверьте, подходит ли такой материал, если вход не содержал PBR.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `mesh` | `MESH` | да | соединение / значение без фиксированного default |
| `voxel_colors` | `VOXEL` | да | соединение / значение без фиксированного default |
| `texture_size` | `INT` | да | по умолчанию: 2048; минимум: 64; максимум: 8192 |
| `reference_mesh` | `MESH` | нет | соединение / значение без фиксированного default |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `base_color` | `IMAGE` | нет |
| `metallic` | `IMAGE` | нет |
| `roughness` | `IMAGE` | нет |
