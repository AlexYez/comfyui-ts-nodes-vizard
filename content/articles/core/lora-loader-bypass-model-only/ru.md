# LoraLoaderBypassModelOnly

## Назначение
Нода — экспериментальный локальный загрузчик LoRA только для диффузионной модели. В режиме bypass адаптеры не складываются заранее с базовыми весами, а подключаются к вычислению слоёв во время прямого прохода. CLIP на входе и выходе отсутствует.
## Место в графе
Подключите её после загрузчика `MODEL`, когда нужно проверить обходное применение LoRA, работу с выгружаемыми весами или обучающий сценарий. Для обычной генерации без специальной причины стабильнее использовать штатный модельный загрузчик LoRA.
## Входы
`model`, `lora_name` и `strength_model` обязательны. Имя выбирается из локального каталога `models/loras`; сила допускает диапазон −100…100 с шагом 0,01. Отрицательное значение передаётся адаптеру как множитель, но визуальный смысл зависит от конкретной LoRA.
## Выход
Возвращается один клон `MODEL`; объект CLIP не создаётся и не передаётся дальше. Файл при этом разбирается целиком, но CLIP-ключи не находят цели и записываются в журнал как незагруженные.
## Как работает
Класс наследует `LoraLoaderBypass`, вызывает его с `clip=None` и `strength_clip=0`, затем берёт первый результат. Адаптерные записи `WeightAdapterBase` превращаются в инъекции forward-прохода; diff, set и bias-записи остаются обычными весовыми заплатками.
## Нулевая сила
При `strength_model=0` обе фактические силы равны нулю. Родительский метод сразу возвращает исходный `MODEL` без разрешения пути и чтения файла. Это настоящий короткий обход, а не загруженная LoRA с нулевым множителем; выход в этой ветви не является новым клоном.
## Кэш
Экземпляр ноды хранит один кэш вида `(полный путь, словарь весов)`. Другой путь очищает кэш и загружается заново. Замена содержимого файла по прежнему пути сама по себе не обнаруживается, поэтому после перезаписи LoRA нужно пересоздать ноду или иначе сбросить её экземпляр.
## Ошибки
Путь проверяется через `get_full_path_or_raise`, файл читается с `safe_load=True`. Ключи, отсутствующие в state dict модели, и записи, не применённые ни к модели, ни к CLIP, попадают в предупреждения. Совместимость формы окончательно проверяется в адаптере и целевом слое.
## Ограничения и ресурсы
«Model Only» означает отсутствие CLIP-ветви, а не предварительную фильтрацию файла. Инъекции добавляют вычисление LoRA при каждом прямом проходе и могут быть медленнее заранее объединённых весов. В 512 официальных JSON нода не встречается; её отладочный рецепт основан на исходнике, а не на проверенном production workflow.
## Совместимость и источники
Проверено по ComfyUI 0.32.0, frontend 1.48.7, `nodes_lora_debug.py`, `comfy/sd.py`, `/object_info` и полному пакету официальных workflow. Нода экспериментальная, формальной замены нет; реальные LoRA и модельный forward Wizard не исполнял, человеческое утверждение ожидается.
