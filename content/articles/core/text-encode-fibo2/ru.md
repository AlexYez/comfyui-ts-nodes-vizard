# Fibo 2.0: текстовые условия и редактирование

Готовит положительные и отрицательные условия и пустой LATENT для локальной Fibo 2.0. Принимает обычный текст или структурированную JSON-подпись; с изображениями промпт задаёт инструкцию редактирования.

## Как пользоваться

Подключите энкодер Fibo 2.0, задайте `prompt`, `negative_prompt`, размеры и размер пакета. Референсы обозначаются в инструкции как `<image_1>`, `<image_2>` и далее. Порты обрабатываются в числовом порядке; изображения из входных пакетов разворачиваются в отдельные референсы.

Нулевые width/height выбирают обученный размер около 1 MP по пропорциям первого изображения, а без изображений — 1024. Явные размеры округляются вниз до кратного 16 с минимумом 16. Одно изображение подгоняется с центральной обрезкой к размеру результата; несколько — каждое к своему обученному размеру.

С VAE референсы кодируются и добавляются в обе ветви условий. Без VAE изображения всё ещё могут участвовать в текстовом кодировании, но reference_latents не создаются. Выходной LATENT имеет форму `[batch_size,128,height//16,width//16]`.

## Пример

Для редактирования подайте изображение, совместимый VAE и инструкцию, например заменить предмет, сохранив сцену. Подключите все три выхода к сэмплеру Fibo 2.0 и декодируйте его результат соответствующим VAE. Пустой отрицательный промпт использует предусмотренную моделью пустую подпись.

## Ограничения

Обычный энкодер SDXL не становится совместимым из-за общего типа CLIP. Проверяйте нумерацию, если на одном порте пакет: число реальных референсов может превышать число подключённых портов. Размер выходного латента не гарантирует сохранения пикселей исходника или точного выполнения инструкции.

## Входы и настройки

Снимок ComfyUI 0.43.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `clip` | `CLIP` | да | соединение / значение без фиксированного default |
| `prompt` | `STRING` | да | соединение / значение без фиксированного default |
| `negative_prompt` | `STRING` | да | соединение / значение без фиксированного default |
| `images` | `COMFY_AUTOGROW_V3` | да | входы: image_1 … image_16 |
| `images → image` | `IMAGE` | да | соединение / значение без фиксированного default |
| `width` | `INT` | да | по умолчанию: 0; минимум: 0; максимум: 16384; шаг: 16 |
| `height` | `INT` | да | по умолчанию: 0; минимум: 0; максимум: 16384; шаг: 16 |
| `batch_size` | `INT` | да | по умолчанию: 1; минимум: 1; максимум: 4096 |
| `vae` | `VAE` | нет | соединение / значение без фиксированного default |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `positive` | `CONDITIONING` | нет |
| `negative` | `CONDITIONING` | нет |
| `latent` | `LATENT` | нет |

## Источники и проверка

[Реализация ComfyUI 0.43.0](https://github.com/Comfy-Org/ComfyUI/blob/426f5eea52a7ece1dd599fff4cb6cd1f352ddd24/comfy_extras/nodes_fibo2.py#L28-L89). Входы и выходы сверены с чистым серверным снимком. Пример поясняет подключение, но не подтверждает выполненную генерацию с весами. Человеческое утверждение ещё нужно.

## Официальные примеры подключения

В закреплённом пакете [workflow-templates-json 0.1.123](https://pypi.org/project/comfyui-workflow-templates-json/0.1.123/) найдено 2 вхождений. Примеры сохранённых связей:

- `image_fibo2_edit_dev_pe.json`, подграф «main»: входы от `CLIPLoader`, `LoadImage`, `PreviewAny`, `VAELoader`; выходы к `KSampler`.
- `image_fibo2_edit_turbo_pe.json`, подграф «main»: входы от `CLIPLoader`, `LoadImage`, `PreviewAny`, `VAELoader`; выходы к `KSampler`.

Это автоматическая сверка сохранённых соединений, не запуск и не ручная проверка всех сценариев. Внешние входы и переключатели подграфа могут менять путь выполнения.
