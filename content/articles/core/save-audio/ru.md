# SaveAudio: устаревшее сохранение FLAC

## Что делает нода

`SaveAudio` записывает входной `AUDIO` в FLAC-файл внутри каталога `output`. FLAC — единственный формат этой ноды; виджета выбора кодека или качества нет.

Каждый элемент waveform-batch сохраняется отдельно. После записи нода возвращает исходный объект `AUDIO` через подключаемый выход `audio`, поэтому его можно передать дальше без повторного чтения файла.

В ComfyUI 0.32.0 класс помечен `deprecated`. Для новых графов предназначен `SaveAudioAdvanced`, где FLAC выбирается в одном общем виджете вместе с MP3 и Opus.

## Когда использовать и когда не использовать

Оставляйте `SaveAudio` в старом рабочем графе, если он открывается и воспроизводимо создаёт нужные FLAC. Срочной замены ради одного запуска не требуется, но перед публикацией или долгим хранением workflow лучше перейти на актуальную ноду.

Не добавляйте `SaveAudio` в новый граф: deprecated-тип может исчезнуть в будущей версии. Для временного прослушивания используйте `PreviewAudio`, а для постоянного FLAC — `SaveAudioAdvanced` с `format: flac`.

Нода не меняет громкость, sample rate, длительность или batch. Подготовьте сигнал заранее и сведите материал к mono или stereo: общий writer helper не сохраняет многоканальный звук корректно.

## Короткий рецепт подключения

1. Подключите готовый `AUDIO` к старой `SaveAudio` и запишите её `filename_prefix`.
2. Добавьте `SaveAudioAdvanced` рядом, выберите `flac` и перенесите тот же prefix.
3. Переподключите вход и, если старый выход использовался дальше, перенесите эту связь на выход `audio` новой ноды.
4. Запустите копию графа и сравните число файлов, sample rate, каналы и длительность.
5. Удалите старую ноду только после проверки пути и downstream-связей.

Fragment «Заменить SaveAudio на SaveAudioAdvanced без смены формата» содержит только актуальную ноду с FLAC и внешний `AUDIO`. Он служит шаблоном миграции, а не автоматическим преобразователем старого workflow; полный fragment с пользовательским звуком не запускался.

## Входы, выходы и параметры

`audio` — обязательный `AUDIO`. При прямом вызове с `None` класс выдаёт `ValueError` и предлагает проверить, была ли аудиодорожка у исходного видео. `filename_prefix` — строка с runtime-default `audio/ComfyUI`.

Выход `audio` имеет тип `AUDIO` и не является list-output. Это тот же объект, который пришёл на вход. Дополнительно UI-result содержит список сохранённых файлов с `type: output`.

Waveform ожидается в форме `[B,C,T]`. Helper проходит по `B`, поэтому создаёт отдельный `.flac` для каждого batch-элемента. `%batch_num%` в имени заменяется его номером; затем добавляется пятизначный счётчик.

## Типовые связки

В старых графах `VAEDecodeAudio → SaveAudio` сохраняет сгенерированный waveform без потерь кодека. `AudioMerge → SaveAudio` пишет сведённую дорожку, а выход saver может продолжить ветку в `CreateVideo` или другую AUDIO-ноду.

При миграции эквивалентная связка выглядит как `источник AUDIO → SaveAudioAdvanced(format=flac)`. Подключаемые вход и выход сохраняют тип, а общий writer helper у обеих нод один и тот же.

Не используйте `LoadAudio` сразу после saver только ради продолжения графа: passthrough уже передаёт исходный tensor. Повторная загрузка нужна лишь тогда, когда проверяется именно файл после кодирования.

## Практический пример

Полный просмотр 512 JSON из `comfyui-workflow-templates-json 0.1.42`, включая 272 subgraph, не нашёл ни одной `SaveAudio`. Для этой deprecated-ноды нет официальных widget values или активной topology в закреплённом наборе.

Изолированный вызов точного класса 0.32.0 записал синтетический stereo `AUDIO` в FLAC, вернул тот же входной объект и UI-result типа `output`. Batch из двух элементов дал два файла. Отдельная проверка общего helper показала, что частота 8 кГц сохраняется без resample.

Fragment миграции построен по совпадающим runtime-портам и FLAC-ветке `SaveAudioAdvanced`. Его не импортировали в живой frontend и не запускали с пользовательским аудио, поэтому research ledger оставляет `exampleExecuted: false`.

## Частые ошибки и способы проверки

**Считают deprecated синонимом нерабочей ноды.** В 0.32.0 класс зарегистрирован и исполняется. Метка означает, что для новых графов следует выбрать замену.

**После замены изменился каталог.** Перенесите `filename_prefix` дословно. Runtime-default обеих нод — `audio/ComfyUI`, но пользовательский prefix может быть другим.

**Ждут один файл для всего batch.** Writer создаёт по файлу на каждый `B`. Проверьте список UI-result и счётчики.

**Полагаются на embedded docs и теряют downstream-связь.** Документация 0.5.9 ошибочно говорит, что выхода данных нет. Runtime объявляет `audio: AUDIO`, а execute возвращает входной объект.

**Сохраняют три и более каналов.** Любое `C != 1` helper объявляет stereo и flatten-ит данные. Сведите их до одного или двух каналов заранее.

## Производительность и внутреннее поведение

Каждый batch-элемент переносится на CPU, переводится в NumPy и целиком кодируется в `BytesIO`; затем буфер записывается на диск. FLAC не теряет данные из-за сжатия, но требует CPU-времени и дополнительной памяти под кодированный буфер.

Sample rate берётся из входного словаря и для FLAC не меняется. Layout выбирается как `mono` при одном канале и `stereo` во всех остальных случаях. Амплитуда не нормализуется и не ограничивается.

При включённых metadata helper добавляет сериализованные `prompt` и `extra_pnginfo` в контейнер. Дополнительные произвольные поля AUDIO в файл не записываются, однако сохраняются в passthrough-объекте.

## Совместимость, изменения и устаревание

Статья закреплена на ComfyUI `0.32.0`, frontend `1.48.7`, runtime ID `SaveAudio` и модуле `comfy_extras.nodes_audio`. Fingerprint: `sha256:78194763541a8d2f37ed547686c4c4680d6018224dbd6cdc5021be2db8a4b975`.

Runtime ставит `deprecated: true`, `output_node: true`; experimental и dev-only выключены. Отображаемое имя прямо содержит `(DEPRECATED)`.

В `/api/node_replacements` 0.32.0 нет автоматического правила для аудиосейверов. `replacedBy: core.save-audio-advanced` в каталоге — редакционная рекомендация по функциональной замене, а не обещание автоматической миграции frontend.
