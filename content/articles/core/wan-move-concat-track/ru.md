# WanMoveConcatTrack

## Назначение

`WanMoveConcatTrack` объединяет два набора Wan Move trajectories в один объект `TRACKS`. Она добавляет новые точки управления на каждом кадре, а не соединяет две траектории последовательно по времени.

## Место в графе

Используйте ноду после `GenerateTracks`, `WanMoveTracksFromCoords` или другого источника `TRACKS`. Результат передаётся в визуализатор либо `WanMoveTrackToVideo`. Для временного продолжения траекторий эта нода не подходит.

## Входы

`tracks_1` обязателен в runtime-схеме, `tracks_2` необязателен. На уровне Python метод принимает `None` для обоих, но нормальный граф должен предоставить первый объект. Каждый объект ожидается как словарь с `track_path` и `track_visibility`.

## Pass-through

Если `tracks_2` отсутствует, метод возвращает `tracks_1` без clone или копирования tensor. Downstream получает тот же объект, поэтому нода в этой ветви не нормализует dtype, устройство, форму или metadata.

## Объединение path

При двух входах `torch.cat` соединяет `track_path` по `dim=1`. Для формы `[T,N,2]` это измерение числа tracks: временная длина и две координаты должны совпасть. Порядок сохраняется — сначала все tracks первого входа, затем второго.

## Объединение visibility

`track_visibility` соединяется по последней оси. Для обычной формы `[T,N]` это также добавляет tracks. Temporal axis должен совпасть; нода не повторяет, не интерполирует и не обрезает видимость.

## Выход

В ветви объединения создаётся новый словарь только с двумя стандартными ключами. Любые дополнительные поля обоих входов теряются. Сами tensors создаются `torch.cat`, то есть результат не разделяет storage с исходными tensors как простой view.

## Проверенный пример

Соедините два объекта формы `[81,1,2]` с visibility `[81,1]`. Результат должен иметь path `[81,2,2]` и visibility `[81,2]`. Перед sampler визуализируйте обе траектории, чтобы проверить порядок и координатную систему.

## Ошибки и ограничения

Разная длина `T`, несовместимые dtype/device или неверная последняя размерность приводят к ошибке `torch.cat`. Нода не проверяет диапазон координат и не согласует visibility с path. Для разных длительностей сначала приведите источники к общей временной сетке.

## Совместимость и источники

Оси concat и pass-through сверены с `WanMoveConcatTrack` в `nodes_wanmove.py` ComfyUI 0.32.0. Полный Wan Move workflow и поведение на реальных модельных весах пока не исполнялись.
