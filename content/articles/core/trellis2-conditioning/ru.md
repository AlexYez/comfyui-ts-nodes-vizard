# Trellis2 Conditioning: изображение как условие 3D-генерации

Извлекает признаки изображения для Trellis2 и возвращает positive и negative conditioning. Это визуальное условие, а не кодирование текстового prompt.

## Как пользоваться

clip_vision_model должен быть совместимым визуальным энкодером. Реализация получает признаки для разрешений 512 и 1024; отрицательное условие строится из нулевых признаков. До этой ноды подготовьте область объекта через ImageCropToMask с pad_factor = 1.0. Качество выделения объекта и его масштаб в кадре влияют на вход генератора.

## Пример подключения

Подготовьте изображение одного объекта с понятным силуэтом, подключите визуальный энкодер и передайте оба conditioning в структурный sampler Trellis2. На следующем этапе используйте выходы Trellis2ShapeStage, а не забудьте переключить только модель при старых метаданных conditioning.

## Ограничения и частые ошибки

Нода не восстанавливает гарантированно верную обратную сторону по одному виду. Обычный текстовый CLIP не подходит. Negative здесь не означает текстовое перечисление нежелательных деталей. Для Pixal3D с геометрической проекцией признаков используются отдельные ноды conditioning.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `clip_vision_model` | `CLIP_VISION` | да | соединение / значение без фиксированного default |
| `image` | `IMAGE` | да | соединение / значение без фиксированного default |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `positive` | `CONDITIONING` | нет |
| `negative` | `CONDITIONING` | нет |
