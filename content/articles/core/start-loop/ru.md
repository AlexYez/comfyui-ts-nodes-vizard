# Start Loop: начало повторяемого участка графа

Задаёт цикл для группы нод: фиксированное число повторений, диапазон индексов или перебор списка. На каждой итерации выдаёт индекс, признаки первой и последней итерации и текущие данные.

## Как пользоваться

simple использует num_iterations. For задаёт start_iteration_index, max_iteration и step; верхняя граница не включается. List перебирает элементы входного списка. initial_iteration_value задаёт начальное переносимое значение; на следующем шаге оно приходит из EndLoop. parent_iteration связывает вложенный цикл с внешним. cache_iterations разрешает повторное использование промежуточного кэша.

## Пример подключения

Создайте штатную пару StartLoop/EndLoop через интерфейс циклов, начните с двух итераций. Передайте initial_iteration_value в обработку, её результат подключите к next_iteration_value у EndLoop. Для перебора готовых данных используйте List и выход list_item, а не искусственный счётчик batch.

## Ограничения и частые ошибки

Произвольная обратная связь проводом не заменяет штатную структуру: backend ожидает метаданные границ и тела цикла от frontend. Кэш может влиять на повторное выполнение одинаковых операций; явно управляйте seed. Число повторений умножает стоимость обработки, поэтому сначала проверяйте короткий цикл.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `mode` | `COMFY_DYNAMICCOMBO_V3` | да | режимы: simple, For, List |
| `mode=simple → num_iterations` | `INT` | да | по умолчанию: 4; минимум: 0 |
| `mode=For → start_iteration_index` | `INT` | да | по умолчанию: 0 |
| `mode=For → max_iteration` | `INT` | да | по умолчанию: 4; максимум: 18446744073709551615 |
| `mode=For → step` | `INT` | да | по умолчанию: 1; минимум: 1 |
| `mode=List → list` | `COMFY_MATCHTYPE_V3` | да | допустимый тип: * |
| `cache_iterations` | `BOOLEAN` | да | по умолчанию: false |
| `parent_iteration` | `INT` | нет | соединение / значение без фиксированного default |
| `initial_iteration_value` | `COMFY_MATCHTYPE_V3` | нет | допустимый тип: * |

## Выходы

## Проверенные источники и кейсы

В Wan Animate 2 цикл последовательно обрабатывает части движения. Его текущее переносимое значение разбирается через два GetItemFromList, а переключатели различают первый и следующие шаги.

В официальном шаблоне `video_wan_animate2`: Граф: Motion Transfer (Wan Animate 2) (root/definitions/subgraphs/1). Входящие связи: `ComfyMathExpression`. Исходящие связи: `ComfySwitchNode`, `GetItemFromList`. Имя файла: `video_wan_animate2.json`, пакет [workflow-templates-json 0.1.92](https://pypi.org/project/comfyui-workflow-templates-json/0.1.92/).
