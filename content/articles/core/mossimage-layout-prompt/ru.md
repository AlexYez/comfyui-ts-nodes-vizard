# MOSS-Image: промпт с планом композиции

Собирает структурированный JSON-промпт MOSS-Image из общего описания и рамок Create Bounding Boxes. Это экспериментальное форматирование STRING, не выполнение генерации.

## Как пользоваться

Подайте `element`, общий `prompt` и точные `width`/`height` будущего изображения. Нормализованные рамки `[y0,x0,y1,x1]` в диапазоне 0–1000 переводятся в пиксели с началом координат в центре холста. Нижние границы округляются вниз, верхние вверх.

Обычный элемент получает метку `object`. Номера в `character_boxes`, например `1, 3`, меняют соответствующие нетекстовые элементы на `character`. Нумерация соответствует позициям в полном массиве, начиная с 1. Текстовые элементы получают `text`, содержимое надписи и описание; непустая палитра тоже переносится.

## Пример

Разместите две рамки, укажите персонажа номером и подайте полученную строку в совместимый текстовый энкодер MOSS-Image. Размеры здесь должны совпадать с генерацией: они определяют пиксельные координаты композиции.

## Ограничения

Пустой массив возвращает исходную строку без JSON-обёртки. Выбор номера персонажа — разметка для модели, а не блокировка идентичности. Формат отличается от FLUX 3 Layout Prompt; эти строки нельзя считать взаимозаменяемыми.

## Входы и настройки

Снимок ComfyUI 0.43.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `prompt` | `STRING` | да | соединение / значение без фиксированного default |
| `element` | `ARRAY` | да | соединение / значение без фиксированного default |
| `width` | `INT` | да | по умолчанию: 1024; минимум: 16; максимум: 16384; шаг: 16 |
| `height` | `INT` | да | по умолчанию: 1024; минимум: 16; максимум: 16384; шаг: 16 |
| `character_boxes` | `STRING` | да | по умолчанию:  |

## Официальные примеры подключения

В закреплённом пакете [workflow-templates-json 0.1.123](https://pypi.org/project/comfyui-workflow-templates-json/0.1.123/) найдено 2 вхождений. Примеры сохранённых связей:

- `image_moss_image_base_t2i_bboxes.json`, подграф «main»: входы от `CreateBoundingBoxes`, `ResolutionSelector`; выходы к `PreviewAny`.
- `image_moss_image_t2i_bboxes.json`, подграф «main»: входы от `CreateBoundingBoxes`, `ResolutionSelector`; выходы к `PreviewAny`.

Это автоматическая сверка сохранённых соединений, не запуск и не ручная проверка всех сценариев. Внешние входы и переключатели подграфа могут менять путь выполнения.
