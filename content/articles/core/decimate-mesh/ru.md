# Decimate Mesh: сокращение числа граней

Упрощает треугольную сетку до целевого числа граней методом квадратичной ошибки. Применяется, когда подробный результат генерации слишком тяжёл для последующих операций или экспорта.

## Как пользоваться

target_face_count — целевой верхний предел; 0 отключает упрощение. midpoint использует стандартное размещение вершин, qem открывает дополнительные веса сохранения линий и резких рёбер. Ограничение clamp_v_to_edge удерживает новую вершину на сокращаемом ребре.

## Пример подключения

Сначала сохраните подробную ветку для запекания. В рабочей ветке задайте умеренное target_face_count, сравните силуэт через RenderMesh и счётчики через GetMeshInfo. После окончательного выбора плотности стройте UV и переносите детали normal map с подробной ветки.

## Ограничения и частые ошибки

Сильное упрощение может уничтожить тонкие элементы. В стандартном batched-MESH пути общий обработчик сбрасывает UV, нормали и касательные; ставьте ноду до развёртки, даже если текстурное поле осталось на объекте. Отключённое упрощение не следует считать гарантией сохранности всех атрибутов после такого обработчика.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `mesh` | `MESH` | да | соединение / значение без фиксированного default |
| `target_face_count` | `INT` | да | по умолчанию: 200000; минимум: 0; максимум: 50000000 |
| `placement_mode` | `COMFY_DYNAMICCOMBO_V3` | да | режимы: midpoint, qem |
| `placement_mode=qem → line_quadric_weight` | `FLOAT` | да | по умолчанию: 0.0; минимум: 0.0; максимум: 100.0; шаг: 0.1 |
| `placement_mode=qem → feature_edge_quadric_weight` | `FLOAT` | да | по умолчанию: 0.0; минимум: 0.0; максимум: 1000.0; шаг: 1.0 |
| `placement_mode=qem → feature_edge_min_dihedral_deg` | `FLOAT` | да | по умолчанию: 30.0; минимум: 0.0; максимум: 180.0; шаг: 1.0 |
| `placement_mode=qem → clamp_v_to_edge` | `BOOLEAN` | да | по умолчанию: true |
