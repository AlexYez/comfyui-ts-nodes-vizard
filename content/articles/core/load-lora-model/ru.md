# Загрузка нескольких LoRA для модели

Последовательно применяет список LoRA к диффузионной модели и возвращает MODEL. Текстовый энкодер не изменяется; для его LoRA есть отдельная Load LoRA (Text Encoder).

## Как пользоваться

Подключите исходную модель и добавьте строки в группе `loras` — от одной до двадцати. Каждая строка содержит `lora_name`, `strength` и `enabled`. Файлы выбираются из зарегистрированных папок LoRA, обычно `models/loras`.

Пустое имя, выключенная строка или нулевая сила пропускаются без чтения файла. Отрицательная сила меняет знак добавки; это не универсальный способ устранить стиль. Строки обрабатываются в порядке списка с передачей изменённой модели дальше.

## Пример

После UNETLoader подключите эту ноду, включите стилевую LoRA и вторую LoRA персонажа с умеренными силами, затем передайте MODEL в сэмплер. Сначала проверьте каждую отдельно: одновременное применение усложняет поиск несовместимости.

## Ограничения

Подходят только адаптеры для архитектуры загруженной модели. Диапазон виджета −100…100 не является рекомендуемым рабочим диапазоном. Загрузка LoRA для CLIP этой нодой не выполняется, даже если файл содержит обе части. Новый frontend должен поддерживать динамическую группу строк.

## Входы и настройки

Снимок ComfyUI 0.43.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `model` | `MODEL` | да | соединение / значение без фиксированного default |
| `loras` | `COMFY_DYNAMICGROUP_V3` | да | минимум: 1; максимум: 20 |
| `loras → lora_name` | `COMBO` | да | соединение / значение без фиксированного default |
| `loras → strength` | `FLOAT` | да | по умолчанию: 1.0; минимум: -100.0; максимум: 100.0; шаг: 0.01 |
| `loras → enabled` | `BOOLEAN` | да | по умолчанию: true |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `MODEL` | `MODEL` | нет |
