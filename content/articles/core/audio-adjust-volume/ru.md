# AudioAdjustVolume: изменить уровень AUDIO в децибелах

## Что делает нода

`AudioAdjustVolume` умножает весь waveform на коэффициент, рассчитанный из децибел: `gain = 10 ** (volume / 20)`. Одно значение применяется ко всем batch-элементам, каналам и отсчётам.

Положительные dB повышают амплитуду, отрицательные понижают. `+6 dB` даёт коэффициент примерно `1.995`, а `-6 dB` — примерно `0.501`; это близко к удвоению и половине, но не ровно 2 и 0.5.

Нода не измеряет loudness, не ищет пики и не нормализует результат. Она выполняет только постоянное линейное усиление.

## Когда использовать и когда не использовать

Регулятор нужен перед `AudioMerge`, чтобы выставить относительные уровни дорожек, после разделения каналов или перед сохранением тихого сигнала. Он полезен и для A/B-проверки фиксированного gain.

Не используйте его вместо компрессора, limiter, автоматизации или loudness normalization. Усиление может вывести waveform далеко за диапазон `[-1, 1]`, а последующая нода или кодек обработает перегрузку по собственным правилам.

Для изменения воспринимаемой громкости на заданное число LUFS требуется измерение и иной алгоритм. Здесь dB относится к амплитудному коэффициенту, а не к измеренной громкости программы.

## Короткий рецепт подключения

1. Подайте `AUDIO` в ноду.
2. Для нейтрального прохода задайте `0 dB`, а не значение по умолчанию.
3. Начните с небольших поправок, например `-3` или `+1`.
4. После сложения дорожек проверьте пики и прослушайте результат.
5. Сравнивайте варианты при понятном downstream-поведении clipping.

Рецепт «Подготовить уровни перед AudioMerge» сохраняет точную локальную топологию официального Sonilo subgraph: два регулятора с `+1 dB` подаются в `AudioMerge(add)`. Это настройка конкретного шаблона, а не общая рекомендация.

## Входы, выходы и параметры

`audio` — обязательный `AUDIO`. `volume` — целое число от `-100` до `100`. Важная деталь схемы 0.32.0: значение по умолчанию равно `1`, поэтому только что добавленная нода усиливает сигнал примерно в `1.122` раза.

Нейтральное значение `0` обрабатывается отдельной веткой: класс возвращает исходный объект `audio`, не умножая tensor. При любом другом значении создаётся новый waveform и новый словарь только с `waveform` и `sample_rate`.

Крайние коэффициенты велики: `+100 dB` соответствует `100000`, `-100 dB` — `0.00001`. Никакого clamp после умножения в коде ноды нет.

## Типовые связки

`LoadAudio → AudioAdjustVolume → PreviewAudio` подходит для проверки одной дорожки. Перед `AudioMerge` обычно ставят отдельный регулятор на каждый источник, чтобы не менять их относительный баланс уже после суммы.

После `SplitAudioChannels` разные gain позволяют скорректировать постоянный перекос stereo. Затем `JoinAudioChannels` собирает стороны обратно.

Регулятор можно ставить и после merge, но тогда меняется весь готовый микс. Если `AudioMerge` уже выполнил глобальную нормализацию из-за пика выше 1, прежний баланс сохранится, однако исходный запас по пикам восстановить нельзя.

## Практический пример

Полный census wheel 0.1.42 нашёл два `AudioAdjustVolume`, оба внутри одного subgraph официального `api_sonilo_v2m`, оба mode Always и оба с виджетом `[1]`. Их выходы подключены к двум входам `AudioMerge` № 721.

Один источник приходит от аудиовыхода `GetVideoComponents`, второй — через внешний порт subgraph; ещё два внешних `INT` управляют gain. В сохранённой конфигурации оба равны `+1 dB`.

Точный tensor-запуск подтвердил коэффициенты для `-100`, `-6`, `0`, `1`, `6` и `100 dB`, отсутствие clamp и особую identity-ветку нуля. Полный Sonilo workflow с внешним API не исполнялся.

## Частые ошибки и способы проверки

**Считают значение по умолчанию нейтральным.** В 0.32.0 default равен `1 dB`. Для отсутствия изменения вручную задайте 0.

**Ожидают ровно двойную амплитуду от `+6 dB`.** Формула даёт примерно `1.995`. Точное удвоение соответствует около `6.0206 dB`, но виджет принимает только целые числа.

**После усиления появился перегруз.** Нода не ограничивает диапазон. Посмотрите абсолютный пик downstream или ослабьте сигнал до сложения.

**При `0 dB` сохраняется metadata, а при другом значении исчезает.** Нулевая ветка возвращает исходный словарь; ненулевая пересобирает его с двумя стандартными полями.

**Пытаются настроить только один batch-элемент.** Gain общий для всего tensor. Разделите batch заранее.

## Производительность и внутреннее поведение

Ненулевое усиление — одна поэлементная операция по всему waveform и выделение нового tensor. Стоимость линейна по числу отсчётов. Устройство и dtype наследуются через обычную арифметику PyTorch.

Ветка `volume == 0` дешева и сохраняет identity объекта. При `audio is None` возвращается `None`. Остальные значения не имеют специальных обходов, в том числе крайние `±100`.

Нода не выполняет ресэмплинг и не меняет длительность. Число каналов и batch остаются прежними.
