# Pixal3D Conditioning: признаки изображения с проекцией камеры

Готовит визуальное conditioning Pixal3D из глобальных и проекционных признаков. В отличие от обычного Trellis2 conditioning учитывает предполагаемую камеру изображения.

## Как пользоваться

Используются совместимые DINOv3 ViT-L/16 и NAF-признаки. camera_angle_x задаёт горизонтальный угол обзора в градусах; из него рассчитывается расстояние камеры. Перед этой нодой подготовьте объект через ImageCropToMask с pad_factor = 1.1. Negative обнуляет глобальные признаки, но сохраняет проекционные данные.

## Пример подключения

Возьмите изображение отдельного объекта и оценку камеры. Если используете MoGeGeometryToFOV, выберите horizontal и degrees, затем подключите значение к camera_angle_x. Передайте оба conditioning в совместимую цепочку Pixal3D/Trellis2 и сначала проверьте форму без материала.

## Ограничения и частые ошибки

Неверный FOV меняет соответствие изображения пространству. Не подавайте вертикальный угол вместо горизонтального и радианы вместо градусов. Нода не калибрует камеру автоматически и не делает невидимую сторону достоверной. Для согласованных нескольких ракурсов предусмотрена отдельная MultiView-нода.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `clip_vision_model` | `CLIP_VISION` | да | соединение / значение без фиксированного default |
| `image` | `IMAGE` | да | соединение / значение без фиксированного default |
| `camera_angle_x` | `FLOAT` | да | по умолчанию: 49.13; минимум: 1.0; максимум: 170.0; шаг: 0.01 |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `positive` | `CONDITIONING` | нет |
| `negative` | `CONDITIONING` | нет |
