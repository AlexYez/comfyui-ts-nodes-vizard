# WanUni3CControlnetApply

## Назначение
Экспериментальная нода добавляет Uni3C ControlNet к Wan по видео, отрисованному из camera trajectory.
## Место в графе
Подайте Wan MODEL, Uni3C MODEL_PATCH, VAE и render_video; patched MODEL используйте в sampler.
## Проверка patch
Тип обязан быть `WanUni3CControlnet`. Иначе выполнение прекращается явным ValueError до clone.
## Проверка модели
Из первого control block берётся `cnet_dim`, а из diffusion model — `dim`. Отсутствие dim означает не-Wan модель; несовпадение также запрещено.
## Входы
Strength −10…10; start/end 0–1. Render video обрезается до RGB.
## Окно
Проценты преобразуются объектом model sampling в `sigma_start` и `sigma_end`. На первом блоке каждого прохода patch активен, когда текущая sigma не выше начала и не ниже конца. Границы не переставляются автоматически, поэтому обратный диапазон способен оставить ControlNet неактивным.
## Подготовка видео
Целевое число кадров вычисляется как `(T−1) × temporal_compression + 1`. Короткое управляющее видео дополняется повторением последнего кадра, длинное обрезается. Размер приводится к геометрии латента bilinear-масштабированием с обрезкой по центру, затем кадры кодируются VAE. Пустое видео недопустимо: повторять последний кадр в нём невозможно.
## Control input
Латент VAE проходит `latent_format.process_in`. Patch берёт первые 20 каналов входа модели, при нехватке дополняет их нулями и присоединяет управляющий латент. Для conditional и unconditional частей residual вычисляется на общей порции samples, а затем при необходимости повторяется по batch; это экономит вычисления, но предполагает совместимую разбивку batch.
## Ограничения
`strength=0` не отменяет patch: подготовка видео и проход ControlNet всё равно выполняются, только residual умножается на ноль. Закодированное управление кэшируется для текущей временно-пространственной формы; при смене формы VAE запускается снова. Перенос patch на другое устройство очищает временные residual, но сохраняет подготовленный латент с переносом на новое устройство.
## Совместимость и источники
Проверено по ComfyUI 0.32.0. Uni3C sampling не исполнялся; type/dim gates закреплены.
