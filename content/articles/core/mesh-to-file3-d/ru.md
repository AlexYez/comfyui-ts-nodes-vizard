# Create 3D File: сериализация MESH в GLB

Преобразует MESH в объект FILE_3D с данными GLB. Сохраняет доступные UV, цвета, нормали и материал, чтобы сетку можно было показать или записать нодами работы с 3D-файлами.

## Как пользоваться

Пользовательский вход один — mesh. Выход model_3d содержит файл в памяти; имени файла и каталога назначения здесь нет. За постоянное сохранение на диск отвечает следующая нода, например Save3DAdvanced.

## Пример подключения

После UnwrapMesh, запекания карт и ApplyTextureToMesh подключите mesh к MeshToFile3D, а model_3d — к Preview3DAdvanced. Когда внешний вид проверен, передайте тот же файл в Save3DAdvanced.

## Ограничения и частые ошибки

Обрабатывается только первый элемент mesh batch; остальные не экспортируются. Пустая сетка вызывает ошибку. Нода не создаёт UV и не запекает материал: отсутствие этих данных на входе нельзя исправить одной сериализацией. Для сохранения нескольких объектов подготовьте отдельную обработку каждого элемента.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `mesh` | `MESH` | да | соединение / значение без фиксированного default |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `model_3d` | `FILE_3D_GLB` | нет |
