# MOSS-Image: управление областями и глубиной

Добавляет управляющие карты областей и глубины к положительным и отрицательным условиям MOSS-Image. Для работы нужен совместимый color/depth-адаптер, загруженный в модель через LoRA loader; эта нода веса не загружает.

## Как пользоваться

Подайте `positive`, `negative`, совместимый VAE и одну или обе карты. `color_map` содержит однотонные области: цвета служат идентификаторами регионов, не обязательными цветами результата. В `depth_map` близкие участки обозначаются белым.

Карты обрезаются до RGB и кодируются VAE. При разных размерах вторая карта подгоняется к первой доступной в латентном пространстве; отсутствующая заменяется нулями. Каналы соединяются в порядке color, depth. `strength` масштабирует управляющий латент; `start_percent` и `end_percent` ограничивают участок расписания сэмплирования, не длительность видео.

## Пример

Подготовьте карту глубины и карту плоских регионов в разрешении результата, подключите адаптер и начните с strength 1 и полного интервала 0–1. Сравнивайте влияние карт по отдельности, затем вместе.

## Ограничения

Без обеих карт условия возвращаются без изменений. При strength 0 код всё равно может кодировать подключённые карты, поэтому это не гарантированное отключение вычислений. Нода не заменяет обычный ControlNet любой архитектуры; несовместимые веса и VAE не исправляются подбором силы.

## Входы и настройки

Снимок ComfyUI 0.43.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `positive` | `CONDITIONING` | да | соединение / значение без фиксированного default |
| `negative` | `CONDITIONING` | да | соединение / значение без фиксированного default |
| `vae` | `VAE` | да | соединение / значение без фиксированного default |
| `strength` | `FLOAT` | да | по умолчанию: 1.0; минимум: 0.0; максимум: 10.0; шаг: 0.01 |
| `start_percent` | `FLOAT` | да | по умолчанию: 0.0; минимум: 0.0; максимум: 1.0; шаг: 0.001 |
| `end_percent` | `FLOAT` | да | по умолчанию: 1.0; минимум: 0.0; максимум: 1.0; шаг: 0.001 |
| `color_map` | `IMAGE` | нет | соединение / значение без фиксированного default |
| `depth_map` | `IMAGE` | нет | соединение / значение без фиксированного default |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `positive` | `CONDITIONING` | нет |
| `negative` | `CONDITIONING` | нет |

## Официальные примеры подключения

В закреплённом пакете [workflow-templates-json 0.1.123](https://pypi.org/project/comfyui-workflow-templates-json/0.1.123/) найдено 1 вхождений. Примеры сохранённых связей:

- `image_moss_image_color_depth_control.json`, подграф «main»: входы от `CLIPTextEncode`, `PreviewImage`, `VAELoader`; выходы к `SamplerCustom`.

Это автоматическая сверка сохранённых соединений, не запуск и не ручная проверка всех сценариев. Внешние входы и переключатели подграфа могут менять путь выполнения.
