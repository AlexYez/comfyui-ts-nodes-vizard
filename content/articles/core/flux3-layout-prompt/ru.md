# FLUX 3: промпт с расположением объектов

Дописывает к тексту JSON-таблицу рамок для модели FLUX 3 Image. На выходе `STRING`, а не готовый conditioning. Нода экспериментальная.

## Как пользоваться

Подайте массив `element` от Create Bounding Boxes и общее описание на `prompt`. Элементы получают идентификаторы `obj_1`, `obj_2` и далее в порядке массива. В тексте можно ссылаться на `<obj_1>`, чтобы связать описание с первой рамкой.

Нода сохраняет координаты `bbox` из массива без пересчёта. Для текстовой рамки непустое поле `text` добавляется в кавычках к описанию. Палитра не переносится: нужный цвет опишите словами.

## Пример

Создайте две рамки для чашки и книги, подпишите объекты и добавьте общую инструкцию. Выход передайте в соответствующий текстовый энкодер FLUX 3. Пустой массив оставляет исходный промпт без изменений.

## Ограничения

Это форматирование данных для определённой модели, не пространственная маска и не универсальная замена региональному conditioning. Структура каждого элемента должна содержать `bbox`; произвольный JSON другой ноды может не подойти. Точность размещения нужно оценивать по результату генерации.

## Входы и настройки

Снимок ComfyUI 0.43.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `prompt` | `STRING` | да | соединение / значение без фиксированного default |
| `element` | `ARRAY` | да | соединение / значение без фиксированного default |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `prompt` | `STRING` | нет |

## Источники и проверка

[Реализация ComfyUI 0.43.0](https://github.com/Comfy-Org/ComfyUI/blob/426f5eea52a7ece1dd599fff4cb6cd1f352ddd24/comfy_extras/nodes_flux.py#L304-L331). Входы и выходы сверены с чистым серверным снимком. Пример поясняет подключение, но не подтверждает выполненную генерацию с весами. Человеческое утверждение ещё нужно.

## Официальные примеры подключения

В закреплённом пакете [workflow-templates-json 0.1.123](https://pypi.org/project/comfyui-workflow-templates-json/0.1.123/) найдено 4 вхождений. Примеры сохранённых связей:

- `image_flux3_klein_distilled_image_edit.json`, подграф «main»: входы от `CreateBoundingBoxes`; выходы к `PreviewAny`.
- `image_flux3_klein_distilled_t2i.json`, подграф «main»: входы от `CreateBoundingBoxes`; выходы к `PreviewAny`.

Это автоматическая сверка сохранённых соединений, не запуск и не ручная проверка всех сценариев. Внешние входы и переключатели подграфа могут менять путь выполнения.
