# VAE Decode Texture Trellis: материал в вокселях

Декодирует текстурный latent Trellis в VOXEL с цветом и свойствами материала. Результат предназначен для переноса на поверхность, а не для прямого сохранения как двумерная картинка.

## Как пользоваться

Подключаются текстурный VAE, sampled latent с координатами и SHAPE_SUBDIVIDES от соответствующей формы. Выход содержит шесть каналов: RGB, металлическость, шероховатость и alpha. При необходимости координаты переводятся из z_up в систему, согласованную с mesh.

## Пример подключения

После Trellis2TextureStage и текстурного sampler декодируйте VOXEL. Для быстрой проверки цвета примените PaintMesh к исходной поверхности и посмотрите рендер; для материала с UV выполните UnwrapMesh и BakeTextureFromVoxel, затем ApplyTextureToMesh.

## Ограничения и частые ошибки

SHAPE_SUBDIVIDES должны происходить из декодирования именно этой формы. Воксельные свойства материала не равны картам normal или ambient occlusion: последние запекаются отдельно. PaintMesh переносит цвет в вершины и не заменяет полноценную текстуру при редкой геометрии.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `samples` | `LATENT` | да | соединение / значение без фиксированного default |
| `vae` | `VAE` | да | соединение / значение без фиксированного default |
| `shape_subdivides` | `SHAPE_SUBDIVIDES` | да | соединение / значение без фиксированного default |

## Выходы
