# LoraSave

## Назначение
`LoraSave` извлекает переносимую LoRA из разности весов. Она принимает результат вычитания моделей и/или текстовых encoder, строит `standard` low-rank разложение либо сохраняет `full_diff` и записывает safetensors.

## Место в графе
Для model-части подайте `MODEL` из `ModelMergeSubtract`; для текста — `CLIP` из `CLIPMergeSubtract`. Оба входа необязательны, но без обоих нода немедленно завершится и не создаст файл.

## Входы
Обязательны `filename_prefix`, `rank`, `lora_type` и `bias_diff`. `rank` лежит в диапазоне 1–4096. `lora_type` выбирается из `standard` и `full_diff`; `model_diff` и `text_encoder_diff` подключаются по необходимости.

## Выходы
Графовых выходов нет. Создаётся `<filename>_<counter>_.safetensors` в output-каталоге. Metadata передаётся как `None`; параметры извлечения не встраиваются в файл отдельным описанием.

## Как работает
Для каждого веса diff загружается на устройство. В режиме `standard` матрица переводится в float32, раскладывается SVD, обрезается до `min(rank, in_dim, out_dim)`, а компоненты ограничиваются симметричным 99-м процентилем и сохраняются в float16 на CPU.

## Параметры
`full_diff` пропускает SVD и записывает полную разность как `.diff`. При `bias_diff=true` смещения сохраняются как `.diff_b`; одномерные веса standard тоже переходят в `.diff`. Для 3×3 convolution down-матрица сохраняет исходное ядро, up имеет ядро 1×1.

## Проверенный пример
Фрагмент принимает внешний `MODEL` diff, выбирает `standard`, rank 8 и сохраняет bias. Это основанный на исходнике пример: официальный пакет 0.1.42 не содержит `LoraSave`, а реальные model weights не обрабатывались.

## Частые ошибки
`rank` не гарантирует фактический ранг выше меньшей размерности слоя. Ошибки SVD для отдельного веса перехватываются широким `except`: нода пишет предупреждение и может сохранить неполный файл вместо полного падения. Проверяйте список ключей результата.

## Ограничения и производительность
SVD каждого веса дорого по времени и памяти; данные временно переводятся в float32. Нулевые или проблемные разности могут быть пропущены. Файл записывается напрямую, а операция помечена experimental.

## Совместимость и источники
Порты и fingerprint взяты из `/object_info` 0.32.0; формулы, ключи и обработка ошибок — из `nodes_lora_extract.py`; документация — embedded-docs 0.5.9. Визуальная проверка загруженной LoRA и человеческое утверждение ещё нужны.
