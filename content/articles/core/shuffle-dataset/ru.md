# ShuffleDataset: воспроизводимая перестановка списка IMAGE

## Что делает нода

`ShuffleDataset` разворачивает входной `IMAGE` в плоский список и меняет порядок элементов по одной перестановке NumPy. Значения пикселей не изменяются.

Перед вычислением код выполняет `np.random.seed(seed % (2**32 - 1))`, затем вызывает `np.random.permutation(len(images))`. Один и тот же эффективный seed и та же длина списка дают один и тот же порядок в закреплённой среде.

Это псевдослучайная, но воспроизводимая перестановка. В частности, `seed = 0` не создаёт новый порядок при каждом запуске, хотя русская встроенная справка утверждает обратное.

## Когда использовать и когда не использовать

Нода подходит, когда нужно перемешать список изображений перед просмотром, разбиением набора или последующей списочной обработкой и сохранить возможность повторить порядок по параметру `seed`.

Она не подходит для пар «изображение–подпись»: переставляется только `IMAGE`, поэтому отдельный список текстов утратит соответствие. Для пары используйте `ShuffleImageTextDataset`.

Не рассчитывайте, что числовой `seed` уникально задаёт состояние во всём диапазоне виджета. Код берёт остаток по модулю `4 294 967 295`, поэтому разные большие значения могут дать одинаковую перестановку.

## Короткий рецепт подключения

1. Подключите список или пакет `IMAGE` ко входу `images`.
2. Установите `seed = 7`.
3. Выполните граф дважды и сравните порядок элементов.
4. Меняйте `seed` только когда нужна другая перестановка.

Фрагмент «Перемешать список с фиксированным seed 7» содержит одну ноду и внешний `IMAGE`. Число 7 выбрано только для воспроизводимого примера; официального графа с таким значением нет. После импорта фрагмент не запускался.

## Входы, выходы и параметры

`images` — обязательный списочный `IMAGE`. Базовый класс разворачивает `[B,H,W,C]` и списки четырёхмерных тензоров в элементы `[1,H,W,C]`. Трёхмерный тензор без размера пакета не принимается.

`seed` — обязательный по схеме исполнения `INT` со значением по умолчанию 0 и диапазоном от 0 до `18 446 744 073 709 551 615`. Из-за списочного режима исполнитель подаёт параметр как одноэлементный список, а базовый класс извлекает скаляр.

Выход `images` — список `IMAGE`. Его длина совпадает с длиной нормализованного входа; пустой список остаётся пустым, а единственный элемент не меняет позицию.

## Типовые связки

`LoadImageDataSetFromFolder → ShuffleDataset` перемешивает загруженный список изображений. `MergeImageLists → ShuffleDataset` сначала формирует общий плоский список, затем переставляет его.

После перестановки можно использовать `ImageGrid` для визуальной проверки порядка или другую ноду с корректной списочной семантикой. `ImageDeduplication` до и после перемешивания оставляет разные первые представители групп, потому что дедупликация сохраняет самый ранний элемент.

Не ведите параллельную ветку подписей отдельно. Совпадающий `seed` в другой самописной ноде не является надёжным контрактом парности; используйте одну ноду парного перемешивания.

## Практический пример

В 512 официальных JSON, 496 корневых графах и 272 подграфах `ShuffleDataset` не найден. Подтверждённого пользовательского сценария в пакете 0.1.42 нет.

Точный прогон развернул два пакета общей длиной восемь. При `seed = 7` порядок стал `2,5,0,6,3,1,4,7`; повторный запуск дал ту же последовательность. При `seed = 8` порядок изменился, а `seed = 4 294 967 302` совпал с 7 из-за взятия остатка.

Проверка также подтвердила пустой выход для пустого списка. Она исполняла закреплённый Python-класс, а не импортированный фрагмент на холсте.

## Частые ошибки и способы проверки

**При `seed = 0` порядок каждый раз одинаков.** Это ожидаемое поведение исходника. Ноль — конкретное состояние NumPy, а не команда выбрать случайный seed.

**Два разных seed дали одинаковый порядок.** Сначала сравните их остатки по модулю `4 294 967 295`. Для коротких списков совпадение возможно и у разных эффективных seed.

**Подписи больше не соответствуют изображениям.** `ShuffleDataset` не знает о текстовой ветке. Вернитесь к исходным данным и перемешайте пары через `ShuffleImageTextDataset`.

**Отдельный `[H,W,C]` вызывает ошибку.** Списочная нормализация ожидает четыре измерения: `[1,H,W,C]` или `[B,H,W,C]`.

**После добавления или удаления элемента прежний seed дал другой расклад.** Пермутация зависит от длины списка; seed не закрепляет постоянный ключ за каждым изображением.

## Производительность и внутреннее поведение

Нода строит массив индексов длины `N` и новый Python-список ссылок на изображения. Пиксели не копируются и не переносятся между CPU и GPU.

Время и дополнительная память линейны по числу элементов. Основная тензорная память остаётся у входных изображений.

Вызов `np.random.seed` сбрасывает глобальный генератор NumPy в процессе ComfyUI. Это может влиять на другой код, который затем использует тот же глобальный генератор; локальный объект генератора нода не создаёт.
