# Размер аудиолатента

Возвращает длину аудиолатента, число его аудиоканалов и размер пакета. Длина измеряется позициями латентной последовательности, не секундами и не отсчётами WAV.

## Как пользоваться

Подайте обычный аудиолатент или составной аудио-видеолатент. В составном случае берётся последний вложенный тензор. Для формы `[B,C,A,L]` выходы равны `L`, `A`, `B`; для `[B,C,L]` число аудиоканалов принимается равным 1. Скрытая размерность `C` не считается числом каналов звуковой дорожки.

## Пример

Форма `[1,32,2,400]` даёт length 400, audio_channels 2 и batch_size 1. Для получения секунд нужны частота и коэффициент сжатия аудио-VAE; эта нода их не определяет.

## Ограничения

Проверьте порядок вложенных тензоров у составного типа своей модели. Нода ожидает аудиоданные, а не произвольный видео-LATENT, и не проверяет совпадение длительности звука и видео. Для размеров видеосетки есть отдельная Get Image/Video Latent Size.

## Входы и настройки

Снимок ComfyUI 0.43.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `latent` | `LATENT` | да | соединение / значение без фиксированного default |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `length` | `INT` | нет |
| `audio_channels` | `INT` | нет |
| `batch_size` | `INT` | нет |
