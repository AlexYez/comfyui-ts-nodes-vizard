# Run SAM3D Body Prediction: поза человека из кадров

Восстанавливает геометрию и позу людей по IMAGE или последовательности кадров. Возвращает MHR_POSE_DATA с геометрией, параметрами тела и оценкой камеры для дальнейшего рендера и экспорта.

## Как пользоваться

Приоритет входов: track_data SAM3, затем bboxes детектора, затем весь кадр как один человек. run_hand_refinement уточняет руки ценой дополнительных вычислений. fov — вертикальный угол в градусах; 0 использует внутреннее приближение камеры. batch_size ограничивает пакет обрабатываемых вырезок людей, а не число возвращаемых кадров.

## Пример подключения

Для одиночного человека начните с короткого IMAGE-batch и просмотра через SAM3DBody_Render. Для нескольких людей передайте согласованные tracking-данные; альтернативно используйте bbox детектора. При нехватке VRAM уменьшите batch_size и отдельно сравните результат без уточнения рук.

## Ограничения и частые ошибки

Без детектора или tracking нода не обещает сама разделить всех людей в кадре. Перекрытия и неверные границы человека влияют на результат. Оценка глубины и абсолютного масштаба зависит от камеры; это реконструкция по изображению, а не точный измерительный motion capture.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `sam3d_body_model` | `SAM3D_BODY_MODEL` | да | соединение / значение без фиксированного default |
| `image` | `IMAGE` | да | соединение / значение без фиксированного default |
| `run_hand_refinement` | `BOOLEAN` | да | по умолчанию: true |
| `fov` | `FLOAT` | да | соединение / значение без фиксированного default |
| `batch_size` | `INT` | да | по умолчанию: 64; минимум: 1; максимум: 512; шаг: 1 |
| `track_data` | `SAM3_TRACK_DATA` | нет | соединение / значение без фиксированного default |
| `bboxes` | `BOUNDING_BOX` | нет | по умолчанию: {"x":0,"y":0,"width":512,"height":512} |
