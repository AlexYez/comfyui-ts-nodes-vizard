# Ming Image Edit: текст и изображения для редактирования

Подготавливает условия `CONDITIONING` для локальной модели Ming Image Edit: текст задания и до восьми изображений. Это текстовый кодировщик, а не самостоятельный генератор или API-сервис.

## Как подключить

Подайте совместимый `CLIP`, напишите задание в `prompt` и добавьте изображения на появляющиеся входы `image_1`…`image_8`. Результат подключите к ветке условий сэмплера. `MODEL`, начальный `LATENT` и декодирование изображения нужны отдельно.

При подключённом `vae` нода кодирует изображения и добавляет их в `reference_latents` — список опорных латентных представлений. Первое изображение задаёт высоту и ширину; следующие приводятся к этому размеру билинейным масштабированием без обрезки. Размер генерируемого латентного изображения должен соответствовать первому референсу.

Без `vae` изображения поступают только в визуальную часть текстового кодировщика. Нода не создаёт опорных латентных кадров, поэтому такая цепочка не равнозначна варианту с VAE.

## Пример

Для замены одежды подайте исходный портрет на `image_1`, совместимые `CLIP` и `VAE`, а в `prompt` опишите новую одежду и что нужно сохранить. Передайте условия сэмплеру Ming и декодируйте результат тем же совместимым VAE. Это схема подключения, а не проверенный запуск с весами или гарантия сохранения лица.

## Ограничения

Кодировщик получает первые три цветовых канала изображения; альфа не становится отдельным условием прозрачности. При разных пропорциях референсов последующие изображения растягиваются до размера первого. Нода не исправляет несовместимость модели, текстового кодировщика и VAE.

## Входы и настройки

Снимок ComfyUI 0.38.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `clip` | `CLIP` | да | соединение / значение без фиксированного default |
| `prompt` | `STRING` | да | соединение / значение без фиксированного default |
| `images` | `COMFY_AUTOGROW_V3` | да | входы: image_1 … image_8 |
| `images → image` | `IMAGE` | да | соединение / значение без фиксированного default |
| `vae` | `VAE` | нет | соединение / значение без фиксированного default |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `CONDITIONING` | `CONDITIONING` | нет |
