# RescaleCFG: нормализация guided-предсказания V-модели

`RescaleCFG` клонирует модель и устанавливает собственную sampler CFG-функцию. Она строит обычное classifier-free guidance, сравнивает стандартное отклонение guided и conditional предсказаний, нормализует первое и смешивает результат с исходным guidance по `multiplier`.

## Что делает нода

Patch меняет не веса и не sampling-сетку, а функцию, которая объединяет conditional и unconditional ветви во время model evaluation. Исходник прямо предупреждает: преобразование написано для output V-prediction модели.

При `multiplier = 1` используется полностью нормализованный guided output; при 0 должен остаться обычный CFG. Однако нормализованная ветвь вычисляется в любом случае, поэтому вырожденные деления способны дать `NaN` даже при нулевом multiplier.

## Место в графе

Ставьте `RescaleCFG` после всех патчей, которые определяют sampling-параметризацию, и до `CFGGuider` или `KSampler`. Используйте его выход в sampling-ветви целиком.

Модель хранит только один `sampler_cfg_function`. Если после `RescaleCFG` поставить `RenormCFG`, `CFGOverride` или другой patch того же hook, последний заменит предыдущий. Эти ноды не складываются автоматически.

## Входы

- `model` — V-prediction `MODEL`, который будет клонирован.
- `multiplier` — число от 0 до 1 с шагом 0,01, по умолчанию 0,7.

CFG scale не задаётся здесь. Функция получает его во время sampling из guider или `KSampler`. Нода также получает текущую sigma и model input через словарь hook-контракта.

## Выход

Выход — cloned `MODEL` с новой sampler CFG-функцией. Исходная модель остаётся без rescale. Тип порта не сообщает, что hook уже установлен, поэтому порядок model patches нужно фиксировать явно.

Нода не возвращает conditioning, guider или изображение. Эффект проявляется только при sampling, где есть conditional и unconditional расчёты и `cond_scale`.

## Как работает формула

Сначала source переводит внутренние `cond` и `uncond` в V-space через `x_orig`, sigma и коэффициенты `sqrt(sigma² + 1)`. Затем вычисляется `x_cfg = uncond + cond_scale * (cond - uncond)`.

Стандартное отклонение `cond` и `x_cfg` считается по осям `(1, 2, 3)` с сохранением размеров. Нормализованная ветвь равна `x_cfg * std(cond) / std(x_cfg)`. Финальное предсказание смешивает её с исходным `x_cfg`, после чего код переводит результат обратно в форму, которую ожидает sampler hook.

## Параметры и настройка

Начинайте с малого сравнения 0 и 0,7 на фиксированном seed. Значение 0 должно сохранять обычный CFG для невырожденных тензоров, 1 полностью задаёт rescale, промежуточные значения линейно смешивают два результата. Probe подтвердил эту аффинность для обычного 4D input.

Не применяйте ноду к epsilon-, flow- или x0-модели без отдельного доказательства. Формула явно восстанавливает V-предсказание. Также не переносите её автоматически на 5D video output: стандартное отклонение жёстко считает только оси 1–3 и оставляет пятую ось вне общей нормализации.

## Проверенный пример

Fragment Wizard ставит `multiplier = 0,7`, подключает patched модель к `CFGGuider` и оставляет positive/negative conditioning внешними. Требование рецепта — подтверждённая V-prediction модель. Сам guider задаёт CFG 7, чтобы действие hook было видно, но это учебное значение, а не универсальная рекомендация.

В official workflow wheel 0.1.42 точной ноды нет: проверены 512 JSON, 496 root и 272 subgraph. Exact hook выполнен на синтетических 4D tensors для multiplier 0, 0,3 и 1; подтверждена линейная смесь и зафиксированы нечисловые результаты на границах. Реальная модель не запускалась. Редактор пока не проверил материал вручную.

## Частые ошибки

- Patch применяется не к V-prediction модели.
- После него стоит другой CFG patch и незаметно заменяет функцию.
- `multiplier = 0` считается гарантированным bypass: вычисление rescale всё равно происходит.
- Sigma равна нулю: формула делит на sigma и даёт нечисловой результат.
- `std(x_cfg) = 0`: отношение стандартных отклонений содержит деление на ноль.
- 5D video tensor нормализуется как обычное изображение, хотя одна ось остаётся вне редукции.

## Ограничения и производительность

Hook добавляет несколько поэлементных операций и два расчёта стандартного отклонения на каждом model evaluation. Обычно это дешевле самого UNet/DiT, но требует временных тензоров размера model output.

Версия 0.32.0 не использует epsilon в знаменателе и не проверяет конечность. Нулевая sigma или дисперсия приводят к `NaN`; умножение такой ветви на нулевой multiplier не восстанавливает число. Batch image поддерживается формой редукции, а video/other-rank tensors требуют отдельной проверки.

## Совместимость и источники проверки

Проверено на ComfyUI 0.32.0 и frontend 1.48.7. Это legacy-описанная core-нода без сериализованных status flags; в source нет `DEPRECATED`, `EXPERIMENTAL` или API-маркера, формальной замены тоже нет.
