# Remesh Mesh: перестроение поверхности через поле расстояний

Заново извлекает поверхность сетки через narrow-band distance field и Dual Contouring. Это меняет топологию и плотность, а не только сокращает существующие треугольники.

## Как пользоваться

resolution задаёт плотность воксельной сетки. udf рассчитан на менее аккуратный вход; sdf требует согласованного направления граней. qef помогает восстановить острые формы. project_back притягивает вершины к исходной поверхности, smooth_iters сглаживает результат, drop_small_components удаляет мелкие компоненты.

## Пример подключения

Для неровной сетки сначала попробуйте невысокое resolution в udf. Проверьте тонкие части и полости. Если форма подходит, примените DecimateMesh для ограничения числа граней, затем UnwrapMesh и запекание материала.

## Ограничения и частые ошибки

В реализации используется фиксированная область около куба [-0.5, 0.5]; произвольный mesh из другой системы масштаба нельзя подавать без проверки нормализации. Память быстро растёт с resolution. Удаление мелких или вложенных компонентов может убрать нужные детали. UV и связанные атрибуты после перестройки нужно готовить заново.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `mesh` | `MESH` | да | соединение / значение без фиксированного default |
| `resolution` | `INT` | да | по умолчанию: 512; минимум: 32; максимум: 2048 |
| `sign_mode` | `COMFY_DYNAMICCOMBO_V3` | да | режимы: udf, sdf |
| `sign_mode=udf → qef` | `BOOLEAN` | да | по умолчанию: false |
| `sign_mode=udf → drop_inverted_components` | `BOOLEAN` | да | по умолчанию: false |
| `sign_mode=udf → drop_enclosed_components` | `BOOLEAN` | да | по умолчанию: false |
| `sign_mode=sdf → qef` | `BOOLEAN` | да | по умолчанию: true |
| `sign_mode=sdf → manifold` | `BOOLEAN` | да | по умолчанию: false |
| `band` | `FLOAT` | да | по умолчанию: 1.0; минимум: 0.5; максимум: 4.0; шаг: 0.1 |
| `project_back` | `FLOAT` | да | по умолчанию: 0.0; минимум: 0.0; максимум: 1.0; шаг: 0.05 |
| `fix_poles` | `BOOLEAN` | да | по умолчанию: false |
| `smooth_iters` | `INT` | да | по умолчанию: 0; минимум: 0; максимум: 20 |
| `drop_small_components` | `FLOAT` | да | по умолчанию: 0.01; минимум: 0.0; максимум: 0.5; шаг: 0.005 |
| `precluster_max_verts` | `INT` | да | по умолчанию: 20000000; минимум: 0; максимум: 100000000 |
