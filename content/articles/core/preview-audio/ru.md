# PreviewAudio: временно сохранить и прослушать AUDIO

## Что делает нода

`PreviewAudio` готовит звук для плеера в интерфейсе ComfyUI. При выполнении она кодирует каждый элемент входного batch в отдельный FLAC, кладёт файлы в каталог `temp` и возвращает UI-описание с типом `temp`.

Это не постоянный экспорт в `output`, но и не воспроизведение прямо из tensor-памяти: временный файл действительно создаётся на диске. Его случайный префикс начинается с `ComfyUI_temp_`.

У ноды есть подключаемый выход `audio` типа `AUDIO`. Через него передаётся тот же входной объект, поэтому preview можно поставить в середине ветки, а не только в её конце.

## Когда использовать и когда не использовать

Ставьте `PreviewAudio` перед экспортом, чтобы проверить содержимое, порядок каналов, паузы и приблизительный уровень. Она удобна после `LoadAudio`, `VAEDecodeAudio`, `AudioMerge` или другой операции, результат которой нужно услышать.

Для файла, который должен остаться в `output`, используйте `SaveAudioAdvanced`. Временный FLAC не следует считать опубликованным артефактом, ссылкой для другой системы или архивной копией.

Нода не показывает sample rate, форму batch или пиковый уровень отдельными числами. Плеер помогает услышать проблему, но точную диагностику формы `[B,C,T]` и амплитуды нужно делать отдельным инструментом.

## Короткий рецепт подключения

1. Подайте `AUDIO` во вход `audio`.
2. Запустите ветку и откройте появившийся плеер.
3. Если batch содержит несколько элементов, проверьте каждый созданный файл.
4. При необходимости подключите выход `audio` к следующей ноде: данные через него не перекодируются.

Fragment «Загрузить файл и создать временное прослушивание» соединяет `LoadAudio` с `PreviewAudio`. Имя файла в fragment служит заменяемым примером и должно существовать в вашем `input`. Официальный набор 0.1.42 не содержит такой пары, поэтому topology помечена как source-derived.

## Входы, выходы и параметры

Обязательный вход `audio` имеет тип `AUDIO`. Если прямой вызов передаст `None`, нода выдаст явную ошибку с подсказкой проверить аудиодорожку исходного видео. В обычном графе порт обязателен.

Подключаемый выход `audio` тоже имеет тип `AUDIO`; runtime отмечает его как обычный, не list-output. Дополнительно возвращается UI-структура `audio` со списком файлов. Для waveform `[B,C,T]` helper проходит по оси `B`, поэтому создаёт `B` FLAC-файлов.

Формат и качество не настраиваются: используется FLAC и исходный `sample_rate`. Один канал записывается с layout `mono`, любое другое число каналов helper объявляет как `stereo`.

## Типовые связки

`LoadAudio → PreviewAudio` подтверждает, что выбран нужный файл. `VAEDecodeAudio → PreviewAudio` позволяет прослушать декодированный latent до сохранения. `AudioMerge → PreviewAudio` помогает проверить наложение и возможную нормализацию пиков.

Выход preview можно продолжить в `SaveAudioAdvanced`: постоянный saver получит исходный AUDIO, а не данные, прочитанные обратно из временного FLAC. Поэтому preview не меняет sample rate, batch, waveform или дополнительные поля словаря для downstream-ноды.

Если нужно сравнить два варианта, используйте отдельную `PreviewAudio` на каждой ветке. Один экземпляр не объединяет batch и не подписывает его элементы пользовательскими именами.

## Практический пример

В wheel `comfyui-workflow-templates-json 0.1.42` проверены все 512 JSON, включая 272 subgraph: `PreviewAudio` не встречается ни разу. Официальных widget values и готовой topology для этой ноды в закреплённом наборе нет.

Изолированный запуск точного класса с `[1,2,800]` при 8 кГц создал один `ComfyUI_temp_….flac` только в `temp`; каталог `output` не изменился. UI-result содержал `type: temp`, а подключаемый выход сохранил идентичность входного словаря.

Отдельная проверка batch из двух элементов создала два файла. Проверка многоканального входа выявила ограничение writer helper: `[1,3,80]` сохранился как stereo с 120 отсчётами, а `[1,4,80]` — как stereo со 160. Это не корректное сохранение трёх или четырёх каналов.

## Частые ошибки и способы проверки

**Ожидают, что файл появится в `output`.** Preview использует `temp`. Для постоянного экспорта добавьте `SaveAudioAdvanced`.

**Считают ноду чисто визуальной.** Плеер получает настоящий временный FLAC. Проверьте свободное место и права записи в temp-каталог.

**Не замечают несколько элементов batch.** Helper пишет отдельный файл на каждый `B`. Прослушивание только первого не проверяет остальные варианты.

**Передают больше двух каналов.** Реализация выбирает layout только между mono и stereo. Сведите материал до одного или двух каналов заранее; иначе каналы сплющатся в более длинный stereo-поток.

**Ищут подключаемый выход и доверяют embedded docs.** Runtime 0.32.0 действительно объявляет `AUDIO` output с именем `audio`, хотя embedded docs 0.5.9 перечисляют только UI.

## Производительность и внутреннее поведение

Каждый batch-элемент переносится на CPU, преобразуется в NumPy и полностью кодируется во внутренний `BytesIO`; затем буфер записывается на диск. Временные затраты зависят от числа отсчётов и batch, а пиковая память включает waveform и готовый кодированный буфер.

FLAC сохраняет waveform без потерь кодека, но preview всё равно выполняет CPU-кодирование и дисковую запись. Для длинных дорожек или большого batch это существенно дороже простого passthrough.

Если metadata не отключены, helper может положить prompt и `extra_pnginfo` в metadata контейнера. Нода не удаляет произвольные дополнительные поля из подключаемого AUDIO, потому что возвращает исходный объект без сборки нового словаря.

## Совместимость, изменения и устаревание

Материал закреплён на ComfyUI `0.32.0`, frontend `1.48.7`, runtime ID `PreviewAudio` и модуле `comfy_extras.nodes_audio`. Schema fingerprint: `sha256:01ab10078d102983846813625c4cda17156b8e411c91de55c0aa78acf89c680d`.

Нода является output node, но не experimental и не deprecated. В исходнике сохранён старый alias метода `save_flac = execute` с пометкой TODO; это Python-совместимость метода, а не исторический `class_type`, поэтому `runtimeIdentity.aliases` остаётся пустым.

Embedded docs верно описывают временный preview и ошибку для `None`, но пропускают подключаемый AUDIO-выход, batch-файлы и ограничение числа каналов. Статья следует runtime `/object_info` и точной реализации.
