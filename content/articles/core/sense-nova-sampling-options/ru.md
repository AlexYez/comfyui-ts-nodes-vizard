# SenseNova Sampling Options: временное расписание модели

Настраивает model_sampling для SenseNova в копии MODEL. Меняет интерпретацию временного расписания сэмплирования, а не текстовое conditioning.

## Как пользоваться

shift передаётся в SenseNovaModelSampling; значение по умолчанию — 3.0. Выход MODEL содержит новую настройку, исходная ветка модели остаётся отдельной. Это не seed, не CFG и не число шагов: эти параметры задаются в соответствующих нодах sampler.

## Пример подключения

После загрузки SenseNova поставьте эту ноду перед sampler и начните с настроек официального workflow для выбранных весов. Если сравниваете shift, фиксируйте seed, количество шагов и остальные условия. Оценивайте не только детализацию, но и устойчивость результата.

## Ограничения и частые ошибки

Нода рассчитана на семейство SenseNova; одинаковый разъём MODEL не гарантирует совместимость с другой архитектурой. Нельзя переносить числовую рекомендацию shift между моделями без проверки. Она не исправляет отсутствие весов и не заменяет правильно выбранное расписание sampler.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `model` | `MODEL` | да | соединение / значение без фиксированного default |
| `shift` | `FLOAT` | да | по умолчанию: 3.0; шаг: 0.01 |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `MODEL` | `MODEL` | нет |
