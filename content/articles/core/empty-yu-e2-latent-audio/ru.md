# Empty YuE2 Latent Audio: начало сэмплирования

Создаёт нулевой latent для музыкального sampler YuE2 с заданной длительностью и размером batch. Он содержит место для будущего звука, но не саму фонограмму.

## Как пользоваться

seconds переводится в число временных позиций с округлением; batch_size задаёт количество элементов. Внутренний тензор имеет 64 канала. Метаданные type = audio и downscale_ratio_temporal = 1920 описывают формат YuE2. По умолчанию запрашивается 120 секунд, поэтому для первого опыта разумно подготовить более короткое conditioning.

## Пример подключения

Подключите фактический seconds из YuE2GenerateMusic, оставьте batch_size = 1 и направьте latent в sampler той же модели. Декодируйте только результат sampler, а не пустую заготовку. Для сравнения нескольких вариантов меняйте seed генерации, сохраняя согласованную длительность.

## Ограничения и частые ошибки

Эта нода не создаёт мелодию и не извлекает звук из ABC. Совпадающий тип LATENT не делает её заменой EmptyMiniMaxMusic3LatentAudio: отличаются число каналов и временная сетка. Увеличение batch и длительности требует больше памяти на следующих этапах.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `seconds` | `FLOAT` | да | по умолчанию: 120.0; минимум: 0.04; максимум: 1000.0; шаг: 0.04 |
| `batch_size` | `INT` | да | по умолчанию: 1; минимум: 1; максимум: 4096 |
