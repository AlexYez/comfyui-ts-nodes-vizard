# LoadImageDataSetFromFolder: список изображений из папки input

## Что делает нода

`LoadImageDataSetFromFolder` читает изображения из выбранной подпапки `input` и выдаёт их как список значений `IMAGE`. Поддерживаются расширения PNG, JPG, JPEG и WEBP без учёта регистра.

Каждый файл превращается в отдельный тензор формы `[1, H, W, 3]` с `float32`-значениями от 0 до 1. Изображение переводится в RGB, поэтому прозрачность и другие дополнительные каналы в выход не попадают. Разные элементы списка могут иметь разную ширину и высоту.

Нода смотрит только на файлы непосредственно в выбранной папке. Вложенные каталоги она не обходит. Если нужен их материал, выберите такую подпапку отдельно в поле `folder`.

## Когда использовать и когда не использовать

Нода подходит для операций, которые умеют принимать списочный `IMAGE`: подготовки набора изображений, поэлементного изменения размера, кадрирования или другой обработки набора данных. Разная геометрия исходников здесь допустима, потому что файлы не объединяются в один тензорный batch.

Для одного известного файла проще использовать `LoadImage`: у него есть отдельный выход маски. Если рядом с изображениями лежат TXT-подписи, берите `LoadImageTextDataSetFromFolder`, иначе связь между картинкой и текстом потеряется.

Нода не ищет файлы рекурсивно, не сортирует их, не выравнивает размеры и не проверяет смысл содержимого. Порядок элементов зависит от `os.listdir`, поэтому не связывайте его с отдельным списком метаданных, собранным другим способом.

## Короткий рецепт подключения

1. Создайте подпапку внутри каталога `input` ComfyUI.
2. Положите в неё PNG, JPG, JPEG или WEBP.
3. Обновите определение ноды и выберите папку в `folder`.
4. Подключите `images` к ноде, которая поддерживает списочный вход.

Fragment «Прочитать изображения из выбранной подпапки» содержит только `LoadImageDataSetFromFolder`. В закреплённом снимке `/object_info` у него стоит папка `3d`; это локальное динамическое значение, которое нужно заменить на вашу папку. Fragment не воспроизводит официальный workflow и не исполнялся после импорта.

## Входы, выходы и параметры

Обязательный `folder` — динамический `COMBO`. Список строится рекурсивно из подпапок `input`, хотя сама нода после выбора читает только непосредственные файлы указанного каталога. В снимке ComfyUI 0.32.0 единственным значением было `3d`; локальные варианты намеренно не входят в schema fingerprint.

Выход `images` имеет тип `IMAGE` и флаг `is_output_list`. Это список отдельных тензоров, а не обычный пакет `IMAGE`. У каждого элемента сохраняется собственная геометрия, batch-ось равна единице, цветовых каналов после RGB-конвертации три.

Путь разрешается относительно `input`. Проверка через `realpath` блокирует `..`, абсолютные пути с выходом наружу и переход через символьную ссылку за пределы каталога.

## Типовые связки

`LoadImageDataSetFromFolder → ResizeImagesByShorterEdge` приводит короткую сторону каждого элемента к выбранному размеру. `CenterCropImages` или `RandomCropImages` затем подготавливают одинаковую область для дальнейшей обработки.

Для визуальной проверки списка можно сначала собрать `ImageGrid`, если размеры уже согласованы с требованиями этой ноды. Для обучения или кодирования подключайте только следующую ноду, которая явно принимает списочный вход: обычный вход `IMAGE` не всегда означает поддержку списка.

`LoadImageTextDataSetFromFolder` решает соседнюю задачу и возвращает два синхронных списка. Не собирайте подписи отдельной нодой после `LoadImageDataSetFromFolder`: из-за несортированного обхода файлов соответствие нельзя считать устойчивым.

## Практический пример

Полный просмотр `comfyui-workflow-templates-json 0.1.42` охватил 512 JSON, 496 корневых workflow и 272 подграфа. `LoadImageDataSetFromFolder` не встретилась ни разу, поэтому официальный способ подключения для неё не заявлен.

Изолированный прогон точной реализации создал временную папку с PNG, WEBP, GIF, TXT и вложенным PNG. Нода вернула только два поддерживаемых файла верхнего уровня: тензоры `[1,5,6,3]` и `[1,4,7,3]`. GIF, TXT и изображение во вложенной папке были пропущены.

Эта проверка подтверждает файловое поведение класса, но не считается исполнением пользовательского fragment в интерфейсе ComfyUI.

## Частые ошибки и способы проверки

**Папка отсутствует в `folder`.** Поле показывает только подпапки `input`, а не сам корневой каталог. Создайте папку внутри `input`, затем обновите сведения о нодах или перезапустите ComfyUI.

**Ошибка `No valid images found in input`.** В выбранном каталоге нет прямых файлов с поддерживаемым расширением. Проверьте вложенность и расширение; содержимое подпапок не учитывается.

**Весь запуск обрывается на одном файле.** Файл может иметь подходящее расширение, но быть повреждённым или неподдерживаемым Pillow. Откройте подозрительные изображения отдельно и перекодируйте их.

**Порядок меняется между системами.** Реализация не вызывает `sorted`. Если порядок важен, добавьте проверенную сортировку ниже по графу либо подготовьте файлы заранее.

**Пропала прозрачность.** Загрузчик вызывает `convert("RGB")`. Для альфа-маски используйте `LoadImage` или отдельную обработку маски.

## Производительность и внутреннее поведение

Каждый файл открывается Pillow, полностью преобразуется в NumPy `float32`, а затем копируется в тензор PyTorch. Все результаты остаются в списке одновременно. Память растёт примерно с суммой `H × W × 3 × 4` байта для всех изображений, без учёта временных объектов.

GPU не используется. Основные затраты приходятся на чтение с диска, декодирование и память CPU. Большой набор лучше делить на папки, если следующий этап не умеет освобождать элементы по мере обработки.

Нода не кэширует декодированные файлы внутри метода и не объединяет их по размеру. Изменение содержимого папки меняет фактический результат, хотя динамический список файлов не является частью структурного fingerprint.
