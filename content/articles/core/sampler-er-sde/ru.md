# SamplerER_SDE: ER-SDE, reverse-time SDE и ODE

`SamplerER_SDE` создаёт один объект `SAMPLER`, но меняет его функцию масштабирования шума в зависимости от `solver_type`. Доступны `ER-SDE`, `Reverse-time SDE` и детерминированный `ODE`; все три исполняются общей низкоуровневой функцией `sample_er_sde`.

## 1. Что делает нода

Нода выбирает noise scaler, ограничивает максимальное число стадий коррекции и передаёт эти настройки в фабрику `er_sde`. `eta` участвует в формулах двух SDE-вариантов. При `eta = 0` либо выборе `ODE` код принудительно переходит на ODE-scaler и устанавливает `s_noise = 0`.

Название solver определяет не отдельную Python-функцию, а конкретную зависимость масштаба от внутренней переменной ER-SDE.

## 2. Место в графе

Выход `SAMPLER` подключают к `SamplerCustom` или `SamplerCustomAdvanced`. SIGMAS задаёт последовательность переходов; модель, noise и guidance находятся в других частях графа.

Нода подходит для контролируемого сравнения стохастического ER-SDE и ODE при неизменных остальных компонентах. Если нужен адаптивный DPM с контролем локальной ошибки, это другой алгоритм — `SamplerDPMAdaptative`.

## 3. Входы

- `solver_type` — `ER-SDE`, `Reverse-time SDE` или `ODE`.
- `max_stage` — максимум стадий `1…3`, по умолчанию `3`.
- `eta` — сила SDE в диапазоне `0…10`, по умолчанию `1`.
- `s_noise` — множитель добавляемого шума `0…100`, по умолчанию `1`.

В runtime tooltip предупреждает, что большое eta может дать невалидный результат. При такой ошибке уменьшайте eta, а не маскируйте NaN дальнейшими image-нодами.

## 4. Выход

Выход — `KSAMPLER` с именем `er_sde`. В options находятся `s_noise`, выбранная callable-функция `noise_scaler` и `max_stage`. Само значение eta отдельно в options не записывается: оно замыкается внутри функции scaler.

Для `ODE` и любого случая с `eta = 0` scaler становится тождественным `f(x) = x`, а effective `s_noise` — нулём. Исходное значение eta при этом не нужно downstream.

## 5. Как работает

Для `ER-SDE` scaler равен `x * (exp(x^0.3) + 10)^eta`. Для `Reverse-time SDE` — `x^(eta + 1)`. Для ODE — просто `x`. На каждом переходе algorithm вычисляет отношение scaler в конечной и начальной точках.

Первая доступная стадия делает Euler-подобное обновление. Вторая использует производную между текущим и предыдущим denoised; третья — изменение этой производной. Реально применяемое число равно `min(max_stage, i + 1)`, поэтому первые шаги неизбежно имеют меньший порядок: для higher stages ещё нет истории.

Коррекционные интегралы оцениваются по 200 точкам. Если следующая sigma равна нулю, результатом шага становится denoised без нового шума. Иначе при положительном `s_noise` добавляется случайный тензор; его амплитуда дополнительно умножается на model-specific `noise_scale`.

## 6. Параметры и настройка

Для первого прогона оставьте `max_stage = 3`, `eta = 1`, `s_noise = 1` и выбранный `ER-SDE`. Чтобы отделить влияние случайной части, сравните с `ODE` при том же seed и SIGMAS.

`max_stage = 1` убирает исторические коррекции и дешевле по служебной арифметике, но не сокращает основной один model call на переход. При `eta = 0` выбор `ER-SDE` или `Reverse-time SDE` всё равно будет нормализован в ODE. Значение `s_noise` в таком случае игнорируется через принудительный ноль.

## 7. Проверенный пример

Recipe `ER-SDE с тремя стадиями` ставит `SamplerER_SDE(solver_type = ER-SDE, max_stage = 3, eta = 1, s_noise = 1)` перед `SamplerCustomAdvanced`. NOISE, GUIDER, SIGMAS и LATENT остаются внешними, чтобы не выдумывать модельный pipeline.

Полный scan 512 официальных JSON и всех subgraph не нашёл ни одного `SamplerER_SDE`. Поэтому fragment обозначен как source/runtime-derived, а не официальный. Exact-source проба проверяет три scaler, принудительный ODE при eta 0 и options фабрики; diffusion model не запускалась.

## 8. Частые ошибки

- Верят embedded docs, будто eta не влияет на `ER-SDE`. В коде eta стоит в показателе его scaler.
- Считают, что при eta 0 сохраняется выбранное имя solver. Код переводит его в ODE.
- Ждут три стадии уже на первом шаге; история накапливается постепенно.
- Принимают `max_stage` за число model calls или SIGMAS.
- Используют большое eta после появления NaN вместо снижения значения.
- Забывают, что `s_noise` ещё умножается на `model_sampling.noise_scale`.
- Подключают `SAMPLER` к порту NOISE.

## 9. Ограничения и производительность

На каждом переходе выполняется один основной вызов модели. Higher stages добавляют тензорную арифметику и численное суммирование по 200 точкам, но обычно модель остаётся главной статьёй затрат. Для крупных video latent промежуточные denoised и производные увеличивают память.

Формулы содержат степени, экспоненты и квадратный корень. Экстремальные eta/SIGMAS могут выйти за устойчивый численный диапазон; финальный noise term применяет `nan_to_num` только к одному корню и не гарантирует исправления всех невалидных значений.
