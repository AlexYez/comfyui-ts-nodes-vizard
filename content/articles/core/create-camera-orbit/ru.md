# Create Camera Orbit: набор ракурсов вокруг объекта

Создаёт орбиту камер вокруг target исходной камеры. Для списка исходных камер строит отдельную орбиту для каждой.

## Подключение и пример

Создайте начальную камеру через Create Camera Info, задайте count, общий поворот yaw и наклон pitch. Полный оборот заканчивается за один шаг до первой камеры, не дублируя её; неполный включает конечный угол. poles добавляет ракурсы сверху и снизу после основных камер. Для UltraTex типовой набор — четыре боковых вида плюс верх и низ.

## Ограничения

Камера не должна находиться прямо в target: у неё тогда нет направления взгляда. Это список ракурсов, а не готовая анимация объекта. Для запекания текстуры сохраняйте порядок и те же параметры рендера.

## Входы и настройки

Снимок ComfyUI 0.45.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `camera_info` | `LOAD3D_CAMERA` | да | соединение / значение без фиксированного default |
| `count` | `INT` | да | по умолчанию: 4; минимум: 1; максимум: 64 |
| `yaw` | `FLOAT` | да | по умолчанию: 360.0; минимум: -720.0; максимум: 720.0; шаг: 1.0 |
| `pitch` | `FLOAT` | да | по умолчанию: 0.0; минимум: -720.0; максимум: 720.0; шаг: 1.0 |
| `poles` | `COMBO` | да | варианты: none, top, bottom, top and bottom |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `camera_info` | `LOAD3D_CAMERA` | нет |
