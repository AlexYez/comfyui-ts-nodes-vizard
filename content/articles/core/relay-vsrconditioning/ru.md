# RelayVSR: подготовка видео к увеличению

Готовит положительные условия и пустой LATENT для специализированной RelayVSR-модели. Она обрабатывает опорные кадры, а полный ряд восстанавливает отдельный VSR Decode.

## Подключение и пример

Подайте MODEL RelayVSR и пакет низкокачественных кадров в исходном размере. Архитектура модели определяет коэффициент увеличения и латентную сетку. Для предусмотренного схемой запуска используйте один шаг с CFG 1, затем передайте результат и те же исходные images в VSR Decode.

## Ограничения

Это не универсальная подготовка для любого Wan checkpoint. Частота кадров и звук не восстанавливаются этой нодой. Сохраняйте исходный порядок и длину images; замена кадров между conditioning и декодированием нарушает согласованность.

## Входы и настройки

Снимок ComfyUI 0.45.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `model` | `MODEL` | да | соединение / значение без фиксированного default |
| `images` | `IMAGE` | да | соединение / значение без фиксированного default |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `positive` | `CONDITIONING` | нет |
| `latent` | `LATENT` | нет |
