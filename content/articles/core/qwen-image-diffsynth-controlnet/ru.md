# Qwen DiffSynth ControlNet: модельная заплатка

Применяет совместимую управляющую модель `MODEL_PATCH` к копии `MODEL`. Экспериментальная локальная нода; веса заплатки загружаются отдельно, выходная модель подключается к сэмплеру.

## Подключение

Подайте модель, заплатку, совместимый VAE и управляющее `image`. Изображение обрезается до RGB. Необязательная `mask` обрабатывается выбранной архитектурой заплатки. Обычный граф этой ноды не имеет порта `inpaint_image`, хотя внутренний метод его принимает.

## Сила и участок генерации

`strength` задаёт силу от −10 до 10. При нуле ComfyUI 0.38.0 возвращает исходную модель без подготовки заплатки. Это отличается от поведения старой версии, описанного раньше в справочнике.

Новые `start_percent` и `end_percent` задают начало и конец воздействия в расписании сэмплирования. По умолчанию 0 и 1, то есть весь проход. Они не задают долю изображения или время внутри видео: через `model_sampling.percent_to_sigma` код получает диапазон уровней шума.

## Архитектура и маска

Для Qwen Image 2.1 Fun Control используется отдельная ветвь QwenImage21FunControlPatch. Для ZImage_Control — ZImageControlPatch; иначе — DiffSynthCnetPatch. В последующих двух ветвях маска получает дополнительные оси и инвертируется, а Qwen 2.1 принимает её до этой общей обработки. Поэтому нельзя считать внутренние форматы маски одинаковыми для всех заплаток.

## Ограничения

Нода не проверяет совместимость только по имени файла. Следуйте workflow именно вашей модели и заплатки. При изменении размера может понадобиться повторное VAE-кодирование управляющего изображения; это влияет на время и память.

## Пример подключения

Для контроля по контурам подготовьте изображение через Canny, загрузите совместимую управляющую заплатку через Load Model Patch и передайте выходную модель в сэмплер Qwen. Сохраните порядок модельных настроек из workflow именно этой заплатки: совпадение портов не подтверждает совместимость весов.

## Входы и настройки

Снимок ComfyUI 0.38.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `model` | `MODEL` | да | соединение / значение без фиксированного default |
| `model_patch` | `MODEL_PATCH` | да | соединение / значение без фиксированного default |
| `vae` | `VAE` | да | соединение / значение без фиксированного default |
| `image` | `IMAGE` | да | соединение / значение без фиксированного default |
| `strength` | `FLOAT` | да | по умолчанию: 1.0; минимум: -10.0; максимум: 10.0; шаг: 0.01 |
| `mask` | `MASK` | нет | соединение / значение без фиксированного default |
| `start_percent` | `FLOAT` | нет | по умолчанию: 0.0; минимум: 0.0; максимум: 1.0; шаг: 0.001 |
| `end_percent` | `FLOAT` | нет | по умолчанию: 1.0; минимум: 0.0; максимум: 1.0; шаг: 0.001 |

## Официальные примеры подключения

`image_qwen_image_controlnet_patch.json`, подграф «main»: входы от `Canny`, `ModelPatchLoader`, `ModelSamplingAuraFlow`, `VAELoader`; выходы к `KSampler`.

`image_z_image_turbo_fun_union_controlnet.json`, подграф «Z-Image-Turbo Fun Control to Image»: входы от `ModelPatchLoader`, `SubgraphInput`, `UNETLoader`, `VAELoader`; выходы к `ModelSamplingAuraFlow`.

Шаблоны из [официального пакета 0.1.96](https://pypi.org/project/comfyui-workflow-templates-json/0.1.96/), закреплённого ComfyUI 0.38.0. Это сохранённые соединения, не отчёт о запуске. Внешние входы и переключатели подграфа могут менять значения и путь выполнения. `SubgraphInput` и `SubgraphOutput` обозначают границы подграфа.
