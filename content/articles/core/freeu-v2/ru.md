# FreeU_V2: пространственно-зависимое усиление backbone

## Что делает нода

`FreeU_V2` патчит то же место U-Net, что и `FreeU`: decoder output block перед объединением backbone-тензора `h` со skip-тензором `hsp`. Нода читает базовое число каналов модели и выбирает два уровня: `model_channels × 4` для `b1/s1` и `model_channels × 2` для `b2/s2`.

Главное отличие V2 — способ применения `b`. Код усредняет `h` по каналам, получает одну пространственную карту на каждый элемент batch и нормализует её по глобальным минимуму и максимуму в диапазон `0…1`. Для первой половины каналов строится множитель:

```text
gain = 1 + (b − 1) × normalized_hidden_mean
```

Если `b > 1`, позиции с минимальным средним сохраняют множитель `1`, а позиции с максимальным доходят до `b`. При `b < 1` карта идёт от `1` к меньшему значению `b`. Вторая половина каналов `h` не меняется.

Skip-ветвь устроена как в FreeU: двумерный FFT в float32, множитель `s` в центральных `2 × 2` frequency bins, обратное преобразование и возврат исходного dtype. Веса checkpoint остаются прежними, а выходом служит клон `MODEL` с output-block patch.

## Когда использовать и когда не использовать

V2 подходит для отдельного A/B-опыта, когда равномерное усиление FreeU кажется слишком грубым и нужна пространственная зависимость от текущих backbone features. Зафиксируйте граф и сравните `FreeU`, `FreeU_V2` и baseline по одному, а не складывайте их сразу.

Нода предполагает обычные 4D feature maps `B, C, H, W`. Нормализация явно добавляет две пространственные оси через `unsqueeze(2).unsqueeze(3)`, а Fourier helper распаковывает ровно четыре измерения. Для 5D video features этот код не является общей реализацией FreeU для видео.

Есть важный граничный случай: если усреднённая по каналам карта постоянна, `hidden_max − hidden_min = 0`. В source нет epsilon или условного bypass, поэтому деление даёт NaN, которые попадают в первую половину каналов. Exact probe воспроизвёл это на постоянном тензоре. При нечисловом результате первым делом проверяйте этот denominator.

Defaults `b1 = 1.3`, `b2 = 1.4`, `s1 = 0.9`, `s2 = 0.2` совпадают с одним из наборов reference-репозитория, но это не делает их универсальными. В официальном workflow wheel 0.1.42 `FreeU_V2` отсутствует во всех 512 JSON и recursive subgraphs.

## Короткий рецепт подключения

1. Подайте U-Net `MODEL` с `unet_config.model_channels` в `FreeU_V2`.
2. Для первой проверки оставьте `b1 = 1.3`, `b2 = 1.4`, `s1 = 0.9`, `s2 = 0.2`.
3. Подключите выход к прежнему sampling path.
4. Сделайте baseline без V2 при том же seed.
5. Для изоляции spatial gain временно задайте `s1 = s2 = 1`.
6. Для изоляции skip-фильтра задайте `b1 = b2 = 1`.
7. Следите за finite values и меняйте один stage parameter за раз.

Fragment «FreeU_V2: source-derived runtime defaults» содержит только patch-ноду и внешний `MODEL`. Полного workflow нет: официальный wheel не даёт реальной topology, а end-to-end генерация с checkpoint не выполнялась.

## Входы, выходы и параметры

`model` — обязательный `MODEL`. При создании patch нода сразу читает `model.model.model_config.unet_config["model_channels"]`; отсутствие поля приводит к ошибке до генерации.

`b1` — advanced `FLOAT`, default `1.3`, диапазон `0…10`, шаг `0.01`. Он задаёт край пространственного gain на уровне `model_channels × 4`. При `1` backbone-ветвь этого уровня остаётся неизменной независимо от карты. При `0` позиции с максимальным normalized mean получают нулевой множитель, а минимальные — единицу.

`b2` имеет тот же диапазон и шаг, default `1.4`, и действует на уровне `model_channels × 2`.

`s1` — advanced `FLOAT`, default `0.9`, диапазон `0…10`, шаг `0.01`. Он масштабирует центральные `2 × 2` частоты skip-тензора на первом уровне. `s2` делает то же на втором, default `0.2`. Значение `1` оставляет соответствующий Fourier spectrum неизменным в пределах погрешности преобразования.

Выход — один `MODEL`. Exact NodeId — `FreeU_V2` с подчёркиванием; это отдельный runtime key, а не alias `FreeU`. Модуль — `comfy_extras.nodes_freelunch`, категория — `model/patch/unet`.

## Типовые связки

Подключение остаётся обычным: `MODEL → FreeU_V2 → sampler` либо `MODEL → FreeU_V2 → CFGGuider → SamplerCustomAdvanced`. Если scheduler использует model sampling object, передавайте тот же выход V2 и в scheduler.

`FreeU` — ближайшая связанная нода. Она применяет постоянный `b` ко всей первой половине каналов, тогда как V2 строит spatial map. Skip-фильтры у обеих реализаций одинаковы. Для сравнения держите `s1/s2` равными и меняйте только вариант backbone patch.

`FreSca` применяет FFT к guidance после model predictions, а не к skip features decoder. Его cutoff настраивается; у V2 центральная область всегда `2 × 2`. Эти различия важнее сходства терминов «частотное масштабирование».

Output-block patches добавляются в список и исполняются по порядку. При цепочке `FreeU → FreeU_V2` карта V2 рассчитывается уже по равномерно изменённому `h`. В обратном порядке FreeU масштабирует результат пространственной карты. Tensor-probe получил разные тензоры для двух порядков, поэтому складывать ноды без явной цели не стоит.

## Практический пример

Probe создал тензор с `16` каналами при `model_channels = 4`. Пространственное среднее менялось от минимума до максимума. Для `b1 = 1.3` вычисленный gain имел диапазон от `1.0` до `1.3`; первая половина каналов совпала с ручной формулой, вторая осталась побитово прежней.

Затем в patch передали постоянный `h`. Среднее по каналам тоже оказалось постоянным, denominator min-max нормализации стал нулём, а первая половина выходных каналов — нечисловой. Это безопасный synthetic probe точного класса, не свидетельство того, что обычная модель постоянно встречает такой feature map.

Skip-ветвь на constant input дала ожидаемое умножение DC-компоненты на `s1`, сохранив dtype. Попытка обработать 5D skip после FFT завершилась ошибкой даже через CPU fallback. Для практического теста используйте 4D image model и отслеживайте finite values после двух целевых decoder stages.

## Частые ошибки и способы проверки

**Появились NaN.** Проверьте `hidden_max − hidden_min` для карты `h.mean(channel)`. В pinned V2 нет защиты от нуля. Удаление V2 или переход на обычный FreeU помогает отделить эту ветвь от FFT и остального графа.

**Ожидалось равномерное усиление `b1`.** V2 не умножает все позиции на `b1`. Его gain меняется от `1` до `b1` согласно нормализованной карте. Для постоянного множителя используйте отдельный `FreeU`.

**Нода ничего не делает.** Убедитесь, что channel count `h` достигает `model_channels × 4` или `×2`. Другие блоки обходятся без изменения.

**Video model падает.** Helper ожидает четыре измерения. Даже если backbone-часть broadcast прошла, `Fourier_filter` распакует 5D tensor с ошибкой и повторит её на CPU.

**Два FreeU-patch дали слишком сильный эффект.** Они не выбирают «последний вариант», а исполняются последовательно. Оставьте один или сравните порядок как отдельную настройку.

## Производительность и внутреннее поведение

На каждом целевом output block V2 считает channel mean, batch-wise spatial min/max и gain map. Эти операции дешевле model forward, но создают дополнительные тензоры размером примерно `B × 1 × H × W`. Первая половина `h` умножается на месте.

Fourier-часть переводит `hsp` в float32, создаёт complex spectrum и маску полного размера, затем возвращает исходный dtype. Если FFT текущего устройства выбрасывает exception, нода запоминает device и переводит будущие skip-тензоры этого device на CPU для фильтрации.

Min-max считается отдельно для каждого batch element: `hidden_max` и `hidden_min` получаются после flatten всех пространственных позиций. Каналы сначала усредняются. Поэтому один элемент batch не влияет на диапазон другого, пока форма соответствует 4D contract.

Порог частот жёсткий: `threshold = 1`, центральный срез имеет две позиции по каждой оси. Параметры `s1/s2` не меняют ширину области.

## Совместимость, изменения и устаревание

Материал проверен по ComfyUI 0.32.0, source commit `c2bcbecd…`, frontend 1.48.7 и pinned runtime inventory. Флаги `experimental`, `deprecated`, `dev_only`, `api_node` равны `false`. Replacement API не содержит `FreeU_V2`.

Python-класс сохраняет совместимый атрибут `patch = execute` с TODO на удаление. Публичная runtime identity статьи строится по `FreeU_V2 + comfy_extras.nodes_freelunch`, а не по имени метода.

Embedded docs 0.5.9 правильно перечисляет коэффициенты и общую частотную модификацию, но не описывает точную min-max формулу, NaN на постоянной карте, 4D constraint и fallback. После обновления ComfyUI сверяйте source и fingerprint, особенно denominator protection.

## Связанные ноды и источники

`FreeU` даёт равномерный backbone multiplier на тех же channel stages. `FreSca` фильтрует conditional-unconditional guidance и использует настраиваемый cutoff. Ни одна из этих связей не является replacement API.

Факты сверены с `comfy_extras/nodes_freelunch.py`, embedded docs 0.5.9, [reference-кодом FreeU](https://github.com/ChenyangSi/FreeU) и обновлённой версией работы [FreeU: Free Lunch in Diffusion U-Net](https://arxiv.org/abs/2309.11497v2). Exhaustive wheel census дал ноль точных экземпляров. Probe подтвердил spatial gain, constant-map NaN, 5D failure и порядок stacking; полный model run и человеческое утверждение ещё ожидаются.
