# Wan22ImageToVideoLatent

## Назначение
Нода создаёт 48-канальный видеолатент Wan 2.2 для text-to-video или image-to-video.
## Место в графе
Подайте VAE и размеры; optional start image фиксирует первые temporal positions перед sampler.
## Входы
Width/height от 32 с шагом 32, length от 1 с шагом 4, batch до 4096. VAE требуется даже без start image по runtime-схеме.
## Пустая ветвь
Без start image возвращаются нули формы `[1,48,((length−1)//4)+1,height//16,width//16]` без noise_mask и без повторения batch_size.
## Image ветвь
Берутся не более `length` первых кадров. Их размер приводится к целевому через bilinear-масштабирование с обрезкой по центру, после чего кадры кодируются VAE. Полученный латент записывается с начала временной оси; нода не растягивает исходное видео на всю заданную длину.
## Mask
`noise_mask` создаётся на промежуточном устройстве ComfyUI, начинается единицами и обнуляется на временных позициях закодированного изображения. Его форма — `[1,1,T,H,W]`: нули сохраняют начало, единицы разрешают сэмплеру синтезировать остальную часть.
## Latent format
Только image-ветвь применяет `Wan22.process_out`: masked region берёт обработанный нулевой latent, fixed region сохраняет encoded latent.
## Batch
При start image samples и mask повторяются до batch_size. Без image параметр batch_size фактически игнорируется — существенная особенность 0.32.0.
## Ограничения
Начальный пустой латент всегда создаётся с batch 1 и лишь в ветви с изображением повторяется до `batch_size`. Если VAE вернёт больше временных позиций, чем помещается в целевой латент, присваивание может завершиться ошибкой: явного обрезания результата VAE нет. Большой batch умножает расход памяти уже после кодирования изображения.
## Совместимость и источники
Проверено по ComfyUI 0.32.0. Различие двух ветвей и игнорирование batch без image закреплены регрессией.
