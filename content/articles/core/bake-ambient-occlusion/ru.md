# Bake Ambient Occlusion: карта затенения углублений

Запекает окружающее затенение high-poly в UV low-poly. Белый обозначает открытую поверхность, тёмный — участки, закрытые соседней геометрией. Результат выходит отдельным IMAGE.

## Как пользоваться

samples — число лучей на texel: больше лучей уменьшает шум, но увеличивает время. max_distance ограничивает дальность поиска как долю диагонали bounding box. bias отодвигает начало луча от поверхности, strength регулирует затемнение. resolution — размер карты.

## Пример подключения

Подайте развёрнутую low-poly сетку и её подробный исходник. Начните с небольшого разрешения, проверьте полости и ровные участки, затем увеличьте качество. Выход occlusion подключите в ApplyTextureToMesh, а не напрямую вместо основного цвета.

## Ограничения и частые ошибки

Тёмные пятна на ровной поверхности могут быть самопересечениями луча — проверьте bias и геометрию. Слишком большой max_distance создаёт широкое затенение там, где ожидался локальный контакт. AO не заменяет освещение сцены и не исправляет неправильную UV-развёртку; нода требует готовые UV.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `low_poly` | `MESH` | да | соединение / значение без фиксированного default |
| `high_poly` | `MESH` | да | соединение / значение без фиксированного default |
| `resolution` | `INT` | да | по умолчанию: 1024; минимум: 64; максимум: 8192; шаг: 64 |
| `samples` | `INT` | да | по умолчанию: 64; минимум: 4; максимум: 1024; шаг: 4 |
| `max_distance` | `FLOAT` | да | по умолчанию: 0.5; минимум: 0.01; максимум: 2.0; шаг: 0.01 |
| `strength` | `FLOAT` | да | по умолчанию: 1.0; минимум: 0.0; максимум: 2.0; шаг: 0.05 |
| `bias` | `FLOAT` | да | по умолчанию: 0.01; минимум: 0.0001; максимум: 0.2; шаг: 0.0005 |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `occlusion` | `IMAGE` | нет |
