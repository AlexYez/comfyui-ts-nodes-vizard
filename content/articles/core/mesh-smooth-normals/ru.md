# Smooth Mesh Normals: плавное и гранёное освещение

Вычисляет нормали вершин для плавного затенения сетки. Не сглаживает координаты поверхности: силуэт и мелкая геометрия от этой операции сами по себе не меняются.

## Как пользоваться

crease_angle задаёт порог резкого ребра в градусах. При 180 вся поверхность сглаживается без изменения топологии. При меньшем значении вершины на резких границах разделяются, чтобы сохранить жёсткое затенение; связанные атрибуты переносятся по соответствию вершин.

## Пример подключения

Если модель в GLB-просмотрщике выглядит гранёной, подключите MeshSmoothNormals перед MeshToFile3D. Для органической формы начните с 180, для предмета с жёсткими гранями сравните порог около 30–60 градусов. Оценивайте не только гладкие части, но и ребра, которые должны оставаться острыми.

## Ограничения и частые ошибки

Плавные нормали не добавляют полигоны и не исправляют неверную геометрию. Порог ниже 180 может увеличить число вершин — это ожидаемое разделение границ, а не рост детализации. После изменения основы затенения перепроверьте ранее запечённую normal map и экспортированный материал.

## Входы и настройки

Снимок ComfyUI 0.37.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `mesh` | `MESH` | да | соединение / значение без фиксированного default |
| `crease_angle` | `FLOAT` | да | по умолчанию: 180.0; минимум: 0.0; максимум: 180.0; шаг: 1.0 |

## Выходы

| Выход | Тип | Список |
| --- | --- | --- |
| `mesh` | `MESH` | нет |
