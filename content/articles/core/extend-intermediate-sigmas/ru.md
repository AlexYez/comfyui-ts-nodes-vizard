# ExtendIntermediateSigmas: уплотнить часть расписания

`ExtendIntermediateSigmas` проходит по соседним значениям входного `SIGMAS` и вставляет дополнительные точки в выбранные интервалы. Нода не обращается к `MODEL` и не пересчитывает расписание целиком: она интерполирует уже готовые пары.

## Входные значения сохраняются в прежнем порядке

Для каждой пары нода сначала добавляет `sigma_current`, при необходимости вставляет точки между ней и `sigma_next`, а после цикла добавляет последний элемент. Исходные значения не удаляются и не переставляются.

Если вход не убывает, output тоже не станет автоматически убывающим. Валидации монотонности или конечности здесь нет.

## steps вставляет на одну точку меньше своего значения

Координаты строятся как `linspace(0, 1, steps + 1)[1:-1]`. Края 0 и 1 исключены, потому что исходная пара уже содержит оба конца. Поэтому в каждый выбранный интервал добавляется `steps - 1` значений.

При `steps = 2` появляется одна точка, при 3 — две, при 100 — 99. Embedded docs называет `steps` числом вставляемых промежуточных шагов, но это не совпадает с pinned-реализацией.

## Проверяется только sigma_current

Интервал расширяется, если `end_at_sigma <= sigma_current <= start_at_sigma`. Значение `sigma_next` в условие не входит.

Например, для `[20, 10, 0]`, `start_at_sigma = 15`, `end_at_sigma = 5`, `steps = 3` первая пара пропускается, а между 10 и 0 вставляются примерно 6,667 и 3,333. Вторая точка уже ниже нижней границы — это ожидаемое следствие проверки только левого конца.

## start_at_sigma = -1 снимает верхнюю границу

Если `start_at_sigma < 0`, код заменяет его на бесконечность. Runtime позволяет минимум −1, значение по умолчанию тоже −1.

При таком режиме остаётся только условие `sigma_current >= end_at_sigma`. Если указать обычное неотрицательное начало, обе границы включаются в сравнение.

## end_at_sigma выбирает левый конец интервала

`end_at_sigma` по умолчанию равен 12 и имеет диапазон 0–20000. Нода не обрезает интерполяцию на этой границе: она лишь решает, обрабатывать ли пару по текущей sigma.

Если `end_at_sigma > start_at_sigma`, ни одно обычное конечное значение не удовлетворит двойному условию. Output сохранит исходную последовательность, но всё равно будет пересобран в новый tensor.

## linear равномерно делит разность sigma

Для `linear` используется сама координата `x`. На входе `[20, 10, 0]` с `steps = 3`, отключённой верхней границей и `end_at_sigma = 12` выбирается только пара 20 → 10; output равен примерно `[20; 16,667; 13,333; 10; 0]`.

Одна и та же сетка координат применяется ко всем выбранным парам независимо от их длины.

## cosine и sine смещают точки к разным концам

`cosine` вычисляет `sin(x·π/2)`, а `sine` — `1 − cos(x·π/2)`. Для убывающей пары 20 → 10 и `steps = 3` cosine даёт `[15; 11,34]`, то есть сильнее сдвигает точки к следующей sigma.

Sine для той же пары даёт примерно `[18,66; 15]` и удерживает точки ближе к текущей sigma. Названия описывают функцию spacing, а не отдельный scheduler.

## steps = 1 ничего не вставляет

При единице срез `[1:-1]` пуст, поэтому все пары проходят без новых значений. Пустой вход также возвращает пустую последовательность.

Оба результата создаются заново. Это не in-place операция и не возврат исходного объекта.

## CPU-вход пересобирается как float32

В конце исходник вызывает `torch.FloatTensor(extended_sigmas)`. Exact probe с CPU tensor типа `float64` вернул новый CPU tensor `float32`. Устройство и dtype входа не сохраняются.

Официальные scheduler-ноды обычно уже выдают CPU `float32`, но для произвольного custom `SIGMAS` это преобразование важно. Поведение с GPU scalar tensors отдельно не проверялось.

## Source-derived fragment ведёт output в sampler

Recipe принимает внешний `SIGMAS`, использует defaults `steps = 2`, `start_at_sigma = -1`, `end_at_sigma = 12`, `spacing = linear` и подключает результат к `SamplerCustomAdvanced.sigmas`. Остальные sampling-компоненты остаются внешними.

Во всех 768 областях официального wheel exact-нода отсутствует, поэтому fragment не является official topology. Метод исполнен на нескольких синтетических последовательностях; полный sampler не запускался и `exampleExecuted=false`. Редактор пока не проверил материал вручную.
