# TextGenerate: генерация текста локальной моделью

Генерирует текст с помощью совместимой языковой модели, переданной как `CLIP`. Может принимать изображение, кадры видео и аудио, если их поддерживает токенизатор модели. Обычный `CLIPTextEncode` для диффузионной модели эту задачу не выполняет.

## Подключение и выходы

Подайте языковую модель на `clip`, задание на `prompt` и направьте первый выход `generated_text` в текстовый кодировщик следующей генерации или в просмотр текста. Второй выход `thinking` содержит отделённый блок рассуждений, если модель выдала его в ожидаемом формате. Не подключайте его вместо основного ответа.

В ComfyUI 0.38.0 у ноды два выхода вместо одного. Код отделяет текст по `</think>`, когда ответ начинается с `<think>` либо исходный запрос заканчивается этим маркером. Это разбор конкретных маркеров, а не универсальное распознавание рассуждений любой модели. При обрыве такого блока основной ответ может остаться пустым.

## Настройки

`max_length` ограничивает длину генерации модели, а не число символов. В режиме `sampling_mode = on` доступны `temperature`, `top_k`, `top_p`, `min_p`, `repetition_penalty`, `presence_penalty` и `seed`. Начните с настроек модели; для сравнения меняйте один параметр и сохраняйте остальные. При `off` используется выбор без случайной выборки.

`thinking` запрашивает режим рассуждений у поддерживающей его модели. `system_prompt` заменяет системную инструкцию в шаблоне диалога, только если включён `use_default_template`; при выключенном шаблоне этот вход игнорируется.

`mtp` управляет предварительным предсказанием нескольких токенов: `auto`, `off` или глубина 2–5. Без соответствующих весов в модели эффекта нет. При включении MTP ответ на том же seed может измениться.

## Изображения, видео и звук

`video` принимает пакет `IMAGE`, не объект `VIDEO`. Подсказка ноды предполагает 24 кадра/с и внутреннюю выборку до одного кадра/с; интерпретация входа зависит от токенизатора. Смена модели может изменить поддержку аудио и изображений.

## Пример и ограничения

Подайте фотографию на `image` и попросите кратко описать видимые объекты. Просмотрите `generated_text` до передачи его в промпт генерации: языковая модель может выдумать детали. Время и память зависят от модели, длины контекста и входных данных. Seed не гарантирует одинаковый ответ после смены модели или вычислительного окружения.

## Входы и настройки

Снимок ComfyUI 0.38.0. Условные поля показаны вместе с режимом, в котором они доступны; список установленных моделей зависит от вашей системы.

| Вход | Тип | Обязательный | Значения из схемы |
| --- | --- | --- | --- |
| `clip` | `CLIP` | да | соединение / значение без фиксированного default |
| `prompt` | `STRING` | да | по умолчанию:  |
| `max_length` | `INT` | да | по умолчанию: 512; минимум: 1; максимум: 32768 |
| `sampling_mode` | `COMFY_DYNAMICCOMBO_V3` | да | режимы: on, off |
| `sampling_mode=on → temperature` | `FLOAT` | да | по умолчанию: 0.7; минимум: 0.01; максимум: 2.0; шаг: 1e-06 |
| `sampling_mode=on → top_k` | `INT` | да | по умолчанию: 64; минимум: 0; максимум: 1000 |
| `sampling_mode=on → top_p` | `FLOAT` | да | по умолчанию: 0.95; минимум: 0.0; максимум: 1.0; шаг: 0.01 |
| `sampling_mode=on → min_p` | `FLOAT` | да | по умолчанию: 0.05; минимум: 0.0; максимум: 1.0; шаг: 0.01 |
| `sampling_mode=on → repetition_penalty` | `FLOAT` | да | по умолчанию: 1.05; минимум: 0.0; максимум: 5.0; шаг: 0.01 |
| `sampling_mode=on → seed` | `INT` | да | по умолчанию: 0; минимум: 0; максимум: 18446744073709551615 |
| `sampling_mode=on → presence_penalty` | `FLOAT` | нет | по умолчанию: 0.0; минимум: 0.0; максимум: 5.0; шаг: 0.01 |
| `image` | `IMAGE` | нет | соединение / значение без фиксированного default |
| `video` | `IMAGE` | нет | соединение / значение без фиксированного default |
| `audio` | `AUDIO` | нет | соединение / значение без фиксированного default |
| `thinking` | `BOOLEAN` | нет | по умолчанию: false |
| `use_default_template` | `BOOLEAN` | нет | по умолчанию: true |
| `mtp` | `COMBO` | нет | по умолчанию: auto; варианты: auto, off, 2, 3, 4, 5 |
| `system_prompt` | `STRING` | нет | соединение / значение без фиксированного default |
