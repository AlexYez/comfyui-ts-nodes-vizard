# TS RTX Upscaler

Аппаратный апскейл через NVIDIA RTX Video Super Resolution (`nvvfx`). Четыре
уровня качества (LOW/MEDIUM/HIGH/ULTRA), батчевая обработка. **Требуется
RTX-видеокарта.**

**Ставится только с индекса NVIDIA** — на обычном PyPI лежит заглушка на 2,7 КБ,
которая падает при сборке, а настоящее колесо (792 МБ; везёт с собой VFX SDK,
TensorRT и NPP — отдельный SDK ставить не нужно) публикуется здесь:

```
pip install nvidia-vfx==0.1.0.1 --no-build-isolation --index-url https://pypi.nvidia.com
```

**Движок теперь живёт между запусками.** Замерено на RTX 3080 Ti: создать его —
около 730 мс, сменить выходной размер на живом — 6 мс, сменить качество — нисколько.
Раньше он создавался на каждый запуск, и на восьми кадрах до 1080p это составляло
93% всей работы ноды. Повторные запуски стали быстрее **в 6,8 раза** (0,93 с →
0,14 с). Движок занимает 162 МБ, и эта память видна менеджеру ComfyUI — то есть
удержание ничего не прячет.

Для сравнения: сам апскейл идёт со скоростью **131 кадр/с** до 1080p и **28
кадров/с** до 4K, причём кадры между этими шагами не покидают видеокарту, — так
что более быстрый источник кадров ускорения не даст.

**Когда использовать:** есть RTX и нужна скорость света для видео-апскейла.
