# TS Krea 2 Text Fusion

Меняет силу текстового пути в Krea 2 через вес `diffusion_model.txtfusion.projector.weight`. Возвращает изменённый клон MODEL и не переписывает файл модели на диске.

## Пример применения

Включите ноду после загрузчика Krea 2, перед sampling. Сравните один и тот же prompt и seed при `strength = 1` и другом значении. Так можно отделить влияние текстового пути от случайного изменения изображения.

## Ограничения

Единица оставляет поведение модели без патча; ноль отключает вклад этого проектора, отрицательные значения меняют его знак. Это не общий CFG и не универсальная настройка для других моделей. При изменённой силе отсутствие нужного веса вызывает ошибку. Нейтральная единица возвращает клон без такой проверки, поэтому сама по себе успешная работа с единицей не подтверждает совместимость модели.
