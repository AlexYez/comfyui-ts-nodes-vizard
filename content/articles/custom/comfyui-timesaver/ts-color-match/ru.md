## Изменения в TimeSaver 12.13.5

Теперь принимается RGBA: цвет сопоставляется только по RGB, а дополнительные каналы target, включая его альфу, возвращаются с результатом. Альфа reference не подменяет альфу target. При размножении одного target по пакету референсов его альфа также повторяется. RGB результата ограничивается 0–1; это не обработка расширенного линейного HDR без потерь.

[Закреплённая реализация](https://github.com/AlexYez/comfyui-timesaver/blob/0e1aa5540cb95b8d5d932d4a082ec01d517cd03a/nodes/image/ts_color_match.py#L677). Этот раздел обновлён по изменениям; последующий исторический текст не считается полностью повторно проверенным.
<!-- november-update:end -->

Перенос цветовой палитры с `reference` на `target` батч. Два алгоритма:

- **MKL** (по умолчанию) — быстро, стабильно, дружелюбно к видео с временным сглаживанием.
- **Sinkhorn** — медленнее, но точнее (на основе оптимального транспорта).

В комплекте: маски совпадения (`rectangle` / `ellipse` для стабилизации только по краям), VRAM-aware чанкинг, флаг `reuse_reference` для видео.

**Когда использовать:** колор-грейдинг видео по одному ключевому кадру, сведение кадров из разных источников, вписывание CG в plate-видео.
