# TS Batch Source: задания из файлов и промптов

Создаёт список заданий и возвращает `item`, исходный `index`, количество выбранных заданий `total` и производный `seed`. Сам источник не загружает изображения, видео или модели.

## Откуда берутся задания

`Files in folder` выдаёт пути к файлам; `file_types` ограничивает их изображениями, видео, аудио либо оставляет все. `include_subfolders` включает вложенные папки. Имена сортируются естественно по частям пути; скрытые элементы и служебные Thumbs.db/desktop.ini пропускаются.

Старое значение `Images in folder` из сохранённых графов поддерживается как режим только изображений. Не меняйте его на All без проверки: соседние файлы подписей иначе тоже могут попасть в загрузчик.

`Lines in text file` выдаёт непустые строки. `Text files in folder` читает каждый .txt/.md целиком как отдельный промпт с сохранением внутренних переносов. `Count only` создаёт строки с номерами. `Prompts from images in folder` извлекает положительные промпты из поддерживаемых метаданных, а не анализирует картинку нейросетью. Отсутствующие или неподдерживаемые промпты пропускаются с сообщением в журнале; произвольный граф невозможно разобрать безошибочно.

## Ограничение набора и очередь

`start_at` пропускает начало, `limit = 0` не ограничивает остаток. `total` — длина выбранного набора; `index` сохраняет исходную нумерацию. Пустой остаток вызывает ошибку.

По умолчанию выходы списковые: ComfyUI может сначала обработать весь список на одной ноде, затем перейти к следующей. Это не обещает расхода памяти в один кадр и немедленного сохранения каждого результата. Для полного прохода графа по одному заданию включите `one_per_run` и задайте число запусков очереди равным total. Завышенное число запусков начинает набор заново.

## Пример и ограничения

Для пакетного видео выберите Files in folder, тип Videos и подключите item к `path` TS Video Loader. Для аудио используйте тип Audio и TS Audio Loader; для изображений — TS Batch Load Image. Подключайте производный seed, если модель должна получать разную случайную выборку.

Курсор one_per_run хранится на сервере в памяти и сбрасывается после перезапуска. Изменение базового seed не сбрасывает позицию. Извлечение метаданных не восстанавливает фактический ответ LLM, которого нет в файле; при сохранении результатов с динамическим промптом используйте подходящую запись метаданных, например TS Image Prompt Injector. Уникальность всех 32-битных seed и разнообразие ответов не гарантируются.
