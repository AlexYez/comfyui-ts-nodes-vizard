# TS Batch Source

Создаёт задания из файлов изображений, строк текстового файла или заданного количества итераций. Возвращает `item`, `index`, `total` и производный `seed`. В режиме папки `item` содержит путь, а не изображение; для чтения нужен TS Batch Load Image.

## Режимы и нумерация

`Images in folder` читает изображения непосредственно в указанной папке, без обхода подпапок, и сортирует имена естественным порядком: img2 перед img10. `Lines in text file` читает непустые строки UTF-8 и убирает пробелы по краям. `Count only` выдаёт номера как строки, начиная с нуля.

`start_at` пропускает начало списка, `limit = 0` снимает ограничение длины. Выход `total` показывает количество оставшихся заданий после этих ограничений; `index` сохраняет исходную нумерацию. Если заданий не осталось, запуск завершается ошибкой.

## Список или один элемент за запуск

По умолчанию нода выдаёт списки. ComfyUI сначала обрабатывает элементы одной ноды и только потом переходит к следующей. Это не полный проход графа для каждого изображения: загрузчик может собрать все изображения до запуска модели, а сохранение начнётся после обработки списка. Потребители с собственным списковым входом могут обрабатывать список целиком.

Для постепенного сохранения и нод, меняющих общие метаданные, включите `one_per_run` и задайте число запусков в очереди равным `total`. Каждый запуск получает одно задание и проходит граф до конца. После последнего задания курсор начинает список заново: завышенное число запусков повторит обработку.

Курсор хранится в памяти серверного процесса. Перезапуск сервера сбрасывает его; это не сохранённая контрольная точка. Изменение базового seed не сбрасывает позицию, потому что seed не входит в ключ курсора.

## Пример и ограничения

Цепочка для подписей: TS Batch Source → TS Batch Load Image → совместимая нода анализа изображения → TS Batch Write. Подключите выход `seed` к соответствующему входу модели, если нужны разные случайные выборки для заданий. Производные 32-битные seed воспроизводимы при той же нумерации, но их абсолютная уникальность и разнообразие ответов не гарантируются.

Передача путей уменьшает размер выхода самого источника, но не ограничивает память всего графа одним кадром. При списковом выполнении загрузчик и другие ноды могут сохранять весь набор в кэше. Для больших изображений начните с `one_per_run` и небольшой очереди; отдельные ноды всё равно могут удерживать свои данные.
