# TS DLSS Upscaler

Обрабатывает IMAGE или последовательность кадров через внешний нативный DLSSNR-движок. Возвращает IMAGE. Для этой реализации нужны Windows и подходящая NVIDIA RTX; это не переносимая замена обычному PyTorch-upscaler.

## Пример применения

После декодирования видео передайте batch кадров в `images`. Для последовательных кадров используйте `temporal`; для независимых картинок выключите его, чтобы история одного кадра не влияла на другой. Начните с одного `nr_passes`: дополнительные проходы требуют дополнительных вычислений. Проверяйте детали, лица и мерцание на коротком фрагменте до обработки всего ролика.

## Загрузка и безопасность

При `download_if_missing = true` первый запуск скачивает примерно 486 МБ внешних бинарных файлов в `models/DLSS`. Это поведение TimeSaver, не справочника Wizard. Движок загружается в процесс ComfyUI; учитывайте источник и лицензии бинарников. Для автономной работы отключите загрузку и подготовьте файлы заранее. Не отключайте проверку контрольных сумм ради обхода ошибки.

## Ограничения

`dlss_model_preset` сохранён для совместимости старых графов и в v9 игнорируется. Для обычного изображения оставьте SDR в `source_curve`; выбор другой кривой должен соответствовать реальным данным. Нода подготавливает CPU-копию входного batch, поэтому нельзя считать весь тракт безусловно находящимся только в VRAM. Скорость и качество на вашей системе требуют измерения; приведённые в upstream справке замеры не являются результатами проверки Wizard.
