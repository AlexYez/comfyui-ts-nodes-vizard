# TS Int Slider: целочисленный параметр

Возвращает INT из слайдера для количества шагов, размера или другого целочисленного входа.

## Как пользоваться

Новый виджет имеет рабочий диапазон 0–2048 и шаг 8. В свойствах доступны min, max, step и default. Серверная схема допускает неотрицательные значения до 100 000; рабочий диапазон frontend не отменяет этого предела.

## Пример и ограничения

Для числа шагов задайте небольшой диапазон и шаг 1; для размеров изображения используйте шаг, соответствующий требованиям модели. Выход — только число, не изображение и не LATENT. Нода не знает, какие размеры или количества шагов допустимы у подключённого потребителя; ноль не означает универсальное отключение вычислений.
