# TS Edit Align: совмещение правки с исходником

Уменьшает небольшой сдвиг и изменение масштаба, которые модель редактирования может добавить ко всему изображению. Сравнивает правку с исходником по участкам с сохранившейся текстурой и корректирует геометрию. Не возвращает перерисованные детали в исходное состояние.

## Подключение

Поставьте ноду после VAE Decode, при необходимости после TS VAE Fix, до апскейла и смешивания с оригиналом. В `image` передайте правку, в `source` — исходное изображение. Без source вход проходит без изменений.

`output_size = source` приводит результат к размерам оригинала; `edit` сохраняет размер сгенерированной правки, а исходник масштабирует только для сравнения. Второй вариант удобен перед дальнейшим увеличением небольшого фото. `max_shift` ограничивает принимаемые смещения участков в пикселях выходного изображения.

## Пример

После удаления объекта сравните результат с оригиналом через TS Compare. Если неподвижные детали фона сдвинулись, подключите TS Edit Align и проверьте их снова. В пакете кадры обрабатываются отдельно; если исходников меньше, для оставшихся используется последний.

## Ограничения

Нужны достаточно похожие участки с текстурой. Если их недостаточно, нода только подгоняет размер и сообщает об этом; поворот, перспективная деформация и произвольное движение объектов не исправляются этой моделью сдвига и масштаба. Интерполяция и ограничение значений 0–1 могут менять пиксели — это не побитовое восстановление и не сохранение расширенного HDR. Численные улучшения из справки автора относятся к его примерам, не гарантируются для любой правки.
