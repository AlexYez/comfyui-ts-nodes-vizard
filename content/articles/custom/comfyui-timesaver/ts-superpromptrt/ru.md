# TS Super Prompt RT

Подготавливает промпты и распознаёт речь через локальную Gemma 4 на LiteRT-LM. Для распознавания отдельный Whisper не нужен. `high_quality` выбирает E2B или E4B; более крупная модель требует больше памяти и не гарантирует лучший ответ на каждый запрос.

## Память и контекст

Модель по умолчанию выгружается после работы: память LiteRT не учитывается менеджером PyTorch так же, как память обычных моделей ComfyUI. `keep_loaded` ускоряет повторную загрузку, но оставляет эту память занятой. Запросы к общему движку выполняются последовательно.

Контекст настроен на 8192 токена. Запрос, который не помещается, отклоняется до загрузки модели вместо молчаливого обрезания. Случайная выборка использует параметры пресета; повторное нажатие может дать другой текст.

## Речь и промпт из графа

Речь распознаётся частями по 30 секунд. Запись микрофона автоматически останавливается через три минуты; серверный ввод ограничивается пятью минутами. Правила распознавания рассчитаны на русский текст с техническими терминами, но результат нужно проверить.

Непустой `prompt` из графа заменяет текст поля и по умолчанию проходит без улучшения. Включите «Улучшать входящий промпт при запуске», чтобы обработать его выбранным пресетом. При пустом входе используется и улучшается поле. Подключённое аудио расшифровывается и добавляется после входного текста.

## Установка

Модели скачиваются из `hfmaster/Gemma-4-RT` в `models/LLM/litert`. Это модифицированные сборки Gemma, а не неизменённые официальные веса Google. Рантайм устанавливается отдельно: `python -m pip install litert-lm-api==0.16.1` — в Python вашей установки ComfyUI.

Автор указывает пакеты для Windows, macOS на Apple Silicon и Linux. Замеры GPU приведены для конкретного Windows-окружения и не подтверждают одинаковую скорость на остальных платформах; при недоступном GPU-бэкенде возможен переход на CPU.
