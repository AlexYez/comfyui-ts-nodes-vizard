# TS Batch Write

## Изменения в TimeSaver 12.13.5

В режиме отдельных файлов имя теперь сохраняется с допустимой пунктуацией, например скобками, вместо молчаливого удаления символов. Недопустимые для переносимого имени символы, завершающая точка/пробел и зарезервированные системные имена вызывают ошибку. Пустое имя заменяется item с индексом. Это не защита от повторного одинакового имени: обеспечьте уникальность, иначе повторная запись по тому же пути может заменить подпись.

RGBA-изображение для JPEG-превью преобразуется в RGB; альфа не записывается в это служебное превью. Текстовая запись и сохранение самого изображения остаются разными действиями.

[Закреплённая реализация](https://github.com/AlexYez/comfyui-timesaver/blob/0e1aa5540cb95b8d5d932d4a082ec01d517cd03a/nodes/files/ts_batch_write.py#L239). Этот раздел обновлён по изменениям; последующий исторический текст не считается полностью повторно проверенным.

Записывает результаты по мере готовности, не дожидаясь окончания пакетного запуска. Если позднее задание завершится ошибкой, уже записанные результаты останутся на диске.

## Форматы записи

`One file, blocks` разделяет результаты пустыми строками; такой файл читает TS Batch Prompt Loader. `One file, one line per item` сворачивает каждый результат в строку для TS Batch Source в режиме `Lines in text file`. `One .txt per item` создаёт отдельные подписи с именами соответствующих изображений.

## Продолжение и превью

Индекс 0 начинает файл заново; другие индексы дописывают результаты. Для продолжения прерванного запуска проверьте начальный индекс, иначе можно перезаписать прежний файл.

Необязательный `image` отправляет текущий результат в превью прогресса. Это позволяет наблюдать обработку отдельного задания, не ожидая общей выдачи превью после последней итерации.
