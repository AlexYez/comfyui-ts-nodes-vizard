# TS Batch Write

Записывает результаты по мере готовности, не дожидаясь окончания пакетного запуска. Если позднее задание завершится ошибкой, уже записанные результаты останутся на диске.

## Форматы записи

`One file, blocks` разделяет результаты пустыми строками; такой файл читает TS Batch Prompt Loader. `One file, one line per item` сворачивает каждый результат в строку для TS Batch Source в режиме `Lines in text file`. `One .txt per item` создаёт отдельные подписи с именами соответствующих изображений.

## Продолжение и превью

Индекс 0 начинает файл заново; другие индексы дописывают результаты. Для продолжения прерванного запуска проверьте начальный индекс, иначе можно перезаписать прежний файл.

Необязательный `image` отправляет текущий результат в превью прогресса. Это позволяет наблюдать обработку отдельного задания, не ожидая общей выдачи превью после последней итерации.
