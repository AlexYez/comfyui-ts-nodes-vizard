# TS Image List to Image Batch

Объединяет список отдельных изображений в один пакет `IMAGE`. Используйте после поэлементной обработки, когда следующий этап ожидает один тензор с несколькими кадрами.

Первое изображение задаёт размер, устройство и тип данных. Остальные при необходимости масштабируются методом Lanczos с центральной обрезкой. Число каналов берётся по минимуму во всём списке: при смешивании RGB и RGBA альфа будет отброшена. Пустые элементы пропускаются. Это сборка пакета, а не создание видеоконтейнера: частоту кадров и сохранение видео задают другие ноды. Для обратного преобразования используйте TS Image Batch to Image List.
