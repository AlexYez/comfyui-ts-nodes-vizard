## Изменения в TimeSaver 12.13.5

Если в списке вместе с цветными изображениями есть одноканальный серый кадр, он разворачивается в RGB, а не сводит весь пакет к одному красному каналу. Однако смешанный набор RGB/RGBA по-прежнему может потерять альфу из-за согласования к общему числу каналов. Для сохранения прозрачности заранее приведите весь список к RGBA.

[Закреплённая реализация](https://github.com/AlexYez/comfyui-timesaver/blob/0e1aa5540cb95b8d5d932d4a082ec01d517cd03a/nodes/image/ts_image_list_to_batch.py#L151). Этот раздел обновлён по изменениям; последующий исторический текст не считается полностью повторно проверенным.
<!-- november-update:end -->

Объединяет список отдельных изображений в один пакет `IMAGE`. Используйте после поэлементной обработки, когда следующий этап ожидает один тензор с несколькими кадрами.

Первое изображение задаёт размер, устройство и тип данных. Остальные при необходимости масштабируются методом Lanczos с центральной обрезкой. Число каналов берётся по минимуму во всём списке: при смешивании RGB и RGBA альфа будет отброшена. Пустые элементы пропускаются. Это сборка пакета, а не создание видеоконтейнера: частоту кадров и сохранение видео задают другие ноды. Для обратного преобразования используйте TS Image Batch to Image List.
