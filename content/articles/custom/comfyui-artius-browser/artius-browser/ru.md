# Artius Browser

## Что это за расширение

Artius Browser добавляет в боковую панель ComfyUI медиатеку с двумя независимыми вкладками: `Assets` и `Workflows`. Он индексирует изображения, видео, аудио и 3D-файлы, показывает превью и метаданные, а workflow читает из штатной папки `user/default/workflows`.

Это не набор нод. Backend-регистрация возвращает пустой список, поэтому искать «Artius Browser» через меню добавления ноды не нужно. Панель открывается значком в sidebar ComfyUI.

## Когда он полезен

Расширение удобно, когда результаты генераций и исходные материалы уже не помещаются в одну папку, а файл нужно найти по имени, prompt или использованной модели. В карточках доступны избранное, сравнение, копирование prompt и workflow, скачивание и безопасное удаление в системную корзину.

Поддерживаются PNG, JPEG, WebP, AVIF, MP4, MOV, WebM, ProRes, MP3, WAV, FLAC, Opus, OGG, GLB, OBJ и JSON workflow. Для видео и аудио желательно установить `ffmpeg` и `ffprobe`: без них ComfyUI запускается, но часть метаданных и waveform недоступна.

## Как материал попадает в граф

Artius не вводит собственные загрузчики. Перетащите карточку на холст — расширение создаст подходящую штатную ноду: `LoadImage`, `LoadVideo`, `LoadAudio` или `Load3D`. Несколько выделенных файлов создают несколько нод и раскладываются сеткой. JSON из вкладки Workflows загружается штатным frontend-механизмом.

3D-файл сначала помещается во входное хранилище ComfyUI, чтобы его увидела нативная 3D-нода. Это отличается от обычного изображения: путь нельзя просто передать произвольной строкой, потому что загрузчик ожидает файл в разрешённой области.

## Поиск, сравнение и метаданные

По умолчанию поиск идёт по имени файла. Переключатель в строке поиска добавляет prompt и названия моделей. Из PNG читаются только поля `Prompt` и `Workflow`; seed извлекается из prompt-графа. Положительный и отрицательный prompt показываются отдельно.

В lightbox изображения можно сравнить шторкой или сеткой 2×2. Для видео есть синхронное сравнение до четырёх клипов и переход по кадрам. Аудио получает waveform и транспорт, а GLB/OBJ открываются в штатном 3D-viewer ComfyUI.

## Хранилище и производительность

Индекс, настройки и кэш лежат в `ComfyUI/output/.ts_artius_browser/`. Глубокая пагинация построена по ключу, сетка виртуализирована, а повторные запросы фильтра имеют короткий response cache. Пересборка кэша заново создаёт превью и индекс, но сохраняет избранное.

Удаление отправляет файл через `send2trash`, а не стирает безвозвратно. Возможность удаления зависит от корня. Для большой библиотеки сначала выполните обычное сканирование; `Rebuild Cache` нужен при повреждённых или устаревших превью, а не после каждого запуска.

## Частые проблемы

**Панель не появилась после установки.** Перезапустите ComfyUI и выполните жёсткое обновление страницы (`Ctrl+F5`). Пак содержит и Python routes, и frontend-файлы: одного обновления списка нод недостаточно.

**У видео нет длительности или у аудио нет waveform.** Проверьте команды `ffmpeg -version` и `ffprobe -version` в окружении, из которого запускается ComfyUI, затем перезапустите сервер.

**Превью устарело.** Запустите `Rebuild Cache`. Полный сброс — удаление `output/.ts_artius_browser`, но при этом локальный индекс и настройки кэша будут созданы заново.

**На холсте не находится нода Artius.** Это нормальное поведение: версия 1.16.0 намеренно возвращает `[]` из `get_node_list()`.
