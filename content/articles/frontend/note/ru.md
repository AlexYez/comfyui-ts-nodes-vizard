# Note: короткое пояснение на холсте

`Note` добавляет на холст обычный многострочный текст. Её удобно ставить рядом с нодой, которую перед запуском нужно включить, настроить или заменить. Текст сохраняется в workflow, но не участвует в вычислениях.

У Note нет входов и выходов. Она не может передать строку другой ноде и не появляется в API prompt. В сохранённом workflow остаются сама frontend-нода, её положение, размер, цвет, заголовок и значение текстового виджета.

## Когда обычный текст уместнее Markdown

Выбирайте Note для короткого действия, которое должно читаться без оформления:

> Перед запуском включите ветку клавишами Ctrl+B.

В официальном workflow `api_bytedance_seedream_5_0_layer_separation` с ID `7d136772-0647-4a55-bd62-7e9c36c41a0b` Note № 26 напоминает переключиться на Nodes 2.0 и открыть compositor. Это характерная роль Note: локальная инструкция рядом с тем местом, где она нужна.

Если пояснение занимает несколько смысловых блоков, содержит ссылки или команды, которые полезно выделить кодом, используйте `MarkdownNote`. Note показывает исходные символы разметки как обычный текст.

## Поведение в classic canvas и Nodes 2.0

В frontend 1.48.7 расширение `Comfy.NoteNode` создаёт для Note многострочный `STRING`-виджет. Оно включает `serialize_widgets`, чтобы значение попало в `widgets_values`, и ставит `isVirtualNode`, чтобы нода не исполнялась на backend.

Для Nodes 2.0 определение Note также входит в общий `SYSTEM_NODE_DEFS`: обязательный вход `text` описан как многострочный STRING, выходов нет. Поэтому один и тот же `type: "Note"` восстанавливается и в классическом, и в новом renderer. Внешний вид редактора различается, а смысл и сохранённое значение остаются теми же.

## Проверяемый пример

Рецепт «Оставить короткое предупреждение» создаёт заметку рядом с учебной веткой. В ней записано конкретное действие: выбрать установленный checkpoint в соседней ноде-загрузчике. Откройте приложенный workflow, измените текст, сохраните файл и откройте его снова — значение должно восстановиться.

Если проверяете Note внутри собственного исполняемого workflow, сравните сохранённый canvas JSON с API prompt: заметка остаётся в первом и отсутствует во втором, потому что frontend исключает виртуальные ноды. Приложенный учебный workflow в этом редакционном прогоне в очередь не ставился.

## Частая ошибка: писать Markdown и ждать форматирования

В Note строка `**важно**` не станет полужирной, а `` `Ctrl+B` `` не превратится в оформленный фрагмент кода. Это не ошибка загрузки и не несовместимость темы: Note использует обычный многострочный текстовый виджет.

Не стоит также хранить в заметке секреты, токены или приватные URL. Текст входит в workflow и передаётся любому, кому вы отправите JSON или изображение со встроенным workflow.

## Что Note не заменяет

Note не задаёт значение widget-входа. Если число, строка или пункт списка должны одновременно управлять несколькими нодами, используйте `PrimitiveNode`. Note не меняет маршрут связи; для этого служит нативная reroute-точка или legacy-тип `Reroute` в старом workflow.

Нода отсутствует в `/object_info`, поскольку её реализует frontend. Nodes Wizard разрешает статью по точному типу `Note` и frontend-происхождению, а не по отображаемому заголовку, который пользователь может переименовать.
