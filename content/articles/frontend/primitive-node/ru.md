# PrimitiveNode: одно значение для нескольких виджетов

`PrimitiveNode` выносит значение виджета в отдельную ноду. Это удобно, когда один параметр должен одновременно управлять несколькими нодами: например, одна ширина — двумя `EmptyLatentImage`, одно число шагов — двумя сэмплерами, а один текст — двумя текстовыми энкодерами.

У новой Primitive только выход `connect to widget input` с неопределённым типом `*`. Первый подключённый widget-вход задаёт настоящий тип, конфигурацию и начальное значение. Если соединить Primitive с `width` у `EmptyLatentImage`, она станет числовой нодой `INT`; если первым будет `text` у `CLIPTextEncode`, появится многострочное поле `STRING`.

## Подключение без ручного поиска

В classic canvas можно дважды щёлкнуть по входу, связанному с виджетом. Frontend создаст `PrimitiveNode` слева от целевой ноды, подключит её и назовёт по имени входа. Тот же тип входит в `SYSTEM_NODE_DEFS`, из которых строится список системных frontend-нод для Nodes 2.0.

Можно и добавить Primitive из меню `utilities/primitive`, а затем провести первую связь вручную. До подключения её нельзя считать «обычным числом» или «строкой»: тип ещё не выбран.

## Какие входы подходят

Primitive подключается к входу, за которым стоит редактируемый виджет, либо к типу, для которого frontend умеет создать виджет. Произвольный сокет данных не подходит. Например, `model`, `clip`, `conditioning`, `latent_image` и `images` передают объекты между вычислительными нодами; Primitive не создаёт такие объекты и не заменяет загрузчик, энкодер или сэмплер.

Дополнительные подключения должны быть совместимы с уже выбранной конфигурацией. Для чисел frontend объединяет ограничения: общее значение должно попадать в пересечение допустимых диапазонов. Для списков выбора остаются общие варианты. Если пересечения нет или типы различаются, соединение отклоняется. Это защита от графа, где одно поле обещает двум нодам взаимоисключающие значения.

## Что происходит перед запуском

Primitive — виртуальная frontend-нода. Перед формированием API prompt frontend вызывает её `applyToGraph()` и копирует первое значение виджета во все связанные целевые виджеты. Затем сама Primitive не становится исполняемой Python-нодой. Backend получает целевые ноды уже с согласованными значениями.

Из этого следуют два практических правила:

1. Смотрите на целевые виджеты, если проверяете итоговый prompt или ищете ошибку backend.
2. Не удаляйте Primitive после настройки, если хотите сохранить единый регулятор: без неё значения снова придётся менять отдельно.

Свойство `Run widget replace on values` по умолчанию выключено. Если его включить для строкового значения, frontend применит подстановки поиска и замены перед распространением значения. Это отдельный режим; для обычного общего числа или текста он не нужен.

## Реальный пример из официального шаблона

В официальном `sdxl_simple_example` с ID `88bcf757-1298-432f-885a-db5ab88cf224` нода № 45 хранит `steps = 25` и передаёт это число двум `KSamplerAdvanced`. Нода № 51 хранит положительный prompt и передаёт одну строку двум `CLIPTextEncode` — для base и refiner. В обоих случаях в workflow сохранены типизированный выход Primitive, имя целевого виджета и `widgets_values`.

В этом примере нода связывает несколько редактируемых параметров одним источником значения. Обычного разветвления линии для этого было бы недостаточно.

## Учебный пример

Рецепт «Управлять шириной двух latent-нод» соединяет одну `PrimitiveNode` со входами `width` двух `EmptyLatentImage`. В Primitive задано `512`; её выход имеет тип `INT` и конфигурацию виджета `width`. Высота и размер пакета остаются независимыми.

Приложенный workflow предназначен для изучения структуры. Его JSON проверяется схемой и содержит все связи, но этот редакционный прогон не включал открытие и запуск файла в живом ComfyUI. Поэтому пример не помечен как исполненный.

## Частая ошибка: подключать Primitive к любому сокету

Название «Primitive» не означает универсальный генератор данных. Если провести её к `LATENT`, `IMAGE`, `MODEL` или другому обычному входу, frontend отклонит связь: за этим входом нет совместимого виджета, значение которого можно редактировать и скопировать.

Другая ошибка — сначала связать Primitive с `FLOAT`, а затем пытаться подключить её к `STRING`, либо объединить два числовых виджета с непересекающимися диапазонами. Reroute здесь тоже не поможет: он меняет трассу линии, но не преобразует тип. Нужна отдельная вычислительная нода или два независимых значения.

## Сериализация и обнаружение

В workflow Primitive хранится как обычная запись canvas-ноды: `type: "PrimitiveNode"`, типизированный выход, имя связанного виджета, связи и `widgets_values`. При очереди она остаётся виртуальной и исключается из API prompt после переноса значения.

`PrimitiveNode` не обязана присутствовать в backend `/object_info`: это frontend-возможность. Nodes Wizard разрешает статью по точному типу `PrimitiveNode` из пакета `comfy-core` и по закреплённой версии frontend, а не по списку исполняемых Python-нод.
