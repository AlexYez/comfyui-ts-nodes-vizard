# Сохранить внешний CLIP по prefix-группам

Подайте `CLIP` и задайте `filename_prefix = clip/wizard-encoder`. Для простого state dict результат может быть одним файлом. Multi-encoder объект может дать несколько файлов: например, `wizard-encoder_clip_l_00001_.safetensors` и `wizard-encoder_t5xxl_00001_.safetensors`. У каждой группы свой вызов счётчика.

Список выходных файлов нода не возвращает. После запуска проверьте `output/clip` и не предполагайте заранее, сколько файлов будет создано: это определяется ключами конкретного state dict. Полного workflow в рецепте нет.

Изолированная проверка выполнила точный цикл разделения на синтетических тензорах во временной папке. Настоящий CLIP и полный fragment в ComfyUI не запускались.

Редактор пока не проверил материал вручную.
