# Проверить разворачивание списка без изменения порядка

Подключите списочный `IMAGE` к внешнему входу. `MergeImageLists` развернёт четырёхмерные пакеты в элементы `[1,H,W,C]` и вернёт их без перестановки или изменения пикселей.

Встроенная справка говорит о нескольких соединениях, но фрагмент фиксирует только один точный порт из `/object_info`. Официального графа с нодой в пакете 0.1.42 нет; после импорта фрагмент не запускался. Для нового объединения нескольких веток исходник рекомендует `CreateList`.
