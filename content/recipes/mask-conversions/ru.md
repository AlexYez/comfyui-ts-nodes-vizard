# Проверка каналов, порога и инверсии

Подайте любой `IMAGE` во внешний вход фрагмента. `ImageToMask` извлечёт red-канал, после чего три параллельные ветки покажут:

1. исходные полутоновые значения;
2. результат `1 - mask`;
3. бинаризацию по строгому порогу `0.41`.

Канал `red` и значение `0.41` взяты из официального примера `basic_mask_operations_and_compositing` пакета 0.1.42. Для своего изображения проверьте `green`, `blue` или `alpha` и подберите порог по содержимому маски.

Три окна просмотра нужны для сравнения, а не для обязательной рабочей цепочки. Оставьте ветку, которая подходит следующей ноде.

Фрагмент прошёл структурную проверку. Его ещё не запускали с тестовым изображением и не утверждали вручную.
