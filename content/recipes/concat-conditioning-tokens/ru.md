# Сцепление двух CONDITIONING по оси токенов

Передайте основной список в `conditioning_to`, а источник добавляемой последовательности — в `conditioning_from`. Результат сохранит число записей и метаданные стороны `to`; со стороны `from` будет использован только тензор первой записи.

Этот fragment намеренно не включает sampler: его задача — показать точную асимметрию портов. Перед применением убедитесь, что тензоры имеют одинаковые batch-размер и ширину признаков.

Полный поиск по 512 official workflow templates JSON 0.1.42 не нашёл `ConditioningConcat`. Пример выведен из runtime-контракта и `torch.cat` в закреплённом исходнике. Он не исполнялся с реальными тензорами и остаётся `in_review`.
