# Сцепление двух CONDITIONING по оси токенов

Передайте основной список в `conditioning_to`, а источник добавляемой последовательности — в `conditioning_from`. Результат сохранит число записей и метаданные стороны `to`; со стороны `from` будет использован только тензор первой записи.

Этот фрагмент намеренно не включает семплер: его задача — показать точную асимметрию портов. Перед применением убедитесь, что тензоры имеют одинаковый размер пакета и ширину признаков.

Полный поиск по 512 официальным JSON-шаблонам версии 0.1.42 не нашёл `ConditioningConcat`. Пример выведен из контракта среды выполнения и `torch.cat` в закреплённом исходнике. Он не исполнялся с реальными модельными тензорами и остаётся на редакционной проверке.
