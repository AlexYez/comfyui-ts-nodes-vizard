# Выбор слоя перед CLIPTextEncode

Подайте совместимый `CLIP` на внешний вход fragment. `CLIPSetLastLayer` создаст отдельную ветвь с индексом −2, а `CLIPTextEncode` закодирует контрольный prompt через эту ветвь. Для сравнения оставьте рядом прямую ветвь от того же загрузчика и не меняйте seed либо параметры sampling.

Fragment проверяет только порядок нод, имена портов и диапазон настройки. В official workflow templates JSON 0.1.42 после полного поиска по 512 файлам `CLIPSetLastLayer` не найден, поэтому этот пример построен по runtime-схеме и реализации, а не скопирован из официального workflow.

Модельный прогон не выполнялся. Значение −2 не объявлено универсально подходящим: фактический результат зависит от text encoder и модели. Рецепт остаётся `in_review` до ручной проверки с закреплёнными весами.
