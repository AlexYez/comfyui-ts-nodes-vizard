# Получить воспроизводимый случайный crop

Fragment выбирает окно `512 × 512` с seed `42`. Повторный запуск при том же входе и версии NumPy должен дать те же координаты; смените seed для другого участка.

Внутри IMAGE batch одинаковый seed применяется заново к каждому кадру, поэтому crop остаётся в одной позиции. Для независимого случайного окна на каждом кадре этот fragment не подходит.

Повторяемость и modulo seed проверены исполнением. Official workflow отсутствует, полный пользовательский fragment ещё не запускался и не утверждён человеком.
