# Добавить первый latent-кадр перед видео

Fragment повторяет связку `LatentCut → LatentConcat` из официального Wan 2.2 S2V workflow. Первый latent-кадр вырезается и добавляется перед исходной временной последовательностью.

## Подключение

Подключите один и тот же пятиосевой sampled video `LATENT` к двум внешним входам: `video_for_cut` и `video_full`. Разделение нужно только формату fragment, где один внешний порт описывает одно подключение. Выход `prepend_first` можно передать в совместимый VAE Decode или следующую video-latent операцию.

## Что именно проверено

В официальном шаблоне `LatentCut` использует `dim = t`, `index = 0`, `amount = 1`, а `LatentConcat` — `dim = t`. Точная связь Cut с `samples1` и полного sampler-выхода с `samples2` сверена по root workflow; аналогичные экземпляры есть в его subgraph.

Fragment прошёл проверку схемы, runtime-портов и типов. Exact-source tensor-проба подтвердила временную форму, порядок кадров и приведение batch. Полный Wan workflow с моделями не исполнялся, поэтому workflow-файл к recipe не приложен.

## На что обратить внимание

`t` означает время только для формы `[B, C, T, H, W]`. Для обычного image latent `[B, C, H, W]` эта настройка работает по каналам. Метаданные результата берутся из выхода `LatentCut`, то есть из исходного словаря, и не перестраиваются под увеличенную временную ось.
