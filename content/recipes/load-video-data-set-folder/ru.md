# Прочитать видео из выбранной подпапки

Выберите реальную подпапку `input` вместо проверочного значения `3d`. Нода отсортирует подходящие файлы верхнего уровня и вернёт список ленивых `VIDEO`-ссылок; вложенные каталоги она не просматривает.

Расширение проверяется сразу, содержимое контейнера — только при дальнейшем чтении. Перед большой обработкой откройте несколько файлов. Официального workflow-примера в пакете 0.1.42 нет; фрагмент после импорта не запускался.
