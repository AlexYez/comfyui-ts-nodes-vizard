# Собрать два LATENT-потока в один пакет

Fragment добавляет `BatchLatentsNode` и готовит первые два расширяемых сокета. Подключите к `latents.latent0` тот поток, чьи ширина, высота и метаданные должны стать основой результата. Второй поток войдёт после него по batch-оси.

До запуска сравните число каналов, dtype и device обоих `samples`. Проверьте `noise_mask`: нода сохраняет маску первого LATENT и не собирает маску второго. Если исходные `batch_index` отсутствуют, нумерация начнётся с нуля внутри каждого входного пакета.

В официальных workflow templates JSON 0.1.42 эта нода не встречается. Рецепт построен по pinned runtime и исходнику; это структурно проверенный fragment, а не исполненный полный workflow.
