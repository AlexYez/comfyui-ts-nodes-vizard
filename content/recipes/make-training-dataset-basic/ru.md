# Кодировать список изображений и подписей

Подключите список `IMAGE`, одну модель `VAE`, одну модель `CLIP` и, при наличии, список `STRING`. Для `texts` допустимы ноль элементов, один общий текст или столько элементов, сколько есть внешних `IMAGE`.

Fragment построен по закреплённому исходнику. Официального workflow с `MakeTrainingDataset` в шаблонах 0.1.42 нет; fragment не импортировался и не исполнялся на холсте. Изолированный probe проверял только метод ноды на синтетических тензорах и заглушках моделей.
