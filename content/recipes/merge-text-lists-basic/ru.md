# Проверить проход подготовленного списка строк

Передайте в `texts` готовый список `STRING`. Метод `MergeTextLists` возвращает этот же список, сохраняя порядок, пустые элементы и повторы; он не соединяет строки через delimiter.

Официальный пакет 0.1.42 не содержит workflow с этой нодой. Фрагмент не обещает несколько соединений с одним портом, не импортировался и не выполнялся на холсте. После вставки сначала проверьте лишний уровень списка старого выходного контракта.
