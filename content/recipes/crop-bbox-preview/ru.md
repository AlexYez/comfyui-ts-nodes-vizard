# Crop по рамке с padding

`PrimitiveBoundingBox` создаёт рамку `x = 64`, `y = 64`, `width = 512`, `height = 512`. `CropByBBoxes` расширяет её на 32 исходных пикселя с каждой стороны, ограничивает границами изображения и вписывает результат в `512 × 512`.

Режим `pad` сохраняет пропорции. Свободная часть выхода заполняется чёрным; это ожидаемая часть результата, а не потеря данных.

Перед использованием замените числа рамки на координаты своего объекта или подключите проверенный детектор с совместимой структурой `BOUNDING_BOX`. Если на кадре передано несколько рамок, нода вырежет их объединение, а не отдельный объект для каждой рамки.

Официального workflow с `CropByBBoxes` в пакете 0.1.42 нет. Схема связей и все параметры проверены, backend crop исполнен на синтетическом batch; полный фрагмент с preview ещё не запускался.
