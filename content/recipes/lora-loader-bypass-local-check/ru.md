# LoraLoaderBypass: LoRA без слияния с базовыми весами: локальная проверочная заготовка

Этот фрагмент добавляет только `LoraLoaderBypass`. Обязательные соединяемые входы вынесены наружу, а значения виджетов взяты из закреплённого снимка `/object_info` ComfyUI 0.32.0.

Это диагностическая заготовка для локального графа, а не готовый workflow. После вставки подключите совместимые модели и данные, проверьте размеры и типы, затем выполните граф вручную. Полное исполнение с весами ещё не подтверждено человеком.
