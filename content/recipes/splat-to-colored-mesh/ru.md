# SPLAT → цветной MESH

Подайте внешний `SPLAT` на `SplatToMesh`. Фрагмент задаёт значения по умолчанию из runtime-схемы: `resolution = 384`, `kernel = 5`, `smooth = 0`, `level = 0.4`, `min_component = 500`, `min_opacity = 0.02`, `color_sharpen = 2`. Затем `SaveGLB` сохраняет цветной `MESH` с флагом `unlit`.

Единственный официальный граф TripoSplat содержит похожую схему соединений, но `SplatToMesh` и `SaveGLB` там отключены обходом, а `level` равен `0.6`. Поэтому этот фрагмент не считается исполненным официальным графом. Перед запуском сохраните исходный SPLAT: расход памяти на решётку плотности быстро растёт вместе с `resolution`.

Редактор пока не проверил материал вручную. Фрагмент целиком не исполнялся; на синтетических данных проверены только расчёт плотности в низком разрешении и вспомогательные функции Surface Nets.
