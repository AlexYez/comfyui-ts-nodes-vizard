# Счётчик Gaussian Splat

Fragment вставляет `GetSplatCount` в SPLAT-ветвь. Первый выход продолжает передавать тот же объект, второй возвращает сумму реальных lengths по batch.

Если источник записал `counts`, padding не учитывается. Без counts нода использует полную длину `positions`. Прямого официального workflow с этой нодой не найдено; рецепт проверен по source/runtime, но не выдаётся за исполненный 3D-кейс.
