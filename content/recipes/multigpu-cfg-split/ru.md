# Назначить primary GPU и включить MultiGPU CFG Split

Подайте внешний `MODEL` в `SelectModelDevice`, оставьте `device = gpu:0`, затем соедините его выход с `MultiGPU_WorkUnits`, где `max_gpus = 2`. Если система видит два устройства, второе может получить полную deepclone-копию модели. Если `gpu:0` недоступен, selector сохраняет исходную маршрутизацию; если дополнительного устройства нет, split-нода не создаёт clone.

Ставьте fragment после compile, attention-switch и других нод, которые меняют объект модели, но до sampler. На каждом выбранном GPU должна помещаться полная модель. Это не tensor sharding.

Параллелизм появляется только при нескольких conditioning work units. Граф с одним фактическим work unit не ускорится только из-за наличия второй копии. Официальный workflow-пакет 0.1.42 не содержит обеих целевых нод, поэтому fragment составлен по exact source/runtime контракту.

Проверка воспроизвела выбор устройств, clone/prune и fallback на синтетических patcher без CUDA-вычислений. Полный fragment на двух GPU не исполнялся.

Редактор пока не проверил материал вручную.
