# Подготовить опорное изображение Flux Kontext и закодировать через VAE

Фрагмент повторяет соединение из официального `flux_kontext_dev_basic`: опорный `IMAGE` проходит через `FluxKontextImageScale`, а затем поступает в `VAEEncode`. Нода сама выбирает один из 17 размеров по соотношению сторон; вручную задать ширину и высоту здесь нельзя.

Если центральная обрезка может задеть объект, добавьте поля до фрагмента. После выбора размера нода сначала обрезает центр под целевое соотношение сторон, затем масштабирует изображение методом Ланцоша. Полученный `LATENT` передайте в совместимую ветвь обработки опорного изображения, сверяясь с графом своего чекпойнта.

Выбор размера, формы тензоров и 8-битный путь через CPU/PIL проверены. Веса VAE и полная цепочка сэмплирования Flux Kontext не запускались.
