# Оформить памятку для workflow

Добавьте `MarkdownNote` рядом с тем участком графа, к которому относится инструкция. Начните с действия, которое нужно выполнить до запуска, затем укажите точный путь и условие проверки.

В примере сохранён такой текст:

```markdown
## Перед запуском

- положите `model.safetensors` в `ComfyUI/models/checkpoints`;
- выберите модель в ноде-загрузчике;
- оставьте ширину кратной 64.
```

Это не команда для ComfyUI: нода не скачивает модель и не меняет параметры. Она сохраняет инструкцию в `widgets_values` вместе с workflow. Замените условное имя файла на настоящее, прежде чем делиться графом.

Официальный шаблон `3d_hunyuan3d-v2.1` использует тот же приём: MarkdownNote № 15 содержит ссылку на checkpoint и дерево папок. Наш пример короче и не копирует текст шаблона.

Fragment описывает смысл ноды и исходный Markdown. Полный workflow можно открыть отдельно; автоматическая вставка произвольного JSON в текущий граф не обещается. Схема примера проверена, но живой запуск в ComfyUI в этом редакционном прогоне не выполнялся.
