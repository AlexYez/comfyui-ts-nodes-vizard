# Загрузить .latent и декодировать для проверки

Скопируйте доверенный файл `.latent` в корень каталога `input`, затем замените служебное имя в `LoadLatent` настоящим. Подайте совместимый VAE через внешний вход `vae`.

## Что проверяет фрагмент

Цепочка `LoadLatent` → `VAEDecode` → `PreviewImage` показывает тензор без нового шумоподавления. Если изображение неверно, сначала сверяйте VAE, формат латента модели и признак старого формата, а не параметры сэмплера.

## Ограничения проверки

Официальных графов с `LoadLatent` в полном наборе 0.1.42 нет. Ветвь чтения файла выполнена в изолированной временной папке; фрагмент с настоящим VAE ещё не исполнялся. Полный граф не приложен.
