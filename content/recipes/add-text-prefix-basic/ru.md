# Добавить фиксированный префикс к одной строке

Подключите один `STRING` к `texts`. Фрагмент задаёт `prefix = "dataset: "`, поэтому строка `portrait 01` должна стать `dataset: portrait 01`; пробел уже входит в настройку.

Этот фрагмент построен по исходнику и не является полным workflow. Официальные шаблоны 0.1.42 не содержат `AddTextPrefix`; фрагмент не импортировался и не исполнялся на холсте. Перед продолжением проверьте дополнительную списочную оболочку старого выхода.
