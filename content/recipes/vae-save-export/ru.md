# Сохранить внешний VAE в output/vae

Подайте объект `VAE` и задайте `filename_prefix = vae/wizard-vae`. Первый файл при свободном prefix получит имя `output/vae/wizard-vae_00001_.safetensors`. Нода записывает state dict `first_stage_model`; она не добавляет diffusion MODEL или CLIP.

После записи отдельно проверьте загрузку файла в том pipeline, для которого он предназначен. В metadata нет универсального идентификатора архитектуры VAE, поэтому имя файла и сопроводительные сведения остаются важны. Полного workflow в рецепте нет.

Изолированная проверка воспроизвела получение синтетического state dict, счётчик, metadata и защищённый путь во временной папке. Полный fragment с настоящим VAE не исполнялся.

Редактор пока не проверил материал вручную.
