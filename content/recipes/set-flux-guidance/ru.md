# Добавить guidance = 4 в CONDITIONING для Flux-подобной модели

Подключите готовый `CONDITIONING` к `FluxGuidance` со значением `guidance = 4`. В закреплённом архиве официальных шаблонов такое значение встречается шесть раз, в том числе в графе Flux2 для генерации по тексту. Это подтверждённый пример, а не универсальная рекомендация для всех чекпойнтов.

Передайте выход в совместимый с моделью сэмплер, ноду типа `GUIDER` или следующую ноду обработки `CONDITIONING`. Не путайте встроенное поле `guidance` с классическим CFG: фрагмент не создаёт отрицательную ветвь и не меняет масштаб `GUIDER`.

Полный запуск модели не выполнялся. Операция над метаданными, диапазон параметра и настройки официальных примеров проверены.
