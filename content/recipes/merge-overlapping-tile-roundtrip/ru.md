# Проверить split/merge для IMAGE 2048 × 1536

Fragment рассчитан на внешний IMAGE ровно `2048 × 1536`. Split создаёт шесть list-элементов: три окна по горизонтали и два по вертикали. Merge получает их напрямую, использует те же tile size и overlap 128 и восстанавливает холст исходного размера.

Между Split и Merge нет обработки. Чистая Python-модель формул воспроизводит вход с малой численной погрешностью. Если изменить пиксели каждого тайла независимо, синусные веса сгладят перекрытия, но не устранят сильные различия.

Для другого исходного размера обязательно измените `final_width` и `final_height`; иначе лишние тайлы будут отброшены или появятся чёрные области. В wheel 0.1.42 этой пары нет. Fragment в ComfyUI не исполнялся. Редактор пока не проверил материал вручную.
