# Увеличить изображение вдвое и сохранить

Fragment воспроизводит основную ветку официального workflow `utility_interpolation_image_upscale`: `LoadImage → ImageScaleBy → SaveImage`.

## Что перенесено из официального примера

`ImageScaleBy` использует `lanczos` и `scale_by = 2`. Ширина и высота удваиваются, поэтому число пикселей возрастает примерно в четыре раза. В официальном workflow исходник и результат также подключены к сравнению методов; в этом компактном fragment оставлена только ветка сохранения.

## Как использовать

Выберите файл в `LoadImage`. `SaveImage` запишет результат с официальным префиксом `ComfyUI` в output-каталог. Перед обработкой большого batch оцените итоговое разрешение: коэффициент относится к каждой стороне, а не к общей площади.

Для уменьшения можно поставить коэффициент меньше единицы, но тогда это уже не точное повторение выбранного официального случая. Метод интерполяции также стоит подбирать по материалу, а не считать `lanczos` обязательным для любого изображения.

## Статус проверки

Настройки, типы и порты сверены с `/object_info` ComfyUI `0.32.0`, а топология, `lanczos`, коэффициент `2` и префикс `ComfyUI` — с официальным пакетом workflow `0.1.42`. Fragment не запускался с реальным файлом. Полный workflow намеренно не приложен.
