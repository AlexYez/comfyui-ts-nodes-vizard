# Область 512 × 512 в пиксельных координатах

Fragment принимает готовое conditioning и назначает ему прямоугольник 512 × 512 с началом в точке 0, 0. В реализации эти числа превращаются в latent-tuple `(64, 64, 0, 0)`.

На canvas 1024 × 1024 это левая верхняя четверть. На canvas 512 × 512 — весь кадр. Если активное разрешение меньше, sampler обрежет область, поэтому требование размера указано явно.

`ConditioningSetArea` отсутствует во всех 512 official workflow templates JSON 0.1.42. Пример подтверждает только runtime-поля и metadata-преобразование; model run не выполнялся, статус — `in_review`.
