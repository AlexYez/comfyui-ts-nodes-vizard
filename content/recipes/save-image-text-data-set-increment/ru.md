# Сохранить пары PNG–TXT без перезаписи имён

Подайте синхронные списки `IMAGE` и `STRING`. Нода сначала сохранит все PNG в `output/dataset`, затем создаст TXT только для пар из `zip`. До запуска сравните длины: несовпадение не вызывает ошибку и даёт неполный набор.

Режим `increment` выбран для безопасного первого прогона, но операция не атомарна. Официальный wheel 0.1.42 не содержит этой ноды; fragment следует точным runtime-портам и после импорта на холст не исполнялся.
