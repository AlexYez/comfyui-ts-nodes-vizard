# Импорт splat-файла с проверкой количества

Подайте splat-совместимый `File3D` в `File3DToSplat`, затем соедините выход `SPLAT` с `GetSplatCount`. Число помогает отличить пустой либо неверно выбранный файл от ожидаемого результата, но само по себе не проверяет геометрию и цвет.

В workflow wheel 0.1.42 точной `File3DToSplat` нет. Fragment построен по pinned runtime и source; полный workflow намеренно отсутствует.
