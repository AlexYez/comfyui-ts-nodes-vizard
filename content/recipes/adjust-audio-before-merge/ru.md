# Подготовить уровни перед AudioMerge

Официальный подграф Sonilo пропускает исходный звук видео и внешнюю дорожку через отдельные `AudioAdjustVolume`, затем подключает их к `AudioMerge` с методом `add`. В сохранённом шаблоне оба регулятора усиления имеют значение `1`, то есть каждый сигнал усиливается примерно в 1,122 раза.

Фрагмент сохраняет эту трёхузловую топологию, но не включает Sonilo API, разбор видео и `CreateVideo`. Значение `+1 dB` — доказанная настройка шаблона, а не универсальная рекомендация для сведения. В реальном проекте сначала выставьте уровни по материалу; для нейтрального прохода нужен `0 dB`.

Полный граф Sonilo не запускался. Формула усиления и локальные связи проверены по исходному коду, полному перечню шаблонов и синтетическим вызовам на тензорах.
