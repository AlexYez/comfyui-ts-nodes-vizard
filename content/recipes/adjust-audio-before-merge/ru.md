# Подготовить уровни перед AudioMerge

Официальный Sonilo subgraph пропускает исходный звук видео и внешнюю дорожку через отдельные `AudioAdjustVolume`, затем подключает их к `AudioMerge` с методом `add`. В сохранённом шаблоне оба gain-виджета имеют значение `1`, то есть каждый сигнал усиливается примерно в 1,122 раза.

Фрагмент сохраняет эту трёхузловую топологию, но не включает Sonilo API, video-разбор и `CreateVideo`. Значение `+1 dB` — доказанная настройка шаблона, а не универсальная рекомендация для сведения. В реальном проекте сначала выставьте уровни по материалу; для нейтрального прохода нужен `0 dB`.

Полный Sonilo workflow не запускался. Формула gain и локальные связи проверены исходным кодом, точным template census и синтетическими tensor-вызовами.
