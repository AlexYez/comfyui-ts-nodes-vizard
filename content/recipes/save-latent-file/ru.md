# Сохранить внешний LATENT в output/latents

Передайте `LATENT` во внешний вход `latent`. Нода создаст файл вида `output/latents/wizard-session_00001_.latent`; следующий запуск с тем же префиксом увеличит счётчик.

## Что попадёт в файл

Сохраняются только тензор `samples` под ключом `latent_tensor`, признак формата и разрешённые служебные метаданные. `noise_mask`, `batch_index` и пользовательские поля словаря на диск не записываются. Выход ноды при этом продолжает текущую ветку с исходным `LATENT`.

## Ограничения проверки

В 496 официальных графах набора 0.1.42 `SaveLatent` не встречается. Ветвь записи файла из точного исходного кода проверена во временной папке, но сам фрагмент ещё не запускался в ComfyUI. Полного графа нет.
