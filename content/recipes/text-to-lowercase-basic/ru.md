# Преобразовать одну строку в нижний регистр

Подключите один `STRING` к `texts`. Нода применит Python `lower()` и вернёт результат внутри дополнительной списочной оболочки старого base class. Проверьте форму значения до следующего соединения.

Для нового графа используйте `CaseConverter` с режимом `lowercase`. Официального workflow с `TextToLowercase` в шаблонах 0.1.42 нет; этот фрагмент не импортировался и не выполнялся на холсте.
