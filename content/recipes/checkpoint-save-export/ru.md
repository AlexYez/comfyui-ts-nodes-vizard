# Сохранить MODEL, CLIP и VAE одним checkpoint

Фрагмент заканчивает ветку одной `CheckpointSave`. Подайте совместимые `MODEL`, `CLIP` и `VAE`, затем оставьте `filename_prefix = checkpoints/wizard-merged` или замените последнюю часть своим именем. При первом запуске ожидается файл `output/checkpoints/wizard-merged_00001_.safetensors`; следующий свободный номер вычисляется по содержимому этой подпапки.

Компоненты должны относиться к совместимому pipeline. Нода собирает их state dict, но не проверяет архитектурную совместимость перед записью и не запускает пробную генерацию после экспорта. Полного workflow в рецепте нет.

Изолированная проверка воспроизвела path helper, счётчик, metadata и маркеры на синтетических объектах во временной папке. Сам fragment с настоящими весами в ComfyUI не исполнялся.

Редактор пока не проверил материал вручную.
