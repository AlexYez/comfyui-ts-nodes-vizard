# Первый блок Cosmos Predict2 2B: 50/50

Подключите к fragment две совместимые Cosmos Predict2 2B-модели. У `blocks.0.` будет значение `0,5`; остальные группы нода создаст с их default `1`, то есть оставит из `model1`.

Сначала запустите контрольный вариант со всеми значениями `1`. Затем сравните fragment на тех же prompt, seed, conditioning и sampler. В официальных workflow templates 0.1.42 прямого примера merge-ноды нет, поэтому это схемный рецепт, а не воспроизведение готового workflow. Полное выполнение с checkpoint ещё не проводилось.
