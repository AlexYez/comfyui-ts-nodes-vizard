# Прочитать изображения из выбранной подпапки

Fragment содержит одну `LoadImageDataSetFromFolder`. Значение `3d` взято из динамического `COMBO` закреплённого снимка `/object_info` и не является универсальным именем: после вставки выберите свою подпапку `input`.

Нода читает только непосредственные PNG, JPG, JPEG и WEBP. Она выдаёт список отдельных `IMAGE`, поэтому следующая нода должна поддерживать списочную семантику. Во всех 512 официальных JSON 0.1.42 эта нода отсутствует; fragment построен по точному контракту и не считается выполненным на холсте.
