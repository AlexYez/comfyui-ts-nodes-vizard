# Проверка VoxelToMeshBasic

Фрагмент получает внешний `VOXEL`, выполняет устаревшую `VoxelToMeshBasic` с порогом `0.6` и сохраняет контрольный GLB. Используйте его только при разборе старого графа. В официальном пакете графов 0.1.42 этой ноды нет.

Для миграции вручную добавьте `VoxelToMesh`, выберите `algorithm = "basic"`, перенесите тот же порог и сравните второй GLB с контрольным. Исходник помечает новую ноду как замену по смыслу, но Node Replacement API не содержит правила автоматической замены.

Редактор пока не проверил материал вручную. Фрагмент проверен структурно, но полный старый граф не исполнялся.
