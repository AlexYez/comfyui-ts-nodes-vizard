# Первый основной блок Krea 2: 50/50

Fragment принимает две совместимые Krea 2-модели и меняет только `blocks.0.` на `0,5`. Группы обработки изображения, времени, text-fusion, остальные блоки и выход получают default `1`.

Сначала сохраните контрольный результат со всеми `1`. Затем запускайте fragment с теми же conditioning, reference inputs и seed. Прямого официального merge-примера в templates 0.1.42 нет; рецепт построен по точной runtime-схеме и исходному коду. Checkpoint-исполнение пока не проводилось.
