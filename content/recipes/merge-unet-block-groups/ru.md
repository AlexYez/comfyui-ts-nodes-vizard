# input из model1, middle пополам, out из model2

Подключите совместимые UNet-подобные модели к `ModelMergeBlocks`. Значения `input = 1`, `middle = 0,5`, `out = 0` берут input-префиксы из `model1`, смешивают middle пополам и берут out-префиксы из `model2`.

Коэффициенты означают долю первой модели. Нода сопоставляет буквальные префиксы state-dict ключей, поэтому перед применением к DiT, Flux или видео-модели проверьте имена весов. Ключи без совпадения в штатном runtime-порядке получают коэффициент `input`.

Редактор пока не проверил материал вручную. Официального serialized case нет; реальные checkpoint не загружались.
