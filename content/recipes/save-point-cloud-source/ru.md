# Point-cloud PLY через SavePointCloud

Подайте `FILE_3D_POINT_CLOUD_ANY` и состояние Load3D-виджета в `SavePointCloud`. Fragment оставляет префикс `3d/ComfyUI` и viewport `1024 × 1024`; байты PLY копируются без перекодирования.

В workflow wheel 0.1.42 exact-нода отсутствует. Рецепт source-derived, не содержит локальный файл, producer или полный workflow.
