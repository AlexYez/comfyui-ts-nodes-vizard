# Прочитать пары изображение–подпись из папки

После вставки замените `3d` на свою подпапку `input`. Рядом с каждым изображением положите TXT с тем же базовым именем; отсутствующий файл даст пустую строку. Числовой префикс дочерней папки, например `3_subject`, повторит её элементы три раза.

Fragment останавливается на загрузчике и не добавляет неподтверждённую схему соединений. Официальный wheel 0.1.42 не содержит этой ноды. Точный класс проверен во временном каталоге, но сам fragment после импорта не запускался.
