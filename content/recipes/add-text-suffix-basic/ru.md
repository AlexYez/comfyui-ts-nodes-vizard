# Добавить фиксированный суффикс к одной строке

Подайте один `STRING` в `texts`. Настройка `suffix = " [draft]"` включает ведущий пробел: `caption 07` превращается в `caption 07 [draft]`.

В официальном пакете 0.1.42 нет workflow с `AddTextSuffix`. Этот фрагмент построен по исходнику, не импортировался и не выполнялся на холсте. До следующей ноды проверьте, что старый базовый класс не оставил строку внутри дополнительного списка.
