# Преобразовать одну строку в верхний регистр

Подключите один `STRING` к `texts`. Python `upper()` может увеличить длину: например, `ß` становится `SS`. Старый base class оборачивает строку в список, поэтому проверьте downstream-контракт.

Для нового графа исходник рекомендует `CaseConverter(UPPERCASE)`. В официальных JSON-шаблонах нода отсутствует; fragment после импорта не запускался.
