# Старое объединение двух LATENT-батчей

Этот fragment нужен для разбора старого workflow с `LatentBatch`. Нода помечена deprecated в ComfyUI 0.32.0; для нового графа доступен современный `BatchLatentsNode` с autogrow-входами.

## Подключение

Подайте основной `LATENT` во вход `first_latent`, добавляемый — в `second_latent`. Первый вход задаёт целевую spatial-форму и основу метаданных. Если последние две оси второго отличаются, нода применит bilinear resize с центральным crop, затем соединит `samples` по batch-оси.

## Ограничения старой ноды

`noise_mask` и прочие поля второго LATENT не входят в результат. Метаданные первого переносятся поверхностно и не расширяются автоматически. Default `batch_index` строится отдельно для каждого входа, поэтому два одиночных LATENT получают `[0, 0]`. Разные каналы или temporal-оси spatial resize не исправляет.

## Статус проверки

Fragment прошёл проверку схемы, runtime-класса и двух входных портов, но не исполнялся. Полный аудит 512 root/subgraph JSON официального workflow-пакета 0.1.42 не нашёл `LatentBatch`; full workflow не приложен.

В Node Replacement API 0.32.0 нет формальной записи для этой ноды. Перед ручным переносом на `BatchLatentsNode` сравните порядок входов, `batch_index`, маски и spatial-размер результата.
