# Старое объединение двух пакетов LATENT

Этот фрагмент нужен для разбора старого графа с `LatentBatch`. Нода помечена устаревшей в ComfyUI 0.32.0; для нового графа доступен современный `BatchLatentsNode` с расширяемыми входами.

## Подключение

Подайте основной `LATENT` во вход `first_latent`, добавляемый — в `second_latent`. Первый вход задаёт целевую пространственную форму и основу метаданных. Если последние две оси второго отличаются, нода применит билинейное изменение размера с центральной обрезкой, затем соединит `samples` по оси пакета.

## Метаданные и индексы

`noise_mask` и прочие поля второго латента в результат не входят. Метаданные первого переносятся поверхностно и не расширяются автоматически. Если `batch_index` отсутствует, он строится отдельно для каждого входа, поэтому два одиночных латента получают `[0, 0]`. Разные каналы или временные оси пространственное изменение размера не исправляет.

## Что проверено

Фрагмент прошёл проверку схемы, точного класса и двух входных портов, но не исполнялся. Полный просмотр 512 корневых и вложенных JSON официального набора 0.1.42 не нашёл `LatentBatch`; полный граф не приложен.

## Миграция

В Node Replacement API версии 0.32.0 нет формального правила для этой ноды. Перед ручным переносом на `BatchLatentsNode` сравните порядок входов, `batch_index`, маски и пространственный размер результата.
