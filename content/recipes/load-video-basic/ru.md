# Выбрать видео из input

Замените `SELECT_INPUT_VIDEO` реальным значением из `file` или загрузите файл через виджет. Служебное значение нельзя выполнять: до выбора файла запуск должен быть заблокирован.

Официальный wheel содержит 55 нод `LoadVideo`, однако переносимого имени файла нет. Fragment не импортировался и не выполнялся; временный probe открывал только созданный им AVI.
