# Показать MASK и продолжить ветку

Подайте проверяемую маску во вход. `MaskPreview` создаст временный PNG для интерфейса и оставит ту же `MASK` на обычном выходе. Выход можно соединить со следующей нодой после вставки фрагмента.

Серый цвет показывает непосредственное значение маски: `0.5` останется серым, порог и инверсия не применяются. Файл сохраняется во временной папке, поэтому для постоянного результата нужна отдельная ветка `MaskToImage → SaveImage`.

Реальный временный файл и точная передача маски без изменений проверены исполнением серверного кода. Сам вставляемый фрагмент ещё не проходил полный пользовательский тест через интерфейс и не утверждён человеком.
