# Отфильтровать список с порогом 0,95

Подключите список или пакет `IMAGE`. Нода развернёт его в отдельные изображения, оставит первый элемент каждой найденной группы и вернёт списочный выход. При `0.95` сходство должно быть не ниже порога: для 64-битного хеша это расстояние Хэмминга не больше трёх бит.

Усреднённый хеш нечувствителен ко многим деталям: однотонные изображения разного цвета совпадают даже при пороге 1,0. Фрагмента нет в официальных шаблонах графов 0.1.42; он построен по исходному алгоритму и после импорта на холст не запускался.
