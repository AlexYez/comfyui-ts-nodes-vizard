# Каталог `web`

ComfyUI раздаёт этот каталог как frontend extension через `WEB_DIRECTORY = "./web"`.

`npm run build` создаёт `nodes-wizard.js`, sourcemap и при необходимости каталоги `assets`/`chunks`. Сборка также копирует подготовленные данные в `data`. Эти артефакты не редактируют вручную: исходники интерфейса находятся в `ui/src`, а исходные статьи — в `content`.

Файл README должен оставаться в каталоге после сборки. Конфигурация Vite не должна очищать весь `web` вместе с документацией и данными, которыми она не владеет.
