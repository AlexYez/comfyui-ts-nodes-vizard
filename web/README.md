# Каталог `web`

ComfyUI раздаёт этот каталог как frontend extension через `WEB_DIRECTORY = "./web"`.

`npm run build` создаёт небольшой `nodes-wizard.js`, отложенные модули `chunks/*.mjs` и обработчик `workers/*.mjs`. Расширение `.mjs` важно: ComfyUI автоматически запускает все файлы `*.js` в паке, а модули справочника должны загружаться только при открытии. Все эти файлы входят в поставку; source maps не создаются. Сборка также копирует подготовленные данные в `data`. Эти артефакты не редактируют вручную: исходники интерфейса находятся в `ui/src`, а исходные статьи — в `content`.

Файл README должен оставаться в каталоге после сборки. Конфигурация Vite не должна очищать весь `web` вместе с документацией и данными, которыми она не владеет.
