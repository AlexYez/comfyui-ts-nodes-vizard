# Политика безопасности

## Поддерживаемые версии

Проект находится в alpha-стадии. Исправления безопасности выпускаются только для последней версии ветки `0.1.x`; более ранние сборки не получают отдельные backport-релизы. До первого опубликованного релиза поддерживаемой Registry-версии нет.

## Как сообщить об уязвимости

Не публикуйте рабочий exploit, приватный workflow или данные пользователя в открытом issue. Используйте private security advisory в GitHub-репозитории. Если функция недоступна, свяжитесь с сопровождающими по приватному каналу, указанному в профиле будущего издателя Registry. Контакт ещё не настроен; до его появления не передавайте секретные материалы и оставьте краткий публичный запрос на открытие приватного канала без технических подробностей.

В сообщении укажите:

- версию Nodes Wizard и ComfyUI;
- браузер и операционную систему;
- минимальные шаги воспроизведения;
- ожидаемый и фактический результат;
- влияние на конфиденциальность, целостность или выполнение кода;
- нужен ли срок на согласованное раскрытие.

Сопровождающие подтвердят получение после настройки приватного канала, проверят воспроизведение и согласуют публикацию исправления. Конкретный срок ответа пока не обещается.

## Модель доверия

Обычный просмотр статьи должен быть локальной операцией. Недоверенными считаются Markdown, URL, workflow-шаблоны, импортированный каталог, данные `/object_info` и метаданные сторонних custom nodes.

Код alpha-обновления проверяет Ed25519-подпись манифеста, точный размер, SHA-256 и схему файла `catalog.json`, а затем просит согласие пользователя. Само обновление выключено, пока в релизной конфигурации не заданы проверенные URL манифеста и открытый ключ. Архивы с локальными ресурсами клиент пока не устанавливает. Закрытый ключ не должен попадать ни в репозиторий, ни в браузерный bundle.

К критическим нарушениям относятся:

- выполнение HTML или JavaScript из статьи;
- переход по `javascript:`, `data:` или иному опасному URL;
- незаявленная отправка workflow, prompts, путей или инвентаря наружу;
- неподписанное удалённое обновление каталога или `catalog.json` с неверным хешем, принятые за доверенные;
- автоматическая постановка workflow в очередь без явного действия пользователя;
- чтение произвольных локальных файлов или обход границ ComfyUI.

Проект не принимает секреты в runtime и не должен хранить Registry-токены в клиентской сборке. Будущая публикация использует только секрет GitHub Actions с минимальными правами; пользовательская сборка этого секрета не содержит.

## Безопасная проверка

Для демонстрации используйте синтетические статьи и workflow без моделей, путей и персональных данных. Не проверяйте проблему на чужой установке или публичном сервере без разрешения. Приложения с секретами очищайте до отправки.
