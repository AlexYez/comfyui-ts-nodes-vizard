## Установка

В [Manager StrictVersion](https://github.com/Comfy-Org/ComfyUI-Manager/blob/9c29dc68a488fd56e15f152807579009d627bfef/glob/manager_util.py) первые три компонента версии разбираются через `int`. На `0.2.0-alpha.2` извлечённый из исходника класс воспроизводимо падает при преобразовании `0-alpha`. `read_cnr_info` перехватывает исключение и возвращает отсутствие Registry-метаданных. Это подтверждённая проблема распознавания старой установки, но не доказательство причины всех пользовательских жалоб.

Версия пакета изменена на 0.3.0. Редакционный канал alpha сохранён отдельно. `.comfyignore` ограничивает Registry-пакет файлами загрузчика, метаданных, лицензий, иконки и готового `web`. Старый опубликованный ZIP содержал 4053 файла; новая локальная сборка — 16. Исходники статей, тесты и инструменты остаются в GitHub, но не нужны для работы установленного справочника.

Проверка `tools/qualify_install.py` собирает ZIP по правилам git-tracked / .comfyignore / includes, распаковывает в новую папку, импортирует Python-загрузчик без ComfyUI, проверяет состав архива и ссылки на модули. Она принимает также `--archive` для проверки скачанного Registry ZIP. Браузерный smoke-test может работать с этой распакованной копией через `WIZARD_WEB_ROOT`.

Отдельный workflow `Clean ComfyUI installation` устанавливает архив в чистые ComfyUI 0.36.0 и 0.37.0 и проверяет `/extensions`, содержимое HTTP-ресурсов и JavaScript MIME для `.mjs`. Публикация зависит от этой проверки. Это проверка Linux CPU-сервера, не замена ручной матрице Portable/Desktop/macOS и испытаниям GPU-workflow.
