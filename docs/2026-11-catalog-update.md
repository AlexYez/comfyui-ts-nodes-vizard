# Актуализация справочника на 2 ноября 2026

Базовая пара — ComfyUI 0.43.0, frontend 1.57.4; TimeSaver — 12.13.5. Снимок ядра получен из чистой CPU-установки без сторонних нод в [успешном nightly-запуске](https://github.com/AlexYez/comfyui-ts-nodes-vizard/actions/runs/41421387267). Инвентарь TimeSaver построен по зарегистрированным ID в закреплённых исходниках; это не живая проверка загрузки всех его необязательных зависимостей.

## Новые статьи

Добавлены 16 локальных нод ComfyUI:

- Branch, Camera Angle, Get Latent Size и Get Audio Latent Size;
- FLUX 3 Layout Prompt, MOSS-Image Layout Prompt, Color/Depth Control и Text Encode MOSS-Image Edit;
- Text Encode Fibo 2.0, Reference Multi Latent, Model Merge MOSS-Image;
- Load LoRA (Model), Load LoRA (Text Encoder), Latent Operation Blend;
- Pad Image и Convert SDR to HDR.

В TimeSaver добавлены шесть нод: TS Edit Align, TS Model Resize, TS VAE Fix, TS H3 Regenerate Model, TS H3 Regenerate и TS H3 Fast VAE Decode. Для каждой написано отдельное описание с подключением, примером и ограничениями. API-ноды в каталог не добавлялись. Удалений относительно октябрьского снимка в этом локальном охвате нет.

## Изменившиеся статьи

Семь существующих статей переписаны: Create Camera Info, Latent Apply Operation CFG и пять TimeSaver — Batch Source, DLSS Upscaler, Film Emulation, Float Slider, Int Slider. Учтён официальный перенос CreateCameraInfo из nodes_gaussian_splat в nodes_camera; сторонние одноимённые ноды не получают эту статью по одному названию.

В 37 статьях добавлены адресные пояснения к изменившейся реализации: 13 статей ядра и 24 TimeSaver. Они размещены в начале и отделены от прежнего текста. Это не выдаётся за полное повторное прочтение старой статьи. Старые даты проверки и исследовательские записи сохраняются; новые источники закреплены отдельными ссылками.

Среди существенных исправлений:

- EXR поддерживает half-float и linear ACEScg; обычный linear по-прежнему означает Rec.709.
- Remesh получил solid/CelloCut; TextGenerate — новые MTP tree-режимы и уточнённое выделение thinking.
- DLSS использует v9 и host-float по умолчанию; dither больше не влияет на результат.
- Film Emulation изменил путь LUT, интерфейс и расчёт ряда пресетов; старый граф может выглядеть иначе.
- Batch Source работает с разными файлами, подпапками и метаданными; проводной path у аудио/видео-загрузчиков отменяет старую обрезку.
- Маска Model Resize белая на содержимом и чёрная на полях: перед обычной перерисовкой полей её нужно инвертировать.
- H3 Fast VAE имеет ограниченный откат при нехватке памяти; он не перехватывает все исключения и не кодирует референсы.

Поиск по Neurosaver и ненавязчивые ссылки на ComfyUI и ComfyLauncher сохраняются в новых статьях, как и связи с соседними нодами. Общие служебные фразы не заменяют конкретные инструкции; русские тексты подготовлены с редакторским скиллом, но не считаются утверждёнными человеком.

## Источники и проверки

Версии, commit, контрольные суммы инвентаря, источников и официального пакета workflow-templates-json 0.1.123 сохранены в [машинном отчёте](../content/research/november-2026-update.json). Сохранённые соединения официальных workflow разобраны с учётом границ подграфов. Их наличие не означает выполненную генерацию с весами.

Из закреплённых исходников сохранены отдельные функции для небольших безопасных тестов: выбор lazy-ветки, чтение формы латента, распределение полей, фильтрация LoRA-строк и обработка имён файлов. Тесты используют маленькие данные и заглушки зависимостей; модели не загружаются, сеть и файловая запись этих функций не запускаются.

В CI матрица чистой установки обновлена до ComfyUI 0.42.1 и 0.43.0, browser-smoke включает новый инвентарь. Тест имитатора frontend проверяет открытие статей и жизненный цикл worker, но не заменяет испытание большого рабочего workflow или генерации на GPU. Runtime-обработчики холста в этой партии не менялись.

Локально прошли 773 проверки контента без пропусков, 45 тестов контрактов и изолированных функций, 56 frontend-тестов, typecheck и production-сборка. После последних правок повторно прошли 26 связанных исторических регрессий. Генератор обновления проверен повторным запуском: текст и собранные данные не меняются без новых входных данных.

Проверенный ZIP версии 0.3.3 содержит 16 файлов, 8 256 714 байт; SHA-256 — `a0608627103033f081b086108415511748846b4c2269c8b5c0b39e75d55e8d69`. Из распакованного архива browser-smoke открыл 91 статью на снимке 0.43.0 без ошибок и освободил workers при закрытии. Старый снимок 0.38.0 дополнительно проверил безопасный fallback после переноса Python-модуля CreateCameraInfo: статья другого модуля не открывается по одному ID. Этот тест не подтверждает поддержку всех старых ComfyUI.

## Что не объявляется завершённым

В каталоге 793 статьи. Все новые ноды указанного охвата имеют статьи, однако остаются 29 ранее известных расхождений схем старых статей. Они перечислены в [текущем отчёте инвентаря](../content/runtime/comfyui-0.43.0.inventory-report.json); их fingerprints не подменены ради зелёного статуса.

Полная вычитка всего каталога, человеческое утверждение и проверка всех workflow с моделями не выполнены. Редакционный статус alpha и блокировка stable 1.0 сохраняются. Обновление GitHub не является публикацией подписанного обновления каталога или релиза в Registry.
