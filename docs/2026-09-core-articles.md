## Что проверено

Для 46 нод разобраны связи и значения в официальных шаблонах из `comfyui-workflow-templates-json==0.1.92`: Pixal3D/Trellis2, SAM3D Body, MiniMax H3, FastH3, MiniMax Music 3, YuE2, Marigold, Qwen Image 2.1 и Wan Animate 2. Учтены внутренние подграфы и оба формата связей; одинаковые node ID в разных подграфах не смешиваются. Для остальных 18 прямого примера в этом пакете нет; статьи обозначают собственные схемы подключения как пояснения по реализации, а не выполненные генерации.

Проверяемое происхождение хранится в `content/research/september-2026-articles.json`: commit, hash исходных файлов, schema fingerprint, hash архива workflow и отдельных JSON. Записи редакционных проверок находятся в `content/research/reviews/`. Авторские тексты — в `tools/september_content/`; `tools/build_september_articles.py` лишь собирает их с таблицами и метаданными, не генерирует объяснения из схемы.

Редактура выполнена по правилам естественного русского текста. Человеческое утверждение не подменяется автоматической проверкой. Полные генерации с весами в этой работе не запускались; примеры в тексте не зарегистрированы как исполняемые, проверенные рецепты.
