# Проверки октябрьской сборки

Версия 0.3.2, каталог из 771 статьи. Это alpha-каталог, а не утверждение готовности stable 1.0.

На Windows проверены 32 теста контрактов и упаковки, 56 frontend-тестов, TypeScript и production-сборка. Генерируемые файлы соответствуют исходному каталогу. Полный набор проверок исторического контента запускается отдельно, без разрешённых пропусков.

Установочный ZIP содержит 16 файлов и около 8,1 МБ. Изолированная распаковка проверяет безопасные пути, отсутствие зависимостей Python, пустой `NODE_CLASS_MAPPINGS`, наличие всех frontend-ресурсов и импорт загрузчика. В устанавливаемом паке нет исходников разработки, весов, тестовых библиотек и необходимости запускать npm.

Браузерный тест запускается на минимальном имитаторе frontend ComfyUI, а не на полном приложении. Из распакованного ZIP открыты 73 статьи со снимком 0.38.0; с предыдущим снимком 0.37.0 — 72 статьи. Ошибок не обнаружено; после закрытия панели активных поисковых workers не осталось. При первоначальной загрузке каталог, `/object_info` и поисковый worker не загружаются.

Тест не измеряет FPS большого пользовательского workflow, время генерации на GPU или совместимость Windows Portable/Desktop, Linux и macOS. Результат имитатора не заменяет эти проверки. В CI установка проверяется на текущем и предыдущем стабильном ComfyUI, а браузерная проверка повторяется на содержимом установочного ZIP.

Изменения редакционных статей не запускают вычисления на холсте. В этой партии не добавлены обработчики кадров или постоянное сканирование графа. Сводка редакционного охвата и оставшихся задач находится в [отчёте каталога](2026-10-catalog-review.md).
