# Обновление на 14 ноября 2026

Проверочная пара — ComfyUI 0.45.0 и frontend 1.58.5; TimeSaver — 12.13.12, commit 18c863d206a537c8d60c8db6d1c7dbdf4a29721a. Чистый CPU-инвентарь ядра взят из nightly-запуска 43578336810. Инвентарь TimeSaver статический: наличие зарегистрированного ID не подтверждает установку всех необязательных зависимостей на машине пользователя.

Добавлены статьи для 13 новых локальных типов: BakeTextureFromViews, BatchCameras, CreateCameraOrbit, MiniMaxH3ContextWindows, MiniMaxH3ImageConditioning, MiniMaxH3LatentUpscaleWithModel, PH3ImageConditioning, RelayVSRConditioning, TextGenerateV2, UltraTexConditioning, VAEComputeDtype, VSRDecode, WeVisOneDetect. Входы, выходы и fingerprints взяты из актуального /object_info. Примеры поясняющие, без выполненной генерации с весами.

Новых ID TimeSaver нет. Адресные дополнения описывают повторы Batch Source, новый Prompt Builder без семантических карт, complete-файл Regenerate Model, NOISE-вход и референсы H3 Regenerate, Fast V2/low VRAM, внешний DLSS v21, рантайм LiteRT и другие изменения. Не все старые статьи или изменения реализации повторно разобраны целиком; это не массовое утверждение актуальности всех исторических текстов. Старые fingerprints не заменены для сокрытия предупреждений.

Во всех 806 статьях проверено наличие одного блока связанных материалов со ссылкой NeuroSaver. Подбор H3, LTX, MOSS-Image и Qwen ведёт к специально просмотренным страницам сайта. У 177 статей осталось общее введение: отдельный узкий материал не подобран. Это намеренная граница, а не утверждение о точном тематическом совпадении каждой пары. Случайное слово edge в изменении размеров больше не ведёт к Canny.

Все 35 адресов списка ответили HTTP 200; сохранены конечные URL и заголовки. Доступность страницы не равна проверке каждого её утверждения.
