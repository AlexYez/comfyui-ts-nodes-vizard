# Проверка каталога на 3 октября 2026

Сверены официальный stable ComfyUI 0.38.0, закреплённый frontend 1.53.6 и TimeSaver 12.12.3. Снимок `/object_info` получен из чистой CPU-установки без custom nodes; это не проверка генерации с весами и не квалификация всех платформ.

В каталоге 771 статья: 666 локальных серверных нод ядра, четыре frontend-only, 82 действующие ноды TimeSaver, 11 архивных статей удалённой Image Studio, семь CosyVoice и справка Artius Browser. API и `dev_only` не входят в этот охват.

## Что исправлено

- Добавлены Ming Image Edit, TS LoRA Unmerged, TS Shifted Sigmas, TS Prompt Library и TS RT Prompt Enhancer.
- Обновлены выходы и системные инструкции TextGenerate/LTX, извлечение JSON из текста, диапазон воздействия ControlNet, опорный кадр Wan и новые цветовые пространства.
- Исправлены описания альфа-канала штатного апскейлера и дополнительных полей ConditioningZeroOut.
- Переписаны 19 статей TimeSaver: убраны рекламные оценки, неподтверждённые универсальные обещания и неоднозначные инструкции. TS Resolution Selector больше не описан как готовый LATENT. В Batch Source убрана гарантия памяти «в один кадр»; в Langevin Inpaint объяснены бинарная маска, собственный шаг Эйлера вместо выбранного `sampler_name` и поведение `denoise = 0`.
- Добавлены связи новых статей с соседними нодами. Подбор материалов Neurosaver учитывает тему ноды, а не случайное слово в описании: слияние мешей не ведёт к слиянию весов.
- Проверены 31 адрес проекта: HTTP 200, конечный URL и заголовок страницы сохранены в отчёте. Это проверка доступности и темы, не отдельная фактологическая экспертиза каждой внешней статьи.
- Компилятор сохраняет проверенный fingerprint статьи, даже если историческая база сборки старее. Иначе статья новой версии ошибочно получала старый hash.

## Что означает «проверено»

Все статьи проходят проверку схемы, уникальности идентификаторов, источников и ссылок между статьями. Автоматический текстовый проход ищет возможные клише; найденное оценивается в контексте. «Уникальный индекс» и техническое противопоставление не удаляются только из-за совпадения слова.

29 статей получили адресную редактуру. В остальных выполнены только узкие терминологические правки там, где их можно сделать без изменения смысла; код, URL и идентификаторы защищены. Прочтение каждой оставшейся статьи целиком не заявляется. По каждой статье сохранены hash текста, признаки изменения схемы и собственного класса, выбранный материал и необходимость дальнейшей вычитки:

- [Подробный редакционный проход](../content/research/october-2026-editorial-audit.json)
- [Исправления и закреплённые источники](../content/research/october-2026-update.json)
- [Инвентарь ядра](../content/runtime/comfyui-0.38.0.object-info.json)
- [Инвентарь TimeSaver](../content/inventory/custom/comfyui-timesaver.json)

Старые примеры и снимки не переименованы в проверки новой версии. Наличие соединений в официальном workflow не означает, что он выполнен с моделями. Для обновлённых статей текущие соединения извлечены из официального пакета templates-json 0.1.96, включая подграфы; ручной разбор этих новых случаев отмечен отдельно как незавершённый.
